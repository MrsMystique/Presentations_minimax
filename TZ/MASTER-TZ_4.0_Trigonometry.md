## A. МЕТОДОЛОГИЯ

### Главные принципы (перенос из TZ 3.0)

1. **Никакой магии.** Каждое утверждение выводится через конструкцию (круг, график, разложение, подстановка).
2. **От нуля до ЦТ за один гайд.** Любой ребёнок может пройти по ступеням.
3. **Конструкторский принцип формул.** sin/cos/tg — это не «принимаем», а «вот как они получаются из круга».
4. **Микро-проверки + кумулятивная сводка.** Каждая секция заканчивается задачами; раз в 3 секции — повторение всего пройденного.
5. **Совет Гарварда из 4 ролей** запускается автоматически на каждом раунде правок.

### Конструкторский принцип для тригонометрии

| Формула | Как получается (без магии) |
|---|---|
| \(\sin\alpha\) | Ордината точки на единичном круге |
| \(\cos\alpha\) | Абсцисса точки на единичном круге |
| \(\tan\alpha\) | Ордината / Абсцисса = наклон луча через точку (1; 0) |
| \(\sin^2 + \cos^2 = 1\) | Теорема Пифагора для точки на единичном круге |
| \(\tan = \sin / \cos\) | Определение: противолежащий / прилежащий |
| Формулы приведения | Через симметрию круга (отражение по осям) |
| \(\sin(\alpha+\beta)\) | Через поворот точки на сумму углов |
| \(\sin 2\alpha\) | Через \(\alpha + \alpha\) |
| Решение триг. уравнений | Через пересечение графика с горизонтальной прямой |
