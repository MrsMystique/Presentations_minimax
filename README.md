## 🛠 Процесс создания нового урока

1. **Изучить эталон** (например, `00_ГОТОВЫЕ_ГАЙДЫ_ЭТАЛОН/Уроки/Урок 10 Арифметический_корень.md`)
2. **Найти задачи РИКС** по теме в `РИКС_СВОДНЫЙ_ИСТОЧНИК.md`
3. **Прочитать PDF урока** в `01_ИСХОДНИКИ_ЦТ/пдф_уроки/`
4. **Написать черновик** в стиле эталона (разговорный тон, мостики, лайфхаки, реальные задачи РИКС, 100+ КБ)
5. **Проверить** по чек-листу эталона
6. **Показать Olga** на одобрение
7. **Положить в `00_ГОТОВЫЕ_ГАЙДЫ_ЭТАЛОН/Уроки/`** только после одобрения
