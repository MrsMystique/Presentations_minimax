# ЧАСТЬ 1: 28 УНИВЕРСАЛЬНЫХ ЗАКОНОВ НАПИСАНИЯ ТЕОРИИ

Применяются к ЛЮБОЙ теме и ЛЮБОМУ качеству материала. Утверждены 21.09.2026.

## Уровень 1: ЗАКОНЫ АРХИТЕКТУРЫ (как устроен материал)

### Закон 1: Контракт между блоками
Каждый блок имеет одну и ту же внутреннюю структуру: **«Почему важно → Что это → Как считать → Где применить → Где ошибиться»**. Ученик, привыкший к одной структуре в Блоке 1, автоматически ориентируется во всех следующих.

### Закон 2: Разделение ролей теории и памятки
Теория (в блоке) **учит** — содержит определение, вывод, пример по шагам, проверку здравым смыслом. Памятка (в сборнике формул) **напоминает** — содержит только формулу, переменные и дискриминатор. Если теория и памятка дублируют — ученик тратит время на повтор без пользы.

### Закон 3: Преемственность через явные ссылки
Каждый новый блок содержит **минимум одну явную отсылку к предыдущему**. Без отсылки блоки выглядят изолированными — ученик не строит карту знаний.

### Закон 4: Закон-триггер в конце блока
Каждый блок заканчивается **одной строкой-связкой**: «Закон-триггер: ...». Это короткое предложение, которое ученик уносит с собой и вспоминает на экзамене.

### Закон 5: Варьирование пауз
Мостики между блоками **не должны быть одного формата**. Чередуйте: паспорт темы → вопрос-размышление → разминочная задача → задача в стиле экзамена → анонс следующего блока.

## Уровень 2: ЗАКОНЫ ОБЪЯСНЕНИЯ (как подавать материал)

### Закон 6: Один шаг = одно действие
В любом решении **каждый шаг = одна операция**. Не «подставь и посчитай» — это два шага в одном.

### Закон 7: Абстракция привязана к конкретному
Каждая формула, термин или метод **появляется вместе с конкретным жизненным сценарием**. Без якоря абстракция не запоминается.

### Закон 8: Два языка для одной идеи
Каждая ключевая идея объясняется **дважды**: один раз через жизненный сценарий, один раз через формальную запись.

### Закон 9: Переменные объяснены явно
У каждой формулы **каждая буква** объяснена в таблице «что обозначает — пример».

### Закон 10: Область определения не зазубривается, а объясняется
Если у формулы есть ограничение — объясните, **почему именно это ограничение** возникает.

## Уровень 3: ЗАКОНЫ ПАМЯТКИ (как закрепить)

### Закон 11: Дискриминатор — обязателен
В каждой памятке есть блок **«Когда используется / Когда НЕ используется»**.

### Закон 12: Памятка умещается в один взгляд
Шпаргалка должна читаться **без скролла**: формула + таблица переменных + дискриминатор — на одном экране.

### Закон 13: Закон сброса базы (универсальный)
В любой теме, где есть **цепочка изменений** (двойная скидка, многолетний рост, смешивание растворов), **новое значение становится базой для следующего шага**.

### Закон 14: Формула + переменные + дискриминатор = памятка
Структура любой памятки: **(1) формула, (2) таблица переменных с примером, (3) дискриминатор применимости**. Три блока, не больше.

## Уровень 4: ЗАКОНЫ САМОПРОВЕРКИ (как научить ученика проверять себя)

### Закон 15: Скрипт проверки ДО записи ответа
Скрипт проверки черновика ставится **перед записью финального ответа**, не после.

### Закон 16: Два теста, не один
Любой скрипт проверки содержит **два независимых теста**: один по сути, другой по форме.

### Закон 17: Свёрнутые ответы
Микро-тесты и скрипты самопроверки имеют **свёрнутые ответы** («> Свернись с ответом: ...»).

### Закон 18: Микро-контроль каждые 5-10 минут
После каждого блока — **точка микро-контроля** (2 задачи на 2 минуты).

## Уровень 5: ЗАКОНЫ КОГНИТИВНОЙ НАГРУЗКИ (как не перегрузить)

### Закон 19: Chunking сложных слайдов
Если на одном слайде больше **3 концепций** — раздели на под-слайды.

### Закон 20: Метод «рисуй» как универсальный анти-ступор
В любой ситуации «не понимаю условие» ученику даётся **инструкция нарисовать**: целое как фигуру, часть как заштрихованный кусок, известные числа подписать.

### Закон 21: Распознавание ДО формулы
Перед формулами ученик должен научиться **распознавать тип задачи по формулировке**.

### Закон 22: Фразы-подсказки и слова-подсказки
Ученик запоминает **3-5 триггерных слов/фраз**, которые мгновенно подсказывают тип задачи.

## Уровень 6: ЗАКОНЫ МОТИВАЦИИ (как не потерять ученика)

### Закон 23: Смягчение негативной обратной связи
Результат «0 из 5» не должен звучать как приговор. Переформулируйте: «это нормально, вернись к Блокам 1–3, попробуй через 2–3 дня».

### Закон 24: Конкретный выигрыш, не абстрактный
Мотивация привязана к **конкретному жизненному выигрышу** («6–8 баллов из 100 на ЦТ»).

### Закон 25: Эмоциональная безопасность тона
Обращение **на «ты»**, без заносчивости, без насмешек, мягкие формулировки ошибок.

## Уровень 7: ЗАКОНЫ РАЗРЕШЕНИЯ ПРОТИВОРЕЧИЙ

### Закон 26: Унифицируй правила между блоками
Если одно и то же понятие трактуется по-разному — **явно укажи правило** в одном месте и проставь ссылки в остальных.

### Закон 27: Исключения объясняются явно
Если правило имеет исключение — **исключение выносится в отдельный абзац** с явной пометкой.

### Закон 28: Устаревший материал синхронизируется с актуальным
Если памятка ссылается на «Слайды 16–21» — **ссылка проверяется при каждом обновлении**.

# ЧАСТЬ 2: МИНИМАЛЬНЫЙ НАБОР ЗАКОНОВ

Для любого материала (даже если есть только тезисы):

1. **Закон 1** — контракт блока
2. **Закон 2** — памятка ≠ теория
3. **Закон 14** — формула + переменные + дискриминатор
4. **Закон 18** — микро-контроль каждые 5-10 минут
5. **Закон 23** — мягкая обратная связь
