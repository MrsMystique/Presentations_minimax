# Урок 39. Числовые последовательности. Арифметическая прогрессия

## Перед тем как начать

Привет. Этот урок — про числовые последовательности и арифметическую прогрессию. Последовательность — это «функция от натурального числа»: каждому n соответствует aₙ. Арифметическая прогрессия — самая простая последовательность: каждый следующий член отличается от предыдущего на одно и то же число.

---

## Блок 1. Числовая последовательность

### Что это такое

**Определение.** Числовая последовательность — это функция, определённая на множестве натуральных чисел. Каждому n ∈ N соответствует единственное действительное число aₙ.

### Виды

- Конечные: 10, 11, ..., 99.
- Бесконечные: 1, 3, 5, 7, ...

### Способы задания

1) **Словесный:** «последовательность чётных чисел».
2) **Формулой общего члена:** aₙ = 2n + 1.
3) **Рекуррентно:** a₁ = 1, aₙ₊₁ = aₙ + 2.

---

## Блок 2. Арифметическая прогрессия

### Что это такое

**Определение.** Арифметическая прогрессия — это последовательность, в которой каждый следующий член отличается от предыдущего на одно и то же число d (разность прогрессии).

### Пример

2, 5, 8, 11, ... — d = 3.
10, 7, 4, 1, -2, ... — d = -3.

### Формула n-го члена

aₙ = a₁ + d · (n - 1).

### Свойство

aₙ = (aₙ₋₁ + aₙ₊₁) / 2 (каждый член — среднее арифметическое соседей).

---

## Блок 3. Формулы суммы

### Сумма n первых членов

Sₙ = n · (a₁ + aₙ) / 2.
Или: Sₙ = n · (2a₁ + d(n - 1)) / 2.

### Задача с разбором

**Задача.** a₁ = 5, d = 3. Найди a₁₀ и S₁₀.

Решение:
- a₁₀ = 5 + 3 · 9 = 32.
- S₁₀ = 10 · (5 + 32) / 2 = 10 · 37 / 2 = 185.

**Ответ: a₁₀ = 32, S₁₀ = 185.**

### Реши сам

**Задача 1.** a₁ = 3, d = 4. Найди a₈.

<details>
<summary>Ответ</summary>

a₈ = 3 + 4 · 7 = 31.
</details>

**Задача 2.** Найди S₂₀, если a₁ = -10, d = 2.

<details>
<summary>Ответ</summary>

a₂₀ = -10 + 2 · 19 = 28. S₂₀ = 20 · (-10 + 28) / 2 = 180.
</details>

---

## Блок 5. Характеристическое свойство

**aₙ = (aₙ₋₁ + aₙ₊₁) / 2.**

Это значит, что в арифметической прогрессии каждый член равен среднему арифметическому соседних.

## Мини-тест

**Задача 1.** Является ли 1, 4, 7, 10, ... арифметической прогрессией?
<details>
<summary>Ответ</summary>

Да, d = 3.
</details>

**Задача 2.** a₁ = 2, d = 5. aₙ = 47. Найди n.
<details>
<summary>Ответ</summary>

2 + 5(n-1) = 47 → 5n - 5 = 45 → n = 10.
</details>

**Задача 3.** Сумма первых 10 членов 100, a₁ = 1. Найди d.
<details>
<summary>Ответ</summary>

S₁₀ = 10 · (1 + a₁₀) / 2 = 100 → 1 + a₁₀ = 20 → a₁₀ = 19. 1 + 9d = 19 → d = 2.
</details>

**Задача 4.** В арифметической прогрессии a₃ = 10, a₇ = 22. Найди d.
<details>
<summary>Ответ</summary>

a₇ - a₃ = 4d → 12 = 4d → d = 3.
</details>

## Босс-файт

### Задача 1. Сумма трёх чисел, образующих арифметическую прогрессию, равна 12. Среднее из них равно 4. Найди числа.

**Решение:** числа a-d, a, a+d. Сумма: 3a = 12 → a = 4. Числа: 4 - d, 4, 4 + d. Но a = 4, значит, d = 0. Числа 4, 4, 4.

### Задача 2. a₁ + a₅ = 14, a₂ · a₄ = 45. Найди прогрессию.

**Решение:** a₃ = 7 (среднее). a₂ · a₄ = (7 - d)(7 + d) = 49 - d² = 45 → d² = 4 → d = ±2. Прогрессия: 5, 6, 7, 8, 9 или 9, 8, 7, 6, 5.

### Задача 3. Найди a₁, если S₅ = 25, a₃ = 5.

**Решение:** a₃ = a₁ + 2d = 5. S₅ = 5 · (2a₁ + 4d)/2 = 25 → 2a₁ + 4d = 10. → a₁ + 2d = 5. Уравнения: a₁ + 2d = 5, a₁ + 2d = 5. Тождество. Бесконечно много прогрессий.

### Задача 4. Между числами 3 и 27 вставь 5 чисел так, чтобы получилась арифметическая прогрессия.

**Решение:** всего 7 чисел. a₁ = 3, a₇ = 27. a₇ = a₁ + 6d → 27 = 3 + 6d → d = 4. Числа: 3, 7, 11, 15, 19, 23, 27.
