## Блок 1. Что такое иррациональное уравнение

### Зачем тебе это знать

Иррациональные уравнения — это способ описать «переменная под корнем». Без них ты не решишь ни одной задачи на физические формулы (где время, например, выражается через √(2h/g)), ни одной геометрической задачи.

### Что это такое

**Определение.** Иррациональными уравнениями называются уравнения, в которых переменная содержится под знаком корня или под знаком возведения в дробную степень.

### Основные методы решения

1) **Возведение обеих частей в одну и ту же степень** (основной метод).
2) **Введение новых переменных.**
3) **Разложение на множители.**
4) **Умножение на сопряжённое выражение** (когда есть сумма/разность корней).
5) **Сведение к уравнению с модулем.**
6) **Функциональный метод** (на отдельном занятии).

### Откуда название

«Иррациональное» — потому что корень — это «иррациональная» операция. В отличие от +, -, ·, :, возведения в целую степень.

### Где применить

В задачах: «при каких x √(x + 1) = 3?»
В физике: t = √(2h/g) — время падения тела.
В геометрии: расстояние между точками.

### Где ошибиться

**Ловушка «при возведении в квадрат всегда можно получить посторонний корень».** Да, поэтому ОБЯЗАТЕЛЬНО проверять.

**Ловушка «ОДЗ — это всё, что нужно проверить».** Нет. Возведение в чётную степень может добавить корни, которые не удовлетворяют исходному уравнению. Поэтому проверка по исходному уравнению обязательна.

### Задача с разбором

**Задача.** Реши √(x + 1) = 3.

Решение:
- ОДЗ: x + 1 ≥ 0 → x ≥ -1.
- Возведём в квадрат: x + 1 = 9 → x = 8.
- Проверка: √(8 + 1) = √9 = 3 ✓. Подходит.

**Ответ: x = 8.**

## Блок 2. Возведение обеих частей в одну и ту же степень

### Зачем тебе это знать

Это основной метод решения иррациональных уравнений. Возведение в чётную степень может дать посторонние корни, поэтому нужна проверка.

### Алгоритм

1) Найти ОДЗ.
2) Если в уравнении несколько радикалов, уединить один (оставить на одной стороне).
3) Возвести обе части в нужную степень (чтобы избавиться от радикалов).
4) Решить полученное уравнение.
5) Проверить каждый корень по ОДЗ и по исходному уравнению.
6) Записать ответ.

### Как уединять радикал

**Пример:** √(x + 1) + √(x - 3) = 4.
Шаг 1: √(x + 1) = 4 - √(x - 3).
Шаг 2: Возведём в квадрат: x + 1 = 16 - 8√(x - 3) + x - 3.
Шаг 3: Упростим: 8 = -8√(x - 3) → √(x - 3) = -1. Нет решений (корень неотрицателен).

### Где применить

В задачах с одним или несколькими радикалами.

### Где ошибиться

**Ловушка «если ОДЗ не нарушена, корень точно подходит».** Нет. Возведение в чётную степень может дать корень, который не удовлетворяет исходному уравнению. Например, √x = -2 — после возведения в квадрат даёт x = 4, но исходному не удовлетворяет.

**Ловушка «уединять радикал необязательно».** Можно не уединять, но уединить удобнее (меньше возведений в квадрат).

### Задача с разбором

**Задача.** Реши √(2x + 1) = x - 1.

Решение:
- ОДЗ: 2x + 1 ≥ 0 → x ≥ -0,5.
- Возведём в квадрат: 2x + 1 = (x - 1)² = x² - 2x + 1.
- 2x + 1 = x² - 2x + 1 → x² - 4x = 0 → x(x - 4) = 0 → x = 0 или x = 4.
- Проверка:
  - x = 0: √1 = 1. 0 - 1 = -1. 1 ≠ -1. Не подходит.
  - x = 4: √9 = 3. 4 - 1 = 3. 3 = 3 ✓. Подходит.

**Ответ: x = 4.**

### Реши сам

**Задача 1.** Реши √(3x - 2) = x.

<details>
<summary>Ответ</summary>

3x - 2 = x² → x² - 3x + 2 = 0 → x = 1 или x = 2. Проверка: x = 1: √1 = 1 ✓. x = 2: √4 = 2 ✓. Оба подходят.
</details>

**Задача 2.** Реши √(x + 1) = x - 3.

<details>
<summary>Ответ</summary>

x + 1 = x² - 6x + 9 → x² - 7x + 8 = 0 → x = (7 ± √17)/2.
Проверка: при x = (7 + √17)/2 ≈ 5,56: √6,56 ≈ 2,56; 5,56 - 3 = 2,56 ✓.
При x = (7 - √17)/2 ≈ 1,44: √2,44 ≈ 1,56; 1,44 - 3 = -1,56. 1,56 ≠ -1,56. Не подходит.
</details>

**Задача 3.** Реши √(x + 3) + √(2x + 1) = 4.

> Подсказка: уедини √(x + 3), потом возведи в квадрат.

<details>
<summary>Ответ</summary>

√(x + 3) = 4 - √(2x + 1). x + 3 = 16 - 8√(2x + 1) + 2x + 1. 8√(2x + 1) = 14 - x. Возведём в квадрат: 64(2x + 1) = (14 - x)². 128x + 64 = 196 - 28x + x². x² - 156x + 132 = 0. x = (156 ± √(24336 - 528))/2 = (156 ± √23808)/2. √23808 ≈ 154,3. x ≈ 155 или x ≈ 1. Проверка по ОДЗ и исходному уравнению нужна.
</details>

## Блок 3. Введение новых переменных и другие методы

### Зачем тебе это знать

Возведение в квадрат работает не всегда. Иногда проще сделать подстановку t = √(...).

### Метод 1: подстановка

Если в уравнении повторяется один и тот же радикал, замени его на t.

**Пример:** √(x + 5) - 3√(x + 5) + 2 = 0.
Пусть t = √(x + 5). Тогда t² - 3t + 2 = 0. t = 1 или t = 2.
Возврат: √(x + 5) = 1 → x + 5 = 1 → x = -4.
√(x + 5) = 2 → x + 5 = 4 → x = -1.

### Метод 2: сопряжённое выражение

Если в уравнении есть сумма корней вида √a + √b, умножь на сопряжённое √a - √b, чтобы получить разность квадратов.

### Метод 3: разложение на множители

Если удалось привести к виду f(x) · g(x) = 0, где f и g — множители.

### Где применить

В задачах с повторяющимися радикалами.
В задачах с суммой/разностью корней.

### Где ошибиться

**Ловушка «после замены нужно вернуться к x».** Да, обязательно.

### Задача с разбором

**Задача.** Реши x + √x - 6 = 0.

Решение: пусть t = √x. Тогда t² + t - 6 = 0. t₁ = 2, t₂ = -3.
t₂ < 0 не подходит (√x ≥ 0). t₁ = 2 → √x = 2 → x = 4.

**Ответ: 4.**

### Реши сам

**Задача 1.** Реши x - 5√x + 6 = 0.

<details>
<summary>Ответ</summary>

t = √x. t² - 5t + 6 = 0. t = 2 или t = 3. x = 4 или x = 9.
</details>

**Задача 2.** Реши (√x - 3)(x - 4) = 0.

<details>
<summary>Ответ</summary>

√x = 3 → x = 9. x = 4. Проверка ОДЗ: x ≥ 0. Оба подходят.
</details>

## Босс-файт

### Задача 1. Реши √(x + 1) = x - 1

**Решение:** x + 1 = (x - 1)² = x² - 2x + 1. x² - 3x = 0. x(x - 3) = 0. x = 0 или x = 3.
Проверка: x = 0: √1 = 1, 0 - 1 = -1. 1 ≠ -1. Не подходит.
x = 3: √4 = 2, 3 - 1 = 2 ✓. Подходит.

**Ответ: 3.**

### Задача 2. Реши x - 7√x + 10 = 0

**Решение:** t = √x. t² - 7t + 10 = 0. t = 2 или t = 5. x = 4 или x = 25.

**Ответ: 4; 25.**

### Задача 3. Реши √(2x + 3) + √(x - 1) = 4

**Решение:** уединим: √(2x + 3) = 4 - √(x - 1). Возведём в квадрат: 2x + 3 = 16 - 8√(x - 1) + x - 1. 8√(x - 1) = 12 - x.
64(x - 1) = (12 - x)². 64x - 64 = 144 - 24x + x². x² - 88x + 208 = 0. x = (88 ± √(7744 - 832))/2 = (88 ± √6912)/2 = (88 ± 24√12)/2 = 44 ± 12√12.
Проверка нужна.

**Ответ: проверь самостоятельно.**

### Задача 4. Реши √(x² - 1) = x - 3

**Решение:** ОДЗ: x² - 1 ≥ 0 → |x| ≥ 1. x² - 1 = x² - 6x + 9. -1 = -6x + 9. 6x = 10. x = 5/3.
Проверка: √(25/9 - 1) = √(16/9) = 4/3. 5/3 - 3 = -4/3. 4/3 ≠ -4/3. Не подходит.

**Ответ: нет решений.**
