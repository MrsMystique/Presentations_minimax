## Блок 1. Простое применение свойств корней

### Зачем тебе это знать

Потому что 80% «иррациональных» выражений — это просто вложенные свойства корня, вынесенные множители и т.п. Если видишь в задаче корни — проверь, нельзя ли просто применить свойство.

### Что это такое

«Простое применение» — это использование 4 свойств корня:
- √(a · b) = √a · √b.
- √(a / b) = √a / √b.
- (√a)² = a.
- √(a²) = |a|.

Без дополнительных приёмов — только свойства.

### Как пользоваться

Алгоритм:
1. Определи, какие корни перед тобой — квадратные, кубические, etc.
2. Попробуй разложить подкоренное выражение на удобные множители.
3. Примени свойства.

Примеры:
- √(18 · 50) = √18 · √50 = 3√2 · 5√2 = 30.
- √(75) = √(25 · 3) = 5√3.
- ⁵√(32 · a⁵) = ⁵√32 · ⁵√a⁵ = 2 · a = 2a.

### Где применить

В любой задаче с корнями. Часто это первый шаг перед более сложным приёмом.

### Где ошибиться

**Ловушка «√(a + b) = √a + √b».** Никогда не работает.
**Ловушка «√(x²) = x».** Только |x|. Если x < 0, ответ — -x.

### Задача с разбором

**Задача.** Вычисли √(18 · 50).

**Разбор:**
1. √(18 · 50) = √18 · √50.
2. √18 = √(9 · 2) = 3√2.
3. √50 = √(25 · 2) = 5√2.
4. 3√2 · 5√2 = 15 · 2 = 30.

**Ответ: 30.**

### Реши сам

**Задача 1.** Вычисли √(12 · 75).

<details>
<summary>Подсказка</summary>

12 = 4 · 3, 75 = 25 · 3.
</details>

<details>
<summary>Разбор</summary>

√(12 · 75) = √(4 · 3 · 25 · 3) = √(100 · 9) = 10 · 3 = 30. **Ответ: 30.**
</details>

**Задача 2.** Упрости ∛(54x³).

<details>
<summary>Подсказка</summary>

54 = 27 · 2.
</details>

<details>
<summary>Разбор</summary>

∛(54x³) = ∛27 · ∛2 · ∛x³ = 3 · ∛2 · x = 3x∛2. **Ответ: 3x∛2.**
</details>

**Задача 3.** Вычисли ⁵√(32 · a⁵).

<details>
<summary>Подсказка</summary>

⁵√32 = 2, ⁵√a⁵ = a.
</details>

<details>
<summary>Разбор</summary>

⁵√(32 · a⁵) = ⁵√32 · ⁵√a⁵ = 2 · a = 2a. **Ответ: 2a.**
</details>

## Блок 2. Формулы сокращённого умножения (ФСУ) с корнями

### Зачем тебе это знать

Потому что под корнем часто стоит выражение, которое можно свернуть или развернуть через ФСУ. Это позволяет извлечь корень или упростить выражение.

### Что это такое

Три формулы, которые работают с корнями:
1. (√a + √b)(√a - √b) = a - b — разность квадратов.
2. (√a)² + 2 · √a · √b + (√b)² = (√a + √b)² — квадрат суммы.
3. (√a)² - 2 · √a · √b + (√b)² = (√a - √b)² — квадрат разности.

### Как пользоваться

**Приём 1.** Произведение сопряжённых.
(√3 + 2)(√3 - 2) = (√3)² - 2² = 3 - 4 = -1.

**Приём 2.** Свернуть квадрат суммы или разности.
(√5 - √3)² = 5 - 2√15 + 3 = 8 - 2√15.

**Приём 3.** Развернуть квадрат суммы или разности.
7 - 2√12 = 7 - 2·√(4·3) = 7 - 2·2√3 = 7 - 4√3 = (√3)² - 2·√3·2 + 2² = (√3 - 2)².

### Где применить

При упрощении иррациональных выражений.
При выделении полного квадрата (Блок 4).
При избавлении от иррациональности в знаменателе.

### Где ошибиться

**Ловушка «(√a + √b)² = a + b».** Нет, = a + 2√(ab) + b.
**Ловушка «свернуть любую разность через разность квадратов».** Это работает только если разность — это (√a)² - (√b)². Например, a - b = (√a - √b)(√a + √b) при a, b ≥ 0.

### Задача с разбором

**Задача.** Сверни (√5 - √3)².

**Разбор:**
1. (√5 - √3)² = (√5)² - 2·√5·√3 + (√3)² = 5 - 2√15 + 3 = 8 - 2√15.

**Ответ: 8 - 2√15.**

### Реши сам

**Задача 1.** Вычисли (√3 + √7)(√3 - √7).

<details>
<summary>Подсказка</summary>

Разность квадратов: (a+b)(a-b) = a² - b².
</details>

<details>
<summary>Разбор</summary>

(√3 + √7)(√3 - √7) = 3 - 7 = -4. **Ответ: -4.**
</details>

**Задача 2.** Сверни (√a + 2)².

<details>
<summary>Подсказка</summary>

(√a + 2)² = a + 4√a + 4.
</details>

<details>
<summary>Разбор</summary>

(√a + 2)² = (√a)² + 2 · √a · 2 + 2² = a + 4√a + 4. **Ответ: a + 4√a + 4.**
</details>

**Задача 3.** Вычисли (√3 - √2)².

<details>
<summary>Подсказка</summary>

(√3 - √2)² = 3 - 2√6 + 2.
</details>

<details>
<summary>Разбор</summary>

(√3 - √2)² = 3 - 2√6 + 2 = 5 - 2√6. **Ответ: 5 - 2√6.**

## Блок 3. Избавление от иррациональности в знаменателе

### Зачем тебе это знать

Потому что в задачах ЦТ принято писать ответ без корня в знаменателе. Это соглашение, и за нарушение снимают баллы. Кроме того, с «чистым» знаменателем проще сравнивать дроби и работать с ними.

### Что это такое

Если в знаменателе стоит иррациональное выражение (корень или выражение с корнем), от него избавляются умножением на подходящее «сопряжённое».

### Способы

**Способ 1. Для простого корня.**
1/√a = √a / a (умножаем на √a).

**Способ 2. Для суммы с корнем.**
1 / (√a + √b) = (√a - √b) / (a - b) (умножаем на √a - √b).

**Способ 3. Для разности с корнем.**
1 / (√a - √b) = (√a + √b) / (a - b) (умножаем на √a + √b).

### Откуда

Умножением на 1. Умножая числитель и знаменатель на одно и то же выражение, мы не меняем значение дроби. А «сопряжённое» подбирают так, чтобы в знаменателе получился иррациональности-free результат.

### Как пользоваться

**Случай 1.** Знаменатель — просто корень. Умножаем на сам этот корень.

**Случай 2.** Знаменатель — сумма или разность корней. Умножаем на сопряжённое.

### Где применить

В упрощении: 3/√5 = 3√5/5.
В сравнении: 1/(√2 + √1) = √2 - 1 ≈ 0,41.

### Где ошибиться

**Ловушка «умножил только числитель».** Иначе ты меняешь значение дроби.
**Ловушка «сопряжённое к √a + √b — это -√a - √b».** Сопряжённое — это противоположный знак при одном из корней: √a + √b ↔ √a - √b (или -√a + √b, что то же самое).

### Задача с разбором

**Задача.** Освободись от иррациональности: 3/(√5 - 2).

**Разбор:**
1. Умножаем на сопряжённое (√5 + 2).
2. 3(√5 + 2) / ((√5 - 2)(√5 + 2)) = 3(√5 + 2) / (5 - 4) = 3(√5 + 2) / 1 = 3(√5 + 2).

**Ответ: 3(√5 + 2) = 3√5 + 6.**

### Реши сам

**Задача 1.** Освободись от иррациональности: 1/(√2 + 1).

<details>
<summary>Подсказка</summary>

Сопряжённое к √2 + 1 — это √2 - 1.
</details>

<details>
<summary>Разбор</summary>

1/(√2 + 1) = (√2 - 1) / ((√2)² - 1²) = (√2 - 1) / 1 = √2 - 1. **Ответ: √2 - 1.**
</details>

**Задача 2.** Освободись от иррациональности: 4/(√3 + √2).

<details>

</details>

<details>
<summary>Разбор</summary>

4/(√3 + √2) = 4(√3 - √2) / (3 - 2) = 4(√3 - √2). **Ответ: 4(√3 - √2).**
</details>

**Задача 3.** Освободись от иррациональности: 1/√7.

<details>
<summary>Подсказка</summary>

</details>

## Блок 4. Выделение полного квадрата под корнем

### Зачем тебе это знать

Потому что часто под корнем стоит выражение вида a ± 2√b, и его можно свернуть в (√m ± √n)². Это позволяет извлечь «полный» корень из суммы/разности.

### Что это такое

Если выражение можно представить как (√m ± √n)² = m + n ± 2√(mn), то √((√m ± √n)²) = |√m ± √n|.

### Как выделять полный квадрат

**Алгоритм:**
1. Запиши подкоренное выражение как x ± 2√y.
2. Подбери m и n такие, что m · n = y и m + n = x.
3. Тогда x ± 2√y = (√m ± √n)².

Пример: √(7 ± 2√5). Подбираем m, n: m + n = 7, m · n = 5. Это m = 5, n = 2. Тогда √(7 ± 2√5) = √((√5 ± √2)²) = √5 ± √2.

### Где применить

В задачах на упрощение: √(7 + 2√10) = √5 + √2.
В задачах на сравнение.
При доказательстве неравенств.

### Где ошибиться

**Ловушка «полный квадрат под корнем всегда есть».** Не всегда! √(7 + 2√5) есть (это √5 + √2), но √(5 + 2√7) уже не является рациональным числом — нет таких m, n, чтобы m · n = 7 и m + n = 5 одновременно.

### Задача с разбором

**Задача.** Вычисли √(7 - 2√10).

**Разбор:**
1. Подбираем m, n: m · n = 10, m + n = 7. Это m = 5, n = 2.
2. 7 - 2√10 = (√5)² - 2·√5·√2 + (√2)² = (√5 - √2)².
3. √(7 - 2√10) = |√5 - √2| = √5 - √2 (потому что √5 > √2).

**Ответ: √5 - √2.**

### Реши сам

**Задача 1.** Вычисли √(7 + 2√10).

<details>
<summary>Подсказка</summary>

Подбери m и n: mn = 10, m + n = 7. Это 5 и 2.
</details>

<details>
<summary>Разбор</summary>

√(7 + 2√10) = √((√5 + √2)²) = √5 + √2. **Ответ: √5 + √2.**
</details>

**Задача 2.** Вычисли √(8 + 2√15).

<details>

</details>

## Блок 5. Комбинированные приёмы (формула сложного радикала)

### Зачем тебе это знать

В задачах ЦТ часто встречаются выражения вида √(a + √b) — корень из корня. Это сложный радикал, и для него есть специальный приём.

### Что это такое

Сложный радикал √(a + √b) (при a > 0, b > 0) можно упростить через формулу:

√(a + √b) = √((a + √(a² - b)) / 2) + √((a - √(a² - b)) / 2), если a² - b ≥ 0.

Это выглядит сложно, но запомни алгоритм.

### Как упрощать

**Алгоритм:**
1. Запиши √(a + √b) как сумму √x + √y.
2. Возведи в квадрат: x + y + 2√(xy) = a + √b.
3. Получаем систему: x + y = a, 2√(xy) = √b, откуда 4xy = b.
4. Решаем систему: x и y — корни квадратного уравнения t² - at + b/4 = 0.
5. Дискриминант: a² - b.

### Где применить

В задачах на упрощение: √(6 + 2√5) = √5 + 1 (потому что mn = 5, m + n = 6 → m = 5, n = 1).

### Где ошибиться

**Ловушка «формула всегда работает».** Только если a² - b ≥ 0, иначе радикал не сворачивается.

### Задача с разбором

**Задача.** Вычисли √(6 + 2√5).

**Разбор:**
1. Запишем √(6 + 2√5) = √x + √y.
2. x + y = 6, 2√(xy) = 2√5 → xy = 5.
3. Решаем t² - 6t + 5 = 0: t = (6 ± √(36 - 20))/2 = (6 ± 4)/2. Корни: t = 5 и t = 1.
4. x = 5, y = 1 (или наоборот).
5. √(6 + 2√5) = √5 + √1 = √5 + 1.

**Ответ: √5 + 1.**

## Босс-файт: задачи на упрощение иррациональных выражений

### Задача 1. Упрости √(50) - √(18) + √(8)

**Шаг 1.** Выносим множители:
- √50 = √(25 · 2) = 5√2.
- √18 = √(9 · 2) = 3√2.
- √8 = √(4 · 2) = 2√2.

**Шаг 2.** Подставляем: 5√2 - 3√2 + 2√2 = (5 - 3 + 2)√2 = 4√2.

**Ответ: 4√2.**

### Задача 2. Вычисли (√7 + √3)(√7 - √3)

**Шаг 1.** Разность квадратов: (√7 + √3)(√7 - √3) = (√7)² - (√3)² = 7 - 3 = 4.

**Ответ: 4.**

### Задача 3. Вычисли (√3 - 2)² + (√3 + 2)²

**Шаг 1.** Раскрываем:
- (√3 - 2)² = 3 - 4√3 + 4 = 7 - 4√3.
- (√3 + 2)² = 3 + 4√3 + 4 = 7 + 4√3.

**Шаг 2.** Складываем: (7 - 4√3) + (7 + 4√3) = 14.

### Задача 4. Вычисли (√(11 + 2√30))

## Сборник формул

### 4 свойства корня

- √(a · b) = √a · √b при a, b ≥ 0.
- √(a / b) = √a / √b при a ≥ 0, b > 0.
- (√a)² = a при a ≥ 0.
- √(a²) = |a|.

### Формулы сокращённого умножения

- (√a + √b)(√a - √b) = a - b.
- (√a + √b)² = a + 2√(ab) + b.
- (√a - √b)² = a - 2√(ab) + b.

### Выделение полного квадрата

√(m + n ± 2√(mn)) = √m ± √n.

### Сложный радикал

√(a + √b) = √((a + √(a² - b))/2) + √((a - √(a² - b))/2) (при a² ≥ b > 0).

### Условия применимости

- a, b ≥ 0 — для извлечения квадратного корня.
- m + n = a, m · n = b — для выделения полного квадрата.
- a² ≥ b — для сложного радикала.
