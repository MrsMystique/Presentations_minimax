## Блок 1. Арифметическая прогрессия

### Характеристическое свойство

aₙ = (aₙ₋₁ + aₙ₊₁) / 2, или 2aₙ = aₙ₋₁ + aₙ₊₁.

### Задача с разбором

**Задача.** При каком a числа 3a - 4, 12 - a, 31 - 8a составляют арифметическую прогрессию?

Решение:
- 2(12 - a) = (3a - 4) + (31 - 8a).
- 24 - 2a = 3a - 4 + 31 - 8a = 5a + 27.
- 24 - 27 = 5a + 2a → -3 = 7a → a = -3/7.

Hmm, ответ в учебнике 1. Перепроверим.

В учебнике ответ 1, давай проверим: при a = 1: 3 - 4 = -1, 12 - 1 = 11, 31 - 8 = 23. Разности: 11 - (-1) = 12, 23 - 11 = 12. Равны! Значит, a = 1.

Где ошибка? А: 2·(12 - a) = (3a - 4) + (31 - 8a). 24 - 2a = 5a + 27. -3 = 7a. a = -3/7. Неверно. Тогда не 2(12 - a)... a посередине, значит:

2·(среднее) = первое + третье. 2·(12 - a) = (3a - 4) + (31 - 8a). 24 - 2a = 3a - 4 + 31 - 8a = -5a + 27. -2a + 5a = 27 - 24 → 3a = 3 → a = 1. ✓

Я ошибся в вычислении правого канала. Правильно: 3a - 4 + 31 - 8a = -5a + 27.

**Ответ: 1.**

## Блок 2. Геометрическая прогрессия

### Характеристическое свойство

bₙ² = bₙ₋₁ · bₙ₊₁.

### Задача с разбором

**Задача.** При каком a числа a - 4, a, 2a + 6 составляют геометрическую прогрессию с отрицательными членами?

Решение:
- a² = (a - 4)(2a + 6) = 2a² + 6a - 8a - 24 = 2a² - 2a - 24.
- a² - 2a² + 2a + 24 = 0 → -a² + 2a + 24 = 0 → a² - 2a - 24 = 0.
- D = 4 + 96 = 100. a = (2 ± 10)/2. a = 6 или a = -4.
- При a = -4: a - 4 = -8, a = -4, 2a + 6 = -2. Все отрицательные. q = (-4)/(-8) = 1/2.
- При a = 6: a - 4 = 2, a = 6, 2a + 6 = 18. Все положительные.

**Ответ: a = -4.**

## Блок 3. Прогрессии в уравнениях

### Задача с разбором

**Задача.** Реши (x² + 1) + (2x² + 3) + (3x² + 5) + ... + (10x² + 19) = 3950.

Решение:
- Сумма x²: (1 + 2 + 3 + ... + 10)x² = 55x².
- Сумма свободных членов: 1 + 3 + 5 + ... + 19 (10 членов арифметической прогрессии с d = 2). S = 10 · (1 + 19)/2 = 100.
- 55x² + 100 = 3950 → 55x² = 3850 → x² = 70 → x = ±√70.

**Ответ: ±√70.**

## Босс-файт

### Задача 1. Сумма первых n членов арифметической прогрессии S_n = 3n² + 5n. Найди a₁ и d.

**Решение:** S₁ = a₁ = 3 + 5 = 8. S₂ = a₁ + a₂ = 12 + 10 = 22 → a₂ = 14. d = a₂ - a₁ = 6.

### Задача 2. b₁ = 2, b₃ = 8. Найди b₅.

**Решение:** b₃ = b₁ · q² → 8 = 2q² → q² = 4 → q = ±2. b₅ = b₃ · q² = 8 · 4 = 32.

### Задача 3. При каком a числа a, 2a + 1, 5a - 4 — геометрическая прогрессия?

**Решение:** (2a + 1)² = a(5a - 4). 4a² + 4a + 1 = 5a² - 4a → a² - 8a - 1 = 0. a = (8 ± √68)/2 = 4 ± √17.

### Задача 4. В арифметической прогрессии a₅ = 12, a₁₀ = 22. Найди S₁₀.

**Решение:** 5d = a₁₀ - a₅ = 10 → d = 2. a₁ = a₅ - 4d = 4. S₁₀ = 10(4 + 22)/2 = 130.
