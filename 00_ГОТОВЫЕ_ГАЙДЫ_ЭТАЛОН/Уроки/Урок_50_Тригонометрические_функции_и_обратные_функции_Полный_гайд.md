# Урок 50. Тригонометрические функции и обратные тригонометрические функции

## Перед тем как начать

Привет. Этот урок — про тригонометрические функции y = sin x, y = cos x, y = tan x, y = cot x, и обратные к ним: arcsin, arccos, arctan, arccot.

---

## Блок 1. Свойства тригонометрических функций

### y = sin x

- **D(y) = R.**
- **E(y) = [-1; 1].**
- Нечётная.
- Период 2π.
- Возрастает на [-π/2 + 2πk; π/2 + 2πk], убывает на [π/2 + 2πk; 3π/2 + 2πk].

### y = cos x

- **D(y) = R.**
- **E(y) = [-1; 1].**
- Чётная.
- Период 2π.
- Убывает на [2πk; π + 2πk], возрастает на [π + 2πk; 2π + 2πk].

### y = tan x

- **D(y) = (-π/2 + πk; π/2 + πk).**
- **E(y) = R.**
- Нечётная.
- Период π.

### y = cot x

- **D(y) = (πk; π + πk).**
- **E(y) = R.**
- Нечётная.
- Период π.

## Блок 2. Обратные тригонометрические функции

### Арксинус

**Определение.** arcsin a — это угол из [-π/2; π/2], синус которого равен a.
**D(y) = [-1; 1].**
**E(y) = [-π/2; π/2].**

### Арккосинус

**Определение.** arccos a — это угол из [0; π], косинус которого равен a.
**D(y) = [-1; 1].**
**E(y) = [0; π].**

### Арктангенс

**Определение.** arctan a — это угол из (-π/2; π/2), тангенс которого равен a.
**D(y) = R.**
**E(y) = (-π/2; π/2).**

### Арккотангенс

**Определение.** arcctg a — это угол из (0; π), котангенс которого равен a.
**D(y) = R.**
**E(y) = (0; π).**

## Босс-файт

### Задача 1. Вычисли arcsin(-1/2).

**Решение:** угол из [-π/2; π/2], синус которого -1/2, это -π/6.

### Задача 2. Вычисли arccos(-1/2).

**Решение:** угол из [0; π], косинус которого -1/2, это 2π/3.

### Задача 3. Вычисли cos(arcsin 3/5).

**Решение:** угол из [-π/2; π/2], синус 3/5, косинус = √(1 - 9/25) = 4/5.

### Задача 4. Вычисли sin(arccos 5/13).

**Решение:** угол из [0; π], косинус 5/13, синус = √(1 - 25/169) = 12/13.
