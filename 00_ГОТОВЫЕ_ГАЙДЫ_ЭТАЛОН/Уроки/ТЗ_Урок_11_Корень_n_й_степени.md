## Часть 3. Что не тронули (заморозка)

- Определение степени с целым показателем (Урок 8) — только ссылка.
- Квадратный корень как частный случай (Урок 10) — не переучивается, а обобщается.
- Рационализация через сопряжение — **не входит**, относится к Уроку 10.
- Иррациональные уравнения повышенной степени — не входят.

## Часть 4. Содержательная карта темы

### 4.1. Механизмы (8)

| № | Механизм | Суть |
|---|---|---|
| 1 | Существование корня | Чётность показателя определяет, есть ли корень и каких корней |
| 2 | Деление показателей | \(\sqrt[n]{a^m} = a^{m/n}\) при \(a \ge 0\) |
| 3 | Корень из произведения | Раскладываем подкоренное на множители, выносим хорошие степени |
| 4 | Модуль при чётном показателе | \(\sqrt[n]{a^n} = \lvert a\rvert\) — центральная ловушка темы |
| 5 | Склейка и сокращение | Объединение корней одного основания, деление показателей |
| 6 | Иррациональность в знаменателе | Загоняем корень в числитель |
| 7 | Сравнение корней | Приведение к общему показателю; переворот при \(0<a<1\) |
| 8 | Уравнения с корнями | ОДЗ → возведение в степень → проверка |

### 4.2. Карта понятий

Корень n-й степени · арифметический корень · ОДЗ по чётности · показатель · подкоренное выражение · «хорошая» степень · модуль · разложение на простые множители · НОК показателей · рационализация знаменателя · посторонний корень · равносильность.

### 4.4. Карта распознавания (триггеры)

| Фраза в условии / вид | → Механизм |
|---|---|
| Показатель корня **нечётный**, подкоренное отрицательное | 1 → считаем, знак переезжает |
| Корень из **степени при основании** | 2 → делим показатели |
| Корень из **произведения** | 3 → раскладываем |
| \(\sqrt[n]{a^n}\), показатели **совпадают** | 4 → модуль |
| **Два корня** с одним основанием | 5 → склеиваем |
| **Дробь, корень в знаменателе** | 6 → рационализируем |
| «**Что больше / расположи**» | 7 → общий показатель |
| **Уравнение** с переменной под корнем | 8 → ОДЗ, степень, проверка |

### 4.5. Карта различий (контрасты)

| Контраст | Суть |
|---|---|
| C1 | \(\left(\sqrt[n]{a}\right)^n = a\) **против** \(\sqrt[n]{a^n} = \lvert a\rvert\) |
| C2 | \(\sqrt[n]{a^m}\) при \(m \ne n\) — **делим показатели**; при \(m = n\) — **берём модуль** |
| C3 | Сокращение показателей: работает **до** потери ОДЗ, ломается **после** |
| C4 | Сравнение корней: при \(a > 1\) показатель растёт → корень падает; при \(0 < a < 1\) **наоборот** |

### 4.6. Карта границ

Работает: \(\sqrt[n]{a^m} = a^{m/n}\) при \(a \ge 0\), всегда при нечётном n.
Не работает: при \(a < 0\) и чётном n; при сокращении, ломающем ОДЗ; при склейке корней с **разными** основаниями.

### 4.7. Каталог ловушек (8)

| № | Ловушка | Почему правдоподобно | Где ломается |
|---|---|---|---|
| Л1 | «Под корнем не может быть отрицательного» | Верно для √a | Показатель нечётный — можно |
| Л2 | \(\sqrt[4]{16} = \pm 2\) | Решаем уравнение | Арифметический корень неотрицателен |
| Л3 | \(\sqrt[4]{a^4} = a\) | Возвели и извлекли | Чётная степень сожгла знак |
| Л4 | Сократили показатели при \(a < 0\) | Формально деление | Потерян модуль |
| Л5 | \(\sqrt[3]{x} = x-6\): «будут посторонние корни» | Слышал про квадратный корень | При нечётном показателе возведение обратимо |
| Л6 | Больший показатель → меньший корень | Проверено на 2 и 8 | При \(0 < a < 1\) наоборот |
| Л7 | Домножили только знаменатель | «Убрал иррациональность» | Значение дроби изменилось |
| Л8 | Расклали произведение корней с \(a < 0\) | Свойство всегда рядом | Чётный корень из отрицательного не существует |

### 4.8. Реестр формул памятки (6)

1. \(\sqrt[n]{a} = a^{1/n}\) — при \(a > 0\) при любом n; при \(a<0\) и нечётном n.
2. \(\sqrt[n]{a^m} = a^{m/n}\) — при \(a \ge 0\).
3. \(\sqrt[n]{a \cdot b} = \sqrt[n]{a} \cdot \sqrt[n]{b}\) — чётное n: \(a,b \ge 0\); нечётное: любые.
4. \(\sqrt[n]{a^n} = \lvert a\rvert\) — n чётное; при нечётном \(= a\).
5. \(\sqrt[m]{x} \cdot \sqrt[n]{x} = \sqrt[mn]{x^{m+n}}\) — при \(x \ge 0\).
6. \(\dfrac{k}{\sqrt[n]{b}} = \dfrac{k\sqrt[n]{b^{n-1}}}{b}\) — при \(b > 0\).
