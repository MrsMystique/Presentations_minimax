# Урок 57. Начальные геометрические сведения. Смежные и вертикальные углы

## Перед тем как начать

Привет. Этот урок — про базовые понятия геометрии: углы, смежные и вертикальные углы, перпендикулярные прямые.

---

## Блок 1. Угол

### Определение

**Угол** — это геометрическая фигура, состоящая из точки (вершины) и двух лучей, исходящих из этой точки.

### Виды углов

- Острый (0° < α < 90°).
- Прямой (α = 90°).
- Тупой (90° < α < 180°).
- Развёрнутый (α = 180°).

---

## Блок 2. Смежные углы

### Определение

**Смежные углы** — два угла, у которых одна сторона общая, а две другие — дополнительные лучи.

### Свойство

**Сумма смежных углов = 180°.**

### Следствия

1) Если смежные углы равны, то каждый из них 90°.
2) Если два угла равны, то равны и смежные с ними.

---

## Блок 3. Вертикальные углы

### Определение

**Вертикальные углы** — два угла, стороны одного из которых — дополнительные лучи к сторонам другого.

### Свойство

**Вертикальные углы равны.**

---

## Блок 4. Перпендикулярные прямые

### Определение

**Перпендикулярные прямые** — две прямые, пересекающиеся под прямым углом.

### Теорема

На плоскости две прямые, перпендикулярные третьей, параллельны.

### Перпендикуляр к прямой

**Перпендикуляр к прямой** — это отрезок, лежащий на прямой, перпендикулярной данной, с концом в точке пересечения.

## Блок 5. Задачи

### Задача с разбором

**Задача.** Один из смежных углов 65°. Найди второй.

Решение: 180° - 65° = 115°.

**Ответ: 115°.**

### Реши сам

**Задача 1.** Смежные углы относятся как 2:3. Найди их.
<details>
<summary>Ответ</summary>

Пусть 2x + 3x = 180 → x = 36. Углы: 72° и 108°.
</details>

**Задача 2.** Вертикальные углы. Один 70°. Другой?
<details>
<summary>Ответ</summary>

70°.
</details>

**Задача 3.** Один из смежных углов равен половине другого. Найди.
<details>
<summary>Ответ</summary>

x + 2x = 180 → x = 60. Углы: 60° и 120°.
</details>

**Задача 4.** Две прямые пересекаются. Сумма трёх из четырёх углов 290°. Найди все четыре.
<details>
<summary>Ответ</summary>

Пусть углы a, b, c, d. a + b + c = 290°. a + c = 180° (вертикальные). Также b = a (вертикальные), c = b. Тогда 2a + c = 290. Но a + c = 180 → a = 110. Углы: 110°, 70°, 110°, 70°.
</details>

## Блок 6. Треугольник. Внешний угол

### Внешний угол

**Внешний угол** — угол, смежный с внутренним углом треугольника.

### Свойство

**Внешний угол равен сумме двух внутренних углов, не смежных с ним.**

### Задача с разбором

**Задача.** Внешний угол при вершине A треугольника ABC = 110°. Угол B = 50°. Найди угол C.

Решение: внешний угол = B + C → 110° = 50° + C → C = 60°.

**Ответ: 60°.**

### Реши сам

**Задача 1.** Внешний угол 140°, угол B 60°. Угол C?
<details>
<summary>Ответ</summary>

C = 80°.
</details>

**Задача 2.** В треугольнике углы 50°, 60°, 70°. Найди внешние углы.
<details>
<summary>Ответ</summary>

130°, 120°, 110°.
</details>

## Босс-файт

### Задача 1. Смежные углы относятся как 1:5. Найди.

**Решение:** x + 5x = 180 → x = 30. Углы: 30° и 150°.

### Задача 2. Внешний угол 120°, разность двух внутренних 30°. Найди углы треугольника.

**Решение:** внешний = сумме двух других. a + b = 120, a - b = 30 (или b - a = 30). a = 75, b = 45 или a = 45, b = 75. Третий угол = 180 - 120 = 60°. Углы: 75°, 45°, 60° или 45°, 75°, 60°.

### Задача 3. Две перпендикулярные прямые пересечены третьей под углом 30°. Найди все углы.

**Решение:** пусть прямые 1 и 2 перпендикулярны. Прямая 3 пересекает их. Угол между 1 и 3 = 30°, тогда угол между 2 и 3 = 90° - 30° = 60°. И так далее по 8 углов: 30°, 150°, 30°, 150°, 60°, 120°, 60°, 120°.

### Задача 4. Сумма трёх внешних углов треугольника (по одному при каждой вершине) = 360°? Всегда ли это верно?

**Решение:** сумма трёх внешних углов всегда 360°. (Внешний угол = 180° - внутренний. Сумма = 540° - сумма внутренних = 540° - 180° = 360°.)
