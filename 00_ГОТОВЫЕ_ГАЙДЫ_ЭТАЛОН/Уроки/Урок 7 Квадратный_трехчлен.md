## О ЧЁМ ЭТОТ ГАЙД

### Зачем это нужно

Квадратный трёхчлен \(ax^2 + bx + c\) — **центральный объект школьной алгебры**. Через него решаются уравнения, неравенства, графики, сокращение дробей и сложные задачи.

**Где встречается в жизни:**

- **Бросок мяча вверх.** Высота: \(h(t) = v_0 t - \frac{g}{2}t^2\). Чтобы найти момент приземления, решаем \(h(t) = 0\) — это уравнение с квадратным трёхчленом.
- **Арка моста или фонтана.** Форма арки — парабола \(y = ax^2 + bx + c\). Зная уравнение, можно рассчитать высоту арки и ширину пролёта.
- **Торможение автомобиля.** Расстояние: \(S(t) = v_0 t - \frac{a}{2}t^2\). Когда \(S\) перестанет расти — машина остановилась.
- **Экономика.** Прибыль: \(P(x) = -x^2 + bx + c\). Максимум прибыли — это вершина параболы.

### Что нужно знать заранее

**Многочлен** — это выражение, в котором переменная (например, \(x\)) стоит в разных степенях, и степени эти складываются с числами (или с другими переменными). Например, \(3x^2 + 5x - 1\) — это многочлен **второй степени** (самая большая степень при \(x\) — двойка). Многочлен первой степени (например, \(2x + 3\)) — это **линейное** выражение, многочлен третьей степени (например, \(x^3 + 5\)) — **кубическое**.

Перед этой темой нужно знать:

- **Формулы сокращённого умножения:** \((a+b)^2 = a^2 + 2ab + b^2\) и \(a^2 - b^2 = (a-b)(a+b)\).
- **Раскрытие скобок:** \(2(x + 3) = 2x + 6\).
- **Приведение подобных:** \(3x + 5x = 8x\).
- **Понятие корня уравнения:** значение переменной, обращающее уравнение в тождество.

### Как устроен гайд

Каждая секция — один механизм. Структура: **зачем → что это → как считать → где применить → где ошибиться**. В конце секции — задача с полным разбором («цепочка мыслей»), чтобы закрепить.

## СЕКЦИЯ 1. КВАДРАТНОЕ УРАВНЕНИЕ И ДИСКРИМИНАНТ

### Зачем

Базовый инструмент. Умеешь решать квадратное уравнение — открываешь двери ко всем остальным темам: неравенства, функции, оптимизация, физика. Без дискриминанта никуда.

### Что это

**Квадратное уравнение** — это уравнение, в котором \(x\) стоит **в квадрате**. Записывают вид:

\[
ax^2 + bx + c = 0,
\]

где \(x\) — переменная, \(a, b, c\) — числа, **\(a \neq 0\)**. Если \(a = 0\), уравнение вырождается в линейное (\(bx + c = 0\)) — это уже не квадратное.

**Три буквы — три коэффициента:**
- \(a\) — старший коэффициент (число перед \(x^2\)).
- \(b\) — средний коэффициент (число перед обычным \(x\)).
- \(c\) — свободный член (число-одиночка в конце).

**Примеры:**
- \(2x^2 + 5x - 3 = 0\) — \(a = 2, b = 5, c = -3\).
- \(x^2 - 9 = 0\) — \(a = 1, b = 0, c = -9\). Здесь нет \(x\) в первой степени — это **неполное** квадратное (для таких уравнений работает простой приём через разность квадратов: \(x^2 - 9 = (x-3)(x+3) = 0\), и сразу видны корни).
- \(-3x^2 + x + 1 = 0\) — \(a = -3\). Старший коэффициент отрицательный, и это нормально.

### Дискриминант — рентген для корней

**Дискриминант** — это число, которое **полностью определяет** количество корней уравнения, ещё до их поиска. Звучит как магия, но на самом деле это просто аккуратная подстановка в формулу:

\[
D = b^2 - 4ac.
\]

**Что говорит дискриминант о корнях:**

| Случай | Что с корнями | Почему |
|---|---|---|
| \(D > 0\) | Два различных корня | Правая часть уравнения положительна — есть два решения |
| \(D = 0\) | Один корень (два совпадающих) | Правая часть = 0 — одно решение |
| \(D < 0\) | Действительных корней нет | Правая часть отрицательна — корней в вещественных числах нет |

> **Не бойся ДУРНЫХ ответов:** \(D < 0\) — это **правильный** ответ, не ошибка. Пиши «действительных корней нет» и не переживай.

**Короткая справка:** **вещественные (действительные) числа** — это все числа, которые мы встречаем в школе: целые, дробные, положительные, отрицательные, ноль. Их можно отметить на числовой прямой. Все корни, которые мы ищем в этой теме — вещественные. Бывают ещё комплексные числа (например, \(i = \sqrt{-1}\)), но в школе мы с ними не работаем. Когда говорят «действительных корней нет» — имеют в виду, что среди вещественных чисел корней нет.

### Откуда берётся дискриминант

Дискриминант — не магическая формула. Это **побочный продукт** простой операции — **выделения полного квадрата**. Покажу шаг за шагом.

**Старт.** Хотим найти корни уравнения \(ax^2 + bx + c = 0\). Применим приём из формул сокращённого умножения: превратим левую часть в «готовый квадрат», и из него найдём корни.

**Шаг 1. Вынесем \(a\) за скобки** (чтобы внутри скобок был приведённый трёхчлен):
\[
ax^2 + bx + c = a\left(x^2 + \frac{b}{a}x + \frac{c}{a}\right).
\]
Спокойно делим на \(a\) — на ноль же не делим, а у нас \(a \neq 0\) по условию.

**Шаг 2. Выделим полный квадрат для \(x^2 + \frac{b}{a}x\).** Приём из ФСУ: чтобы из \(x^2 + px\) получить квадрат \((x + \text{что-то})^2\), нужно **добавить и вычесть** квадрат «половинки».

Найдём наше «что-то» — это просто **половина** от \(\frac{b}{a}\), то есть \(\frac{b}{2a}\).

**Шаг 3. Запишем «прибавили — вычли»:**
\[
x^2 + \frac{b}{a}x = \left(x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2\right) - \left(\frac{b}{2a}\right)^2.
\]

**Шаг 4. Свернём первую скобку по ФСУ** \((u + v)^2 = u^2 + 2uv + v^2\) (где \(u = x\), \(v = \frac{b}{2a}\)):
\[
x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = \left(x + \frac{b}{2a}\right)^2.
\]

**Шаг 5. Подставим обратно и соберём всю скобку:**
\[
x^2 + \frac{b}{a}x + \frac{c}{a} = \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2} + \frac{c}{a}.
\]

**Шаг 6. Приведём \(\frac{c}{a}\) к общему знаменателю \(4a^2\):**
\[
\frac{c}{a} = \frac{4ac}{4a^2}.
\]

**Шаг 7. Заметим, что \(\frac{4ac - b^2}{4a^2} = -\frac{b^2 - 4ac}{4a^2} = -\frac{D}{4a^2}\), где \(D = b^2 - 4ac\).**

**Шаг 8. Подставим обратно в уравнение:**
\[
\left(x + \frac{b}{2a}\right)^2 = \frac{D}{4a^2}.
\]

**Главный вывод:** это уравнение имеет решение тогда и только тогда, когда **правая часть неотрицательна**. То есть когда \(D \geq 0\). Если \(D < 0\) — корней в вещественных числах нет.

> **Вот откуда берётся дискриминант** — это условие существования корней, которое само выпрыгнуло из выделения квадрата. Не магия, а алгебра.

### Как считать корни

**Алгоритм (3 шага):**

1. **Посчитай дискриминант** \(D = b^2 - 4ac\).
2. **Проверь знак**: если \(D < 0\) — действительных корней нет (это **нормальный** ответ).
3. **Примени формулу** (если \(D \geq 0\)):

\[
x = \frac{-b \pm \sqrt{D}}{2a}.
\]

**Знак «минус» перед \(b\)** — обязателен. Это не опечатка, это часть формулы. Если забыть — получишь неправильные ответы.

### Где применить

Любое уравнение, где \(x\) в квадрате: физика (бросок, торможение), экономика (равновесие).

### Где ошибиться

- **Забыл знак «минус» перед \(b\)** — пиши \(\dfrac{-b \pm \sqrt{D}}{2a}\), не \(\dfrac{b \pm \sqrt{D}}{2a}\).
- **\(D < 0\) объявил «решений нет»** — это **правильный** ответ, не ошибка. Так и пиши.
- **Поделил на \(a\) до дискриминанта** — нельзя, потеряешь корни. Деление на \(a\) делаем **только** когда корень уже найден (или в самом конце, для упрощения).

> **Дискриминант — коварная штука, если мы что-то сократили.** Дискриминант выдаёт корни **только того уравнения, к которому его применили** — без учёта того, что было до этого. Если до дискриминанта мы сократили обе части на что-то (например, на \(\sqrt{1 - x}\), на \(x - 2\), или разделили всё на выражение с переменной) — можно потерять корни или получить лишние. Поэтому **всегда проверяй найденные корни подстановкой в исходное уравнение**, а не в упрощённое.

### Задача с полным разбором

**Условие.** Реши \(2x^2 + 5x - 3 = 0\).

**Цепочка мыслей (как рассуждать):**

1. **Смотрю на уравнение.** Здесь \(x\) в квадрате, \(a = 2 \neq 0\) — это квадратное.

2. **Проверяю — может, есть очевидный корень.** Подставляю \(x = 1\): \(2 + 5 - 3 = 4 \neq 0\). Подставляю \(x = -1\): \(2 - 5 - 3 = -6 \neq 0\). Не подошло.

3. **Считаю дискриминант** по формуле \(D = b^2 - 4ac\):
   \[
   D = 5^2 - 4 \cdot 2 \cdot (-3) = 25 - (-24) = 25 + 24 = 49.
   \]
   Аккуратно: \(-4 \cdot 2 \cdot (-3) = -24\), и **минус на минус** даёт **плюс** \(25 + 24 = 49\).

4. **Проверяю знак \(D\).** \(D = 49 > 0\) → два корня.

5. **Извлекаю корень:** \(\sqrt{49} = 7\).

6. **Подставляю в формулу корней:**
   \[
   x_1 = \frac{-5 - 7}{2 \cdot 2} = \frac{-12}{4} = -3, \qquad x_2 = \frac{-5 + 7}{2 \cdot 2} = \frac{2}{4} = \frac{1}{2}.
   \]

7. **Проверяю подстановкой** (это критически важно — ловит 50% ошибок):
   - \(x = -3\): \(2 \cdot 9 + 5 \cdot (-3) - 3 = 18 - 15 - 3 = 0\) — верно.
   - \(x = \frac{1}{2}\): \(2 \cdot \frac{1}{4} + 5 \cdot \frac{1}{2} - 3 = \frac{1}{2} + \frac{5}{2} - 3 = 3 - 3 = 0\) — верно.

**Ответ:** \(x_1 = -3\), \(x_2 = \frac{1}{2}\).

#### Контрольная точка после Секции 1

Прежде чем двигаться дальше, проверь себя:

1. Могу выписать коэффициенты \(a, b, c\) из любого квадратного уравнения.
2. Могу посчитать дискриминант \(D = b^2 - 4ac\).
3. Понимаю, что \(D > 0\) — два корня, \(D = 0\) — один, \(D < 0\) — действительных корней нет (и это **нормальный** ответ).
4. Могу применить формулу корней \(x = \dfrac{-b \pm \sqrt{D}}{2a}\).
5. Всегда проверяю корни подстановкой в исходное уравнение.

Если хотя бы один пункт — «нет», вернись к этой секции.

## СЕКЦИЯ 2. ТЕОРЕМА ВИЕТА

### Зачем

Смотри: если коэффициенты уравнения **маленькие и целые**, корни часто подбираются в уме — без дискриминанта, без ручки, без бумаги. Это приём **«быстрого ответа»**, когда хочется сэкономить время на тестах.

### Что это

**Теорема Виета** — мост между корнями и коэффициентами уравнения.

**Для приведённого** \(x^2 + px + q = 0\):

> Сумма корней — это \(p\) с **противоположным знаком**, а произведение — сам \(q\).

\[
x_1 + x_2 = -p, \qquad x_1 \cdot x_2 = q.
\]

**Для неприведённого** \(ax^2 + bx + c = 0\) (когда перед \(x^2\) стоит число):

\[
x_1 + x_2 = -\frac{b}{a}, \qquad x_1 \cdot x_2 = \frac{c}{a}.
\]

> **Почему знак минус у суммы?** Запомни: в уравнении \(x^2 + px + q = 0\) центр имеет знак \(p\), а у корней сумма «зеркалит» его с минусом. Потому что в разложении \((x - x_1)(x - x_2)\) при раскрытии в центре появляется **минус**. Это просто факт, который мы сейчас увидим своими глазами.

### Откуда берётся (вывод через раскрытие скобок)

Давай не будем зубрить формулу — **получим её из раскрытия скобок**.

**Старт.** Допустим, у нас есть корни \(x_1\) и \(x_2\). Тогда наш трёхчлен **раскладывается в скобки** (это мы строго докажем в Секции 3, а пока поверь на слово):

\[
x^2 + px + q = (x - x_1)(x - x_2).
\]

**Шаг 1. Раскрываем правую часть «крест-накрест»** (каждое с каждым):

\[
(x - x_1)(x - x_2) = x \cdot x + x \cdot (-x_2) + (-x_1) \cdot x + (-x_1)(-x_2) = x^2 - x_1 x - x_2 x + x_1 x_2.
\]

Группируем одинаковые иксы:

\[
= x^2 - (x_1 + x_2)x + x_1 x_2.
\]

**Шаг 2. Сравниваем с исходным выражением.** Слева у нас \(x^2 + px + q\), справа \(x^2 - (x_1 + x_2)x + x_1 x_2\). Это **одно и то же** — значит, одинаковые куски равны:

- Центр (то, что при \(x\)): \(p = -(x_1 + x_2)\), то есть \(x_1 + x_2 = -p\).
- Хвост (то, что без \(x\)): \(q = x_1 x_2\).

**Вот и теорема Виета** — не формула из справочника, а **прямое следствие раскрытия скобок**. Запомнилась сама.

> **Почему знак минус у суммы?** Теперь видно: при раскрытии \((x - x_1)(x - x_2)\) в центре появляется \(-x_1\) и \(-x_2\), то есть **минус** суммы. Отсюда \(-(x_1 + x_2) = p\), и \(x_1 + x_2 = -p\).

**Альтернативный вывод** (через прямую подстановку) — если интересно, как выводится теорема о разложении. Но он длинный и неудобный, так что **используй вывод выше — он проще и нагляднее**.

### Как считать

**Задача — подобрать два числа с заданным произведением и суммой.** Это и есть применение Виета.

**Алгоритм в три шага:**
1. **Запиши произведение** (\(q\) или \(\frac{c}{a}\)) — это хвост уравнения.
2. **Запиши сумму** (\(-p\) или \(-\frac{b}{a}\)) — это центр с минусом.
3. **Подбирай пары** с этим произведением. Проверяй сумму.

**Пример.** Возьмём \(x^2 - 5x + 6 = 0\).

- Хвост \(+6\) — произведение корней \(6\).
- Центр \(-5\), минус меняем — сумма корней \(5\).
- Пары с произведением 6: \((1, 6), (2, 3), (-1, -6), (-2, -3)\).
- Какая пара даёт сумму 5? Пара \((2, 3)\): \(2 + 3 = 5\). **Верно.**

**Корни:** \(x_1 = 2, x_2 = 3\).

#### Рентген знаков (как угадать знаки корней за секунду)

Чтобы в уме понять, **какие знаки** у будущих корней, посмотри на знак свободного члена (хвоста).

**Правило:**
- Хвост **плюс** → корни **одинаковых знаков** (оба плюс или оба минус).
- Хвост **минус** → корни **разных знаков**.

А **кто из разных сильнее** — определяется знаком центра \(p\):
- \(p > 0\) → сумма \(= -p\) отрицательная → **минус побеждает**.
- \(p < 0\) → сумма \(= -p\) положительная → **плюс побеждает**.

**Пример 1.** \(x^2 - 5x + 6 = 0\). Хвост \(+6\) → знаки одинаковые. Сумма \(5\) (с плюсом) → оба плюс. Корни: \(2\) и \(3\).

**Пример 2.** \(x^2 + x - 6 = 0\). Хвост \(-6\) → знаки разные. Центр \(p = +1\) → сумма \(= -1\) (отрицательная) → **минус побеждает**. Корни: \(-3\) и \(2\).

> **Запомнить:** **плюс в конце → знаки одинаковые**, **минус в конце → знаки разные**. Плюс проверь знак центра — он скажет, кто из разных сильнее.

#### Виет через «фонтанчик» (ещё один способ увидеть ту же теорему)

Если тебе не зашла разложение через скобки, есть другой путь — **раскрыть скобки в общем виде** и просто посмотреть, что получится.

Раскрываем \((x - x_1)(x - x_2)\) — каждое слагаемое первой скобки на каждое слагаемое второй:

\[
(x - x_1)(x - x_2) = x^2 - x_1 x - x_2 x + x_1 x_2 = x^2 - (x_1 + x_2) x + (x_1 \cdot x_2).
\]

**Что увидели:**
- **Хвост** раскрытой скобки = \(x_1 \cdot x_2\) = **произведение корней**.
- **Центр** раскрытой скобки = \(-(x_1 + x_2)\) = **сумма корней с минусом**.

Сравниваем с \(x^2 + px + q\):
- Хвост: \(q = x_1 x_2\).
- Центр: \(p = -(x_1 + x_2)\), значит \(x_1 + x_2 = -p\).

**Вот и Виет** — но уже не через теорему Безу, а через прямое раскрытие. Оба пути дают одно и то же.

### Где применить

- **Подбор целых корней** в тестах с простыми коэффициентами.
- **Сокращение дробей через разложение** (когда знаменатель раскладывается через Виета).
- **Нахождение суммы/произведения корней** вообще **без** решения уравнения — просто посмотрел на коэффициенты и записал ответ.
- **Составление уравнения** по его корням (обратная задача).

### Где ошибиться

- **Применил Виета при \(D < 0\)** — нет действительных корней, Виета не работает. **Сначала проверь дискриминант** (если коэффициенты дробные — лучше начать с дискриминанта).
- **Забыл сменить знак** суммы — помни: \(x_1 + x_2 = -p\), а **не** \(+p\). Один лишний минус — и весь ответ вверх ногами.

### Задача с полным разбором

**Условие.** Не решая уравнения \(x^2 + 2x - 15 = 0\), найди сумму и произведение его корней.

**Цепочка мыслей:**

1. **Смотрю на уравнение.** Перед \(x^2\) стоит \(1\) — это **приведённый** трёхчлен. Значит, применяю Виета в чистом виде (без деления на \(a\)).

2. **Записываю коэффициенты:** \(p = 2, q = -15\).

3. **Применяю формулу** \(x_1 + x_2 = -p\) и \(x_1 x_2 = q\):
   - Сумма: \(-p = -2\).
   - Произведение: \(q = -15\).

4. **Проверяю подбором.** Ищу два числа с суммой \(-2\) и произведением \(-15\).
   - Рентген: в конце \(-15\) → знаки **разные**.
   - Кто побеждает? Центр \(p = 2 > 0\) → сумма отрицательная → **минус побеждает**.
   - Перебираю пары: \((3, -5)\)? \(3 + (-5) = -2\) **верно**, \(3 \cdot (-5) = -15\) **верно**.

5. **Корни:** \(x_1 = 3, x_2 = -5\).

**Ответ:** сумма = \(-2\), произведение = \(-15\).

#### Связка Виета с пропорцией корней

Часто в задаче дано **отношение корней** (например, \(4 : 3\)). Это значит, что оба корня сделаны из **одного общего числа** (параметра \(y\)), умноженного на доли из пропорции.

**Алгоритм:**
1. **Запиши корни через параметр \(y\):** больший корень \(x_1 = ky\), меньший \(x_2 = ly\) (где \(k : l\) — данная пропорция).
2. **Подставь в сумму по Виету:** \(x_1 + x_2 = ky + ly = (k + l)y\).
3. **Найди \(y\):** приравняй к сумме, данной в условии (или найденной через Виета).
4. **Восстанови корни:** умножь \(y\) на доли.
5. **Найди нужную величину** (другой коэффициент, произведение, и т.п.).

**Пример.** Уравнение \(x^2 - 21x + q = 0\) имеет корни, относящиеся как \(4 : 3\). Найди сумму большего корня и числа \(q\).

- **Корни через \(y\):** больший \(x_1 = 4y\), меньший \(x_2 = 3y\).
- **Сумма по Виету:** \(x_1 + x_2 = -(-21) = 21\).
- **Подставляем:** \(4y + 3y = 21 \Rightarrow 7y = 21 \Rightarrow y = 3\).
- **Корни:** \(x_1 = 4 \cdot 3 = 12\), \(x_2 = 3 \cdot 3 = 9\).
- **Произведение по Виету:** \(q = x_1 \cdot x_2 = 12 \cdot 9 = 108\).
- **Ответ:** сумма большего корня и \(q\) = \(12 + 108 = 120\).

> **Запомнить:** пропорция корней — это «масштаб» \(y\), который умножается на доли. Виет даёт сумму и произведение — через них находим \(y\).

## СЕКЦИЯ 3. РАЗЛОЖЕНИЕ КВАДРАТНОГО ТРЁХЧЛЕНА НА МНОЖИТЕЛИ

### Зачем

Когда у трёхчлена есть корни, его можно превратить в произведение двух скобок. Это главный приём для **сокращения дробей** — одного из самых частых заданий.

> **Главная идея (философия разложения).** Вся алгебра сводится к одному трюку: **представить выражение как произведение множителей**, каждый из которых можно «занулить» по отдельности. Если произведение равно нулю, то хотя бы один из множителей равен нулю — и это даёт простой способ найти корни или сократить дробь. Поэтому разложение трёхчлена на множители — это не отдельная операция, а ключ ко всей алгебре.

### Что это

**Если \(D > 0\) и \(x_1, x_2\) — два корня трёхчлена \(ax^2 + bx + c\):**

\[
ax^2 + bx + c = a(x - x_1)(x - x_2).
\]

**Если \(D = 0\) и \(x_0\) — единственный (двукратный) корень:**

\[
ax^2 + bx + c = a(x - x_0)^2.
\]

**Если \(D < 0\):** разложить на множители с действительными коэффициентами **нельзя** (корни комплексные).

### Откуда берётся формула разложения

**Шаг 1. Почему разложение вообще существует.** Это следствие **теоремы о корнях многочлена** (теорема Безу): если \(x_1\) и \(x_2\) — два корня многочлена второй степени \(ax^2 + bx + c\) (с \(D > 0\)), то этот многочлен раскладывается на произведение линейных множителей. То есть **обязательно существует** разложение вида \(a(x - x_1)(x - x_2)\). Это строгая теорема, она доказывается через **деление столбиком многочленов** (деление работает почти так же, как деление чисел столбиком: делишь \(ax^2 + bx + c\) на \(x - x_0\) и смотришь, есть ли остаток; если остаток = 0 — значит, делится нацело, и \(x_0\) — корень; затем применяем к обоим корням).

> **Если деление столбиком многочленов тебе не знакомо — не переживай.** В этой секции мы обойдёмся без него: вместо деления используем метод группировки (см. далее) или готовую формулу разложения \(a(x - x_1)(x - x_2)\), где \(x_1, x_2\) — найденные корни. Деление столбиком пригодится в теме «многочлены 3-й степени» (Секция 6), и то только для понимания, почему работает теорема Безу.

**Шаг 2. Прямая проверка раскрытием.** Если \(x_1, x_2\) — корни, то по теореме Виета \(x_1 + x_2 = -b/a\) и \(x_1 \cdot x_2 = c/a\). Раскроем правую часть:

\[
a(x - x_1)(x - x_2) = a[x^2 - (x_1 + x_2)x + x_1 x_2] = a\left[x^2 + \frac{b}{a}x + \frac{c}{a}\right] = ax^2 + bx + c.
\]

Это **в точности** наш трёхчлен. Значит, формула верна.

### Как считать

**Алгоритм в два шага:**
1. **Найди корни** трёхчлена (дискриминант или Виет).
2. **Подставь** в формулу \(a(x - x_1)(x - x_2)\).

#### Лайфхак с дробными корнями (Страж скобок)

Коэффициент \(a\) **никогда нельзя терять** — он обязан стоять перед скобками.

Если один из корней получился **дробным** (например, \(x_1 = -\dfrac{4}{3}\)), не оставляй дробь в скобке — умножь скобку на знаменатель \(a\), чтобы уничтожить дробь.

**Пример.** Разложить \(3x^2 - x - 4\).

- \(a = 3\), \(b = -1\), \(c = -4\).
- \(D = 1 + 48 = 49\). Корни: \(x_1 = \dfrac{1 + 7}{6} = \dfrac{4}{3}\), \(x_2 = \dfrac{1 - 7}{6} = -1\).
- Формула: \(3 \cdot \left(x - \dfrac{4}{3}\right) \cdot (x + 1)\).
- Умножаем первую скобку на \(a = 3\) (компенсируя делением на 3): \(3 \cdot \dfrac{1}{3} \cdot (3x - 4) \cdot (x + 1) = (3x - 4)(x + 1)\).
- Итог: \(3x^2 - x - 4 = (3x - 4)(x + 1)\).

**Проверка:** \((3x - 4)(x + 1) = 3x^2 + 3x - 4x - 4 = 3x^2 - x - 4\) — верно.

**Пример.** Разложить \(2x^2 + 5x - 3\).

- \(a = 2\), \(b = 5\), \(c = -3\).
- \(D = 25 + 24 = 49\). \(\sqrt{D} = 7\). Корни: \(x_1 = \dfrac{-5 + 7}{4} = \dfrac{1}{2}\), \(x_2 = \dfrac{-5 - 7}{4} = -3\).
- Идеальный вид: \(2 \cdot \left(x + 3\right) \cdot \left(x - \dfrac{1}{2}\right)\).
- **Куда закидывать стража \(a = 2\)?** Смотрим на скобки: первая \((x + 3)\) — целая, красивая, портить её не надо. Вторая \(\left(x - \dfrac{1}{2}\right)\) — дробная, требует помощи. Поэтому страж идёт **только** во вторую скобку.
- Умножаем **фонтанчиком**: \(2 \cdot x = 2x\), \(2 \cdot \left(-\dfrac{1}{2}\right) = -1\). Вторая скобка становится \((2x - 1)\).
- **Итог:** \(2x^2 + 5x - 3 = (x + 3)(2x - 1)\).

**Проверка фонтанчиком назад:** \((x + 3)(2x - 1) = 2x^2 - x + 6x - 3 = 2x^2 + 5x - 3\) — верно.

> **Правило Стража Коэффициента (куда закидывать).** Старший коэффициент \(a\) умножается **только на ту скобку, в которой сидит дробный корень**. Цель — сделать числа красивыми, убрать дробную «шелуху» и перевести всё в целые числа. Это не интуиция, а **прагматизм**: можно умножить \(a\) на любую скобку (весы не рухнут), но **зачем портить красивую целую скобку**, если рядом страдает скобка с дробью?

> **Проверка.** Если при обратном раскрытии скобок получается исходное выражение — значит, всё сделано верно. Это универсальный «рентген» для самопроверки.

#### Капкан с перевёрнутыми скобками

Скобки \((5 - x)\) и \((x - 5)\) **не одинаковые** — у них противоположные знаки внутри. Сокращать такие скобки напрямую **нельзя**.

**Приём:** вынеси минус из одной скобки, превратив её в противоположную:
\[
(5 - x) = -(x - 5).
\]

После этого сокращение станет законным.

**Пример.** Сократить \(\dfrac{25 - x^2}{3x^2 - 11x - 20}\).

1. **Числитель** — разность квадратов: \(25 - x^2 = (5 + x)(5 - x)\).
2. **Знаменатель** — раскладываем по ближнему прицелу: \(3x^2 - 11x - 20 = (3x + 4)(x - 5)\).
3. **Дробь:** \(\dfrac{(5 + x)(5 - x)}{(3x + 4)(x - 5)}\).
4. **Капкан:** \((5 - x)\) и \((x - 5)\) — противоположные. Выносим минус: \((5 - x) = -(x - 5)\).
5. **Записываем:** \(\dfrac{-(5 + x)(x - 5)}{(3x + 4)(x - 5)}\).
6. **Сокращаем** на \((x - 5)\): \(-\dfrac{5 + x}{3x + 4}\).
7. **Итог:** \(\dfrac{-5 - x}{3x + 4}\).

**Проверка ОДЗ (области допустимых значений):** ОДЗ — это набор всех значений \(x\), при которых исходная дробь имеет смысл (то есть знаменатель не равен нулю). Если в какой-то точке знаменатель = 0, дробь в этой точке **не определена** — её нельзя туда подставлять. После сокращения знаменатель всё равно не должен быть нулём. Для нашего примера: знаменатель \((3x + 4)(x - 5) \neq 0\), значит \(x \neq -\dfrac{4}{3}\) и \(x \neq 5\).

#### Метод ближнего прицела (разложение трёхчлена в уме)

Когда перед \(x^2\) стоит «тяжёлое» число (например, \(4\), \(6\)) и нужно разложить в уме, используй **прицел**: ищи числа, которые крест-накрест «прыгают» к центру.

**Алгоритм:**
1. **Раскинь иксы** на две заготовки скобок (для \(4x^2\) — заготовки \(4x\) и \(x\)).
2. **Найди запчасти** для числа в конце.
3. **Включи прицел:** возьми первый коэффициент (\(a\)) и умножь его по очереди на каждую «запчасть» из концовки. Смотри, какое произведение **ближе всего** к центральному числу (но не равно ему) — это и есть «минимальный перелёт». Например, для \(4x^2 + 5x - 6\): центр = \(+5\), запчасти = \(2\) и \(-3\). Проверяем: \(4 \cdot 2 = 8\) (перелёт за \(5\) на \(3\)), \(4 \cdot (-3) = -12\) (далеко). Значит, берём \(2\).
4. **Проверь чётность:** если центр нечётный, то промежуточные куски не могут быть оба чётными.
5. **Засели** найденные числа в скобки.

**Пример.** \(4x^2 + 5x - 6\).

- Заготовки: \((4x \quad)(x \quad)\).
- Свободный член \(-6\) — ищем пары: \(-1 \cdot 6\), \(-2 \cdot 3\), \(1 \cdot -6\), \(2 \cdot -3\).
- Центр \(+5\). Включаем прицел: \(4 \cdot 2 = 8\) — это минимальный перелёт за \(5\). Берём \(2\).
- Пара для второго икса: \(-3\) (через Виета: \(2 \cdot (-3) = -6\) — верно; \((4 \cdot 2) + (1 \cdot (-3)) = 8 - 3 = 5\) — верно).
- Заселяем: \((4x - 3)(x + 2) = 4x^2 + 8x - 3x - 6 = 4x^2 + 5x - 6\) — верно.

> **Запомнить:** метод ближнего прицела — **раскинь иксы → найди запчасти → ищи минимальный перелёт → проверь чётность → засели**. Разложение «в уме» для тяжёлых коэффициентов.

**Кейс №1. Когда в конце плюс.** \(x^2 - 6x + 8 = 0\).

- **Рентген знаков:** в конце \(+8\) → знаки корней **одинаковые**. Центр \(-6\) (меняем на \(+6\)) → оба корня **положительные**.
- **Подбор в уме:** перемножаются в \(8\), складываются в \(6\). Чистые иксы: \(x_1 = 4\) и \(x_2 = 2\).
- **Мостик в скобки:** знак переворачивается — раз корни \(+4\) и \(+2\), то в скобках они становятся **противоположными**: \((x - 4)(x - 2) = 0\).

**Кейс №2. Когда в конце минус.** \(2x^2 + 5x - 3 = 0\).

- **Заготовки** (по старшему коэффициенту \(2\)): \((2x \quad)(x \quad) = 0\).
- **Свободный член \(-3\)** — пары: \((-1 \cdot 3)\) или \((-3 \cdot 1)\).
- **Прицел на центр \(+5\):** \(2x \cdot 3 = 6x\) — первый «прыжок». Чтобы получить \(+5x\), нужно \(6x - 1x = 5x\). Значит, во второй скобке «\(x\)» умножается на \(-1\), а во второй скобке первый икс — на \(+3\).
- **Заселяем:** \((2x - 1)(x + 3) = 0\).
- **Корни** (знак переворачивается): \(2x - 1 = 0 \Rightarrow x_1 = \dfrac{1}{2}\); \(x + 3 = 0 \Rightarrow x_2 = -3\).

> **Запомнить:** в Кейсе №2 ближний прицел сработал потому, что** \(2x \cdot 3 = 6x\) **— минимальный перелёт за \(+5\).** Если бы перелёт был больше (например, при \((2x + 4)(x - 1) = 2x^2 + 2x - 4\), центр \(+2\) — не подходит), нужно искать другую пару.

### Где применить

**Сокращение дробей** — главное применение. Когда в числителе и знаменателе стоят квадратные трёхчлены, разложи оба и сократи общий множитель.

### Где ошибиться

- **Потерял коэффициент \(a\)** — разложение — это \(a \cdot (x - x_1)(x - x_2)\), не \((x - x_1)(x - x_2)\).
- **Забыл ОДЗ при сокращении** — корни знаменателя исключаются.
- **Попытался разложить при \(D < 0\)** — нельзя (корни комплексные).

### Задача с полным разбором

**Условие.** Сократи дробь \(\dfrac{x^2 - 4}{2x^2 + 5x + 2}\). Укажи ОДЗ.

**Цепочка мыслей:**

1. **Распознаю тип.** Числитель и знаменатель — два квадратных трёхчлена. Применяю разложение на множители для каждого.

2. **Разлагаю числитель** \(x^2 - 4\). Это **разность квадратов**: \(x^2 - 2^2 = (x - 2)(x + 2)\). Корни: \(\pm 2\).

3. **Разлагаю знаменатель** \(2x^2 + 5x + 2\). Считаю дискриминант: \(D = 25 - 16 = 9\). Корни: \(\frac{-5 \pm 3}{4}\). Получаю \(x_1 = -\frac{1}{2}\) и \(x_2 = -2\).

4. **Проверяю через подстановку:** \(2 \cdot (-2)^2 + 5 \cdot (-2) + 2 = 8 - 10 + 2 = 0\) — верно. \(2 \cdot \left(-\frac{1}{2}\right)^2 + 5 \cdot \left(-\frac{1}{2}\right) + 2 = \frac{1}{2} - \frac{5}{2} + 2 = 0\) — верно.

5. **Записываю разложение знаменателя** через корни:
   \[
   2x^2 + 5x + 2 = 2\left(x - \left(-\frac{1}{2}\right)\right)(x - (-2)) = 2\left(x + \frac{1}{2}\right)(x + 2).
   \]

6. **Избавляюсь от дроби** \(\frac{1}{2}\) внутри скобок, умножая на 2:
   \[
   2\left(x + \frac{1}{2}\right) = 2x + 1.
   \]
   Значит, разложение знаменателя: \((2x + 1)(x + 2)\).

7. **Собираю дробь:**
   \[
   \frac{x^2 - 4}{2x^2 + 5x + 2} = \frac{(x - 2)(x + 2)}{(2x + 1)(x + 2)}.
   \]

8. **Сокращаю общий множитель** \((x + 2)\):
   \[
   = \frac{x - 2}{2x + 1}.
   \]

9. **Указываю ОДЗ.** Знаменатель исходной дроби не должен быть равен нулю: \(x \neq -2\) и \(x \neq -\frac{1}{2}\). (Числитель в ОДЗ **не входит**: дробь может быть равна нулю, если числитель ноль — это не запрещено.)

**Ответ:** \(\dfrac{x - 2}{2x + 1}\), при \(x \neq -2, x \neq -\frac{1}{2}\).

Ты прошёл три базовые секции. Проверь себя:

## СЕКЦИЯ 4. ВЫДЕЛЕНИЕ ПОЛНОГО КВАДРАТА

### Зачем

Смотри: квадратный трёхчлен можно записать двумя способами. Либо «в развёрнутом виде» \(ax^2 + bx + c\), либо **«в свёрнутом»** — как \(a(x + p)^2 + q\). Второй способ — главный ключ к поиску min/max, к решению неравенств, к доказательству тождеств. Без этого приёма ты будешь решать производными, которых ещё нет. С этим приёмом — справишься руками.

**Где встречается:**
- **Арка моста.** Зная «свёрнутую» форму, сразу видишь, на какой высоте вершина арки и где она расположена по горизонтали.
- **Оптимизация.** Если функция задана «свёрнуто» (например, \(y = 2(x - 3)^2 + 5\)), её min/max читаются мгновенно: ветви вверх, минимум \(5\) в точке \(x = 3\).
- **Решение неравенств.** Вместо «метода интервалов» через корни — используешь параболу: где она выше оси, где ниже, где касается.

### Что это

**Идея:** превращаем \(ax^2 + bx + c\) в форму \(a(x + p)^2 + q\). Это **обратный ход** к формуле сокращённого умножения \((u + v)^2 = u^2 + 2uv + v^2\).

**Главная формула выделения:**

\[
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{D}{4a}.
\]

Здесь два важных куска:
- \(-\dfrac{b}{2a}\) — это **координата вершины параболы** \(x_0\). Именно в этой точке квадратный «домик» достигает своей вершины.
- \(-\dfrac{D}{4a}\) — это **значение трёхчлена в вершине**: минимум, если \(a > 0\), или максимум, если \(a < 0\).

**Зачем это знать:** записал трёхчлен в свёрнутой форме — сразу видишь, где вершина и какое там значение. Не надо считать производные, не надо гадать.

### Откуда берётся формула

Сейчас сделаем то же самое, что в Секции 1 для дискриминанта — **выделим квадрат руками**, шаг за шагом.

**Старт.** Хотим превратить \(ax^2 + bx + c\) в \(a(x + \text{что-то})^2 + \text{хвост}\).

**Шаг 1.** Вынесем \(a\) за скобки (это легально — на \(a\) не делим, просто группируем):
\[
ax^2 + bx + c = a\left(x^2 + \frac{b}{a}x\right) + c.
\]

**Шаг 2.** Внутри скобок у нас теперь **приведённый** трёхчлен \(x^2 + \frac{b}{a}x\). По формуле ФСУ, чтобы получить полный квадрат, нужно **прибавить и вычесть** квадрат «половинки»:
\[
x^2 + \frac{b}{a}x = \left(x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2\right) - \left(\frac{b}{2a}\right)^2.
\]

**Шаг 3.** Свернём первую скобку по ФСУ:
\[
x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = \left(x + \frac{b}{2a}\right)^2.
\]

**Шаг 4.** Подставим обратно и раскроем скобку с \(a\):
\[
a\left[\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2}\right] + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c.
\]

**Шаг 5.** Приведём \(-\frac{b^2}{4a} + c\) к общему знаменателю:
\[
-\frac{b^2}{4a} + \frac{4ac}{4a} = \frac{4ac - b^2}{4a}.
\]

**Шаг 6.** Узнаём дискриминант: \(4ac - b^2 = -(b^2 - 4ac) = -D\). Значит:
\[
\frac{4ac - b^2}{4a} = -\frac{D}{4a}.
\]

**Итог:**
\[
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{D}{4a}.
\]

**Главный вывод:** в свёрнутой форме у параболы **вершина в точке** \(x_0 = -\frac{b}{2a}\), **значение в вершине** — \(-\frac{D}{4a}\). Если \(a > 0\) — это минимум, если \(a < 0\) — максимум.

> **Зачем тут дискриминант?** Он вылез сам — из алгебры, без подсказок. Величина \(-\frac{D}{4a}\) — это и есть «высота» вершины параболы. Если \(D < 0\) — вершина **не касается** оси, парабола целиком выше (или целиком ниже) оси \(x\).

### Как считать

**Случай 1: \(a = 1\) (приведённый трёхчлен).**

Здесь всё просто: выделяем квадрат в «первых двух» членах, остаток уходит в «хвост».

**Пример.** \(x^2 + 6x + 5\):
1. **Берём центр**: \(+6x\). Половина от \(6\) — это \(3\).
2. **Квадрат половинки**: \(3^2 = 9\).
3. **Прибавляем и вычитаем**: \(x^2 + 6x + 9 - 9 + 5\).
4. **Сворачиваем**: \((x + 3)^2 - 4\).

**Случай 2: \(a \neq 1\) (неприведённый трёхчлен).**

Здесь добавляется шаг: сначала выносим \(a\) за скобки, потом работаем внутри.

**Пример.** \(3x^2 - 12x + 5\):
1. **Выносим \(a\):** \(3(x^2 - 4x) + 5\).
2. **Внутри скобок** \(x^2 - 4x\) — это «приведённый» случай. Половина от \(4\) — \(2\). Квадрат: \(4\).
3. **Прибавляем и вычитаем**: \(x^2 - 4x + 4 - 4 = (x - 2)^2 - 4\).
4. **Подставляем** обратно: \(3[(x - 2)^2 - 4] + 5\).
5. **Умножаем «хвост» на \(a\):** \(3 \cdot (-4) = -12\).
6. **Собираем**: \(3(x - 2)^2 - 12 + 5 = 3(x - 2)^2 - 7\).

**Главная ловушка** — пункт 5: **не забыть умножить «хвост» на \(a\)**. Без этого шага ответ будет на \(3\) единицы больше или меньше — и неправильный.

### Где применить

- **Нахождение min/max функции** в одно действие. Записал \(y = 3(x-2)^2 - 7\) → минимум = \(-7\) при \(x = 2\). Никаких уравнений.
- **Доказательство неравенств.** Любое выражение вида \((x - 2)^2 + 4\) **всегда \(\geq 4\)** — потому что квадрат неотрицателен. Используй как готовый аргумент.
- **Решение неравенств методом параболы.** Вместо интервалов — рисуешь параболу и смотришь, где она выше или ниже оси.
- **Физика и экономика.** Бросок, торможение, прибыль — все они «прячут» ответ в вершине параболы.

### Где ошибиться

- **Забыл умножить «хвост» на \(a\).** После \((x + \frac{b}{2a})^2 - k\) нужно \(a \cdot (x + \frac{b}{2a})^2 - ak\), а не просто \((x + \frac{b}{2a})^2 - k\).
- **Перепутал знак координаты вершины.** Координата вершины — \(x_0 = -\frac{b}{2a}\) (со знаком **минус**). Внутри скобки формулы — \(+\frac{b}{2a}\) (со знаком **плюс**). Это **разные знаки**, и оба правильные.
- **Перепутал min и max.** При \(a > 0\) — минимум (ветви вверх, дно параболы). При \(a < 0\) — максимум (ветви вниз, верх параболы). Смотри на знак \(a\), а не на знак свободного члена.
- **Не проверил раскрытием.** После выделения — раскрой обратно и сверь с исходным трёхчленом. Это ловит 80% ошибок.

> **Запомнить:** формула выделения — \(ax^2 + bx + c = a(x + \frac{b}{2a})^2 - \frac{D}{4a}\). Координата вершины \(x_0 = -\frac{b}{2a}\). Значение в вершине \(f(x_0) = -\frac{D}{4a}\). При \(a > 0\) это минимум, при \(a < 0\) — максимум.

### Задача с полным разбором

**Условие.** Найди наименьшее значение \(f(x) = 2x^2 - 8x + 3\). В какой точке оно достигается?

**Цепочка мыслей:**

1. **Распознаю тип.** Это квадратный трёхчлен с \(a = 2 > 0\). Значит, ветви параболы направлены **вверх** → есть минимум. Именно его ищем.

2. **Запускаю выделение полного квадрата:**
   - Выношу \(a\): \(2(x^2 - 4x) + 3\).
   - Внутри скобок: \(x^2 - 4x\). Половина от \(4\) — это \(2\). Квадрат половинки: \(4\).
   - Прибавляю и вычитаю \(4\): \(x^2 - 4x + 4 - 4 = (x - 2)^2 - 4\).
   - Подставляю обратно: \(2[(x - 2)^2 - 4] + 3\).
   - **Умножаю «хвост» на \(a\):** \(2 \cdot (-4) = -8\).
   - Собираю: \(2(x - 2)^2 - 8 + 3 = 2(x - 2)^2 - 5\).

3. **Анализирую полученное выражение** \(2(x - 2)^2 - 5\):
   - \((x - 2)^2 \geq 0\) — это квадрат, всегда неотрицателен.
   - Значит, \(2(x - 2)^2 \geq 0\).
   - Минимум \(2(x - 2)^2 = 0\) при \(x = 2\).
   - В этой точке \(f(2) = 0 - 5 = -5\).

4. **Проверяю подстановкой в исходную формулу:** \(f(2) = 2 \cdot 4 - 8 \cdot 2 + 3 = 8 - 16 + 3 = -5\) — верно.

5. **Проверяю координату вершины по короткой формуле:** \(x_0 = -\frac{b}{2a} = -\frac{-8}{2 \cdot 2} = \frac{8}{4} = 2\) — совпадает. Значение в вершине: \(-\frac{D}{4a} = -\frac{64 - 24}{8} = -\frac{40}{8} = -5\) — тоже совпадает.

**Ответ:** наименьшее значение = \(-5\), достигается при \(x = 2\).

> **Запомнить:** решил задачу на min/max двумя способами (выделением и формулой вершины) — значит, точно не ошибся. Если один способ даёт \(-5\), а другой \(-4\) — где-то потерял знак или забыл умножить «хвост» на \(a\).

##### Подсекция А. Метод весов (без переписывания с добавкой)

Смотри, «прибавил — вычёл» — рабочий способ, но иногда хочется **без переписывания**. Тогда включаем **метод весов**: сначала строим «идеальную» скобку, потом **балансируем** разницу хвостов.

**Алгоритм (5 шагов):**
1. **Ловим центр.** Берём первые два члена трёхчлена (например, \(x^2 + 2x\)). Знак центра подсказывает знак в скобке.
2. **Ищем половинку центра.** Центр — это удвоенное произведение \(2 \cdot 1 \cdot \text{половинка}\). Делим коэффициент центра пополам.
3. **Записываем идеальную скобку** \((x + \text{половинка})^2\).
4. **Раскрываем** эту скобку и **сравниваем** с исходным трёхчленом — смотрим разницу хвоста.
5. **Балансируем:** добавляем или вычитаем разницу, чтобы восстановить исходное выражение.

**Пример 1.** Выдели квадрат из \(x^2 + 2x - 1\).

- **Ловим центр:** \(+2x\) → скобка со знаком «+» \((x + \ldots)^2\).
- **Половинка центра:** \(2 / 2 = 1\). Идеальная скобка: \((x + 1)^2\).
- **Раскрываем** \((x + 1)^2 = x^2 + 2x + 1\).
- **Сравниваем хвосты:** в исходном трёхчлене \(-1\), в идеальной скобке \(+1\). Разница: \(-1 - 1 = -2\).
- **Балансируем:** вычитаем \(2\). Итог: \((x + 1)^2 - 2\).

**Проверка раскрытием:** \((x + 1)^2 - 2 = x^2 + 2x + 1 - 2 = x^2 + 2x - 1\) — верно.

**Пример 2.** Выдели квадрат из \(x^2 - 6x + 8\).

- **Ловим центр:** \(-6x\) → скобка со знаком «минус» \((x - \ldots)^2\).
- **Половинка:** \(6 / 2 = 3\). Идеальная скобка: \((x - 3)^2\).
- **Раскрываем** \((x - 3)^2 = x^2 - 6x + 9\).
- **Сравниваем хвосты:** в исходном \(+8\), в идеальной \(+9\). Разница: \(8 - 9 = -1\).
- **Балансируем:** вычитаем \(1\). Итог: \((x - 3)^2 - 1\).

**Проверка:** \((x - 3)^2 - 1 = x^2 - 6x + 9 - 1 = x^2 - 6x + 8\) — верно.

> **Запомнить:** метод весов — **ловим центр → половинка → идеальная скобка → раскрываем → сравниваем хвосты → балансируем**. Баланс всегда либо «прибавить», либо «вычесть» — но не «плюс-минус внутри скобок». Никаких \(\pm\) посередине, только итоговая «гирька» в конце.

**Когда метод весов удобнее «прибавил — отнял»:** когда свободный член большой или странный, и не хочется переписывать длинное выражение. Построил идеальную скобку, вычел разницу — готово.

##### Подсекция Б. Случай \(a < 0\) (минус на старте)

Когда перед \(x^2\) стоит **отрицательный** коэффициент, метод весов и «прибавил — вычёл» работают **криво**: знаки путаются на каждом шаге. Поэтому для \(a < 0\) есть **отдельный алгоритм — с выносом минуса**.

**Алгоритм (3 шага):**
1. **Вынеси минус за скобки:** \(-x^2 + bx + c = -(x^2 - bx - c)\). Внутри скобок \(a = 1\) — обычный приведённый трёхчлен.
2. **Работай внутри скобок** любым удобным способом — метод весов или «прибавил — отнял».
3. **Верни внешний минус** обратно, **распределив его на оба члена**: \(-[(x - p)^2 + q] = -(x - p)^2 - q\).

**Пример.** Выделить квадрат из \(-x^2 + 2x + 1\).

1. **Выносим минус:** \(-x^2 + 2x + 1 = -(x^2 - 2x - 1)\).
2. **Работаем внутри** (методом весов):
   - Центр \(-2x\) → половинка \(1\) → идеальная скобка \((x - 1)^2 = x^2 - 2x + 1\).
   - Сравниваем хвосты: внутри нужно \(-1\), получилось \(+1\). Разница: \(-1 - 1 = -2\).
   - Балансируем: вычитаем \(2\). Итого внутри: \((x - 1)^2 - 2\).
3. **Возвращаем внешний минус**, распределяя его на оба куска: \(-[(x - 1)^2 - 2] = -(x - 1)^2 + 2\).

**Проверка:** \(-(x - 1)^2 + 2 = -(x^2 - 2x + 1) + 2 = -x^2 + 2x - 1 + 2 = -x^2 + 2x + 1\) — верно.

> **Запомнить:** при выделении квадрата из трёхчлена с \(a < 0\) **сначала выноси минус** за скобки, потом работай внутри как с обычным трёхчленом, потом **возвращай минус**, распределив его на оба члена. Иначе знаки перепутаются.

**Типичная ловушка — главная причина ошибок.** Если сразу пытаться применить метод весов к \(-x^2 + 2x + 1\), то внутри выделенного квадрата получится \(+1\), а тебе нужно \(-1\). Можно по ошибке написать \(-(x - 1)^2 - 2\) вместо правильного \(-(x - 1)^2 + 2\). Решение одно: **работай внутри общих скобок**, где \(a = 1\), и **только в самом конце применяй внешний минус**.

**Ещё пример для закрепления.** Выделить квадрат из \(-2x^2 + 4x - 5\).

1. **Выносим минус:** \(-2x^2 + 4x - 5 = -(2x^2 - 4x + 5)\).
2. **Работаем внутри** (теперь \(a = 2\), неприведённый случай):
   - Выносим \(2\): \(2(x^2 - 2x) + 5\).
   - Внутри \(x^2 - 2x\): половинка от \(2\) — это \(1\), квадрат \(1\).
   - \(x^2 - 2x + 1 - 1 = (x - 1)^2 - 1\).
   - Подставляем: \(2[(x - 1)^2 - 1] + 5 = 2(x - 1)^2 - 2 + 5 = 2(x - 1)^2 + 3\).
3. **Возвращаем внешний минус:** \(-[2(x - 1)^2 + 3] = -2(x - 1)^2 - 3\).

**Проверка:** \(-2(x - 1)^2 - 3 = -2(x^2 - 2x + 1) - 3 = -2x^2 + 4x - 2 - 3 = -2x^2 + 4x - 5\) — верно.

> **Запомнить:** при \(a < 0\) после вынесения минуса внутри скобок работаем **по общим правилам** (выносим \(a\), выделяем квадрат, балансируем), а внешний минус — **только в самом конце**, распределяя его на всё выражение в скобках.

## СЕКЦИЯ 5. ЧАСТНЫЕ СЛУЧАИ И БИКВАДРАТНЫЕ УРАВНЕНИЯ

### Зачем

Два приёма, которые превращают получасовую возню в тридцать секунд.

**Приём 1 — частные случаи.** Иногда квадратное уравнение «подсказывает» один корень **в самих коэффициентах**: достаточно сложить или вычесть их по определённой формуле. Если угадал — второй корень получается по Виету моментально. Без дискриминанта, без корней из дискриминанта, без дробей.

**Приём 2 — биквадратные уравнения.** Это когда переменная стоит только в чётных степенях: \(x^4\) и \(x^2\). На первый взгляд — степень 4-я, страшно. На деле — обычное квадратное, но через подстановку. Замена \(y = x^2\) — и ты снова в знакомой territory.

**Где встречается:**
- **Частные случаи** — везде, где коэффициенты целые и небольшие. На тестах это спасает, когда нужно быстро отобрать правильный ответ.
- **Биквадратные** — физика колебаний (период связан с \(x^2\)), некоторые уравнения движения по окружности, теория вероятностей (плотности).

### Что это: частные случаи

У квадратного уравнения \(ax^2 + bx + c = 0\) есть **два волшебных соотношения коэффициентов**, которые мгновенно выдают по корню.

**Случай 1: \(a + b + c = 0\).** Тогда \(x_1 = 1\), а второй корень \(x_2 = \dfrac{c}{a}\).

**Почему работает:** подставь \(x = 1\) в уравнение — получится \(a \cdot 1 + b \cdot 1 + c = a + b + c = 0\). Значит, \(x = 1\) обращает уравнение в ноль — это и есть корень.

**Случай 2: \(a - b + c = 0\).** Тогда \(x_1 = -1\), а второй корень \(x_2 = -\dfrac{c}{a}\).

**Почему работает:** подставь \(x = -1\) — получится \(a \cdot 1 + b \cdot (-1) + c = a - b + c = 0\). Значит, \(x = -1\) — корень.

**Что делать с этими корнями:** одного мало, нужно два. Второй корень **находим по Виету**: \(x_1 \cdot x_2 = \dfrac{c}{a}\). Если \(x_1 = 1\) — значит, \(x_2 = \dfrac{c}{a}\). Если \(x_1 = -1\) — значит, \(x_2 = -\dfrac{c}{a}\).

**Главная фишка:** оба случая проверяются за секунду — просто складываешь или вычитаешь три числа. Если получился ноль — у тебя уже есть один корень, второй доберёшь по Виету.

### Что это: биквадратное уравнение

**Определение.** Это уравнение вида \(ax^4 + bx^2 + c = 0\), где переменная стоит **только в чётных степенях**. Никаких \(x^3\), никаких \(x^1\).

**Идея решения:** делаем **замену переменной** \(y = x^2\). Тогда \(x^4 = y^2\), и уравнение превращается в обычное квадратное относительно \(y\):

\[
ay^2 + by + c = 0.
\]

Решаем его дискриминантом или Виетом — получаем корни \(y_1\) и \(y_2\).

**Возврат к \(x\):** здесь кроется главная магия. Каждый \(y_i\) — это квадрат настоящего \(x\), значит:
- Если \(y > 0\): \(x = \pm\sqrt{y}\) — **два** корня.
- Если \(y = 0\): \(x = 0\) — **один** корень.
- Если \(y < 0\): решений **нет** (отрицательное под корнем не бывает).

**Сколько всего корней** получится — зависит от знаков \(y_1\) и \(y_2\). Два положительных \(y\) дают 4 корня. Один ноль и одно положительное — 3 корня. Любой отрицательный — режется в ноль.

### Откуда берётся биквадратное

Это не магия, а **прямое следствие подстановки**. Если в уравнении \(x\) встречается только в чётных степенях, мы **заранее знаем**, что \(x^2\) — это некая «новая переменная», которую можно обозначить через \(y\). Сделали замену — свели задачу к обычному квадратному. Это и есть приём **«замены переменной»** — один из мощнейших в алгебре.

**Почему биквадратное решается так легко:** потому что \(x^2 \geq 0\) всегда. Это значит, что \(y\) — не любое число, а только неотрицательное. Поэтому из отрицательных \(y\) корней не получится — и это **нормально**.

### Как считать

**Частные случаи (3 шага):**

1. **Считаю** \(a + b + c\). Если ноль — корень \(1\) у меня в кармане.
2. **Считаю** \(a - b + c\). Если ноль — корень \(-1\) у меня в кармане.
3. **Если оба ≠ 0** — это обычный случай, считаю дискриминант.

Если угадал корень — второй нахожу по Виету: \(x_2 = \dfrac{c}{a}\) (для \(x_1 = 1\)) или \(x_2 = -\dfrac{c}{a}\) (для \(x_1 = -1\)).

**Биквадратное (3 шага):**

1. **Замена** \(y = x^2\). Получаю обычное квадратное: \(ay^2 + by + c = 0\).
2. **Решаю его** дискриминантом или Виетом — получаю \(y_1\) и \(y_2\).
3. **Возвращаюсь к \(x\)** для каждого \(y_i\):
   - \(y_i > 0\): \(x = \pm\sqrt{y_i}\) — два корня.
   - \(y_i = 0\): \(x = 0\) — один корень.
   - \(y_i < 0\): решений нет.

**Главное — не пропустить знак «\(\pm\)»** при возврате из \(y\) обратно к \(x\).

### Где применить

- **Частные случаи** — любые уравнения с целыми коэффициентами: \(2x^2 + 3x - 5 = 0\), \(5x^2 - 4x - 1 = 0\), \(x^2 - 7x + 6 = 0\). Сначала проверь \(a \pm b + c\), потом берись за дискриминант.
- **Биквадратные** — уравнения с \(x^4\) и без \(x^3, x^1\).
- **Физика и геометрия** — там часто возникают биквадратные из геометрических соотношений.

### Где ошибиться

- **Забыл \(\pm\) при возврате** из биквадратного: \(x^2 = 4\) даёт **два** корня \(x = \pm 2\), не один \(x = 2\). Это самая частая ошибка — теряешь половину ответов.
- **Принял \(y < 0\) за решение**: в биквадратном отрицательное \(y\) не даёт \(x\). Это не «потерянные корни», а **нормальный** отсев.
- **Не проверил частный случай** перед дискриминантом: потратил 3 минуты вместо 30 секунд. Всегда начинай с \(a + b + c\).
- **Перепутал знак** в Виете для случая \(x_1 = -1\): там \(x_1 \cdot x_2 = c/a\), значит \(-1 \cdot x_2 = c/a \Rightarrow x_2 = -c/a\). Не \(+c/a\).

> **Запомнить:** частный случай проверяется за 5 секунд — сложил три коэффициента, посмотрел на ноль. Биквадратное проверяется за 3 секунды — посмотрел, нет ли \(x^3\) или \(x^1\). Если их нет — замена \(y = x^2\) и привет, знакомая задача.

### Задача с полным разбором (биквадратное)

**Условие.** Реши биквадратное уравнение \(x^4 - 5x^2 + 4 = 0\). Сколько корней?

**Цепочка мыслей:**

1. **Распознаю тип.** Уравнение содержит \(x^4\) и \(x^2\), а \(x^3\) и \(x\) отсутствуют. Переменная только в чётных степенях → это биквадратное.

2. **Применяю замену** \(y = x^2\):
   \[
   y^2 - 5y + 4 = 0.
   \]
   Получилось обычное квадратное уравнение с маленькими коэффициентами.

3. **Решаю как обычное квадратное.** Коэффициенты маленькие — пробую Виета. Произведение корней \(4\), сумма \(5\). Перебираю пары: \((1, 4)\) — произведение \(4\), сумма \(5\). Подходит.

4. **Проверяю дискриминантом:** \(D = 25 - 16 = 9 > 0\). Корни: \(\frac{5 \pm 3}{2}\). Получаю \(y_1 = 1\) и \(y_2 = 4\). Совпало с Виетом — значит, не ошибся.

5. **Возвращаюсь к \(x\)** для каждого корня \(y\):
   - \(y_1 = 1 > 0\): \(x^2 = 1 \Rightarrow x = \pm 1\) — два корня.
   - \(y_2 = 4 > 0\): \(x^2 = 4 \Rightarrow x = \pm 2\) — два корня.

6. **Собираю все корни:** \(x \in \{-2, -1, 1, 2\}\).

7. **Проверка подстановкой** (обязательно — ловит потерянные знаки):
   - \(x = 2\): \(16 - 20 + 4 = 0\) — верно.
   - \(x = -1\): \(1 - 5 + 4 = 0\) — верно.
   - \(x = 1\): \(1 - 5 + 4 = 0\) — верно.
   - \(x = -2\): \(16 - 20 + 4 = 0\) — верно.

**Ответ:** четыре корня: \(-2, -1, 1, 2\).

> **Запомнить:** в биквадратном уравнении с двумя положительными \(y\) получается **4 корня**. Если бы один из \(y\) был нулём — было бы 3 корня. Если бы один из \(y\) был отрицательным — было бы 2 корня.

### Задача с полным разбором (частный случай)

**Условие.** Реши уравнение \(3x^2 + 2x - 5 = 0\).

**Цепочка мыслей:**

1. **Распознаю тип.** Квадратное уравнение с \(a = 3, b = 2, c = -5\).

2. **Проверяю частные случаи** (это всегда первый шаг — быстрее дискриминанта):
   - \(a + b + c = 3 + 2 + (-5) = 0\) — попадание!
   - Значит, один из корней = \(1\).

3. **Нахожу второй корень по Виету:** \(x_1 \cdot x_2 = \dfrac{c}{a} = -\dfrac{5}{3}\). Если \(x_1 = 1\), то \(x_2 = -\dfrac{5}{3}\).

4. **Проверяю подстановкой** (без этого никуда):
   - \(x = 1\): \(3 \cdot 1 + 2 \cdot 1 - 5 = 3 + 2 - 5 = 0\) — верно.
   - \(x = -\dfrac{5}{3}\): \(3 \cdot \dfrac{25}{9} + 2 \cdot \left(-\dfrac{5}{3}\right) - 5 = \dfrac{25}{3} - \dfrac{10}{3} - \dfrac{15}{3} = \dfrac{0}{3} = 0\) — верно.

**Ответ:** \(x_1 = 1\), \(x_2 = -\dfrac{5}{3}\).

> **Запомнить:** в задачах с целыми коэффициентами всегда **сначала проверяй** \(a + b + c\) и \(a - b + c\). Если ноль — корень в кармане, второй по Виету. Это не «трюк для теста», это полноценный метод, который экономит минуты.

---

#### Контрольная точка после Секций 4–5

Ты освоил выделение квадрата и быстрые приёмы. Проверь себя:

1. Могу выделить полный квадрат из \(ax^2 + bx + c\) (включая случай \(a \neq 1\)).
2. Понимаю, что минимум/максимум параболы — это ордината вершины.
3. Проверяю частные случаи \(a + b + c = 0\) и \(a - b + c = 0\) **до** дискриминанта.
4. Могу решить биквадратное уравнение через замену \(y = x^2\) и возвращение через \(\pm\sqrt{y}\).
5. Не забываю про \(\pm\) при возврате из биквадратного.

Если хотя бы один пункт — «нет», вернись к соответствующей секции.

## СЕКЦИЯ 6. МНОГОЧЛЕНЫ 3-Й СТЕПЕНИ (ТЕОРЕМА БЕЗУ)

### Зачем

Смотри: квадратные трёхчлены мы раскладываем уверенно — дискриминант или Виет. Но иногда в задаче вылезает **кубическое выражение** (\(x^3, x^2, x\), число). Что с ним делать? Если просто бить дискриминантом — долго и неудобно. Если использовать **предохранитель Безу и группировку** — вылетает за минуту.

**Где встречается:**
- **Рациональные дроби.** Числитель — куб, знаменатель — квадрат. Без разложения числителя дробь не сократишь.
- **Кубические уравнения.** Иногда их решают «угадал корень — поделил — нашёл остаток».
- **Любые задачи**, где \(x^3\) стоит рядом с квадратами или линейными членами.

**Главная идея секции:** есть два приёма — **предохранитель** (быстрая проверка, разложится ли) и **группировка** (само разложение без умных слов). Вместе они дают надёжный метод.

### Что это

**Многочлен 3-й степени** (по-простому — кубическое выражение) — это выражение вида \(ax^3 + bx^2 + cx + d\), где \(a, b, c, d\) — коэффициенты, \(a \neq 0\). Всего четыре числа: одно перед \(x^3\), одно перед \(x^2\), одно перед обыкновенным \(x\), и одно свободное число в конце.

**Теорема Безу (без умных слов):** если подставить в выражение какое-то число и оно превратится в чистый ноль, то выражение **железно делится** на скобку с этим числом, без остатка. Это факт, а не трюк — сейчас увидим почему.

**Предохранитель Безу** — это проверка **до попытки разложения**: смотрим на коэффициенты парами и понимаем, разложится ли вообще нацело, или придётся искать другой путь.

### Откуда берётся всё это

**Идея группировки — простая.** Если у тебя в кубе есть две пары членов, и из каждой пары выносится общий множитель, причём **один и тот же** — ты в деле. Осталось вынести его наружу.

**Почему это работает:** пусть в выражении спрятался множитель \((x + p)\). Это значит, что при подстановке \(x = -p\) всё выражение зануляется. Значит, можно «вытащить» эту скобку из выражения как общий множитель — точно так же, как вытаскиваем \(x\) из \(x^2 + 3x\).

**Откуда знать, есть ли такая скобка вообще:** это и говорит **предохранитель**. Если коэффициенты **делятся в одинаковой пропорции парами** — значит, группировка сработает. Если пропорция ломается — значит, нужного множителя в виде «красивой» скобки нет, и придётся искать корень перебором делителей свободного члена (это дольше, но работает всегда).

### Как считать

#### Приём 1. Предохранитель (проверка пропорции коэффициентов)

**Алгоритм (3 шага):**
1. Запиши коэффициенты парами — (старший, второй) и (третий, свободный).
2. Посчитай отношение в каждой паре.
3. Если отношения совпадают — **предохранитель открыт**, можно разлагать группировкой.

**Пример.** \(x^3 + 5x^2 - 4x - 20\).

- Первая пара: коэффициенты при \(x^3\) и \(x^2\) — это \(1\) и \(5\). Отношение \(1 : 5\).
- Вторая пара: коэффициенты при \(x\) и свободный — это \(-4\) и \(-20\). Отношение \(-4 : -20\). Сокращаем на \(4\) — получается \(1 : 5\).
- Пропорции совпали: \(1 : 5\) в обеих парах. **Предохранитель открыт.**

Если бы вместо \(-20\) стояло \(-17\) — отношение во второй паре было бы \(4 : 17\), и пропорция сломалась. Это сигнал: в уме разложить не получится, нужен другой путь.

> **Запомнить:** пропорция совпала → разложение группировкой **сработает**; пропорция сломалась → разложение на «красивые» целочисленные скобки невозможно, ищи другой путь (перебор делителей свободного члена).

#### Приём 2. Безу без умных слов (разложение группировкой)

Если предохранитель открыт, делаем само разложение — **разбиваем на две семьи и выносим общий множитель**.

**Алгоритм (5 шагов):**
1. **Разбей на две семьи:** обычно (старший член + второй) и (третий + свободный).
2. **Из первой семьи** вынеси общий множитель.
3. **Из второй семьи** вынеси общий множитель.
4. **Должен появиться одинаковый «мешок-скобка»** — вынеси его наружу.
5. **Остаток** (то, что осталось в скобках) раскладывай дальше — часто по ФСУ.

**Пример.** \(x^3 + 5x^2 - 4x - 20\).

- **Семья 1:** \(x^3 + 5x^2 = x^2(x + 5)\).
- **Семья 2:** \(-4x - 20 = -4(x + 5)\).
- **Мешок-скобка:** \((x + 5)\). Выносим:
  \[
  x^3 + 5x^2 - 4x - 20 = x^2(x + 5) - 4(x + 5) = (x + 5)(x^2 - 4).
  \]
- **Остаток:** \(x^2 - 4\). Это разность квадратов: \((x - 2)(x + 2)\).
- **Итог:** \(x^3 + 5x^2 - 4x - 20 = (x + 5)(x - 2)(x + 2)\).

**Проверка подстановкой:** возьмём \(x = -5\) (тот самый «корень предохранителя»): \((-5)^3 + 5 \cdot 25 - 4 \cdot (-5) - 20 = -125 + 125 + 20 - 20 = 0\). Занулилось — значит, делится на \((x + 5)\), верно.

**Второй пример для закрепления.** \(x^3 - 3x^2 - 4x + 12\).

- **Проверяю предохранитель:**
  - Первая пара: \(1\) (при \(x^3\)) и \(-3\) (при \(x^2\)). Отношение \(1 : (-3)\).
  - Вторая пара: \(-4\) (при \(x\)) и \(12\) (свободный). Отношение \(-4 : 12 = 1 : (-3)\).
  - Пропорции совпали → предохранитель открыт.
- **Разбиваю на две семьи:**
  - Семья 1: \(x^3 - 3x^2 = x^2(x - 3)\).
  - Семья 2: \(-4x + 12 = -4(x - 3)\).
- **Мешок-скобка:** \((x - 3)\). Выносим:
  \[
  x^3 - 3x^2 - 4x + 12 = x^2(x - 3) - 4(x - 3) = (x - 3)(x^2 - 4).
  \]
- **Остаток:** \(x^2 - 4 = (x - 2)(x + 2)\) (разность квадратов).
- **Итог:** \(x^3 - 3x^2 - 4x + 12 = (x - 3)(x - 2)(x + 2)\).

**Проверка подстановкой:** \(x = 3\): \(27 - 27 - 12 + 12 = 0\) — делится на \((x - 3)\), верно.

> **Запомнить:** алгоритм — **проверь пропорцию → разбей на две семьи → вынеси общий множитель → раскрой остаток**. Если на шаге 4 не появился одинаковый мешок — значит, ты перепутал разбиение или неверно вынес.

### Где применить

- **Разложение числителя или знаменателя рациональной дроби**, когда это кубическое выражение.
- **Решение кубических уравнений**, если коэффициенты допускают разложение на целые скобки.
- **Сокращение сложных дробей** с кубическими многочленами в числителе и знаменателе.
- **Любые задачи на разложение**, где требуется разбить куб на множители.

### Где ошибиться

- **Пропустил предохранитель** и пытаешься разложить то, что нацело не раскладывается — потеря времени и сил.
- **Перепутал семьи** при разбиении — общий множитель не появится, разложение «заклинит». Если мешка-скобки нет — пробуй другую группировку.
- **Забыл раскрыть остаток** после вынесения мешка. Например, получил \((x + 5)(x^2 - 4)\) и записал как ответ — а нужно ещё дожать до трёх скобок: \((x + 5)(x - 2)(x + 2)\).
- **Потерял ОДЗ после разложения** — нужно исключить значения, при которых любая скобка в знаменателе = 0.
- **Забыл проверить подстановкой** — а ведь \(x = -p\) в подставленном виде должно дать ноль. Если не ноль — ошибся в группировке.

> **Запомнить:** после разложения всегда **подставляй обратно корень в исходное выражение** — должно получиться \(0\). Это самый быстрый способ убедиться, что ты нашёл правильный множитель.

### Задача с полным разбором

**Условие.** Разложи на множители \(x^3 + 5x^2 - 4x - 20\) и сократи \(\dfrac{x^3 + 5x^2 - 4x - 20}{x^2 - 4}\).

**Цепочка мыслей:**

1. **Распознаю задачу.** Числитель — кубическое выражение, знаменатель — разность квадратов. План: разложить числитель по теореме Безу (без умных слов), знаменатель — по ФСУ, потом сократить.

2. **Проверяю предохранитель** для числителя \(x^3 + 5x^2 - 4x - 20\):
   - Первая пара коэффициентов: \(1\) (при \(x^3\)) и \(5\) (при \(x^2\)). Отношение \(1 : 5\).
   - Вторая пара: \(-4\) (при \(x\)) и \(-20\) (свободный). Отношение \(-4 : -20\). Сокращаем на \(4\) — получается \(1 : 5\).
   - Пропорции совпали → **предохранитель открыт**, можно разлагать.

3. **Разбиваю на две семьи:**
   - Семья 1: \(x^3 + 5x^2 = x^2(x + 5)\).
   - Семья 2: \(-4x - 20 = -4(x + 5)\).

4. **Выношу общий мешок** \((x + 5)\) наружу:
   \[
   x^3 + 5x^2 - 4x - 20 = x^2(x + 5) - 4(x + 5) = (x + 5)(x^2 - 4).
   \]

5. **Раскладываю остаток** \(x^2 - 4\) по ФСУ (разность квадратов): \((x - 2)(x + 2)\).

**Промежуточный итог:** числитель разложен на \((x + 5)(x - 2)(x + 2)\). Половина пути пройдена — теперь работаем со знаменателем и сокращаем.

---

**Часть 2. Сокращение дроби и проверка.**

6. **Итог разложения числителя:** \((x + 5)(x - 2)(x + 2)\).

7. **Раскладываю знаменатель:** \(x^2 - 4 = (x - 2)(x + 2)\).

8. **Сокращаю дробь** на общий множитель \((x - 2)(x + 2)\):
   \[
   \frac{(x + 5)(x - 2)(x + 2)}{(x - 2)(x + 2)} = x + 5.
   \]

9. **Нахожу ОДЗ.** Знаменатель исходной дроби не должен быть нулём: \((x - 2)(x + 2) \neq 0 \Rightarrow x \neq 2\) и \(x \neq -2\).

10. **Проверка подстановкой** при \(x = 0\) (входит в ОДЗ):
    - Числитель: \(0 + 0 - 0 - 20 = -20\).
    - Знаменатель: \(0 - 4 = -4\).
    - Дробь: \(-20 / -4 = 5\).
    - Результат \(x + 5\) при \(x = 0\): \(0 + 5 = 5\). Совпало.

**Ответ:** \(\dfrac{x^3 + 5x^2 - 4x - 20}{x^2 - 4} = x + 5\), при \(x \neq 2\) и \(x \neq -2\).

> **Запомнить:** задача на сокращение дроби с кубом в числителе — это всегда **разложить → найти общий множитель → сократить → записать ОДЗ**. Четыре шага, ни одного лишнего.

## СЕКЦИЯ 7. ГЕОМЕТРИЯ ПАРАБОЛЫ (ВЕРШИНА, ВЕТВИ, МИН/МАКС)

### Зачем

Смотри: квадратный трёхчлен \(y = ax^2 + bx + c\) — это не просто алгебраическая формула. Это **график**: кривая в форме буквы U (если ветви вверх) или перевёрнутой U (если ветви вниз). Зная формулу, можно **через вычисления** узнать все ключевые точки параболы — не рисуя, а считая.

Что даёт геометрия:
- **Вершина** — место, где парабола достигает минимума или максимума. Здесь же — ответ на задачи оптимизации.
- **Направление ветвей** — куда «смотрит» парабола: вверх (минимум) или вниз (максимум).
- **Пересечения с осью \(x\)** — это корни уравнения, и их существование зависит от дискриминанта.
- **Ось симметрии** — вертикаль, относительно которой парабола «отзеркалена».

**Где встречается:**
- **Физика.** Траектория мяча под углом — парабола. Максимальная высота — это вершина.
- **Экономика.** Прибыль как функция от цены — парабола. Оптимальная цена — вершина.
- **Архитектура.** Арки, мосты, фонтаны — параболические формы. Зная уравнение, рассчитывают высоту и ширину пролёта.

### Что это

**Координатная плоскость** — это сетка из двух осей: горизонтальная \(x\) и вертикальная \(y\). Любая точка задаётся парой \((x; y)\). У пары чисел \((x; y)\) первое число \(x\) называется **абсцисса** — это горизонтальное положение точки (насколько она сдвинута вправо или влево от центра). Второе число \(y\) называется **ордината** — это вертикальное положение точки (насколько она поднята вверх или опущена вниз от центра). Например, точка \((3; -2)\) — это точка, которая сдвинута на \(3\) вправо и на \(2\) вниз.

**Парабола** — график квадратного трёхчлена \(y = ax^2 + bx + c\). Всегда симметрична относительно своей оси.

**Вершина параболы** — точка, в которой парабола достигает **экстремума**: минимума (если ветви вверх, \(a > 0\)) или максимума (если ветви вниз, \(a < 0\)). Это «дно ямы» или «пик горы».

**Ось симметрии параболы** — вертикальная линия, проходящая через вершину. Левая и правая части параболы — зеркальные копии друг друга.

### Откуда берётся формула вершины

**Идея: парабола симметрична.** Если у неё есть два корня \(x_1\) и \(x_2\), то вершина находится **ровно посередине** между ними:

\[
x_{\text{в}} = \frac{x_1 + x_2}{2}.
\]

Это просто среднее арифметическое корней.

**Подставляем Виета.** Для уравнения \(ax^2 + bx + c = 0\) сумма корней \(x_1 + x_2 = -\dfrac{b}{a}\). Подставляем:

\[
x_{\text{в}} = \frac{-\frac{b}{a}}{2} = -\frac{b}{2a}.
\]

Вот и формула абсциссы вершины — вылезла из Виета за три действия.

**Ордината вершины** — это просто значение функции при \(x = x_{\text{в}}\): подставь найденную абсциссу в исходную формулу и посчитай.

**Важная связка:** значение функции в вершине можно найти **двумя способами** — подстановкой \(x_{\text{в}}\) или через формулу \(-\dfrac{D}{4a}\) из Секции 4. Если оба способа дают одно число — значит, всё правильно.

### Как считать

**Шаг 1. Направление ветвей.**

Смотри на старший коэффициент \(a\):
- \(a > 0\) — ветви **вверх**, минимум в вершине.
- \(a < 0\) — ветви **вниз**, максимум в вершине.
- \(a = 0\) — это уже не парабола, а линейная функция.

**Пример 1.** \(y = 2x^2 + 5x - 3\). \(a = 2 > 0\) → ветви вверх, есть минимум.
**Пример 2.** \(y = -x^2 + 4x - 1\). \(a = -1 < 0\) → ветви вниз, есть максимум.

**Шаг 2. Абсцисса вершины \(x_{\text{в}}\).**

Формула:
\[
x_{\text{в}} = -\frac{b}{2a}.
\]

**Пример.** \(y = x^2 - 6x + 8\), \(a = 1, b = -6\).
\[
x_{\text{в}} = -\frac{-6}{2 \cdot 1} = \frac{6}{2} = 3.
\]

**Шаг 3. Ордината вершины \(y_{\text{в}}\).**

Подставь найденную \(x_{\text{в}}\) в исходную формулу:
\[
y_{\text{в}} = a \cdot x_{\text{в}}^2 + b \cdot x_{\text{в}} + c.
\]

**Пример.** При \(x_{\text{в}} = 3\):
\[
y_{\text{в}} = 3^2 - 6 \cdot 3 + 8 = 9 - 18 + 8 = -1.
\]

**Итог:** вершина в точке \((3; -1)\).

**Шаг 4. Точки пересечения с осью \(x\) (корни).**

Решай уравнение \(ax^2 + bx + c = 0\) через дискриминант или Виет:
- \(D > 0\) — две точки пересечения (два корня).
- \(D = 0\) — одна точка пересечения (парабола касается оси).
- \(D < 0\) — точек пересечения нет (парабола «висит» выше или ниже оси).

**Пример.** Для \(y = x^2 - 6x + 8\): \(D = 36 - 32 = 4 > 0\) → два корня: \(x = 2\) и \(x = 4\).

**Шаг 5. Точка пересечения с осью \(y\).**

Подставь \(x = 0\) в формулу:
\[
y = c.
\]

Это мгновенно: при \(x = 0\) всё выражение, кроме \(c\), обнуляется.

**Пример.** Для \(y = x^2 - 6x + 8\) при \(x = 0\) получаем \(y = 8\). Точка \((0; 8)\).

### Где применить

- **Построение графика** квадратного трёхчлена — нужны вершина, направление ветвей, пересечения с осями.
- **Нахождение min/max** величины: физика (минимальная энергия, максимальная скорость), экономика (максимальная выручка).
- **Задачи оптимизации** — выбрать значение \(x\), при котором функция достигает экстремума.
- **Проверка симметрии** — если знаешь один корень и ось симметрии, второй корень найдёшь сразу.

### Где ошибиться

- **Перепутал знак в формуле абсциссы.** Вершина: \(x_{\text{в}} = -\dfrac{b}{2a}\), а не \(\dfrac{b}{2a}\). Без минуса получишь не то.
- **Забыл, что ордината вершины — это экстремум функции.** При \(a > 0\) это минимум, при \(a < 0\) — максимум. Не путай с произвольным значением функции.
- **Путаешь ось симметрии с осью \(y\).** Ось симметрии — это вертикаль \(x = x_{\text{в}}\), а ось \(y\) — это \(x = 0\). Они совпадают только когда \(b = 0\).
- **Путаешь дискриминант с координатой вершины.** Дискриминант показывает, есть ли пересечения с осью \(x\) (корни), а не координаты вершины.

> **Запомнить:** формула вершины \(x_{\text{в}} = -\dfrac{b}{2a}\) **выводится через Виета** (среднее корней). Поэтому если знаешь корни — не считай \(b\), а бери среднее: \(x_{\text{в}} = \dfrac{x_1 + x_2}{2}\).

### Задача с полным разбором

**Условие.** Построй параболу \(y = x^2 - 6x + 8\): найди вершину, направление ветвей, точки пересечения с осями.

**Цепочка мыслей:**

1. **Распознаю задачу.** Квадратный трёхчлен с \(a = 1, b = -6, c = 8\). Нужно найти все параметры для построения графика.

2. **Направление ветвей.** \(a = 1 > 0\) → ветви **вверх** (минимум).

3. **Абсцисса вершины.**
   \[
   x_{\text{в}} = -\frac{b}{2a} = -\frac{-6}{2 \cdot 1} = 3.
   \]

4. **Ордината вершины.**
   \[
   y_{\text{в}} = 3^2 - 6 \cdot 3 + 8 = 9 - 18 + 8 = -1.
   \]
   Вершина: \((3; -1)\).

5. **Точки пересечения с осью \(x\).** Решаю \(x^2 - 6x + 8 = 0\):
   \[
   D = 36 - 32 = 4, \quad \sqrt{D} = 2.
   \]
   \[
   x_1 = \frac{6 + 2}{2} = 4, \qquad x_2 = \frac{6 - 2}{2} = 2.
   \]
   Точки пересечения: \((2; 0)\) и \((4; 0)\).

**Промежуточный итог:** вершина найдена, корни найдены. Теперь — дополнительные точки и проверка симметрии.

---

**Часть 2. Проверка симметрии и итог.**

6. **Проверка симметрии.** Середина корней: \(\dfrac{2 + 4}{2} = 3\) — совпадает с \(x_{\text{в}}\). Значит, вершина найдена правильно.

7. **Точка пересечения с осью \(y\).** При \(x = 0\): \(y = 0^2 - 6 \cdot 0 + 8 = 8\). Точка: \((0; 8)\).

8. **Ось симметрии.** Вертикальная линия \(x = 3\).

9. **Собираю параметры параболы:**
   - Ветви: **вверх**.
   - Вершина: \((3; -1)\) — минимум функции.
   - Корни: \(x = 2\) и \(x = 4\).
   - Пересечение с \(Oy\): \((0; 8)\).
   - Ось симметрии: \(x = 3\).

**Ответ:** парабола с ветвями вверх, вершиной в \((3; -1)\), пересекает ось \(x\) в точках \(2\) и \(4\), ось \(y\) — в точке \(8\).

> **Запомнить:** после нахождения вершины **всегда проверяй симметрию** — среднее корней должно совпасть с \(x_{\text{в}}\). Если не совпало — где-то потерял знак или ошибся в формуле.

#### Углублённый материал (можно пропустить при первом чтении)

> Ниже — три дополнительных применения параболы: выделенная форма, сдвиги и обратная задача на коэффициенты. Если освоил основной шаг «вершина + направление + корни + ось y» — **этого достаточно** для большинства задач. Возвращайся сюда, когда встретишь обратную задачу или работу со сдвигами.

##### Подсекция А. Парабола в форме выделенного квадрата

Если квадратный трёхчлен уже **выделен** (то есть записан в виде \(y = a(x - x_0)^2 + y_0\)), координаты вершины **видны сразу**:
- абсцисса вершины: \(x_{\text{в}} = x_0\);
- ордината вершины: \(y_{\text{в}} = y_0\).

**Пример 1.** \(y = (x + 2)^2 - 2\). Это \(y = (x - (-2))^2 + (-2)\) → вершина \(x_0 = -2, y_0 = -2\). Точка вершины: \((-2; -2)\).

**Пример 2.** \(y = (x - 5)^2 + 7\). Вершина \((5; 7)\).

**Пример 3.** \(y = -2(x - 1)^2 + 3\). Вершина \((1; 3)\), ветви **вниз** (потому что \(a = -2 < 0\)), максимум в вершине.

**Главная фишка:** если парабола в форме выделенного квадрата, то **все шаги Секции 7 уже сделаны** — вершина, направление ветвей, поведение. Это самая удобная форма для анализа.

##### Подсекция Б. Сдвиги параболы \(y = x^2\)

Парабола \(y = a(x - p)^2 + q\) получается из базовой \(y = x^2\) (или \(y = ax^2\) при \(a \neq 1\)) **сдвигами**:
- сдвиг **вправо на \(|p|\)** (если \(p > 0\)) или **влево на \(|p|\)** (если \(p < 0\));
- сдвиг **вверх на \(q\)** (если \(q > 0\)) или **вниз на \(|q|\)** (если \(q < 0\)).

**Пример 1.** \(y = (x - 4)^2 + 3\) — это \(y = x^2\), сдвинутая на 4 вправо и на 3 вверх. Вершина \((4; 3)\).

**Пример 2.** \(y = (x + 2)^2 - 5\) — это \(y = x^2\), сдвинутая на 2 влево (потому что \(+2\) — это \(-(-2)\), то есть \(p = -2\)) и на 5 вниз. Вершина \((-2; -5)\).

**Пример 3.** \(y = -x^2 + 3\) — это \(y = -x^2\) (ветви вниз), сдвинутая на 3 вверх. Вершина \((0; 3)\).

**Полезный трюк:** запомни **знак «минус» в скобке** даёт **сдвиг влево**. То есть \(y = (x + 5)^2\) — это парабола, сдвинутая влево на 5, а не вправо. Знак «минус» в скобке и направление сдвига имеют **противоположный знак** — это и сбивает с толку.

##### Подсекция В. Нахождение коэффициентов по свойствам параболы

Иногда в задаче известно **свойство** параболы (наименьшее/наибольшее значение, ось симметрии) и нужно **найти сами коэффициенты**. Это обратная задача — идём от свойств к формуле.

**Алгоритм (4 шага):**
1. **Запиши, что дано** (например, «наименьшее значение = \(-3\)»).
2. **Запиши формулу параболы** с неизвестным коэффициентом.
3. **Вырази свойство через координаты вершины.**
4. **Составь уравнение** и реши.

**Пример 1.** Наименьшее значение функции \(y = x^2 + 8x + c\) равно \(-3\). Найди \(c\).

- Абсцисса вершины: \(x_{\text{в}} = -\dfrac{8}{2 \cdot 1} = -4\).
- Ордината вершины (подставляю \(x_{\text{в}} = -4\) в формулу):
  \[
  y_{\text{в}} = (-4)^2 + 8 \cdot (-4) + c = 16 - 32 + c = c - 16.
  \]
- Наименьшее значение = \(y_{\text{в}}\) (потому что \(a = 1 > 0\), ветви вверх, минимум = ордината вершины).
- Уравнение: \(c - 16 = -3 \Rightarrow c = 13\).

**Ответ:** \(c = 13\).

**Пример 2.** Наибольшее значение функции \(y = -x^2 + bx - 31\) достигается в точке \(x = 3\). Найди \(b\).

- Абсцисса вершины: \(x_{\text{в}} = -\dfrac{b}{2 \cdot (-1)} = \dfrac{b}{2}\).
- Условие «достигается в точке \(x = 3\)» означает \(x_{\text{в}} = 3\).
- Уравнение: \(\dfrac{b}{2} = 3 \Rightarrow b = 6\).

**Ответ:** \(b = 6\).

**Пример 3.** Наименьшее значение функции \(y = x^2 + bx - 21\) достигается при \(x = 4\). Найди \(b\).

- Абсцисса вершины: \(x_{\text{в}} = -\dfrac{b}{2 \cdot 1} = -\dfrac{b}{2}\).
- Условие: \(-\dfrac{b}{2} = 4 \Rightarrow b = -8\).

**Ответ:** \(b = -8\).

> **Запомнить:** обратная задача решается **через ту же формулу вершины**. Если знаешь свойство (экстремум, ось симметрии, точку достижения) — выражай его через \(x_{\text{в}} = -\dfrac{b}{2a}\) и составляй равенство. Один шаг — и коэффициент найден.

# СБОРНИК ФОРМУЛ

| Формула | Переменные | Когда использовать | Когда НЕ использовать |
|---|---|---|---|
| \(D = b^2 - 4ac\) | \(a, b, c\) — коэффициенты | Всегда для подсчёта числа корней | — |
| \(x = \dfrac{-b \pm \sqrt{D}}{2a}\) | То же | При \(D \geq 0\) | При \(D < 0\) (корней нет) |
| \(x_1 + x_2 = -\dfrac{b}{a}\), \(x_1 x_2 = \dfrac{c}{a}\) | \(a, b, c\) | Когда коэффициенты целые и небольшие | При дробных/больших коэффициентах |
| \(ax^2 + bx + c = a(x - x_1)(x - x_2)\) | \(x_1, x_2\) — корни | При \(D > 0\) для разложения | При \(D < 0\) (нельзя разложить) |
| \(ax^2 + bx + c = a\left(x + \dfrac{b}{2a}\right)^2 - \dfrac{D}{4a}\) | \(a, b, c\) | Для нахождения min/max | Когда корни не нужны |
| \(a + b + c = 0 \Rightarrow x = 1\) | \(a, b, c\) | **Перед** дискриминантом | При \(a+b+c \neq 0\) |
| \(a - b + c = 0 \Rightarrow x = -1\) | То же | То же | То же |
| \(y = x^2\) для биквадратного | — | Уравнения вида \(ax^4 + bx^2 + c = 0\) | Не подходит для \(x^3\) или \(x^5\) |

# ТИПИЧНЫЕ ЛОВУШКИ

**Ловушка 1.** \(D < 0\) — это **ответ**, не ошибка.

**Ловушка 2.** При сокращении дроби не забудь **ОДЗ**.

**Ловушка 3.** Забыл \(\pm\) при возврате из биквадратного.

**Ловушка 4.** Применил Виета к уравнению с \(D < 0\) — нет действительных корней.

**Ловушка 5.** При выделении полного квадрата с \(a \neq 1\) забыл **умножить «хвост» на \(a\)**.

**Ловушка 6.** Принял \(a+b+c = 0\) за «корень = 1», но забыл найти **второй** корень.

**Ловушка 7.** При сокращении дроби потерял коэффициент \(a\).
