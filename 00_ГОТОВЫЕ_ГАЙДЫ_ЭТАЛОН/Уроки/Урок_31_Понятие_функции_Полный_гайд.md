# Урок 31. Понятие функции. Область определения и множество значений

## Перед тем как начать

Привет. Этот урок — про функцию, центральное понятие всей школьной математики. Функция — это «закон», по которому каждому x соответствует единственное y. Звучит абстрактно, но на практике это «калькулятор»: ты вводишь x, он выдаёт y.

Что я хочу, чтобы ты почувствовал к концу: **функция — это не «график», а правило. График — это способ увидеть правило глазами**.

## Блок 1. Понятие функции

### Что это такое

**Определение.** Функцией называется зависимость переменной y от переменной x, при которой значению x соответствует единственное значение y.

**Обозначения:** y = f(x), где x — независимая переменная (аргумент), y — зависимая переменная (значение функции).

### Способы задания функции

1) **Аналитический** (формула): y = 2x + 1.
2) **Табличный:** таблица значений.
4) **Описательный:** словесное описание.
4) **Графический:** график.

## Блок 2. Область определения и множество значений

### Что это такое

**Область определения D(y)** — это множество всех допустимых значений аргумента x.

**Область значений E(y)** — это множество всех значений, которые принимает y при x ∈ D(y).

### Как находить D(y)

- Если в формуле есть дробь с x, исключи x, при которых знаменатель = 0.
- Если есть √x (или √(...)), подкоренное выражение должно быть ≥ 0.
- Если есть log x, то x > 0.

### Как находить E(y)

- Построй график и посмотри, какие значения y он принимает.
- Или проанализируй функцию аналитически.

## Блок 3. Нули функции и промежутки знакопостоянства

### Нули функции

**Нули функции** — это значения x, при которых f(x) = 0. Чтобы найти, реши уравнение f(x) = 0.

### Промежутки знакопостоянства

**Промежутки знакопостоянства** — это промежутки из D(y), на которых функция принимает только положительные или только отрицательные значения.

- Чтобы найти промежутки, где f(x) > 0, реши неравенство f(x) > 0.
- Чтобы найти, где f(x) < 0, реши f(x) < 0.

---

## Блок 4. Чётность и нечётность

### Что это такое

**Чётная функция:** f(-x) = f(x). График симметричен относительно оси Oy. Пример: y = x².

**Нечётная функция:** f(-x) = -f(x). График симметричен относительно начала координат. Пример: y = x³.

### Как определить

1) Проверь, что D(y) симметрична относительно нуля (если D не симметрична, то функция ни чётная, ни нечётная).
2) Сравни f(-x) и f(x).
3) Если f(-x) = f(x) — чётная.
4) Если f(-x) = -f(x) — нечётная.
5) Иначе — ни та, ни другая.

## Босс-файт

### Задача 1. Найди D(y) и E(y) для y = x² - 4x + 5

**Решение:** D(y) = R (любой x, многочлен). E(y): выделим полный квадрат: y = (x - 2)² + 1 ≥ 1. E(y) = [1; +∞).

### Задача 2. Найди промежутки знакопостоянства y = x² - 9

**Решение:** нули ±3. f(x) > 0 при x < -3 или x > 3. f(x) < 0 при -3 < x < 3.

### Задача 3. Чётная или нечётная y = x⁴ - 5x²?

**Решение:** y(-x) = x⁴ - 5x² = y(x). Чётная.

### Задача 4. Найди нули y = (x² - 1)/(x + 2)

**Решение:** числитель = 0 → x = ±1. Знаменатель ≠ 0 → x ≠ -2. Нули: x = -1, x = 1.
