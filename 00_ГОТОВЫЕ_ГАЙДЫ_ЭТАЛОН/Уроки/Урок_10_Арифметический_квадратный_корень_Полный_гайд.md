# Урок 10. Арифметический квадратный корень

## Перед тем как начать

Привет. Этот урок — про арифметический квадратный корень: что это, какие у него свойства, как им пользоваться. Всё это лежит в основе каждой второй-третьей задачи ЦТ, и без этого не работают ни показательные уравнения, ни иррациональные выражения.

Что я хочу, чтобы ты почувствовал к концу: **квадратный корень — это не страшная конструкция, а самый обычный инструмент «отменить возведение в квадрат»**. Если ты умеешь сказать «2² = 4», то √4 = 2 — это та же самая мысль, развёрнутая в обратную сторону.

### Привычка, которая пригодится на весь урок

Прежде чем решать любую задачу, задай себе четыре вопроса:

1. **Что я вижу?** (√ стоит под числом, в знаменателе, в обеих частях уравнения?)

3. **Что я применю?** (свойство корня, вынесение множителя, сопряжение?)
4. **Что от меня хотят?** (вычислить значение, упростить выражение, избавиться от иррациональности?)

Это не тест, а мгновенная проверка перед тем, как взяться за ручку.

## Блок 1. Что такое арифметический квадратный корень

### Зачем тебе это знать

Без понимания того, что такое √a, ты не сможешь работать с уравнениями (√x = 5), неравенствами (√x > 3), выражениями (√a · √b), задачами на иррациональность (1/(√2 + √1)) и кучей других тем. Это базовый инструмент, который появляется везде.

### Что это такое

**Определение.** Арифметическим квадратным корнем из неотрицательного числа a называется такое неотрицательное число b, что b² = a.

Запись: √a = b, где b ≥ 0 и b² = a.

Это «обратное действие» к возведению в квадрат: если 2² = 4, то √4 = 2. Если 7² = 49, то √49 = 7.

### Откуда взялся запрет на отрицательный результат

Без этого запрета Mатематика ломается. Например, если бы √4 было и 2, и -2 (оба в квадрате дают 4), то выражение √(x²) было бы неоднозначным — оно могло бы равняться и x, и -x. Чтобы этого не было, ввели жёсткое правило: **√a — это всегда неотрицательное число**.

Из этого правила сразу следуют два следствия, которые важны для всей темы:

- √a существует только при a ≥ 0 (потому что в квадрате не может быть отрицательное число).
- √(x²) = |x| (потому что √ возвращает неотрицательное значение, а x² = (-x)², так что оба дают одно и то же расстояние до нуля).

### Как найти √a на практике

Чтобы найти √a, нужно найти такое b ≥ 0, что b² = a. Это работает только для «хороших» a — тех, которые сами являются квадратами целых чисел.

Примеры:
- √1 = 1 (потому что 1² = 1).
- √9 = 3 (потому что 3² = 9).
- √16 = 4 (потому что 4² = 16).
- √100 = 10 (потому что 10² = 100).
- √2 ≈ 1,414 (но это уже не целое число — обычный калькулятор даёт √2 ≈ 1,414).

### Где применить

В уравнениях: √x = 5 → x = 25 (один шаг).
В выражениях: √(a² + 1) — можно вынести √1 = 1? Нет, потому что a² + 1 ≠ (что-то)² в общем случае.
В задачах: найти сторону квадрата по его площади.

### Где ошибиться

**Ловушка «√a — это ±√a».** Нет, √a — это только неотрицательное число. Если в задаче √x = 5, то x = 25, а не ±25.

**Ловушка «√(x²) = x».** На самом деле √(x²) = |x|, не x. Это и есть та причина, по которой ввели запрет на отрицательный √. Если x отрицательный, √(x²) всё равно даст положительное значение.

**Ловушка «√a существует всегда».** Не всегда: √(-1) не существует (ни одно число в квадрате не даёт -1). Условие существования — a ≥ 0.

### Задача с разбором

Решение:

- √(100) = 10, потому что 10² = 100.

Здесь всё просто: √a = b, где b² = a, b ≥ 0. Для «круглых» a это работает без калькулятора.

## Блок 2. Свойства арифметического квадратного корня

### Зачем тебе это знать

Свойства — это то, что превращает «√25 = 5» в инструмент для работы с большими выражениями. Без них ты не сможешь упростить √(a · b) до √a · √b, и каждое выражение будешь считать отдельно. Со свойствами ты берёшь сложное выражение и за пару шагов приводишь его к простому виду.

### Четыре главных свойства

**В жизни (где это реально пригождается):**

- **Физика и волны.** Период колебаний T = 2π · √(l/g). Чтобы посчитать период маятника длиной 1 метр, тебе не нужно знать значение √10 — ты можешь работать с √(l/g) символически.
- **Строительство.** Диагональ квадрата со стороной a — это a√2. Это потому что (a√2)² = 2a² = a² + a². Свойство √(a·b) = √a · √b здесь работает напрямую.
- **География.** Масштаб карты 1:50000 означает, что 1 см на карте = √(50000²) см = 50000 см = 500 м в реальности. Это потому что (1 см)² = 1 см², и √(1·50000²) = 50000.

**Свойство 1. √(a · b) = √a · √b** при a ≥ 0, b ≥ 0.
**Свойство 2. √(a / b) = √a / √b** при a ≥ 0, b > 0.
**Свойство 3. (√a)² = a** при a ≥ 0.
**Свойство 4. √(a²) = |a|** для любого a.

Все они работают при условии неотрицательности подкоренного выражения. Это важно: **√(-4) не существует**, поэтому и √(-4 · 9) нельзя превратить в √(-4) · √9.

### Откуда они берутся

Каждое свойство — это «отмена» возведения в квадрат или умножения.

Свойство 1: (√a · √b)² = (√a)² · (√b)² = a · b, значит √a · √b — это такой b, что b² = a · b, то есть √(a · b).

Свойство 2: аналогично через деление.

Свойство 3: это прямо определение корня — √a такое число, что его квадрат = a.

Свойство 4: из определения, что √ возвращает неотрицательное.

### Как пользоваться свойствами

Алгоритм: видишь √(a · b) или √(a / b) — раскрывай по свойствам. Видишь (√a)² — убирай квадрат и знак корня, но помни, что a ≥ 0. Видишь √(a²) — пиши |a|.

Примеры:
- √(9 · 16) = √9 · √16 = 3 · 4 = 12.
- √(100 / 4) = √100 / √4 = 10 / 2 = 5.
- (√5)² = 5.
- √((-3)²) = |-3| = 3, не -3.

### Где применить

В упрощении длинных выражений: √(a² · b) = a · √b (если a ≥ 0).
В сравнении чисел: √50 = √(25 · 2) = 5√2 ≈ 7,07.
В уравнениях: √(x² - 6x + 9) = √((x - 3)²) = |x - 3|.

### Где ошибиться

**Ловушка «√(a + b) = √a + √b».** Это не работает ни для какого a + b > 0. Контрпример: √(9 + 16) = √25 = 5, а √9 + √16 = 3 + 4 = 7. 5 ≠ 7.

**Ловушка «√(a²) = x, если x = √(a²)».** Нет √(x²) = |x|, не x. Если x = -3, то √(9) = 3, не -3.

**Ловушка «√(-4 · 9) = √(-4) · √9».** √(-36) не существует. Свойство работает только при неотрицательных подкоренных.

### Задача с разбором

**Задача.** Вычисли √(18 · 50).

Решение:
1. Ищу «круглые» множители внутри 18 · 50.

3. √(9 · 25 · 4) = √9 · √25 · √4 = 3 · 5 · 2 = 30.

**Ответ: 30.**

## Блок 3. Вынесение множителя из-под знака корня

### Зачем тебе это знать

Потому что в задачах ЦТ 80% иррациональных выражений даны в форме «√(8 · 10)», и без вынесения множителя ты не поймёшь, что √8 = 2√2. Без этого ты не сможешь сравнить два корня или привести выражение к «удобному» виду.

### Что это такое

Если под корнем стоит произведение числа и квадрата, число можно вынести:

√(a² · b) = a · √b (при a ≥ 0).

Пример: √(9 · 2) = √9 · √2 = 3√2. Это и есть вынесение: 9 вышло из-под корня как 3.

### Откуда это берётся

Из Свойства 1 (√(a · b) = √a · √b). Если a само — точный квадрат (1, 9, 25, …), его корень — целое число, и его умножают на оставшийся корень.

### Как выносить — алгоритм

1. Разложи подкоренное выражение на множители.
2. Выдели множитель, который является точным квадратом (1, 4, 9, 16, 25, 36, 49, 64, 81, 100, …).
3. Вынеси корень из этого множителя как целое число.
4. Оставшийся множитель — под корнем.

Пример:
- √(75) = √(25 · 3) = √25 · √3 = 5√3.
- √(180) = √(36 · 5) = √36 · √5 = 6√5.
- √(48) = √(16 · 3) = √16 · √3 = 4√3.
- √(20) = √(4 · 5) = 2√5.

### Где применить

При упрощении: √a^4 = a² (при a ≥ 0).
При сравнении: √75 vs √27 — после вынесения 5√3 vs 3√3, ясно что первое больше.
При подготовке к избавлению от иррациональности.

### Где ошибиться

**Ловушка «√(a + b) = √a + √b».** Здесь не работает, потому что это сумма, не произведение.

**Ловушка «корень из 75 = 8, потому что 8² ≈ 75».** Нет, 8² = 64, а √75 — иррациональное число, не целое. Вынесение даёт 5√3 ≈ 8,66, но это не точное значение, а приближение.

**Ловушка «вынес с минусом».** √(a²) = |a|, не a. Если a < 0, выносится |a|, не -a.

### Задача с разбором

**Задача.** Вынеси множитель из-под знака корня в √(180).

**Разбор:**
1. 180 = 36 · 5 (потому что 36² = 36², и 36 · 5 = 180).
2. √(180) = √(36 · 5) = √36 · √5 = 6√5.

**Ответ: 6√5.**

## Блок 4. Внесение множителя под знак корня

### Зачем тебе это знать

Потому что в задачах часто нужно сделать обратную операцию: взять 2√3 и превратить в √(4 · 3) = √12. Это нужно, когда в задаче требуется сравнить два выражения, или когда нужно привести подобные слагаемые с корнями.

### Что это такое

Если множитель перед корнем неотрицательный (a ≥ 0), его можно внести под корень, возведя в квадрат:

a · √b = √(a² · b).

Пример: 2√3 = √(2² · 3) = √12.

### Откуда это берётся

Из Свойства 3 в обратную сторону: (√a)² = a. Если a ≥ 0, то √a = √((√a)²) = √a · a. Значит, a · √b = √a · √b · √b = √(a² · b).

### Как вносить — алгоритм

1. Возведи множитель перед корнем в квадрат.
2. Умножь на то, что стоит под корнем.
3. Запиши результат под одним корнем.

Примеры:
- 2√3 = √(4 · 3) = √12.
- 5√2 = √(25 · 2) = √50.
- 3√7 = √(9 · 7) = √63.
- a√b = √(a² · b).

### Где применить

При сравнении: 3√5 vs √40 = √45 — после введения 3√5 = √45, и они равны.
При приведении подобных: √12 + √27 = 2√3 + 3√3 = 5√3.
При работе с уравнениями с корнем: x · √3 = √(3x²).

### Где ошибиться

**Ловушка «вносим множитель с минусом».** Если a < 0, нельзя внести под корень так просто: (-2)√3 = √(4 · 3) только если a = |a|. На самом деле (-2)√3 = -√12 = √12 только если результат интерпретируется через знак. Для простоты: вноси только положительные множители.

**Ловушка «√a · a = √(a²)».** На самом деле √a · a = a√a. И только если a ≥ 0, то a√a = √(a² · a) = √(a³).

**Ловушка «внесение меняет знак».** Внесение не меняет знак всего выражения. Если перед корнем стоял «−», то √a и -√a — разные вещи.

### Задача с разбором

**Задача.** Внеси множитель под знак корня: 2√5.

**Разбор:**
1. Возводим 2 в квадрат: 2² = 4.
2. Умножаем на то, что под корнем: 4 · 5 = 20.
3. Записываем под одним корнем: 2√5 = √20.

**Ответ: √20.**

## Блок 5. Избавление от иррациональности в знаменателе

### Зачем тебе это знать

Потому что в задачах ЦТ (и вообще в математике) принято писать ответ без корня в знаменателе. Это не прихоть, а соглашение, и за его нарушение могут снять баллы.

### Что это такое

Если в знаменателе стоит корень (или выражение с корнем), от него избавляются, умножая числитель и знаменатель на подходящее выражение.

**Базовый случай:** 1/√a = √a / a (при a > 0).

Пример: 1/√2 = √2 / 2.

### Откуда это берётся

Из умножения на 1. Умножая и числитель, и знаменатель на одно и то же число, мы не меняем значение дроби, но можем убрать корень из знаменателя. В простейшем случае 1/√a умножаем на √a/√a — получается √a / a (потому что √a · √a = a).

### Как избавляться — алгоритм

**Случай 1.** Знаменатель — просто корень. Умножаем на этот же корень.

1/√a = (1 · √a) / (√a · √a) = √a / a.

**Случай 2.** Знаменатель — сумма с корнем. Умножаем на «сопряжённое» — то же выражение, но с минусом.

1 / (√a + √b) = (√a - √b) / ((√a)² - (√b)²) = (√a - √b) / (a - b).

Пример: 1 / (√2 + 1) = (√2 - 1) / ((√2)² - 1²) = (√2 - 1) / 1 = √2 - 1.

### Где применить

При упрощении дробей: 3/√5 = 3√5 / 5.
При сравнении: √3 / 2 vs √5 / 3 — после избавления становится яснее.
При решении уравнений с иррациональностью.

### Где ошибиться

**Ловушка «умножил только числитель».** Нужно умножать и числитель, и знаменатель — иначе ты меняешь значение дроби.

**Ловушка «сопряжённое к √a + √b — это -√a - √b».** Сопряжённое — это выражение с противоположным знаком при одном из корней. Если в знаменателе √a + √b, сопряжённое — √a - √b (или -√a + √b, что то же самое).

**Ловушка «неправильное использование разности квадратов».** (√a + √b)(√a - √b) = a - b. Не a + b и не a² - b².

### Задача с разбором

**Задача.** Избавься от иррациональности в знаменателе: 1/√3.

**Разбор:**
1. Умножаем числитель и знаменатель на √3.
2. Получаем: √3 / (√3 · √3) = √3 / 3.

**Ответ: √3 / 3.**

## Босс-файт: задачи ЦТ на арифметический квадратный корень

Четыре задачи по образцу ЦТ — на вычисление, упрощение и работу с модулем. Каждая задача разобрана по шагам, ответ явно выделен жирным.

> **Замечание о задаче 1.** В исходных слайдах задача записана как `√2 + √7 - 2√10` с ответом √5, но численная проверка показывает, что ответ √5 неверен (получается -2,265). Скорее всего, в исходнике потеряны скобки. Корректная формулировка: `√2 + √(7 - 2√10) = √5`. Дальше в гайде используется именно она. Этот пример — урок для ученика: всегда проверяй ответ численно, если ответ из учебника не совпадает с твоим.

> **Замечание о задаче 4.** В исходных слайдах условие записано как `(5+3√3)² + (5-3√3)²`, но это даёт 104, а не вариант 6√3. По решению и ответу исходника видно, что условие должно быть `|5+3√3| + |5-3√3|`. Корректная формулировка использована ниже.

### Задача 1. (по образцу ЦТ_2018) Вычисли √2 + √(7 - 2√10)

**Условие.** Упрости √2 + √(7 - 2√10).

**Шаг 1.** Под корнем 7 - 2√10. Ищем такое выражение, которое в квадрате даёт (√a - √b)² = a + b - 2√(ab).

Подбираем: 2√(ab) = 2√10 → √(ab) = √10 → ab = 10. a + b = 7.

Подбор: a = 5, b = 2. Проверим: a + b = 5 + 2 = 7 ✓. ab = 5 · 2 = 10 ✓.

Значит, 7 - 2√10 = (√5 - √2)².

**Шаг 2.** √(7 - 2√10) = √((√5 - √2)²) = |√5 - √2| = √5 - √2 (потому что √5 > √2).

**Шаг 3.** √2 + √(7 - 2√10) = √2 + √5 - √2 = √5.

**Ответ: √5.**

### Задача 2. (ЦТ2021) Упрости |a-6| - |a| при 1/6 < a < 3/8

**Условие.** При 1/6 < a < 3/8 найди |a-6| - |a|.

**Шаг 1.** Определяем диапазон. 1/6 ≈ 0,167, 3/8 = 0,375. Значит, 0,167 < a < 0,375.

**Шаг 2.** Определяем знаки. a > 0, значит |a| = a. a < 6 (потому что a < 0,375 < 6), значит a - 6 < 0, значит |a - 6| = -(a - 6) = 6 - a.

**Шаг 3.** Подставляем: |a-6| - |a| = (6 - a) - a = 6 - 2a.

**Проверка.** При a = 1/4: |1/4 - 6| - |1/4| = |−5,75| - 0,25 = 5,75 - 0,25 = 5,5. По формуле: 6 - 2 · 1/4 = 6 - 0,5 = 5,5. ✓

**Ответ: 6 - 2a.**

### Задача 3. (ЦТ2017) Вычисли 8√3 + (1/8) · √192

**Условие.** Найди значение выражения 8√3 + (1/8) · √192.

**Шаг 1.** √192 = √(64 · 3) = √64 · √3 = 8√3.

**Шаг 2.** (1/8) · √192 = (1/8) · 8√3 = √3.

**Шаг 3.** 8√3 + √3 = (8 + 1)√3 = 9√3.

**Проверка.** 8√3 ≈ 8 · 1.732 = 13,856. (1/8) · √192 ≈ (1/8) · 13,856 = 1,732. Итого ≈ 15,588. По формуле: 9√3 ≈ 15,588. ✓

**Ответ: 9√3.**

### Задача 4. (ЦТ2018, исправлено) Вычисли |5+3√3| + |5-3√3|

**Условие.** Найди значение |5+3√3| + |5-3√3|.

**Шаг 1.** Определяем знаки. 5² = 25, (3√3)² = 9 · 3 = 27. Значит 5 < 3√3 ≈ 5,196. То есть 3√3 > 5.

**Шаг 2.** 5 + 3√3 > 0 (потому что 3√3 > 0). Значит |5+3√3| = 5 + 3√3.

5 - 3√3 < 0 (потому что 5 < 3√3). Значит |5-3√3| = -(5 - 3√3) = 3√3 - 5.

**Шаг 3.** |5+3√3| + |5-3√3| = (5 + 3√3) + (3√3 - 5) = 6√3.

**Ответ: 6√3.**

## Сборник формул

### Определение

√a = b, где b ≥ 0 и b² = a. Условие: a ≥ 0.

### Свойства

- √(a · b) = √a · √b при a ≥ 0, b ≥ 0.
- √(a / b) = √a / √b при a ≥ 0, b > 0.
- (√a)² = a при a ≥ 0.
- √(a²) = |a| для любого a.

### Вынесение и внесение

- Вынесение: √(a² · b) = a · √b при a ≥ 0.
- Внесение: a · √b = √(a² · b) при a ≥ 0.

### Избавление от иррациональности

- 1/√a = √a / a при a > 0.
- 1/(√a + √b) = (√a - √b) / (a - b) при a ≠ b.

### Дискриминатор

**Когда работает:** a ≥ 0 (для √a), a > 0 (для 1/√a).
**Когда не работает:** √(-1) не существует. √(a + b) ≠ √a + √b.
