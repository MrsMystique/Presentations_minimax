## Перед тем как начать

Привет. Этот урок — про корень n-й степени: что это, как отличить от квадратного корня, какие у него свойства, и где он применяется. Ты уже знаешь √a — это корень 2-й степени. Сейчас мы расширим идею на n-ю степень: ∛a, ⁴√a, ⁵√a, и т.д.

Что я хочу, чтобы ты почувствовал к концу: **корень n-й степени — это та же идея «отменить возведение в n-ю степень»**, что и квадратный корень, только теперь «n» любое натуральное число. Если ты умеешь сказать «3³ = 27», то ∛27 = 3 — та же самая мысль.

## Блок 1. Что такое корень n-й степени

### Зачем тебе это знать

Потому что квадратный корень — это только вершина айсберга. Кубические корни встречаются в физике (объём шара, время падения), в геометрии (сторона куба), в химии (концентрация растворов). Без них ты не сможешь прочитать половину задач ЦТ.

### Что это такое

**Определение.** Корнем n-й степени из числа a называется такое число b, что b^n = a.

Запись: ⁿ√a = b, где b^n = a.

Если n = 2 — это квадратный корень √a (ты знаешь с Урока 10).
Если n = 3 — кубический корень ∛a.
Если n = 4 — корень четвёртой степени ⁴√a.
И так далее, n — любое натуральное число.

### Откуда

Та же идея, что и в квадратном корне, но «отменяем» возведение не в квадрат, а в n-ю степень. Если 3³ = 27, то ∛27 = 3. Если 2⁴ = 16, то ⁴√16 = 2.

### Важное различие чётных и нечётных корней

Здесь появляется критическая развилка: поведение корня зависит от чётности n.

**Чётные корни (n = 2, 4, 6, …).** Корень чётной степени **всегда возвращает неотрицательное число**, даже если в задаче «минус под корнем». Это потому что в чётной степени любое число даёт неотрицательный результат: (-3)² = 9, (-3)⁴ = 81.

- ⁴√16 = 2 (а не ±2).
- √4 = 2.
- ⁴√(-16) не существует.

**Нечётные корни (n = 3, 5, 7, …).** Корень нечётной степени **сохраняет знак** исходного числа. Если под корнем минус, ответ тоже минус.

- ∛(-8) = -2.
- ∛8 = 2.
- ∛27 = 3.
- ⁵√(-32) = -2.

Это потому что в нечётной степени: (-2)³ = -8, (-2)⁵ = -32, и так далее.

### Как найти корень

Нужно найти такое b, что b^n = a. Для «хороших» a (8, 27, 16, 64, 32, 128) это делается в уме.

Примеры:
- ∛8 = 2, потому что 2³ = 8.
- ∛27 = 3, потому что 3³ = 27.
- ⁴√16 = 2, потому что 2⁴ = 16.
- ⁴√81 = 3, потому что 3⁴ = 81.
- ∛64 = 4, потому что 4³ = 64.
- ⁵√32 = 2, потому что 2⁵ = 32.

### Где применить

- В уравнениях: ∛x = 3 → x = 27.
- В выражениях: ⁵√(32 · a) = ⁵√32 · ⁵√a = 2 · ⁵√a.
- В вычислениях: среднее геометрическое (позже в этом уроке).

### Где ошибиться

**Ловушка «⁴√16 = ±2».** Нет, ⁴√16 = 2, потому что корень чётной степени всегда неотрицательный.

**Ловушка «∛-8 не существует».** Существует! ∛(-8) = -2, потому что (-2)³ = -8.

**Ловушка «корня чётной степени из отрицательного числа нет».** Правильно, нет: ⁴√(-16) не существует, потому что любое число в 4-й степени даёт неотрицательный результат.

### Задача с разбором

**Задача.** Вычисли: ∛125, ⁴√81, ⁵√-32.

Решение:
- ∛125 = 5, потому что 5³ = 125.
- ⁴√81 = 3, потому что 3⁴ = 81.
- ⁵√(-32) = -2, потому что (-2)⁵ = -32.

**Закономерность:** если знаешь степени маленьких чисел (2ⁿ, 3ⁿ, 4ⁿ…), то и обратно — корни из этих степеней — будут маленькие целые числа.

## Блок 2. Свойства корня чётной степени

### Зачем тебе это знать

Потому что квадратный корень (и все чётные) — это самые капризные из всех корней. Без понимания их свойств ты не сможешь работать с выражениями вроде √(a · b), √(a / b), √(a²). А ведь это самые частые в задачах.

### Четыре свойства

**Свойство 1. √(a · b) = √a · √b** при a ≥ 0, b ≥ 0.
**Свойство 2. √(a / b) = √a / √b** при a ≥ 0, b > 0.
**Свойство 3. (√a)² = a** при a ≥ 0.
**Свойство 4. √(a²) = |a|** для любого a.

Те же, что и для квадратного корня! Распространяются автоматически на любой чётный корень n = 2k: ²ᵏ√(a · b) = ²ᵏ√a · ²ᵏ√b и так далее.

### Откуда

Из определения. Если b² = a, то (√a · √b)² = a · b, значит √a · √b — это такое c, что c² = a · b, то есть √(a · b). Аналогично для остальных свойств.

### Как пользоваться

Алгоритм — тот же, что и для квадратного корня:
- √(a · b) → √a · √b.
- √(a / b) → √a / √b.
- (√a)² → a.
- √(a²) → |a|.

### Где применить

В упрощении: √(18 · 50) = √18 · √50 = 3√2 · 5√2 = 3 · 5 · 2 = 30.
В дробях: √(x² · y) = √x² · √y = |x| · √y.
В уравнениях: √(x² - 6x + 9) = |x - 3|.

### Где ошибиться

**Ловушка «√(a + b) = √a + √b».** Никогда не работает. Контрпример: √(9 + 16) = 5, а √9 + √16 = 7.

**Ловушка «√(x²) = x».** Нет, √(x²) = |x|. Если x = -3, то √(x²) = 3, не -3.

**Ловушка «√(-4) = -2».** Нет, √(-4) не существует (под корнем отрицательное число).

### Задача с разбором

**Задача.** Вычисли √(18 · 50).

**Разбор:**
1. √(18 · 50) = √18 · √50 = (3√2) · (5√2) = 15 · 2 = 30.

**Ответ: 30.**

<summary>Подсказка 2 (конкретный шаг)</summary>

## Блок 3. Свойства корня нечётной степени

### Зачем тебе это знать

Потому что кубические корни и корни более высоких нечётных степеней ведут себя **ровно так же, как целые степени** — с одним важным отличием: они сохраняют знак. Если ты это понимаешь, все свойства переносятся автоматически.

### Четыре свойства

**Свойство 1. ∛(a · b) = ∛a · ∛b** при a ≥ 0, b ≥ 0 (и для отрицательных тоже — с минусами).
**Свойство 2. ∛(a / b) = ∛a / ∛b** при b ≠ 0.
**Свойство 3. (∛a)³ = a** при любом a.
**Свойство 4. ∛(a³) = a** при любом a.

Свойства 1 и 2 имеют более широкий диапазон — работают для всех a, b (с учётом знака).

### Откуда

Из определения корня: ∛a — это b, где b³ = a. Тогда (∛a · ∛b)³ = a · b, значит ∛a · ∛b — это кубический корень из a · b. Аналогично для остальных свойств.

### Главное отличие от чётного корня

Ключевое: **для нечётного корня √(x²) = x** (не |x|). Это потому что кубический корень сохраняет знак. ∛(-8) = -2, поэтому ∛((-2)³) = -2.

| Выражение: x. | Чётный корень | Нечётный корень |
|---|---|---|
| √(x²) | \|x\| | x |
| √(-a) при a > 0 | не существует | -∛a |
| √a · √a | a (при a ≥ 0) | a (при любом a) |

### Как пользоваться

Всё так же, как для чётного корня, но без модуля для квадратов. Например:
- ∛(x³) = x (всегда, не |x|).
- ∛(8x³) = ∛8 · ∛x³ = 2x.

### Где применить

В упрощении: ∛(54x³) = ∛(27 · 2 · x³) = 3x · ∛2 = 3x∛2.
В уравнениях: ∛(x³) = 2 → x = 2.
В разложении на множители: x³ + 8 = (x + 2)(x² - 2x + 4) — формула суммы кубов.

### Где ошибиться

**Ловушка «∛(-8) не существует».** Существует: ∛(-8) = -2, потому что (-2)³ = -8.

**Ловушка «∛(x²) = |x|».** Нет, ∛(x²) — это вообще другое выражение. ∛(x²) = (x²)^(1/3) = x^(2/3). Здесь модуль не нужен.

**Ловушка «∛(x³) = |x|».** Нет, ∛(x³) = x. Это и есть главное отличие нечётного корня.

### Задача с разбором

**Задача.** Упрости ∛(54x³).

**Разбор:**
1. 54 = 27 · 2. Значит ∛(54x³) = ∛(27 · 2 · x³).
2. По свойствам: = ∛27 · ∛2 · ∛x³ = 3 · ∛2 · x = 3x∛2.

**Ответ: 3x∛2.**

### Реши сам

**Задача 1.** Вычисли ∛(-27).

> Подсказка 1 (направление): нечётный корень сохраняет знак.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

Ищи число, куб которого равен -27.
</details>

<details>
<summary>Разбор</summary>

(-3)³ = -27, значит ∛(-27) = -3. **Ответ: -3.**
</details>

<summary>Разбор</summary>

## Блок 4. Свойства корня n-й степени (общие)

### Зачем тебе это знать

Потому что здесь собираются воединые случаи — и для чётных, и для нечётных корней. Это место, где ты видишь общую картину и перестаёшь разделять «одно правило для √, другое для ∛».

### Главные свойства

**Свойство 1. ⁿ√(a · b) = ⁿ√a · ⁿ√b** при a ≥ 0, b ≥ 0.
**Свойство 2. ⁿ√(a / b) = ⁿ√a / ⁿ√b** при a ≥ 0, b > 0.
**Свойство 3. (ⁿ√a)ⁿ = a** при a ≥ 0.
**Свойство 4. ⁿ√(aⁿ) = a** (только для нечётных n).

### Объяснение через степени

Всё проще, если ты помнишь, что ⁿ√a = a^(1/n). Тогда:

- ⁿ√(a · b) = (a · b)^(1/n) = a^(1/n) · b^(1/n) = ⁿ√a · ⁿ√b.
- (ⁿ√a)ⁿ = (a^(1/n))ⁿ = a.
- ⁿ√(aⁿ) = (aⁿ)^(1/n) = a (только для нечётных n, для чётных будет |a|).

### Где применить

В упрощении: ⁵√(32 · a⁵) = ⁵√32 · ⁵√a⁵ = 2 · a = 2a.
В вынесении: ⁵√(32 · x⁵) = 2x.
В освобождении от иррациональности.

### Где ошибиться

**Ловушка «⁴√(a⁴) = a для всех a».** Нет, ⁴√(a⁴) = |a|. Только ⁵√(a⁵) = a для всех a (нечётная степень).

**Ловушка «ⁿ√(a + b) = ⁿ√a + ⁿ√b».** Не работает. Контрпример: ∛(8 + 27) = ∛35 ≈ 3,27, а ∛8 + ∛27 = 2 + 3 = 5.

### Задача с разбором

**Задача.** Упрости ⁵√(32a⁵).

**Разбор:**
1. ⁵√(32a⁵) = ⁵√32 · ⁵√a⁵ = 2 · a = 2a.

**Ответ: 2a.**

### Реши сам

**Задача 1.** Упрости ∛(8x³y⁶).

<details>
<summary>Подсказка 2</summary>

∛8 = 2, ∛x³ = x, ∛y⁶ = y².
</details>

<details>
<summary>Разбор</summary>

∛(8x³y⁶) = 2 · x · y² = 2xy². **Ответ: 2xy².**
</details>

**Задача 2.** Упрости ⁴√(16a⁴).

<details>
<summary>Подсказка 2</summary>

⁴√16 = 2, ⁴√a⁴ = |a|.
</details>

<details>
<summary>Разбор</summary>

⁴√(16a⁴) = 2 · |a| = 2|a|. **Ответ: 2|a|.**
</details>

**Задача 3.** Упрости ⁵√(32a⁵b⁵).

<details>
<summary>Подсказка 2</summary>

⁵√32 = 2, а⁵⁵√ = a, b⁵⁵√ = b.
</details>

<details>
<summary>Разбор</summary>

⁵√(32a⁵b⁵) = 2 · a · b = 2ab. **Ответ: 2ab.**
</details>

- Я знаю 4 общих свойства корня n-й степени

- Я умею применять свойства к упрощению

## Блок 5. Освобождение от иррациональности в знаменателе

### Зачем тебе это знать

Потому что в задачах ЦТ принято писать ответ без корня в знаменателе. Это соглашение, и за его нарушение могут снять баллы. Особенно это важно для корней n-й степени, где обычный приём (умножение на сам корень) не всегда срабатывает.

### Что это такое

Если в знаменателе стоит корень n-й степени, от него избавляются умножением на подходящее выражение.

### Способы

**Способ 1. Для простого корня.** 1/ⁿ√a = ⁿ√(aⁿ⁻¹) / a (при a > 0).

Примеры:
- 1/√3 = √3/3 (потому что √3 · √3 = 3).
- 1/∛2 = ∛4/2 (потому что ∛2 · ∛4 = ∛8 = 2).
- 1/⁴√2 = ⁴√8/2 (потому что ⁴√2 · ⁴√8 = ⁴√16 = 2).

**Способ 2. Для суммы с корнем.** Используем формулу разности n-х степеней или сопряжённое выражение.

Пример: 1/(∛a + ∛b) = (∛a² - ∛(ab) + ∛b²) / (a - b) — это формула для суммы кубических корней. Но это уже продвинутый уровень, в ЦТ редко нужно.

### Откуда это берётся

Умножением на 1. Умножая числитель и знаменатель на ⁿ√(aⁿ⁻¹), мы получаем в знаменателе a (потому что ⁿ√a · ⁿ√(aⁿ⁻¹) = ⁿ√(aⁿ) = a).

### Как избавляться — алгоритм

**Случай 1.** Знаменатель — просто корень n-й степени.

1/ⁿ√a = (1 · ⁿ√(aⁿ⁻¹)) / (ⁿ√a · ⁿ√(aⁿ⁻¹)) = ⁿ√(aⁿ⁻¹) / a.

**Случай 2.** Знаменатель — сумма/разность корней. Используем сопряжённое.

### Где применить

В упрощении: 3/∛5 = 3∛25/5.
В сравнении: ∛2/3 vs ∛3/4 — после освобождения становится яснее.

### Где ошибиться

**Ловушка «1/∛2 = ∛2/2».** Неправильно! 1/∛2 = ∛4/2, потому что ∛2 · ∛4 = ∛8 = 2, а ∛2 · ∛2 = ∛4 ≠ 2.

**Ловушка «умножил только числитель».** Нужно умножать и числитель, и знаменатель, иначе ты меняешь значение дроби.

### Задача с разбором

**Задача.** Освободись от иррациональности: 1/∛2.

**Разбор:**
1. Умножаем числитель и знаменатель на ∛4 (потому что ∛2 · ∛4 = ∛8 = 2).
2. Получаем: ∛4 / 2.

**Ответ: ∛4/2.**

## Блок 6. Среднее геометрическое

### Зачем тебе это знать

Среднее геометрическое — частый гость в задачах ЦТ. Это инструмент, который позволяет «сгладить» два числа в одно, симметричное по отношению к умножению (среднее арифметическое симметрично по сложению).

### Что это такое

**Определение.** Среднее геометрическое n чисел a₁, a₂, …, aₙ — это ⁿ√(a₁ · a₂ · … · aₙ).

Для двух чисел: среднее геометрическое a и b — это √(a · b).

### Откуда

Если все числа одинаковы и равны x, то среднее геометрическое n чисел = ⁿ√(xⁿ) = x. То есть если все числа равны x, то среднее геометрическое = x. Это согласуется с интуицией «среднее».

### Как пользоваться

Для двух чисел a и b: среднее геометрическое = √(a · b).
Для трёх чисел a, b, c: ∛(a · b · c).
Степень корня = количество чисел.

### Где применить

В задачах на средние значения.
В геометрии: среднее геометрическое двух отрезков — это сторона квадрата, площадь которого равна площади прямоугольника с этими сторонами.

### Где ошибиться

**Ловушка «среднее геометрическое = (a + b)/2».** Нет, это среднее арифметическое. Среднее геометрическое — это √(a · b).

**Ловушка «степень корня равна степени чисел».** Степень корня равна **количеству чисел**, не степени чисел.

### Задача с разбором

**Задача.** Найди среднее геометрическое чисел 8 и 18.

**Разбор:**
1. Два числа, значит корень 2-й степени (квадратный).
2. √(8 · 18) = √144 = 12.

**Ответ: 12.**

Подожди, здесь нужен другой подход. Посчитаем A² + B².

A² + B² = (A + B)² - 2AB = (2√8)² - 2 · (-7) = 4 · 8 + 14 = 32 + 14 = 46.

## Сборник формул

### Определение

ⁿ√a = b, где b^n = a. Условие: a ≥ 0 для чётных n, для нечётных n — любое a.

### Свойства

- ⁿ√(a · b) = ⁿ√a · ⁿ√b при a ≥ 0, b ≥ 0.
- ⁿ√(a / b) = ⁿ√a / ⁿ√b при a ≥ 0, b > 0.
- (ⁿ√a)ⁿ = a при a ≥ 0.
- ⁿ√(aⁿ) = |a| для чётных n; ⁿ√(aⁿ) = a для нечётных n.

### Чётное vs нечётное

- Чётный корень: всегда неотрицательный, не существует для отрицательных a.
- Нечётный корень: сохраняет знак, существует для любых a.

### Среднее геометрическое

Среднее геометрическое n чисел a₁, ..., aₙ = ⁿ√(a₁ · a₂ · ... · aₙ).

### Дискриминатор

**Когда работает:** для чётных n — a ≥ 0, для нечётных n — любое a.
**Когда не работает:** ⁴√(-16) не существует; ⁿ√(a + b) ≠ ⁿ√a + ⁿ√b.
