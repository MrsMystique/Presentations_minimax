## Блок 1. Рациональные уравнения: целые и дробные

### Зачем тебе это знать

Рациональные уравнения — это фундамент для задач с дробями: «у Васи 1/3 всех яблок, у Пети 1/4, а всего 14, сколько у каждого?». Без них ты не решишь ни одной такой задачи.

### Что это такое

**Определение.** Рациональные уравнения — это уравнения, в которых и левая, и правая части — рациональные выражения.

**Рациональные выражения** могут содержать сложение, вычитание, умножение, деление и возведение в степень с целым показателем (но не корень из переменной).

**Деление:**
- **Целые рациональные уравнения:** нет деления на переменную.
- **Дробно-рациональные уравнения:** есть деление на выражение с переменной.

### Откуда название

«Рациональное» — потому что в таких выражениях нет корней из переменной. Они состоят только из рациональных операций.

### Главное правило: дробь равна нулю

**Рациональная дробь равна нулю тогда и только тогда, когда числитель равен нулю, а знаменатель не равен нулю.**

### Где применить

В задачах на движение: «катер прошёл 1/3 пути по течению и 2/5 против...».
В задачах с процентами: «1/4 класса получила пятёрки...».
В задачах на работу: «первый рабочий сделал 1/3 работы...».

### Где ошибиться

**Ловушка «дробь равна нулю, когда числитель = 0».** Почти верно, но нужно ещё проверить знаменатель (он не должен быть 0).

**Ловушка «можно умножить обе части на знаменатель».** Можно, но только если знаменатель не равен 0. Иначе получаются посторонние корни.

### Задача с разбором

**Задача.** Реши (x - 3)/(x + 2) = 0.

Решение: дробь равна нулю, когда числитель = 0 (и знаменатель ≠ 0).
- x - 3 = 0 → x = 3.
- Проверим ОДЗ: x + 2 ≠ 0 → x ≠ -2. x = 3 подходит.

**Ответ: x = 3.**

### Реши сам

**Задача 1.** Реши (2x - 1)/(x - 5) = 0.

> Подсказка 1 (направление): числитель = 0, знаменатель ≠ 0.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

2x - 1 = 0 → x = 1/2. x - 5 ≠ 0 → x ≠ 5. Подходит.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x = 1/2.**
</details>

**Задача 2.** Реши (x² - 9)/(x - 3) = 0.

> Подсказка 1 (направление): разложи числитель.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(x - 3)(x + 3) / (x - 3) = 0. Сокращать нельзя (потеряем ОДЗ). Числитель = 0 → x = ±3. Но x ≠ 3 (ОДЗ). Остаётся x = -3.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x = -3.**
</details>

**Задача 3.** Реши 3x/(x + 1) = 0.

> Подсказка 1 (направление): числитель = 0.

<details>

3x = 0 → x = 0. x ≠ -1. Подходит.
</details>

</details>

## Блок 2. Решение дробно-рациональных уравнений

### Зачем тебе это знать

Это основной тип задач с дробями. Без алгоритма ты будешь угадывать ответы или получать посторонние корни.

### Алгоритм из 5 шагов

1) Найти ОДЗ (все x, при которых знаменатели ≠ 0).
2) Умножить обе части уравнения на общий знаменатель (или привести к общему знаменателю).
3) Решить полученное целое уравнение.
4) Проверить каждый корни по ОДЗ (исключить те, что в ОДЗ исключены).
5) Записать ответ.

### Откуда алгоритм

Из двух фактов:
- Чтобы избавиться от дробей, нужно умножить на их общий знаменатель.
- Но это «безопасно» только если знаменатель не 0 (иначе мы умножим на 0).

### Где применить

В задачах с дробями (везде, где есть части целого).
В задачах на движение с разными скоростями по разным участкам.

### Где ошибиться

**Ловушка «после умножения на знаменатель можно забыть про ОДЗ».** Нельзя. Это самое частое место потери корней или появления посторонних.

**Ловушка «ОДЗ = знаменатели ≠ 0».** Да, но записывать нужно как x ≠ -2, x ≠ 3 и т.д.

**Ловушка «после умножения можно сократить знаменатель».** Можно, если помнишь про ОДЗ.

### Задача с разбором

**Задача.** Реши (x - 3)/(x + 2) = 5/(x + 2).

Решение:
1) ОДЗ: x ≠ -2.
2) Умножим обе части на (x + 2): x - 3 = 5.
3) Решим: x = 8.
4) Проверим: 8 ≠ -2. Подходит.

**Ответ: x = 8.**

### Реши сам

**Задача 1.** Реши (x - 1)/(x - 2) = (x + 3)/(x - 2).

> Подсказка 1 (направление): умножь на (x - 2), но проверь ОДЗ.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

x - 1 = x + 3 → 0 = 4. Нет решений.
</details>

<details>
<summary>Разбор</summary>

**Ответ: нет решений.**
</details>

**Задача 2.** Реши 2/(x - 1) + 1/(x + 1) = 0.

> Подсказка 1 (направление): приведи к общему знаменателю.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(2(x + 1) + (x - 1)) / ((x - 1)(x + 1)) = 0 → 3x + 1 = 0 → x = -1/3.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x = -1/3.**
</details>

**Задача 3.** Реши 1/x + 2/(x + 3) = 1.

> Подсказка 1 (направление): умножь на x(x + 3).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(x + 3) + 2x = x(x + 3) → 3x + 3 = x² + 3x → x² = 3 → x = ±√3.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x = -√3; x = √3.**
</details>

## Блок 3. Уравнения, сводящиеся к дробно-рациональным

### Зачем тебе это знать

В задачах часто уравнения выглядят как обычные целые, но после преобразований становятся дробно-рациональными. Например, x/(x - 1) - (x + 3)/(1 - x) = 0. Без навыка ты застрянешь.

### Что это такое

Уравнения, в которых при упрощении появляются дроби с переменной в знаменателе.

### Как решать

Тот же алгоритм из 5 шагов, что и в Блоке 2.

### Где применить

В задачах с «разностью дробей».
В задачах: «найди x, при котором разность дробей равна 0».

### Где ошибиться

**Ловушка «можно умножать на (1 - x) как на (-(x - 1))».** Можно, но тогда знак меняется. И нельзя сокращать, потому что потеряем ОДЗ.

**Ловушка «знаменатель (1 - x) = 0 при x = -1».** Нет, при x = 1. ОДЗ: x ≠ 1.

### Задача с разбором

**Задача.** Реши x/(x - 1) - 5/(1 - x) = 3.

Решение:
1) ОДЗ: x ≠ 1.
2) Заметим: 1 - x = -(x - 1). Тогда -5/(1 - x) = -5/-(x - 1) = 5/(x - 1).
3) Уравнение: x/(x - 1) + 5/(x - 1) = 3 → (x + 5)/(x - 1) = 3.
4) Умножим на (x - 1): x + 5 = 3(x - 1) = 3x - 3 → 2x = 8 → x = 4.
5) Проверка: 4 ≠ 1. Подходит.

**Ответ: x = 4.**

### Реши сам

**Задача 1.** Реши 2/(x - 3) - 1/(3 - x) = 1.

> Подсказка 1 (направление): приведи к одному знаменателю (x - 3).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

1/(3 - x) = -1/(x - 3). Уравнение: 2/(x - 3) + 1/(x - 3) = 1 → 3/(x - 3) = 1 → x - 3 = 3 → x = 6.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x = 6.**
</details>

**Задача 2.** Реши (x² - 1)/(x + 1) - x = 0.

> Подсказка 1 (направление): разложи числитель.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(x - 1)(x + 1)/(x + 1) - x = 0. Сократим (но помним про ОДЗ): (x - 1) - x = 0 → -1 = 0. Нет решений.
</details>

<details>
<summary>Разбор</summary>

**Ответ: нет решений.**
</details>

## Босс-файт: задачи на рациональные уравнения

### Задача 1. Реши (x² - 9)/(x - 3) = 0

**Решение:** (x - 3)(x + 3)/(x - 3) = 0. Числитель = 0 → x = 3 или x = -3. ОДЗ: x ≠ 3. Остаётся x = -3.

**Ответ: -3.**

### Задача 2. Реши 1/(x - 2) + 1/(x + 2) = 1

**Решение:**
Общий знаменатель: (x - 2)(x + 2) = x² - 4.
((x + 2) + (x - 2)) / (x² - 4) = 1.
2x / (x² - 4) = 1.
2x = x² - 4 → x² - 2x - 4 = 0. D = 4 + 16 = 20. x = (2 ± √20)/2 = 1 ± √5.
Проверка ОДЗ: x ≠ ±2. 1 + √5 ≈ 3.24 ≠ 2; 1 - √5 ≈ -1.24 ≠ -2. Подходят.

**Ответ: 1 - √5; 1 + √5.**

### Задача 3. Реши (x + 1)/(x - 3) = (x - 1)/(x + 1)

**Решение:**
ОДЗ: x ≠ 3, x ≠ -1.
Умножим на (x - 3)(x + 1): (x + 1)² = (x - 1)(x - 3).
x² + 2x + 1 = x² - 4x + 3 → 6x = 2 → x = 1/3.
Проверка: 1/3 ≠ 3, 1/3 ≠ -1. Подходит.

**Ответ: 1/3.**

### Задача 4. Реши x/(x - 1) - (x + 3)/(1 - x) = 0

**Решение:**
ОДЗ: x ≠ 1.
(1 - x) = -(x - 1), значит -(x + 3)/(1 - x) = (x + 3)/(x - 1).
x/(x - 1) + (x + 3)/(x - 1) = 0 → (2x + 3)/(x - 1) = 0 → 2x + 3 = 0 → x = -3/2.
Проверка: -3/2 ≠ 1. Подходит.

**Ответ: -3/2.**

## Сборник формул

### Рациональное уравнение

ax = b (целое), a/x + b/(x + c) = d (дробно-рациональное).

### Правило: дробь = 0

Числитель = 0 и знаменатель ≠ 0.

### Алгоритм

1) ОДЗ.
2) Умножь на общий знаменатель.
3) Реши.
4) Проверь по ОДЗ.
