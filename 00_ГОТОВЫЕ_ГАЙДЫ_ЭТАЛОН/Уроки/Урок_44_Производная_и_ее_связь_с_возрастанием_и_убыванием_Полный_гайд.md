# Урок 44. Производная. Связь с возрастанием и убыванием

## Перед тем как начать

Привет. Этот урок — про связь между знаком производной и поведением функции. Это важнейший инструмент для исследования функций.

---

## Блок 1. Геометрический смысл производной

### Что это такое

Производная f'(x₀) — это тангенс угла наклона касательной к графику f в точке (x₀, f(x₀)).

### Уравнение касательной

y = f(x₀) + f'(x₀)(x - x₀).

---

## Блок 2. Связь между знаком производной и возрастанием

### Теорема (признак возрастания)

Если f'(x) > 0 на промежутке, то f возрастает на этом промежутке.

### Теорема (признак убывания)

Если f'(x) < 0 на промежутке, то f убывает на этом промежутке.

---

## Блок 3. Экстремумы функции

### Определение

- **Точка максимума:** f(x₀) ≥ f(x) для всех x из окрестности.
- **Точка минимума:** f(x₀) ≤ f(x) для всех x из окрестности.

### Необходимое условие экстремума

Если x₀ — точка экстремума и f'(x₀) существует, то f'(x₀) = 0.

### Достаточное условие

- Если f' меняет знак с «+» на «-» в x₀, то x₀ — точка максимума.
- Если f' меняет знак с «-» на «+», то x₀ — точка минимума.

## Блок 4. Задачи

### Задача с разбором

**Задача.** f(x) = x³ - 3x² + 2. Найди промежутки возрастания/убывания и точки экстремума.

Решение:
- f'(x) = 3x² - 6x = 3x(x - 2).
- f'(x) = 0 при x = 0 или x = 2.
- f'(x) > 0 при x < 0 или x > 2 → возрастает.
- f'(x) < 0 при 0 < x < 2 → убывает.
- x = 0 — точка максимума (f(0) = 2).
- x = 2 — точка минимума (f(2) = -2).

**Ответ: возрастает на (-∞; 0) ∪ (2; +∞), убывает на (0; 2); max = 2 в x = 0, min = -2 в x = 2.**

### Реши сам

**Задача 1.** f(x) = x² - 4x + 1. Найди экстремум.

## Босс-файт

### Задача 1. f(x) = x³ - 3x. Исследуй.

**Решение:** f'(x) = 3x² - 3 = 3(x-1)(x+1). Возрастает: (-∞; -1) ∪ (1; +∞). Убывает: (-1; 1). Max = 2 при x = -1, min = -2 при x = 1.

### Задача 2. f(x) = x · e^(-x). Найди max.

**Решение:** f'(x) = e^(-x) - x · e^(-x) = e^(-x)(1 - x). f'(x) = 0 → x = 1. f'(0) > 0, f'(2) < 0 → max при x = 1. f(1) = 1/e.

### Задача 3. Касательная к y = x² - 2x + 3 в точке x₀ = 2.

**Решение:** y(2) = 4 - 4 + 3 = 3. y'(2) = 4 - 2 = 2. Касательная: y = 3 + 2(x - 2) = 2x - 1.

### Задача 4. Найди наибольшее значение f(x) = x³ - 3x² + 1 на [-1; 3].

**Решение:** f'(x) = 3x² - 6x = 3x(x - 2). Нули: 0, 2.
f(-1) = -1 - 3 + 1 = -3.
f(0) = 1.
f(2) = 8 - 12 + 1 = -3.
f(3) = 27 - 27 + 1 = 1.
Наибольшее: 1 (при x = 0 или x = 3).
