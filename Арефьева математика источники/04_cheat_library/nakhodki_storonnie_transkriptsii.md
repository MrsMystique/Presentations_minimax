# Находки из сторонних транскрипций (Артур Шерафиев и др., сентябрь 2026)

Статус: AI/третьесторонний REFERENCE, математика перепроверена самостоятельно.
Использовать идеи/структуру, не копировать формулировки/регистр напрямую.

## 1. Скрытый корень при чётной степени (a²=1, b³=8 → a+b=?)

Проверено: a²=1 → a=±1 (два корня, чётная степень). b³=8 → b=2 (только один
действительный корень, нечётная степень). Полный ответ: a+b ∈ {3, 1}.

**Релевантность проекту:** живая иллюстрация асимметрии чётный/нечётный
корень — той же самой, что лежит в основе условия a>0 в определении §1 и
объясняет, почему нечётный корень из отрицательного существует, а чётный —
нет. Кандидат в Повторение или в блок про модуль (когда будет написан).

## 2. "Упёрлись в стену → придумали обозначение" (мотивация логарифма)

2^x=4 (x=2) → 2^x=8 (x=3) → 2^x=7 (стоп, нет целого — придумываем логарифм).

**Релевантность:** это тот же паттерн, который уже дважды использован в наших
блоках §1 (Попытка в лоб в блоке 1; "упрёмся в стену" в блоке 3 при
доказательстве теоремы). Независимое подтверждение, что паттерн рабочий.
Предложение: добавить фразу-мостик в текст ("этот же трюк встретишь снова у
логарифмов") для связности между главами — не выполнено пока, ждёт решения.

## 3. Нельзя сокращать слагаемые, только множители (переработанная версия)

Оригинал (не для использования, чужой грубый регистр) иллюстрировал
(15x³⁰−x³⁰)/x³⁰=14 через историю про "15 существ на остановке, одного сбила
машина, осталось 14". Математика верна: сокращать можно только после
объединения подобных слагаемых, не почленно.

**Наша чистая версия (готова к использованию, вариант «мемы»):**
> У тебя в сохранённых 15 совершенно одинаковых мемов — один в один, пиксель
> в пиксель. Ты случайно смахнул не туда и удалил один. Осталось 14 — не
> «15 минус мем, который сам себя удалил», а просто на один меньше. То же
> самое с 15x³⁰ и x³⁰: это не два разных числа, которые можно сократить друг
> с другом — это «15 одинаковых x³⁰» и «ещё один такой же x³⁰». Сначала
> посчитай, сколько их осталось (15−1=14), и только потом дели на сам x³⁰.

**Релевантность:** прямое попадание в ловушку «сокращать слагаемые, а не
множители» (отмечена ещё в CONTENT_PLAN_FRACTIONS.md, самом первом документе
проекта). У нас в блоках §1 этой ловушки пока нет в явном виде — кандидат
для навыка S10 (алгебраическое упрощение с дробными показателями), когда
будем писать этот блок.

## 4. «Недостепень» — находка для будущей главы про логарифмы

Логарифм — не что-то принципиально новое, а степень, которая просто "не
вышла круглым числом", поэтому пришлось дать ей отдельное имя вместо
десятичного приближения. Работает по тому же принципу keyword mnemonic, что
"job — вJobываешь" — само слово несёт объяснение. Также подтверждает
механизм снижения когнитивной нагрузки в приёме "упёрлись в стену" (см. п.2):
не строится новая система координат, старая линия рассуждения продолжается
на один шаг. Кандидат для главы про логарифмы (не текущий §1).
