# АЛГЕБРА ДЛЯ ВСЕХ

Проект учебного пособия для подготовки к ЦТ/ЦЭ по математике (Беларусь).
Текущий фокус: Глава 1 «Обобщение понятия степени», §1 «Степень с рациональным
показателем и её свойства».

## Структура репозитория

```
00_project_instructions/   Правила работы, стиль, "личность" книги
01_sources/                 Все исходные материалы (по категориям, см. ниже)
02_paragraph_1/              Рабочие документы по текущему параграфу
03_council/                  Вопросы и решения THE MATHEMATICS LEARNING COUNCIL
```

## Категории в 01_sources/

| Папка | Что кладём | Статус по умолчанию |
|---|---|---|
| `normative/` | Учебники и сборники с грифом Минобра, той же линии авторов | VERIFIED |
| `exam_bank_rikz_2022/` | Официальный открытый банк РИКЗ | VERIFIED |
| `exam_archive_raw/` | Целые PDF реальных вариантов ЦТ/ЦЭ/ДРТ/РТ с прямой ссылкой на источник | VERIFIED REAL EXAM |
| `exam_archive_notes/` | Наши выписки отдельных задач с внешних архивов (sdamgia и т.п.), которые нельзя целиком скачать | VERIFIED REAL EXAM (с id и ссылкой) |
| `drafts_reference/` | Черновики без подтверждённого/авторского статуса, в т.ч. AI-generated | AI_GENERATED / REFERENCE — использовать только после независимой проверки |
| `reference_non_normative/` | Общие справочники других стран/программ | REFERENCE ONLY, не авторитетно для границ ЦТ/ЦЭ РБ |

Полный реестр с деталями по каждому файлу — `01_sources/source_registry.md`.

## Правило работы с источниками

Ничего не попадает в текст параграфа напрямую из источника. Каждый элемент проходит:
`SOURCE → EVIDENCE/FACT → ANALYSIS → PEDAGOGICAL DECISION → BOOK ELEMENT`.

Статусы: **VERIFIED** (нормативный/канонический) · **VERIFIED REAL EXAM** (подтверждено
прямой ссылкой на первичный вариант) · **ADAPTED** (математика проверена, происхождение
как экзамен не подтверждено) · **ORIGINAL** (создано нами) · **UNVERIFIED** (нельзя
подтвердить, использовать с пометкой) · **AI_GENERATED/REFERENCE** (не нормативно, не
приоритетно, требует проверки каждого утверждения).
