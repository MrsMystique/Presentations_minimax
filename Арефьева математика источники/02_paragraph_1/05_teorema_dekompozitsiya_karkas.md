## Структура (7 шагов)

1. **Мотивация ДО доказательства** — явная связка с уже знакомым правилом через аналогию, явный ответ на «зачем».
2. **Попытка «в лоб» на числах, заходящая в тупик** — показать неудобство прямого счёта, оправдывающее переход к общему виду.
3. **Декомпозиция на «большие шаги»**, каждый содержит: цель шага → формулу в общем виде → параллельный числовой пример на тех же данных → указание, какое уже известное правило используется.
4. **Финальная сборка** — вся цепочка в одну строку.
5. **Именованные «инсайты»** — 2-3 переносимые идеи, отдельно от самого доказательства.
6. **Изоморфная задача на закрепление** — та же структура на новых числах.
7. **Чек-лист самопроверки по шагам** (не один общий вопрос).

## Применение к S7 (теорема aᵐ/ⁿ·aᵖ/ᵍ=a^(m/n+p/q))

Основная цепочка шагов (мотивация→замена на корни→общий знаменатель→перемножение→
возврат к степени→разбиение дроби) проверена математически, совпадает по существу
с доказательством Источника B (стр.5-6), но методически лучше разбита для восприятия.

### Найденные и исправленные ошибки оригинала (Источник F)

- Число 8^(1/6)≈1,348 — НЕВЕРНО. Верно: 8^(1/6)=2^(1/2)=√2≈1,414
- Задача-матрёшка на числах 4^(1/2)·4^(1/3): неудачный подбор (документ пытался связать
  результат с 4⁶=4096, хотя нужно 4⁵=1024) — приводит к видимой путанице в тексте

### Исправленная задача-матрёшка (используется вместо оригинальной)

```
4^(1/2)·4^(1/3) = √4 · ∛4
общий показатель корней: НОК(2,3)=6
√4 = 4^(3/6) = ⁶√(4³) = ⁶√64
∛4 = 4^(2/6) = ⁶√(4²) = ⁶√16
⁶√64 · ⁶√16 = ⁶√1024
1024 = 4⁵  →  ⁶√1024 = ⁶√(4⁵) = 4^(5/6)
Проверка суммой показателей: 1/2+1/3 = 3/6+2/6 = 5/6 ✓ — совпало ТОЧНО, без калькулятора
```

Урок для чек-листа: важно, ПОЧЕМУ в примере выбраны «удобные» числа (1024=4⁵), а не
произвольные — иначе проверка утонет в приближённых вычислениях.
