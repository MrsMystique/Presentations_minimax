# ВЕРИФИЦИРОВАННОЕ МАТЕМАТИЧЕСКОЕ ЯДРО §1

Статус: собрано и проверено. Источник приоритета — Источник B (канонический,
подтверждён РИКЗ как эталонный для этого параграфа: Гл.1 §1 с.4–21).

## Определения (VERIFIED, Источник B)

- Для a>0, n∈N, n>1: a^(1/n) := ⁿ√a (через свойство (a^(1/n))ⁿ=a)
- Для a>0, m∈Z, n∈N, n>1: a^(m/n) := ⁿ√(aᵐ) = (ⁿ√a)ᵐ
- Особый случай: 0^(m/n) := ⁿ√(0ᵐ) = 0, для m,n натуральных
- Степень с иррациональным/действительным показателем — через десятичные приближения
  показателя (концепт, не строгий предел в рамках школьного курса)

## Свойства (для a>0, b>0, рациональные показатели)

1. aᵐ·aⁿ = a^(m+n)
2. aᵐ:aⁿ = a^(m-n)
3. (aᵐ)ⁿ = a^(mn)
4. aⁿ·bⁿ = (ab)ⁿ
5. aⁿ/bⁿ = (a/b)ⁿ

Доказано в Источнике B (стр.5–6) только свойство 1 — образец строгости, остальные
принимаются по аналогии.

## ЗАКРЫТЫЙ МАТЕМАТИЧЕСКИЙ ВОПРОС: отрицательное основание + рациональный показатель

**Формальная проверка проведена, вопрос математически решён.**

Определение a^(m/n)=ⁿ√(aᵐ) для a<0 не может быть корректно распространено как функция
самого рационального числа m/n — оно зависит от конкретной записи дроби:

- (−8)^(1/3) = −2 (нечётный корень существует)
- То же число через запись 2/6: ⁶√((−8)²) = ⁶√64 = **2**

−2 ≠ 2 → нотация ломается как однозначная операция. Ограничение a>0 в Источнике B —
не педагогическое упрощение, а математическая необходимость.

**Локальное уточнение (не меняет вывод):** если ограничиться только несократимыми
дробями с нечётным знаменателем, единичные примеры считаются согласованно, но:
(а) это условие нигде не зафиксировано ни в одном черновике проекта, которые поднимали
тему; (б) законы степеней (a^r·a^s=a^(r+s) и т.д.) в общем виде всё равно ломаются при
смешивании показателей с чётным и нечётным знаменателем; (в) официальный экзаменационный
корпус (проверено: sdamgia, 3 варианта 2022–2025, ~90 заданий) НИ РАЗУ не содержит
отрицательное основание с дробным показателем.

**Вывод: следовать определению Источника B без исключений.** Единственный оставшийся
вопрос — методический (упоминать ли где-то сноской существование неформальной
калькуляторной конвенции) — вынесен в Council (см. `03_council/backlog.md`).
