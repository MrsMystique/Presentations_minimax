## Ключевые выводы

### Что экзамен проверяет наиболее стабильно
1. **Разложение на множители** — 40+ задач, 4 темы
2. **Свойства степеней** — 30+ задач, 4 темы
3. **Теорема Виета** — 25+ задач, 4 темы
4. **Свойства логарифмов** — 20+ задач, 3 темы

### Главные конструкции (STRUCTURAL REPEAT)
- «Корни квадратного → катеты → площадь» — 6+ повторов
- «Строительная бригада / 3 поставщика» — 6+ повторов
- «Симметрия относительно прямой» — 8+ повторов
- «Сумма углов при пересечении» — 8+ повторов
- «Касательная + секущая» — 7+ повторов

### Главные ловушки
1. Забытый ОДЗ (10+)
2. Путаница знака в скобках (5+)
3. Свойство применено к сумме (3+)
4. Вписанный/центральный углы перепутаны (3+)
5. Неравенство треугольника (3+)

### Что изменилось в 2024-2026
- B1 (соответствие) — возможная реформа формата в 2025
- Производная усиливается (B19 в ДРТ-2026)
- Стереометрия в B-части растёт (B12, B16, B20)
- Текстовые задачи становятся прикладными
