## Сборник задач "Корни и степени с дробным показателем" (агент MiniMax, сентябрь 2026)

`ROOTS_AND_FRACTIONAL_POWERS.md` — 50+ задач по теме, отобранных из открытого банка
РИКЗ + ДРТ-2026, с разбором ловушек. Статус: **AI_GENERATED, требует выборочной
проверки** (тот же протокол, что для анализа Mavis).

**Проверено выборочно:** базовые задачи Г1-1, Г1-2, Г1-3, А1-1, А1-2 — пересчитаны
независимо, математически верны.

**Найдена и подтверждена ОШИБКА:** задача Е2-1 (заявлена как ДРТ-2026, B6) даёт ответ
"−42" для выражения вида 15^(...). Это математически невозможно — **15 в любой
действительной степени положительно**, отрицательный результат исключён по
определению. Сам документ не завершает вычисление честно ("многоэтапное
преобразование, дающее в итоге... по ключам −42"), то есть источник декларирует
непроверенный результат. **Задача Е2-1 исключена из использования.** Остальные
задачи раздела Е (включая Е1 = уже известная ДРТ-2026 A4) не затронуты этой ошибкой.

**Найдена и подтверждена ВТОРАЯ ОШИБКА:** задача Д1-2 — (⁴√(a²))² заявлена равной
√a (вариант 1), но верный ответ — a (вариант 2). Проверено расчётом (a=16 и a=5,
оба раза расхождение). **Исключена из использования.**

**Верифицированы независимым расчётом и приняты в работу:** Г1-1, Г1-2, Г1-3, Г1-4,
Г2-1, Г2-2, Г2-3, Г2-4, Г3-1, Г3-2, Г3-3, Г3-4, Д1-1 — все математически верны,

**Вывод:** базовый и средний уровень требуют выборочной проверки, но при проверке

две ошибки уже найдены на малой выборке, каждую задачу этого уровня нужно
