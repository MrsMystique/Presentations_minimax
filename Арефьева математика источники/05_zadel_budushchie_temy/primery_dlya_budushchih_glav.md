# Задел примеров для будущих тем (не §1 — для всего курса)

Собрано из брейнштормов пользователя. Оценка по критериям: тест на несущую
нагрузку + математическая точность + принцип "эмоционально близкое" +
"funds of knowledge". Не текущая работа — складируется на будущее.

## Готово к использованию

**Пропорции/масштаб** — телефон vs телевизор: одна и та же картинка не
искажается на разных экранах именно потому, что сохраняется пропорция
(отношение ширины к высоте). Точно, нагляднее, чем стандартные учебниковые
примеры.

**Проценты** — расход батареи телефона при постоянной нагрузке. Сильная
находка: попадает в принцип "эмоционально близкое" (тревога за % батареи —
реальный ежедневный опыт подростка), математически корректно описывает
"процент от числа".

**Дроби** — стакан воды, 1/2=2/4. Надёжный, точный, не оригинальный, но
рабочий без специфичных знаний аудитории.

## Требует доработки

**НОД/НОК через рейд с зельями.** Как сформулировано изначально — это просто
деление, не НОД/НОК. Рабочий вариант-заготовка: "Рейд с боссом типа А тратит
зелья пачками по 18, с боссом типа Б — пачками по 12. Какое наименьшее
количество зелий закупить, чтобы его можно было без остатка потратить на
ЛЮБОЙ из двух рейдов (не зная заранее, в какой поведут)?" → НОК(18,12)=36.
Для НОД нужна другая структура вопроса — "поровну разделить одно между двумя
разными группами", не "два разных расхода".

## Для темы "углы/тригонометрия" (не проверено, ждёт своей главы)

- Футбол — рабочий, но клише, часто встречается в учебниках, невысокая
  новизна.
- Строительство дорог (уклон, вираж поворота) — точнее и свежее футбола,
  реальная инженерная практика. Приоритетный кандидат.
- Человек-паук/паутина — идея хороша (кино+физика), но ТРЕБУЕТ привязки к
  конкретной считаемой величине (угол натяжения, длина дуги качания) прежде
  чем использовать — иначе рискует стать декоративной "соблазнительной
  деталью" (упоминание фильма без реального математического содержания).
  Не использовать в текущем виде, доработать при подходе к теме.
