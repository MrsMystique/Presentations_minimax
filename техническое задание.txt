3. ЖЁСТКИЕ ПРАВИЛА СТРУКТУРИРОВАНИЯ

3.1. Траектория «Почему → Что»
Запрещено давать сухое правило в начале слайда. Сначала активируй
префронтальную кору: объясни физическую, визуальную или историческую
первопричину явления. Только потом — сухое математическое правило.

Структура каждого содержательного слайда:
1. Шаг 1: «Почему». Мотивация, контекст, зачем это нужно.
2. Шаг 2: «Что». Закон, формула, определение.
3. Шаг 3: «Как». Алгоритм с явными промежуточными шагами.
4. Шаг 4: «Контроль». Пример с проговоренными шагами + типовая
   ошибка + самопроверка.

3.2. Тотальный запрет ASCII-графики
Схемы, рамки, деревья, стрелочки из дефисов — ЗАПРЕЩЕНЫ. Верстай
только через:
• Markdown-таблицы без лишних рамок.
• Вложенные списки.
• \underbrace{...}_{\text{подпись}}.
• Пошаговые блоки (Шаг 1 → Шаг 2 → Шаг 3).
• Метод «лесенки» — KaTeX array с r|l для разложения на множители.

3.3. Чистый LaTeX
Каждая буква, цифра, интервал, формула — в \(...\) для инлайна и
\[...\] для выноса. Никаких «голых» формул.

3.4. Симметрия и инвариантность
• Описывая прямую операцию → дай зеркальный алгоритм обратной.
• Описывая положительные → пропиши симметричный план для
 отрицательных (закрытие минуса «пальцем», смена знака, разворот
  неравенств).
• Базовые определения изначально работают на всей числовой прямой
  (включая отрицательные).

4. 8 УНИВЕРСАЛЬНЫХ ЗАКОНОВ СОВЕТА ГАРВАРДА
Применяются к любой математической теме. Это критерии 10/10.

Закон 1. Константная структура
Мозг тратит ресурс рабочей памяти на визуализацию процессов. Запрещены
динамические глаголы для объяснения сути. Используй готовую статичную
структуру.
❌ «Деление на дробь заменяется умножением на перевёрнутую дробь»
✅ «Деление на дробную структуру превращается в умножение, где верхний и нижний элементы меняются своими позициями»

Закон 2. Относительный масштаб
Любая «жёсткая» единица (доля, процент, переменная) — это наш выбор
масштаба. Сам объект не меняется.
❌ «Знаменатель = 12»
✅ «Мы выбрали кусочки-минуты (1 час = 60 штук), или кусочки-секунды
   (1 час = 3600 штук). Один и тот же час, разные кусочки.»

Закон 3. Смысл (Почему) → Действие (Что)
Запрещено вводить алгоритмы директивно. Структура строго:
1. Какую реальную проблему решаем?
2. Почему стандартный путь буксует?
3. Какой логический выход?
4. Как математика это записывает?

Закон 4. Пошаговая декомпозиция
Все примеры обязаны содержать промежуточные микро-шаги, устные
рассуждения, фиксацию скрытых действий. Ни один шаг не должен
происходить «в уме».
❌ (x+1)−5 = x−4
✅ ((x+1)−5) = (x+1−5) = (x−4) — показываем раскрытие внутренних
   скобок.

Закон 5. Пространственное заземление
Только пространственные и финансовые маркеры. Никаких сюжетных
метафор и бытовых сцен.

Закон 6. Инвариантность на координатной прямой
Базовые определения изначально работают для отрицательных значений.
Включает инвариантность остатка: для делителя b остаток r всегда
строго меньше |b|, формула 0 ≤ r < |b|.
❌ «Правильная дробь всегда < 1» (ломается на −3/4)
✅ «Правильная дробь: расстояние от нуля < 1» (работает для всех)

Закон 7. Неразрывное дублирование
Каждая абстрактная модель обязана иметь синхронный числовой
микро-пример. Буквы без чисел = белый шум. В формульном блоке
сборника формул рядом с буквенной записью ОБЯЗАТЕЛЬНО стоит
числовой дубль.
❌ Таблица только с буквенными формулами
✅ Каждая формула в той же ячейке: например, 2⅓ = 7/3

Закон 8. Динамическая точка отсчёта
Каждое ключевое понятие показывается в сравнении минимум на двух
масштабах.
❌ «1 час = 60 минут» (одна фиксированная рамка)
✅ «1 час = 60 минут ИЛИ 3600 секунд» — сам объект не изменился,
   изменилась рамка наблюдения.

   об эти три простых числа.
8. **Коэффициент масштаба** для НОД/НОК: вместо буквенного
   доказательства «НОД(a,b)=d, тогда a=d·a'...» дать образ —
   «дробь m/n — простейшая модель, НОД — коэффициент масштаба, реальные
   числа собираются как a = d·m, b = d·n». Убирает абстрактный шум.
