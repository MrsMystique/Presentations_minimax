# Урок 46. Единичная окружность. Синус, косинус, тангенс произвольного угла

## Перед тем как начать

Привет. Этот урок — про единичную окружность и определение тригонометрических функций для произвольного угла.

---

## Блок 1. Единичная окружность

### Определение

**Единичная окружность** — это окружность с центром в начале координат и радиусом 1.

### Зачем нужна

Она позволяет определять тригонометрические функции для любых углов (включая тупые, отрицательные и т.д.).

---

## Блок 2. Градусная и радианная мера

### Градусы

Полный круг = 360°.

### Радианы

Полный круг = 2π радиан. 1 радиан ≈ 57,3°.

### Перевод

- 180° = π рад.
- 90° = π/2 рад.
- 60° = π/3 рад.
- 45° = π/4 рад.
- 30° = π/6 рад.

### Как переводить

- Из градусов в радианы: умножь на π/180.
- Из радиан в градусы: умножь на 180/π.

---

## Блок 3. Определение тригонометрических функций

### Через единичную окружность

Пусть точка P на единичной окружности соответствует углу α. Тогда:
- **sin α** = y-координата точки P.
- **cos α** = x-координата точки P.
- **tan α** = y/x = sin α / cos α.
- **cot α** = x/y = cos α / sin α.

### Знаки по четвертям

| | I | II | III | IV |
|---|---|---|---|---|
| sin | + | + | - | - |
| cos | + | - | - | + |
| tan | + | - | + | - |

---

## Блок 4. Свойства

### Чётность/нечётность

- sin(-α) = -sin α (нечётная).
- cos(-α) = cos α (чётная).
- tan(-α) = -tan α (нечётная).

### Периодичность

- sin(α + 2π) = sin α.
- cos(α + 2π) = cos α.
- tan(α + π) = tan α.

### Ограниченность

- -1 ≤ sin α ≤ 1.
- -1 ≤ cos α ≤ 1.

## Блок 5. Задачи

### Задача с разбором

**Задача.** Чему равен sin(7π/6)?

Решение: 7π/6 — это угол в III четверти (180° + 30° = 210°). sin(210°) = -sin(30°) = -1/2.

**Ответ: -1/2.**

## Босс-файт

### Задача 1. sin(5π/3)?

**Решение:** 5π/3 = 360° - 60° = -60° в IV четверти. sin(-60°) = -sin 60° = -√3/2.

### Задача 2. cos(11π/6)?

**Решение:** 11π/6 = 360° - 30° = -30°. cos(-30°) = cos 30° = √3/2.

### Задача 3. tan(7π/4)?

**Решение:** 7π/4 = -π/4. tan(-π/4) = -1.

### Задача 4. Переведи 7π/12 в градусы.

**Решение:** 7π/12 · 180/π = 105°.
