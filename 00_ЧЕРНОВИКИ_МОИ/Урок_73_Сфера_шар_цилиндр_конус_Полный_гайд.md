# Урок 73. Сфера, шар, цилиндр, конус

## Перед тем как начать

Привет. Этот урок — про тела вращения: сфера, шар, цилиндр, конус, усечённый конус. Это финальная тема стереометрии.

---

## Блок 1. Сфера и шар

### Определения

**Сфера** — это множество точек пространства, равноудалённых от данной точки (центра).

**Шар** — это тело, ограниченное сферой.

### Формулы

- **Площадь поверхности сферы:** S = 4πr².
- **Объём шара:** V = (4/3)πr³.

---

## Блок 2. Цилиндр

### Определение

**Цилиндр** — тело, образованное вращением прямоугольника вокруг одной из его сторон.

### Формулы

- **Площадь боковой поверхности:** S_бок = 2πrh.
- **Полная площадь:** S = 2πr² + 2πrh = 2πr(r + h).
- **Объём:** V = πr²h.

---

## Блок 3. Конус

### Определение

**Конус** — тело, образованное вращением прямоугольного треугольника вокруг одного из катетов.

### Формулы

- **Площадь боковой поверхности:** S_бок = πrl, где l — образующая (l² = r² + h²).
- **Полная площадь:** S = πr² + πrl.
- **Объём:** V = (1/3)πr²h.

---

## Блок 4. Усечённый конус

### Определение

**Усечённый конус** — это часть конуса между двумя параллельными плоскостями.

### Формулы

- **Объём:** V = (1/3)πh(R² + Rr + r²), где R, r — радиусы оснований, h — высота.
- **Боковая поверхность:** S = πl(R + r).

## Босс-файт

### Задача 1. Шар вписан в цилиндр. Найди отношение объёмов.

**Решение:** пусть радиус шара R, тогда радиус цилиндра R, высота 2R. V_шар = (4/3)πR³. V_цил = πR² · 2R = 2πR³. Отношение = 2/3.

### Задача 2. Конус вписан в шар. Образующая конуса 25, радиус основания 15. Радиус шара?

**Решение:** высота конуса h = √(625 - 225) = 20. По теореме о вписанном конусе: радиус шара R = (l²)/(2h) = 625/40 = 15,625.

### Задача 3. Прямая треугольная призма описана около шара. Площадь основания 11,5. Найди полную поверхность.

**Решение:** шар вписан в призму, значит, радиус шара = высоте призмы / 2. Полная поверхность = S_бок + 2 · S_осн. S_бок = периметр_осн · h = периметр · 2r (h = 2r, т.к. шар вписан). Для треугольника, описанного около круга: S = p · r, где p — полупериметр. Поэтому 11,5 = p · r. Полная поверхность = 2p · 2r + 2 · 11,5 = 4pr + 23 = 4 · 11,5 + 23 = 46 + 23 = 69.

### Задача 4. Усечённый конус с радиусами 3 и 6 и высотой 4. Объём?

**Решение:** V = (1/3)π · 4 · (36 + 18 + 9) = (4/3)π · 63 = 84π.
