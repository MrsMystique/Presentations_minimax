## Блок 1. Показательные уравнения

### Что это такое

**Показательное уравнение** — это уравнение, в котором неизвестное находится в показателе степени.

### Простейшее показательное уравнение

a^x = b, где a > 0, a ≠ 1.

**Если b > 0:** x = log_a(b).
**Если b ≤ 0:** решений нет.

### Главный принцип

**Две степени с одним основанием равны тогда и только тогда, когда равны их показатели.**

Это значит: a^(f(x)) = a^(g(x)) ⇔ f(x) = g(x).

### Как решать

1) Привести все степени к одному основанию.
2) Приравнять показатели.
3) Решить полученное уравнение.

### Задача с разбором

**Задача.** Реши 2^x = 8.

Решение: 2^x = 2^3 → x = 3.

**Ответ: 3.**

### Реши сам

**Задача 1.** Реши 3^(x+1) = 9.
<details>
<summary>Ответ</summary>

3^(x+1) = 3^2 → x + 1 = 2 → x = 1.
</details>

**Задача 2.** Реши 2^(2x - 1) = 1.
<details>
<summary>Ответ</summary>

2^0 = 1 → 2x - 1 = 0 → x = 1/2.
</details>

**Задача 3.** Реши 5^x = 25.
<details>
<summary>Ответ</summary>

5^x = 5^2 → x = 2.
</details>

## Блок 2. Методы решения показательных уравнений

### Метод 1: Приведение к одному основанию

a^(f(x)) = a^(g(x)) → f(x) = g(x).

### Метод 2: Подстановка

Если a^(2x) + a^x = k, замени y = a^x и реши квадратное.

### Метод 3: Вынесение общего множителя

a^(x+2) + a^x = a^x(a² + 1).

### Задача с разбором

**Задача.** Реши 2^x + 2^(x+1) = 12.

Решение: 2^x(1 + 2) = 12 → 3 · 2^x = 12 → 2^x = 4 → x = 2.

**Ответ: 2.**

### Реши сам

**Задача 1.** Реши 2^x + 2^(x-1) = 6.
<details>
<summary>Ответ</summary>

2^x(1 + 1/2) = 6 → 3/2 · 2^x = 6 → 2^x = 4 → x = 2.
</details>

**Задача 2.** Реши 4^x - 3 · 2^x - 4 = 0.
<details>
<summary>Ответ</summary>

y = 2^x. y² - 3y - 4 = 0. D = 9 + 16 = 25. y = (3 ± 5)/2. y = 4 или y = -1. y > 0 → y = 4 → x = 2.
</details>

**Задача 3.** Реши 9^x - 10 · 3^x + 9 = 0.
<details>
<summary>Ответ</summary>

y = 3^x. y² - 10y + 9 = 0. y = 1 или y = 9. x = 0 или x = 2.
</details>

## Блок 3. Показательные неравенства

### Правило

**Если a > 1:** a^(f(x)) > a^(g(x)) ⇔ f(x) > g(x).
**Если 0 < a < 1:** a^(f(x)) > a^(g(x)) ⇔ f(x) < g(x).

### Задача с разбором

**Задача.** Реши 2^x > 8.

Решение: 2^x > 2^3 → x > 3.

**Ответ: x > 3.**

### Реши сам

**Задача 1.** Реши (1/2)^x > 4.
<details>
<summary>Ответ</summary>

2^(-x) > 2^2 → -x > 2 → x < -2.
</details>

**Задача 2.** Реши 3^x < 1/9.
<details>
<summary>Ответ</summary>

3^x < 3^(-2) → x < -2.
</details>

## Босс-файт

### Задача 1. Реши 9^x - 4 · 3^x + 3 = 0.

**Решение:** y = 3^x. y² - 4y + 3 = 0. y = 1 или y = 3. x = 0 или x = 1.

### Задача 2. Реши 2^x + 2^(x+2) = 20.

**Решение:** 2^x(1 + 4) = 20 → 5 · 2^x = 20 → 2^x = 4 → x = 2.

### Задача 3. Реши 6^x = 36.

**Решение:** 6^x = 6^2 → x = 2.

### Задача 4. Реши 2^x < 1/8.

**Решение:** 2^x < 2^(-3) → x < -3.
