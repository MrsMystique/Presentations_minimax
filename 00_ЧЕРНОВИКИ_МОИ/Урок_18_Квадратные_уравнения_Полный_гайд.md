## Блок 1. Квадратное уравнение. Неполные квадратные уравнения

### Зачем тебе это знать

Квадратное уравнение — это базовый инструмент алгебры. Без него ты не сможешь решать задачи на оптимизацию (где функция достигает экстремума), задачи на движение (где встречаются два объекта), задачи с площадями.

### Что это такое

**Определение.** Уравнение вида ax² + bx + c = 0, где x — переменная, a, b, c — числа, причём a ≠ 0, называется квадратным уравнением. Число a называется первым коэффициентом, b — вторым, c — свободным членом.

**Неполные квадратные уравнения:** те, в которых или b = 0, или c = 0, или оба сразу.

### Откуда взялось название «квадратное»

Потому что наибольшая степень x в нём — вторая (квадрат). Если бы наибольшая степень была 3 — это было бы кубическое уравнение.

### Как решать неполные уравнения

**Случай 1: ax² + bx = 0, где b ≠ 0.**
Разложи на множители: x(ax + b) = 0. Произведение равно нулю, когда хотя бы один множитель равен нулю. Получаем: x = 0 или x = -b/a. Два корня.

**Случай 2: ax² + c = 0, где c ≠ 0.**
ax² = -c. Если a и c одного знака, то -c/a < 0, и уравнение не имеет решений. Если разных знаков, то -c/a > 0, и x² = -c/a, откуда x = ±√(-c/a). Два корня.

**Случай 3: ax² = 0.**
x² = 0 → x = 0. Один корень.

### Где применить

В задачах: «найди стороны прямоугольника, если известно, что площадь = 36, а периметр = 26».
В задачах с временем: «через сколько секунд тело упадёт на землю, если ускорение g = 10?» — это квадратное уравнение.

### Где ошибиться

**Ловушка «ax² + c = 0 всегда имеет корни».** Не всегда. Если a и c одного знака, корней нет.

**Ловушка «ax² = 0 имеет два корня».** Один: x = 0.

**Ловушка «ax² + bx = 0 имеет корень только x = 0».** Два корня: x = 0 и x = -b/a.

### Задача с разбором

**Задача.** Реши 4x² - x = 0.

Решение: вынесем x за скобку: x(4x - 1) = 0. Получаем два корня: x = 0 или 4x - 1 = 0 → x = 1/4.

**Ответ: 0; 1/4.**

## Блок 2. Приведённое квадратное уравнение. Дискриминант

### Зачем тебе это знать

Приведённое уравнение — это частный случай с a = 1. Для него работает теорема Виета (мощный инструмент для устного решения). А дискриминант — это «лакмусовая бумажка» для любого квадратного уравнения.

### Что это такое

**Приведённое квадратное уравнение:** если первый коэффициент равен 1, то есть x² + px + q = 0.

**Дискриминант:** D = b² - 4ac. Показывает, сколько корней у уравнения.

### Как дискриминант связан с числом корней

- **D > 0:** два корня.
- **D = 0:** один корень (два совпадающих).
- **D < 0:** нет корней.

### Формулы корней

- Если D > 0: x₁ = (-b - √D) / (2a), x₂ = (-b + √D) / (2a).
- Если D = 0: x = -b / (2a).
- Если D < 0: решений нет.

### Откуда формулы

Через выделение полного квадрата: ax² + bx + c = a(x + b/(2a))² - D/(4a²). Приравниваем к нулю и решаем.

### Где применить

В задачах: «при каких a уравнение ax² + 3x + 1 = 0 имеет корни» — нужно D ≥ 0.
В задачах с условием «имеет единственный корень» — нужно D = 0.

### Где ошибиться

**Ловушка «D = 0 означает два корня».** Один корень (двукратный).

**Ловушка «D = 1 даёт иррациональные корни».** √1 = 1, корни рациональные.

**Ловушка «если D < 0, корни комплексные».** В рамках школьной программы — корней просто нет.

### Задача с разбором

**Задача.** Сколько корней у 3x² - 5x + 2 = 0?

Решение: D = (-5)² - 4·3·2 = 25 - 24 = 1 > 0. Два корня.

**Ответ: два корня.**

## Блок 3. Теорема Виета

### Зачем тебе это знать

Теорема Виета — это «шпаргалка» для устного решения приведённых квадратных уравнений и для определения знаков корней без решения. На тестах и экзаменах это экономит минуты.

### Что это такое

**Теорема Виета.** Сумма корней приведённого квадратного уравнения x² + px + q = 0 равна -p (второму коэффициенту с противоположным знаком), а произведение корней равно q (свободному члену).

То есть: x₁ + x₂ = -p, x₁ · x₂ = q.

**Обратная теорема Виета.** Если числа x₁ и x₂ таковы, что x₁ + x₂ = -p и x₁ · x₂ = q, то они являются корнями уравнения x² + px + q = 0.

### Откуда теорема

Если x₁ и x₂ — корни, то x² + px + q = (x - x₁)(x - x₂) = x² - (x₁ + x₂)x + x₁x₂. Сравнивая коэффициенты: p = -(x₁ + x₂), q = x₁x₂.

### Как применять

**Устное решение:** ищи два числа, которые в сумме дают -p, а в произведении — q.

Пример: x² - 7x + 12 = 0. Ищем числа с суммой 7 и произведением 12. Это 3 и 4. Корни: 3 и 4.

**Определение знаков корней без решения:** для x² + px + q = 0 при D ≥ 0:
- Если p < 0 и q > 0: оба корня положительные.
- Если p > 0 и q > 0: оба корня отрицательные.
- Если q < 0: корни разных знаков.
- Если q = 0: один корень 0, второй = -p.
- Если p = 0: корни противоположные числа ±√q (если q > 0).

### Где применить

В задачах: «не решая, определи знаки корней».
В задачах: «составь уравнение по его корням».
В задачах с параметром: «при каком a сумма корней равна 5».

### Где ошибиться

**Ловушка «теорема Виета работает только для приведённых».** Для ax² + bx + c = 0: x₁ + x₂ = -b/a, x₁ · x₂ = c/a.

**Ловушка «если D < 0, то теорема не работает».** Работает, но корней нет, значит, и суммы/произведения нет.

**Ловушка «при q = 0 оба корня равны 0».** Один корень 0, второй -b/a.

### Задача с разбором

Решение: D = 625 - 28 > 0 (есть корни). По Виету: x₁ + x₂ = 25 > 0, x₁ · x₂ = 7 > 0. Сумма и произведение положительные → оба корня положительные.

**Ответ: оба корня положительные.**

## Блок 4. Метод переброски и биквадратное уравнение

### Зачем тебе это знать

**Метод переброски** позволяет решать почти все квадратные уравнения устно (как приведённые). **Биквадратное** уравнение — частый гость в задачах с многочленами четвёртой степени.

### Что это такое

**Метод переброски:** для ax² + bx + c = 0 найди корни приведённого уравнения y² + by + ac = 0, затем раздели каждый на a.

**Биквадратное уравнение:** ax⁴ + bx² + c = 0, где a ≠ 0.

### Как работает метод переброски

Решаем 3x² + 10x + 3 = 0. Делаем «переброску»: y² + 10y + 9 = 0. По Виету: y₁ · y₂ = 9, y₁ + y₂ = -10. Это y = -9 и y = -1. Возвращаемся: x₁ = -9/3 = -3, x₂ = -1/3.

### Как решать биквадратное уравнение

Замена: t = x². Тогда ax⁴ + bx² + c = at² + bt + c = 0. Это квадратное уравнение относительно t. Решаешь, потом x = ±√t (если t > 0).

Пример: x⁴ - 5x² + 4 = 0. Пусть t = x². t² - 5t + 4 = 0. t₁ = 1, t₂ = 4. Тогда x² = 1 → x = ±1. x² = 4 → x = ±2.

### Где применить

В задачах с многочленами 4-й степени.
В задачах: «найди корни, не используя формулу дискриминанта».

### Где ошибиться

**Ловушка «метод переброски работает всегда».** Работает, если «переброшенное» уравнение имеет целые/рациональные корни.

**Ловушка «биквадратное уравнение имеет 4 корня».** Может иметь меньше, если t < 0 (тогда нет x).

**Ловушка «при t = 0 один корень».** Два корня: x = 0 (двукратный).

### Задача с разбором

**Задача.** Реши x⁴ - 13x² + 36 = 0.

Решение: t = x². t² - 13t + 36 = 0. t₁ = 4, t₂ = 9. Тогда x² = 4 → x = ±2. x² = 9 → x = ±3.

**Ответ: -3; -2; 2; 3.**

## Блок 5. Решение уравнений, сводящихся к квадратным

### Зачем тебе это знать

Большинство уравнений в задачах — это «маскировка»: под видом сложного выражения прячется квадратное уравнение. Если ты умеешь снимать маскировку (через замену переменной, разложение на множители), ты решишь почти любую задачу.

### Три главных типа

**Типу 1: f₁(x) · f₂(x) · ... · fₙ(x) = 0.** Разложи на множители, каждый приравняй к нулю, реши каждый.

**Типу 2: A·f(x)² + B·f(x) + C = 0.** Замена t = f(x), реши относительно t, потом вернись к x.

**Типу 3: ax² + bx + c · dx² + ex + f = ... **. Замена t = ax² + bx, чтобы упростить.

### Как применять

**Пример 1 (тип 1):** x³ + x² + x + 1 = 0 → x²(x + 1) + (x + 1) = 0 → (x² + 1)(x + 1) = 0 → x² + 1 = 0 (нет решений) или x + 1 = 0 (x = -1).

**Пример 2 (тип 2):** (x - 2)² - 5(x - 2) + 6 = 0 → t = x - 2. t² - 5t + 6 = 0 → t₁ = 2, t₂ = 3. x - 2 = 2 → x = 4. x - 2 = 3 → x = 5.

**Пример 3 (тип 3):** (x² + 3x + 1)(x² + 3x + 3) + 1 = 0 → t = x² + 3x. (t + 1)(t + 3) + 1 = 0 → t² + 4t + 4 = 0 → t = -2. x² + 3x = -2 → x² + 3x + 2 = 0 → x = -1 или x = -2.

### Где ошибиться

**Ловушка «любая замена переменной безопасна».** Нужно убедиться, что замена корректна (нет потери решений).

**Ловушка «при разложении на множители всегда получаются простые множители».** Иногда остаются неразложимые (как x² + 1), и тогда такие множители корней не дают.

### Задача с разбором

**Задача.** Реши (x - 1)⁴ - (x - 1)² - 72 = 0.

Решение: t = (x - 1)². t² - t - 72 = 0. t₁ = 9, t₂ = -8. t₂ < 0 — нет решений. t₁ = 9 → (x - 1)² = 9 → x - 1 = ±3 → x = 4 или x = -2.

**Ответ: -2; 4.**

### Реши сам

**Задача 1.** Реши (x - 2)² - 5(x - 2) + 6 = 0.

> Подсказка 1 (направление): t = x - 2.

### Задача 4. Реши (x² + 3x + 1)(x² + 3x + 3) + 1 = 0

## Сборник формул

### Квадратное уравнение

ax² + bx + c = 0, a ≠ 0. D = b² - 4ac.

### Число корней

- D > 0: два корня. x = (-b ± √D) / (2a).
- D = 0: один корень. x = -b / (2a).
- D < 0: нет корней.

### Теорема Виета

Для x² + px + q = 0: x₁ + x₂ = -p, x₁ · x₂ = q.

Для ax² + bx + c = 0: x₁ + x₂ = -b/a, x₁ · x₂ = c/a.

### Биквадратное

ax⁴ + bx² + c = 0. Замена t = x², решить at² + bt + c = 0.
