## Блок 1. Квадратичная функция и формы её записи

### Зачем тебе это знать

Парабола — это не просто график, а рабочий инструмент. Зная её свойства, ты сможешь решать задачи на экстремумы (где функция достигает максимума/минимума), на пересечение с осью (нули), на область значений.

### Что это такое

**Определение.** Функция вида y = ax² + bx + c, где a, b, c — числа, причём a ≠ 0, называется квадратичной.

**Три формы записи:**
1) Стандартная: y = ax² + bx + c.
2) Выделение полного квадрата: y = a(x - m)² + n.
3) Корневая (через корни): y = a(x - x₁)(x - x₂).

### Свойства квадратичной функции

**Область определения:** D = R (для любого x найдётся y). Это потому, что ax² + bx + c — это многочлен, который определён для всех действительных чисел.

**Множество значений:**
- Если a > 0: E = [yв; +∞), где yв — ордината вершины.
- Если a < 0: E = (-∞; yв].

**Вершина параболы:** xв = -b/(2a), yв = y(xв).

**Ось симметрии:** x = -b/(2a) (вертикальная прямая).

**Направление ветвей:**
- a > 0: ветви вверх (парабола «улыбается»).
- a < 0: ветви вниз (парабола «грустит»).

### Откуда название «парабола»

Из древнегреческого «παραβολή» — «приложение». Греки открыли это слово, когда изучали конические сечения (сечения конуса плоскостью).

### Где применить

В задачах на оптимизацию: «найди максимум площади».
В задачах с движением: «через сколько секунд мяч упадёт?».
В экономике: «при каком объёме производства прибыль максимальна?».

### Где ошибиться

**Ловушка «парабола всегда пересекает ось x».** Нет. Если D < 0, не пересекает (нулей нет).

**Ловушка «вершина всегда ниже оси x».** Зависит от знака a и значения c. Если a < 0, вершина может быть выше.

**Ловушка «xв = -b/(2a) даёт максимум».** Даёт максимум, если a < 0, минимум, если a > 0.

**Ответ: (2; -1).**

## Блок 2. Нули функции и пересечение с осью

### Зачем тебе это знать

Нули функции — это точки, где парабола пересекает ось x. Они нужны для решения квадратных уравнений, для понимания, где функция меняет знак, для построения графика.

### Что это такое

**Нуль функции** — это значение аргумента, при котором y = 0. То есть x, при которых ax² + bx + c = 0.

### Три случая по дискриминанту

- **D > 0:** два нуля (парабола пересекает ось x в двух точках).
- **D = 0:** один нуль (парабола касается оси x в одной точке).
- **D < 0:** нет нулей (парабола не пересекает ось x).

### Как найти нули

Реши уравнение ax² + bx + c = 0. Если корни есть — это нули. Если нет — нулей нет.

### Как построить график по 5 точкам

1) Определить направление ветвей (по знаку a).
2) Найти координаты вершины.
3) Найти нули функции (если есть).
4) Найти точку пересечения с осью y (это точка (0; c)).
5) Найти симметричную ей точку относительно оси симметрии.
6) Соединить точки плавной кривой.

### Где применить

В задачах: «при каких x функция положительна?» — это промежутки вне корней.
В задачах на построение графика.

### Где ошибиться

**Ловушка «функция y = ax² + bx + c всегда имеет нули».** Не всегда. Если D < 0, нулей нет.

**Ловушка «если D = 0, то x = 0 — нуль функции».** Нет, x = -b/(2a) — нуль функции, и это не ноль (только если b = 0).

**Ловушка «нуль функции — это точка на графике».** Нуль функции — это значение x (не точка). Точка — это (x; 0).

### Задача с разбором

**Задача.** Найди нули y = x² - 5x + 6.

Решение: D = 25 - 24 = 1 > 0. x = (5 ± 1)/2. x₁ = 2, x₂ = 3.

**Ответ: x = 2 и x = 3 (нули функции).**

## Блок 3. Наибольшее и наименьшее значение, множество значений

### Зачем тебе это знать

Это ключевой навык для задач оптимизации: «найди максимальную прибыль», «найди минимальную площадь». Без него ты не решишь ни одной такой задачи.

### Что это такое

**Наибольшее (наименьшее) значение** квадратичной функции на всей области определения — это ордината вершины параболы (если a < 0 — наибольшее, если a > 0 — наименьшее).

**Множество значений:**
- a > 0: E = [yв; +∞).
- a < 0: E = (-∞; yв].

### Как найти

Шаг 1: Определи знак a.
Шаг 2: Найди координаты вершины.
Шаг 3: Если a > 0 — наименьшее значение равно yв, наибольшего нет (или +∞). Если a < 0 — наибольшее равно yв, наименьшего нет.

### Где применить

В задачах: «найди минимальную стоимость при данном объёме».
В задачах: «найди максимальный доход от продаж».

### Где ошибиться

**Ловушка «у параболы есть и максимум, и минимум».** Нет, на всей области определения только одно из них (другое «убегает в бесконечность»).

**Ловушка «xв = -b/(2a) — это и есть ответ».** Нет, xв — это координата, а значение функции в ней — это yв = y(xв).

### Задача с разбором

Решение: a = 2 > 0 → наименьшее в вершине. xв = -(-8)/(2·2) = 2. yв = 2·4 - 8·2 + 5 = 8 - 16 + 5 = -3.

## Блок 4. Применение свойств квадратичной функции в задачах

### Зачем тебе это знать

Это «боевое» применение: задачи, где нужно найти x, при котором функция принимает определённое значение, или x, при которых функция больше/меньше заданного числа. Эти задачи будут в Босс-файте.

### Типы задач

**Тип 1: Найти x, при которых y = k.** Это уравнение ax² + bx + c = k, то есть ax² + bx + (c - k) = 0. Решай как обычное квадратное.

**Тип 2: Найти x, при которых y > k.** Это неравенство ax² + bx + c > k, то есть ax² + bx + (c - k) > 0. Используй метод интервалов или график (Урок 20).

**Тип 3: Найти промежутки возрастания/убывания.** Возрастает там, где функция идёт вверх (за вершиной, если a > 0 — справа; если a < 0 — слева).

### Где применить

В задачах: «при каких x значение функции больше 5?»
В задачах: «на каком промежутке функция убывает?»

### Где ошибиться

**Ловушка «функция возрастает слева от вершины».** Зависит от знака a. Если a > 0, убывает слева, возрастает справа. Если a < 0 — наоборот.

**Ловушка «промежутки возрастания зависят от c».** Не зависят. Зависят только от a и b.

### Задача с разбором

**Задача.** При каких x значение y = x² - 4x + 3 больше 3?

Решение: x² - 4x + 3 > 3 → x² - 4x > 0 → x(x - 4) > 0. Это произведение положительно, когда оба множителя одного знака: x < 0 или x > 4.

**Ответ: x ∈ (-∞; 0) ∪ (4; +∞).**

## Босс-файт: задачи на квадратичную функцию

Четыре задачи — на вершину, нули, множество значений, промежутки.

### Задача 1. Найди координаты вершины y = 3(2x - 5)(x + 1)

**Решение:**
Раскроем скобки: 3(2x² + 2x - 5x - 5) = 6x² - 9x - 15.
xв = -(-9)/(2·6) = 9/12 = 3/4.
yв = 6·(9/16) - 9·(3/4) - 15 = 27/8 - 27/4 - 15 = 27/8 - 54/8 - 120/8 = -147/8.

**Ответ: (3/4; -147/8).**

### Задача 2. Построй график y = x² - 4x + 3

**Решение:**
1) a = 1 > 0 → ветви вверх.
2) xв = 2, yв = -1.
3) Нули: x² - 4x + 3 = 0 → x = 1, x = 3.
4) Пересечение с Oy: (0; 3).
5) Симметричная точка: (4; 3).
6) Соединяем плавной линией.

**Ответ: парабола с вершиной (2; -1), нулями x = 1 и x = 3.**

### Задача 3. Найди наибольшее значение y = -2x² + 8x - 5

**Решение:**
a = -2 < 0 → наибольшее в вершине.
xв = -8/(2·(-2)) = 2.
yв = -2·4 + 8·2 - 5 = -8 + 16 - 5 = 3.

**Ответ: 3.**

### Задача 4. При каких x y = x² - 5x + 6 меньше 2?

**Решение:**
x² - 5x + 6 < 2 → x² - 5x + 4 < 0.
D = 25 - 16 = 9. x₁ = 1, x₂ = 4.
Метод интервалов: парабола вверх, между корнями < 0. Значит, x ∈ (1; 4).

**Ответ: (1; 4).**

## Сборник формул

### Вершина

xв = -b/(2a), yв = y(xв).

### Множество значений

- a > 0: E = [yв; +∞).
- a < 0: E = (-∞; yв].

### Наибольшее/наименьшее

- a > 0: наименьшее = yв, наибольшего нет.
- a < 0: наибольшее = yв, наименьшего нет.

### Нули

Корни уравнения ax² + bx + c = 0. Число нулей — по дискриминанту.

### Промежутки монотонности

- a > 0: убывает на (-∞; xв), возрастает на (xв; +∞).
- a < 0: возрастает на (-∞; xв), убывает на (xв; +∞).
