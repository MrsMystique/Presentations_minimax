## 1. Метафора страницы

Нарисовали карандашом слева на листе. Чернила пошли **рядом**. Когда рисунок кончился — строка сама вышла на всю ширину.

```
┌─────────────────────────────────────────────┐
│ Слайд N. Заголовок                    штамп │
│ ┌─────────────┐  Абзац. Абзац. Абзац.       │
│ │   рисунок   │  Формула не обтекает.       │
│ │             │  Таблица не обтекает.       │
│ └─────────────┘                             │
│ Дальше мысль на всю ширину листа.           │
└─────────────────────────────────────────────┘
```

Опора не «полушария», а два рабочих правила:

1. **Слева картинка, справа текст** — паттерн чтения LTR, как в сетке урока 40/60.
2. **Spatial contiguity (Майер):** слова живут у кромки того кадра, который они объясняют. Широкий по роли кадр (титул, финал) — **над** текстом, никогда под ним.

## 5. Механика рисунка

### 5.1. Разметка

Каждый учебный кадр — только так:

```html
<figure class="sketch">
  <img src="assets/….png" alt="…">
  <figcaption>тот же текст, что alt</figcaption>
</figure>
```

`<img>` внутри `<p>` запрещён (баг 22.7). Вынести, абзац склеить.

### 5.2. Один квадратный кадр на слайде (все текущие PNG 1024×1024)

```css
.sketch {
  float: left;
  width: min(42%, 340px);
  margin: 0 28px 16px 0;
  border: 1px solid #6E554F;
  background: #F5F2EB;
}
.sketch img { display: block; width: 100%; height: auto; }
.sketch figcaption {
  font-size: 12px; color: #6E554F;
  padding: 6px 8px; line-height: 1.35;
}
```

Текст **после** `<figure>` обтекает справа и уходит на всю ширину под кадром.

### 5.3. Два кадра на одном слайде (сейчас только слайд 9)

Не два float подряд (склеятся в кашу). Ряд сверху на ширину листа, текст под ним:

```css
.sketch-row { display: flex; gap: 16px; margin: 0 0 16px; }
.sketch-row .sketch { float: none; width: 50%; margin: 0; }
```

### 5.4. Крышка (титул, финал)

`.sketch-cover` — без float, ширина 100%, рамка контура, подпись можно спрятать если alt = «Титульник» / «Финальный слайд».

### 5.5. Что НЕ обтекает

У блоков ниже — `clear: both`:

- `.math-block`
- `table`
- `details.fold`
- `.quote-trap / .quote-rule / .quote-note`
- `ol`, `ul` длиннее трёх пунктов — не обязательно clear, но формула и таблица — обязательно

Иначе дробь и «маляры» снова ломаются.

### 5.6. Узкий экран ≤900px

Float снимается. Кадр на ширину колонки **сверху**, текст под ним. TOC уезжает наверх страницы. «Наверх» скроллит к `#toc`.

### 5.7. Куда встаёт кадр

Существующие `<img class="slide-image">` **переезжают в начало** `.slide-body` (сначала рисунок, потом чернила). Это вёрстка, не правка текста.

Новые кадры — тоже первым ребёнком `.slide-body`, если на слайде ещё не было этого файла.

## 8. Три жанра цитат

Один розовый `blockquote` запрещён. Класс ставится по **уже существующему** тексту, слова не меняем.

| Класс | Условие (есть в тексте) | Вид |
|---|---|---|
| `details.fold` | «Свернись с ответом» | свёрнуто, summary «Ответ свёрнут — открой, когда решишь»; внутри тот же текст |
| `quote-trap` | ловуш / ограничение / ошиб / ️ Возможная | левая черта `#D97443`, фон бумаги |
| `quote-rule` | Лайфхак / Закон / Практический приём / Правило | черта `#D1A153` |
| `quote-note` | всё остальное (мостики-итоги и т.п.) | черта `#618B8B` |

Без скругления, без розового `#F8E8E5`.

## 9. Навигация

- Ссылки TOC цветом чернил, не синие.
- Заголовки блоков — якоря на первый слайд блока.
- Мостики в TOC — якоря на свой `bridge-after-*`.
- `.is-active` — мята, без подложки-карточки.
- Кнопка «Наверх» скроллит к `#toc`, не к `scrollTo(0,0)`.
- Порядок пунктов TOC = порядок в документе. Номера 11.5 → 9.1 и 21 → 16 **не переставляем**: так выстроены блоки. Это не баг оглавления.
