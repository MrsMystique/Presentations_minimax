Равносильные уравнения

Уравнения 3𝑥 − 15 = 120, 3𝑥 = 135, 𝑥 = 45 имеют один и тот же 
корень. Такие уравнения называют равносильными.

равносильными.

Определение. Уравнения, имеющие одно и то же
множество корней, называются равносильными.

7. Методы решения систем 
уравнений

Существует два основных метода решения 
системы линейных уравнений с двумя 
переменными:

1) Метод подстановки
2) Метод сложения

Способ подстановки

1. Из одного уравнения системы 
выразить одну из переменных

2. Заменить во втором уравнении эту 

переменную на ее выражение.

3. Решить полученное уравнение, найти 

значение другой переменной.

4. Найденное значение переменой 

подставить в выражение из п.1 и найти 
значение выраженной переменной.

5. Записать ответ - упорядоченную пару 

найденных значений переменных.

Способ сложения

1. Одно из уравнений системы оставить 

без изменения, а другое заменить суммой 
уравнений системы.

2. Из полученного уравнения (суммы) найти 

значение переменной.

3. Подставить это значение переменной в 
оставленное без изменения уравнение 
системы.

4. Решить полученное линейное уравнение, 
т. е. найти значение другой переменной.

5. Записать ответ.
