> **Для чего:** Olga вёрстает гайд в финальный документ и хочет заменить ASCII-схемы на качественные иллюстрации.
> **Формат промптов:** подходят для DALL-E 3, Midjourney, Stable Diffusion. Стиль — учебная иллюстрация, минималистичная, без фона, чёткие линии.
> **Общие параметры для всех:** `style: flat educational illustration, white background, mathematical diagram, clean lines, monochrome with one accent color, no decorations, no shadows, vector style, 4K, mathematical typography`

## РЕКОМЕНДАЦИИ ПО ГЕНЕРАЦИИ

1. **Если генерируешь через DALL-E 3:** просто копируй промпт как есть. Можно добавить `aspect ratio: 16:9` если нужны горизонтальные картинки.

2. **Если через Midjourney:** добавь `--ar 16:9 --style raw --v 6` в конце промпта.

3. **Если через Stable Diffusion:** рекомендую LoRA для математических диаграмм (например, "MathV2" или "DiagramGen"). Без LoRA качество может быть низким.

4. **Альтернатива:** можешь использовать **Matplotlib / Desmos / GeoGebra** для построения графиков (Ф-14, Ф-15, Ф-16, Ф-17, Ф-18, Ф-19). Это даст более точные результаты, чем генерация.

5. **Для ASCII-схем (Ф-1 ... Ф-13):** они математически точные. Лучше генерировать, чем рисовать вручную — экономит время.

6. **Согласованность стиля:** все фигуры должны быть в одном стиле — белый фон, чёрные тонкие линии, математическая типографика (Computer Modern или KaTeX). Если будешь генерировать серию, добавь префикс ко всем промптам для консистентности.
