 КОНСПЕКТ: Квадратный трёхчлен
1. Квадратное уравнение и его корни
Определение:
 Уравнение вида ax^2 +
bx
 + c = 0, где x — переменная, a, b, c — действительные числа, причем a ≠ 0.
Дискриминант:
 D = b^2 - 4ac
Количество корней:
Если
D &gt;
 0: два корня.
x1 = (-b - √D) / 2a
x2 = (-b + √D) / 2a
Если D = 0: один корень (два совпадающих
).
x
 = -b / 2a
Если D
&lt; 0
: действительных корней нет.
2. Приведенное квадратное уравнение и Теорема Виета
Приведенное уравнение:
 Уравнение, где первый коэффициент равен единице: x^2 +
px
 + q = 0.
Теорема Виета:
 Сумма корней приведенного квадратного уравнения равна второму коэффициенту, взятому с противоположным знаком, а произведение равно свободному члену.
x1 + x2 = -p
x1 * x2 = q
Обратная теорема Виета:
 Если числа x1 и x2 таковы, что x1 + x2 = -p и x1 * x2 = q, то они являются корнями уравнения x^2 +
px
 + q = 0. (Используется для быстрого подбора корней).
Полезная формула (сумма квадратов корней
):
x
1^2 + x2^2 = (x1 + x2)^2 - 2x1x2
3. Квадратный трёхчлен и разложение на множители
Определение:
 Многочлен вида ax^2 +
bx
 + c, где a ≠ 0. Корни трёхчлена — это значения переменной, при которых он равен нулю.
Формулы разложения на множители:
Если
D &gt;
 0: ax^2 + bx + c = a(x - x1)(x - x2)
Если
 D = 0: ax^2 + bx + c =
a(
x - x1)^2
Если D
&lt; 0
: квадратный трёхчлен нельзя разложить на множители (в области действительных чисел).
4. Выделение полного квадрата двучлена
Суть:
 Представить выражение ax^2 +
bx
 + c в виде
a(
x + p)^2 + q, где p и q — действительные числа.
Алгоритм:
Если a ≠ 1, вынести коэффициент a за скобки.
Представить средний член (
bx
) как удвоенное произведение: 2 * x * (b/2a).
Прибавить и тут же вычесть квадрат этого числа (b/2
a)^
2 (прибавляем, чтобы дополнить до полного квадрата, вычитаем для компенсации). Не забываем прибавить свободный член c.
Свернуть первые три слагаемых в квадрат суммы или разности, а оставшиеся числа аккуратно посчитать.
Пример:
2x^2 + 12x + 14 = 2(x^2 + 6x + 7) = 2(x^2 + 2 * 3 * x + 3^2 - 3^2 + 7) = 2((x +
3)^
2 - 2) = 2(x + 3)^2 - 4
Применение:
 Используется для доказательства неравенств и нахождения наименьшего или наибольшего значения выражения (так как квадрат любого числа ≥ 0).
5. Метод «переброски» и частные случаи
Метод «переброски» старшего
коэффициента:
Чтобы
 решить ax^2 +
bx
 + c = 0, решаем вспомогательное уравнение y^2 +
by
 +
ac
 = 0.
Затем находим исходные корни, разделив корни y на a:
x1 = y1 / a, x2 = y2 / a.
Частные случаи решения (без дискриминанта):
Случай 1:
 Если a + b + c = 0, то один корень равен 1, а второй равен c /
a.
(
Пример: 3x^2 + 2x - 5 = 0 → 3 + 2 - 5 = 0 → x1 = 1, x2 = -5/3)
Случай 2:
 Если a + c = b (или a - b + c = 0), то один корень равен -1, а второй равен -c /
a.
(
Пример: 11x^2 + 9x - 2 = 0 → 11 + (-2) = 9 → x1 = -1, x2 = 2/11)
