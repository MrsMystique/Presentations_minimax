# Урок 54. Логарифм. Свойства логарифмов

## Перед тем как начать

Привет. Этот урок — про логарифм и его свойства. Логарифм — это «обратная операция» к степени: log_a(b) — это показатель степени, в которую нужно возвести a, чтобы получить b.

---

## Блок 1. Определение

### Что это такое

**Определение.** Логарифмом числа b (b > 0) по основанию a (a > 0, a ≠ 1) называется показатель степени, в которую нужно возвести основание a, чтобы получить число b.

log_a(b) = c ⇔ a^c = b.

### Основное логарифмическое тождество

**a^(log_a(b)) = b.**

### Десятичный логарифм

Если основание = 10, то log₁₀(b) = lg b.

### Натуральный логарифм

Если основание = e, то log_e(b) = ln b.

---

## Блок 2. Свойства логарифмов

### Семь свойств

1) **log_a(1) = 0.**
2) **log_a(a) = 1.**
3) **log_a(bc) = log_a(b) + log_a(c).**
4) **log_a(b/c) = log_a(b) - log_a(c).**
5) **log_a(b^c) = c · log_a(b).**
6) **log_a(b) = 1 / log_b(a).**
7) **log_(a^k)(b) = log_a(b) / k.**

### Условия применимости

Все свойства работают при условии: a > 0, a ≠ 1, b > 0, c > 0.

## Блок 4. Преобразования

### Формула перехода к другому основанию

log_a(b) = log_c(b) / log_c(a).

### Задача с разбором

**Задача.** log₂(3) вырази через lg.

Решение: log₂(3) = lg(3) / lg(2).

**Ответ: lg(3)/lg(2).**

### Реши сам

**Задача 1.** log₄(8).
<details>
<summary>Ответ</summary>

lg(8)/lg(4) = 3lg2 / (2lg2) = 3/2.
</details>

**Задача 2.** log₈(4).
<details>
<summary>Ответ</summary>

lg(4)/lg(8) = 2lg2 / (3lg2) = 2/3.
</details>

## Босс-файт

### Задача 1. Вычисли log₆(2) + log₆(3).

**Решение:** log₆(2 · 3) = log₆(6) = 1.

### Задача 2. Вычисли log₁₂(2) + log₁₂(6).

**Решение:** log₁₂(2 · 6) = log₁₂(12) = 1.

### Задача 3. Вычисли 3^(log₉(5)).

**Решение:** 3^(log₉(5)) = 3^((1/2)log₃(5)) = √(3^(log₃(5))) = √5.

### Задача 4. Вычисли log₄(3) · log₉(2).

**Решение:** log₄(3) · log₉(2) = (lg3/lg4) · (lg2/lg9) = (lg3/(2lg2)) · (lg2/(2lg3)) = 1/4.
