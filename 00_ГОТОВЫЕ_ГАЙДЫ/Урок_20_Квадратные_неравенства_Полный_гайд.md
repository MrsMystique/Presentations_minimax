## Блок 1. Что такое квадратное неравенство

### Зачем тебе это знать

Квадратные неравенства — это способ описать «когда функция положительна / отрицательна». Они нужны в задачах оптимизации (когда прибыль > 0), в физике (когда тело движется), в геометрии (когда площадь положительна).

### Что это такое

**Определение.** Неравенства вида ax² + bx + c > 0, ax² + bx + c < 0, ax² + bx + c ≥ 0, ax² + bx + c ≤ 0, где a ≠ 0, называются квадратными.

### Как решать — метод параболы

1) Привести к виду ax² + bx + c > 0 (или < 0, ≥ 0, ≤ 0).
2) Найти нули функции (если есть): решить ax² + bx + c = 0.
3) Определить направление ветвей (по знаку a).
4) Нарисовать схему параболы.
5) Выбрать промежутки, где парабола выше или ниже оси x в зависимости от знака неравенства.

### Откуда метод

Из того, что ax² + bx + c — это парабола. Неравенство ax² + bx + c > 0 означает «парабола выше оси x». Чтобы понять, где это происходит, рисуем схему.

### Где применить

В задачах: «при каких x прибыль положительна?»
В задачах с площадями: «при каких x площадь больше 0?»
В задачах с движением: «когда тело выше земли?»

### Где ошибиться

**Ловушка «при D < 0 неравенство не имеет решений».** Зависит от знака неравенства. Если a > 0 и ax² + bx + c > 0 — решений нет, потому что парабола всегда выше. Но ax² + bx + c < 0 тоже не имеет решений (парабола никогда не ниже).

**Ловушка «при D = 0 один промежуток».** Одна точка, а не промежуток. Например, (x + 5)² < 0 — решений нет.

**Ловушка «при a < 0 нужно умножать на -1».** Можно, но это равносильное преобразование. Лучше сразу нарисовать параболу с ветвями вниз.

### Задача с разбором

**Задача.** Реши 2x² - 5x + 3 > 0.

Решение:
1) Нули: D = 25 - 24 = 1 > 0. x = (5 ± 1)/4. x₁ = 1, x₂ = 1,5.
2) a = 2 > 0 → ветви вверх.
3) Схема: парабола выше оси x вне корней.
4) Решение: x < 1 или x > 1,5.

**Ответ: x ∈ (-∞; 1) ∪ (1,5; +∞).**

## Блок 2. Решение квадратных неравенств (все случаи)

### Зачем тебе это знать

В задачах встречаются все возможные комбинации: D > 0, D = 0, D < 0. Если ты знаешь, как ведёт себя парабола в каждом случае, ты решишь любое неравенство.

### Все шесть случаев

| a | D | ax² + bx + c > 0 | ax² + bx + c < 0 |
|---|---|---|---|
| a > 0 | D > 0 | вне корней | между корнями |
| a > 0 | D = 0 | везде, кроме вершины | нигде |
| a > 0 | D < 0 | везде | нигде |
| a < 0 | D > 0 | между корнями | вне корней |
| a < 0 | D = 0 | нигде | везде, кроме вершины |
| a < 0 | D < 0 | нигде | везде |

### Как пользоваться таблицей

1) Найди a и D.
2) Найди строку в таблице.
3) Примени ответ.

### Где применить

В задачах: «при каких x функция не определена?» (это когда знаменатель = 0, и нужно исключить эти x из ОДЗ).
В задачах: «найти все x, при которых функция меняет знак».

### Где ошибиться

**Ловушка «при D = 0 у неравенства одно решение».** Двукратный корень — одна точка. (x - 3)² ≤ 0 → x = 3.

**Ловушка «если D < 0 и a > 0, неравенство > 0 не имеет решений».** Наоборот: имеет все решения (парабола всегда выше).

### Задача с разбором

**Задача.** Реши (x + 5)² ≤ 0.

Решение: квадрат неотрицателен, поэтому (x + 5)² ≥ 0 всегда. (x + 5)² ≤ 0 выполняется только когда (x + 5)² = 0, то есть x = -5.

**Ответ: x = -5.**

умножь на -1: x² + 4 < 0. D < 0, нет решений.

## Блок 3. Системы и совокупности квадратных неравенств

### Зачем тебе это знать

В задачах часто несколько условий: «x² < 9 и x > 0» — это система. Если путать систему и совокупность, ответ будет неправильным.

### Что это такое

**Система:** все неравенства должны выполняться одновременно (пересечение решений).

**Совокупность:** хотя бы одно должно выполняться (объединение решений).

### Как решать

1) Реши каждое неравенство отдельно.
3) Для системы — найди пересечение множеств решений. Для совокупности — объединение.

### Где применить

В задачах с несколькими условиями.
В задачах: «при каких x функция положительна и определена?»

### Где ошибиться

**Ловушка «система и совокупность решаются одинаково».** Нет. Система — пересечение, совокупность — объединение.

**Ловушка «если множества не пересекаются, у системы нет решений».** Верно для системы. Для совокупности — пустое объединение тоже невозможно, но объединение обычно непустое.

### Задача с разбором

**Задача.** Реши систему {x² - 4x + 3 < 0, x > 0}.

Решение:
- Первое неравенство: x ∈ (1; 3).
- Второе: x > 0.
- Пересечение: (1; 3).

**Ответ: (1; 3).**

### Реши сам

**Задача 1.** Реши систему {x² < 9, x > 0}.

> Подсказка 1 (направление): первое — это (-3; 3).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(-3; 3) ∩ (0; +∞) = (0; 3).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (0; 3).**
</details>

**Задача 2.** Реши совокупность {x² - 4 > 0, x > 0}.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

((-∞; -2) ∪ (2; +∞)) ∪ (0; +∞) = (-∞; -2) ∪ (0; +∞).
</details>

<summary>Разбор</summary>

**Ответ: (-∞; -2) ∪ (0; +∞).**
</details>

## Блок 4. Сложные случаи: замена переменной и параметры

### Зачем тебе это знать

В задачах часто встречаются неравенства, где переменная «спрятана»: «(x² - 3x - 2)(x² - 3x + 1) < 10». Без замены переменной ты такое не решишь.

### Что это такое

Замена переменной позволяет свести сложное неравенство к обычному квадратному.

### Как применять

**Пример:** (x² - 3x - 2)(x² - 3x + 1) < 10.
Пусть t = x² - 3x - 2. Тогда x² - 3x + 1 = t + 3. Получаем: t(t + 3) < 10 → t² + 3t - 10 < 0. D = 9 + 40 = 49. t ∈ (-5; 2).
Возвращаемся: -5 < x² - 3x - 2 < 2. Это два неравенства, решаем систему.

### Где применить

В задачах с «многоэтажными» неравенствами.
В задачах: «при каких a неравенство выполнено для всех x?»

### Где ошибиться

**Ловушка «после замены нужно вернуться к x».** Да, обязательно. Иначе ответ будет в t, а не в x.

**Ловушка «при замене t = f(x) можно забыть про ОДЗ».** Обычно нет, потому что f(x) определена для всех x (если это многочлен).

### Задача с разбором

**Задача.** Найди наибольшее a, при котором 3x² - 18x - 3 ≥ a для всех x.

Решение: запишем как 3x² - 18x - (3 + a) ≥ 0. Это неравенство верно для всех x, если D ≤ 0.
D = 324 + 12(3 + a) = 360 + 12a ≤ 0 → a ≤ -30.
Наибольшее: a = -30.

**Ответ: -30.**

### Реши сам

**Задача 1.** Найди сумму целых решений (x² - 3x - 2)(x² - 3x + 1) < 10.

> Подсказка 1 (направление): t = x² - 3x - 2.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

t(t + 3) < 10 → t ∈ (-5; 2). Два неравенства. Целые: 0, 1, 2, 3. Сумма = 6.
</details>

<details>
<summary>Разбор</summary>

**Ответ: 6.**
</details>

**Задача 2.** При каких a неравенство x² - 2ax + 9 > 0 верно для всех x?

> Подсказка 1 (направление): D < 0 (строго).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

D = 4a² - 36 < 0 → a² < 9 → a ∈ (-3; 3).
</details>

<details>
<summary>Разбор</summary>

**Ответ: a ∈ (-3; 3).**
</details>

## Босс-файт: задачи на квадратные неравенства

### Задача 1. Реши 3x - 15 > x² - 10x + 25

**Решение:**
3x - 15 - x² + 10x - 25 > 0
-x² + 13x - 40 > 0
x² - 13x + 40 < 0
D = 169 - 160 = 9. x = (13 ± 3)/2. x₁ = 5, x₂ = 8.
Решение: x ∈ (5; 8).
Сумма целых решений: 6 + 7 = 13.

**Ответ: x ∈ (5; 8), сумма целых = 13.**

### Задача 2. Найди сумму целых решений (x² - 3x - 2)(x² - 3x + 1) < 10

**Решение:**
t = x² - 3x - 2. x² - 3x + 1 = t + 3.
t(t + 3) < 10 → t² + 3t - 10 < 0. D = 49. t = (-3 ± 7)/2. t₁ = -5, t₂ = 2.
-5 < x² - 3x - 2 < 2.
{x² - 3x - 2 < 2, x² - 3x - 2 > -5} = {x² - 3x - 4 < 0, x² - 3x + 3 > 0}.
Первое: (x - 4)(x + 1) < 0 → (-1; 4).
Второе: D = 9 - 12 < 0 → все x.
Пересечение: (-1; 4).
Целые: 0, 1, 2, 3. Сумма = 6.

**Ответ: 6.**

### Задача 3. Найди наибольшее a, при котором 3x² - 18x - 3 ≥ a для всех x

**Решение:**
3x² - 18x - 3 - a ≥ 0. D ≤ 0: 324 + 12(3 + a) ≤ 0 → 324 + 36 + 12a ≤ 0 → a ≤ -30.
Наибольшее: a = -30.

**Ответ: -30.**

### Задача 4. Реши (x + 1)(x + 2)(x + 3)(x + 4) ≤ 3

**Решение:**
Это сложное неравенство. Заметим: (x + 1)(x + 4) = x² + 5x + 4. (x + 2)(x + 3) = x² + 5x + 6.
Пусть t = x² + 5x + 5 (среднее арифметическое). Тогда (t - 1)(t + 1) = t² - 1 ≤ 3 → t² ≤ 4 → -2 ≤ t ≤ 2.
-2 ≤ x² + 5x + 5 ≤ 2.
{x² + 5x + 7 ≥ 0, x² + 5x + 3 ≤ 0}.
Первое: D = 25 - 28 < 0 → все x.
Второе: D = 25 - 12 = 13. x = (-5 ± √13)/2.
Решение второго: x ∈ [(-5 - √13)/2; (-5 + √13)/2].
Пересечение: то же самое.
Целые в этом промежутке: -3, -2. Сумма = -5.
Проверим: при x = -3: (-2)(-1)(0)(1) = 0 ≤ 3 ✓. При x = -2: (-1)(0)(1)(2) = 0 ≤ 3 ✓.
При x = 0: 1·2·3·4 = 24 > 3 — не подходит.

**Ответ: x ∈ [(-5 - √13)/2; (-5 + √13)/2], целые решения: -3, -2 (сумма -5).**

## Сборник формул

### Решение неравенства ax² + bx + c > 0

1) Найти нули (если есть).
2) Определить направление ветвей.
3) Нарисовать схему параболы.
4) Выбрать нужные промежутки.

### Все случаи

- a > 0, D > 0: вне корней (для >), внутри (для <).
- a > 0, D = 0: все кроме вершины (для >), нигде (для <).
- a > 0, D < 0: все (для >), нигде (для <).
- a < 0: симметрично.
