# Урок 43. Производная

## Перед тем как начать

Привет. Этот урок — про производную. Производная — это «скорость изменения» функции. Если функция описывает путь, производная — скорость. Если функция описывает количество, производная — скорость изменения этого количества.

---

## Блок 1. Определение производной

### Что это такое

**Определение.** Производная функции f(x) в точке x₀ — это предел отношения приращения функции к приращению аргумента, когда приращение аргумента стремится к нулю:

f'(x₀) = lim (f(x₀ + Δx) - f(x₀)) / Δx, Δx → 0.

### Как записывать

f'(x), y', dy/dx — всё это обозначения производной.

---

## Блок 2. Таблица производных

| Функция | Производная |
|---|---|
| c (константа) | 0 |
| x | 1 |
| xⁿ | n·x^(n-1) |
| e^x | 1 |
| a^x | a^x · ln a |
| ln x | 1/x |
| log_a(x) | 1/(x ln a) |
| sin x | cos x |
| cos x | -sin x |
| tan x | 1/cos²x |
| cot x | -1/sin²x |

## Блок 3. Правила дифференцирования

### Пять правил

1) **(f + g)' = f' + g'** — производная суммы.
2) **(cf)' = cf'** — производная с константой.
3) **(fg)' = f'g + fg'** — производная произведения.
4) **(f/g)' = (f'g - fg') / g²** — производная частного.
5) **(f(g(x)))' = f'(g(x)) · g'(x)** — производная сложной функции (chain rule).

---

## Блок 4. Физический и геометрический смысл

### Физический смысл

Если x(t) — закон движения, то x'(t) — мгновенная скорость, x''(t) — ускорение.

### Геометрический смысл

f'(x₀) — угловой коэффициент касательной к графику f в точке (x₀, f(x₀)).

**Уравнение касательной:** y = f(x₀) + f'(x₀)(x - x₀).

## Блок 6. Производная в задачах

### Монотонность

- f'(x) > 0 → f возрастает.
- f'(x) < 0 → f убывает.
- f'(x) = 0 → критическая точка (возможный экстремум).

### Экстремум

Если f' меняет знак с «+» на «-» в точке x₀, то x₀ — точка максимума.
Если с «-» на «+», то точка минимума.

## Босс-файт

### Задача 1. f(x) = x³ - 3x. Найди экстремумы.

**Решение:** f'(x) = 3x² - 3 = 3(x - 1)(x + 1). Нули: x = ±1.
- x < -1: f' > 0 (возрастает).
- -1 < x < 1: f' < 0 (убывает).
- x > 1: f' > 0 (возрастает).
x = -1 — максимум (f = 2), x = 1 — минимум (f = -2).

### Задача 2. Касательная к y = x² - 4x + 1 в точке x₀ = 1.

**Решение:** y(1) = 1 - 4 + 1 = -2. y'(x) = 2x - 4. y'(1) = -2. Касательная: y = -2 - 2(x - 1) = -2x.

### Задача 3. f(x) = 2x³ - 9x² + 12x + 1. Найди наибольшее и наименьшее на [-1; 2].

**Решение:** f'(x) = 6x² - 18x + 12 = 6(x² - 3x + 2) = 6(x - 1)(x - 2). Нули: 1, 2.
f(-1) = -2 - 9 - 12 + 1 = -22.
f(1) = 2 - 9 + 12 + 1 = 6.
f(2) = 16 - 36 + 24 + 1 = 5.
Наибольшее: 6 (при x = 1). Наименьшее: -22 (при x = -1).

### Задача 4. Найди f'(x) для f(x) = x² · e^x.

**Решение:** f'(x) = 2x · e^x + x² · e^x = x · e^x · (2 + x).
