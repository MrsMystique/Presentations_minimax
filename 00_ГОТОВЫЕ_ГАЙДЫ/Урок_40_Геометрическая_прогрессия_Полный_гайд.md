# Урок 40. Геометрическая прогрессия

## Перед тем как начать

Привет. Этот урок — про геометрическую прогрессию. Если в арифметической прогрессии каждый следующий член отличается на d, то в геометрической — каждый следующий член умножается на q (знаменатель).

---

## Блок 1. Геометрическая прогрессия

### Что это такое

**Определение.** Геометрическая прогрессия — это числовая последовательность, в которой каждый следующий член равен предыдущему, умноженному на одно и то же число q (знаменатель), q ≠ 0.

### Примеры

3, 6, 12, 24, ... — q = 2.
2, -6, 18, -54, ... — q = -3.
16, 4, 1, 1/4, ... — q = 1/4.

### Формула n-го члена

bₙ = b₁ · q^(n-1).

---

## Блок 2. Свойства геометрической прогрессии

### Характеристическое свойство

bₙ² = bₙ₋₁ · bₙ₊₁ (каждый член в квадрате равен произведению соседних).

### Знаки

- Если q > 0: все члены одного знака (как у b₁).
- Если q < 0: знаки чередуются.
- Если b₁ > 0 и q > 1: возрастает.
- Если b₁ > 0 и 0 < q < 1: убывает.

---

## Блок 3. Формула суммы

### Сумма n первых членов

Sₙ = b₁ · (q^n - 1) / (q - 1), если q ≠ 1.
Если q = 1, то Sₙ = n · b₁.

### Сумма бесконечно убывающей геометрической прогрессии (|q| < 1)

S = b₁ / (1 - q).

### Задача с разбором

**Задача.** b₁ = 2, q = 3. Найди b₅ и S₅.

Решение:
- b₅ = 2 · 3⁴ = 2 · 81 = 162.
- S₅ = 2 · (3⁵ - 1) / (3 - 1) = 2 · 242 / 2 = 242.

**Ответ: b₅ = 162, S₅ = 242.**

### Реши сам

**Задача 1.** b₁ = 5, q = 2. Найди b₆.

<details>
<summary>Ответ</summary>

b₆ = 5 · 2⁵ = 5 · 32 = 160.
</details>

**Задача 2.** Сумма бесконечно убывающей геометрической прогрессии 8, b₁ = 4. Найди q.

<details>
<summary>Ответ</summary>

S = b₁ / (1 - q) → 8 = 4 / (1 - q) → 1 - q = 1/2 → q = 1/2.
</details>

---

## Блок 5. Характеристическое свойство

**bₙ² = bₙ₋₁ · bₙ₊₁.**

Пример: 2, 6, 18, 54. 6² = 36, 2 · 18 = 36 ✓.

**Задача 2.** b₁ = 1, q = -2. Найди b₅.
<details>
<summary>Ответ</summary>

b₅ = 1 · (-2)⁴ = 16.
</details>

**Задача 3.** Сумма 4 членов геометрической прогрессии 150, b₁ = 8. Найди q.
<details>
<summary>Ответ</summary>

S₄ = 8(q⁴ - 1)/(q - 1) = 150. 8(q² + 1)(q + 1) = 150. (q² + 1)(q + 1) = 18,75. Попробуй q = 1,5: (2,25 + 1)(2,5) = 3,25 · 2,5 = 8,125 ≠ 18,75. q = 2: 5 · 3 = 15. q = 2,5: (6,25 + 1)(3,5) = 7,25 · 3,5 = 25,375. Итого не целый q.
</details>

## Босс-файт

### Задача 1. Сумма трёх чисел, образующих геометрическую прогрессию, равна 26. Среднее равно 6. Найди числа.

**Решение:** числа b/q, b, bq. Сумма: b/q + b + bq = 26. b = 6. 6/q + 6 + 6q = 26 → 6/q + 6q = 20 → 6(q² + 1) = 20q → 6q² - 20q + 6 = 0 → 3q² - 10q + 3 = 0. D = 100 - 36 = 64. q = (10 ± 8)/6. q = 3 или q = 1/3. Числа: 2, 6, 18 или 18, 6, 2.

### Задача 2. b₁ = 1, b₃ = 16. Найди прогрессию.

**Решение:** b₃ = b₁ · q² = 16 → q² = 16 → q = ±4. Прогрессия: 1, 4, 16, ... или 1, -4, 16.

### Задача 3. b₁ + b₃ = 10, b₂ · b₃ = -8. Найди прогрессию.

**Решение:** пусть b₁ = a, q = r. a + ar² = 10. ar · ar² = a²r³ = -8. Дели: (a + ar²)/(a²r³) = -10/8. (1 + r²)/(ar²) = -5/4. Подбери r. При r = -1: 2 / a = -5/4 → a = -8/5. Проверим: b₁ = -8/5, b₂ = 8/5, b₃ = -8/5. b₁ + b₃ = -16/5 ≠ 10. Не подходит.

### Задача 4. Найди S₄ геометрической прогрессии, если b₂ = 6, b₄ = 54.

**Решение:** b₄ = b₂ · q² → 54 = 6q² → q² = 9 → q = ±3. b₁ = b₂/q = 6/q.
S₄ = b₁(q⁴ - 1)/(q - 1). При q = 3: b₁ = 2. S₄ = 2 · 80/2 = 80.
При q = -3: b₁ = -2. S₄ = -2 · 80/(-4) = 40.
