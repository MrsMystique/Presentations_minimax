## Блок 1. Числовые неравенства и их свойства

### Зачем тебе это знать

Без этих свойств ты не сможешь решать неравенства, потому что каждый шаг решения — это либо сложение/вычитание, либо умножение/деление, либо возведение в степень. И для каждого действия есть своё правило.

### Что это такое

Число a больше числа b, если разность a - b — положительное число. Число a меньше b, если a - b — отрицательное.

**Строгие неравенства:** <, > (границы не включаются).
**Нестрогие неравенства:** ≤, ≥ (границы включаются).

### Главные свойства неравенств

1) Если a > b, то b < a.
2) Если a < b и b < c, то a < c.
3) Если к обеим частям прибавить одно и то же число, получится верное неравенство.
4) Если обе части умножить или разделить на одно и то же положительное число — знак сохраняется.
5) Если обе части умножить или разделить на одно и то же отрицательное число — знак меняется на противоположный.

### Откуда эти правила

Из здравого смысла. Если у тебя 5 яблок, а у Пети 3, и тебе дали ещё 2 яблока, то у тебя 7, у Пети 5. Разница осталась 2. Если ты отдал половину яблок (умножил на 1/2 — положительное число), то у тебя 7/2 = 3,5, у Пети 5/2 = 2,5, разница 1 — знак сохранился.

Если ты «отдал» все яблоки Пете (умножил на -1), то у тебя -5, у Пети -3, теперь ты «меньше» — знак поменялся.

### Как применять на практике

Пример: x + 3 < 7 → вычти 3 из обеих частей → x < 4. (Прибавление одного числа сохраняет знак.)

Пример: -2x > 6 → раздели на -2, знак меняется → x < -3.

### Где применить

В задачах с процентами: «цена выросла меньше чем на 5%» → новая_цена < 1,05 · старая_цена.
В задачах с границами: «возраст от 18 до 25» → 18 ≤ возраст ≤ 25.

### Где ошибиться

**Ловушка «при умножении на -1 знак сохраняется».** Нет, меняется на противоположный. -3 < 5 → после умножения на -1 → 3 > -5 (не 3 < -5).

**Ловушка «возведение в квадрат сохраняет знак».** Сохраняет только если обе части неотрицательные. Иначе нельзя.

**Ловушка «почленное сложение всегда работает».** Работает для неравенств одного знака: если a < b и c < d, то a + c < b + d.

### Задача с разбором

**Задача.** Сложи почленно неравенства 2 < 3 и 5 < 7.

Решение: оба неравенства одного знака (<). Складываем: 2 + 5 < 3 + 7 → 7 < 10. ✓

**Ответ: 7 < 10.**

## Блок 2. Числовые промежутки

### Зачем тебе это знать

Решение любого неравенства — это числовой промежуток. Если ты не знаешь, как его записывать и читать, ты не сможешь ответить на вопрос «на каком промежутке лежат решения?»

### Что это такое

Числовой промежуток — это множество чисел между двумя границами (включая или не включая их).

**Основные виды:**
- (-∞; +∞) — все числа.
- [a; +∞) — от a включительно и дальше.
- (-∞; a] — все числа до a включительно.
- (a; +∞) — от a (не включая) и дальше.
- (-∞; a) — все числа до a (не включая).
- [a; b] — отрезок, обе границы включены.
- (a; b) — интервал, обе границы исключены.
- [a; b), (a; b] — полуинтервалы, одна граница включена.

### Откуда это

Из координатной прямой. Каждому промежутку соответствует штриховка на прямой: закрашенная точка — граница включена, пустая — исключена.

### Как записывать и читать

- (-∞; +∞): «от минус бесконечности до плюс бесконечности», все числа.
- [a; +∞): «от a включительно и до плюс бесконечности».
- (-∞; a]: «от минус бесконечности до a включительно».
- (a; +∞): «от a (не включая) до плюс бесконечности».
- (-∞; a): «от минус бесконечности до a (не включая)».

### Где применить

В задачах: «найди все x, при которых функция определена» — ответ в виде промежутка.
В задачах с возрастом: «от 18 до 25 лет» → [18; 25].

### Где ошибиться

**Ловушка «(-∞; +∞) содержит бесконечности».** Нет, это просто обозначение для «все числа». Бесконечности не являются числами.

**Ловушка «скобки [ и ] всегда означают одно и то же».** Нет, круглая ( ) — граница исключена, квадратная [ ] — включена.

**Ловушка «(a; b) и [a; b] отличаются только одной точкой».** Нет, различаются тем, включена ли a и включена ли b.

### Задача с разбором

**Задача.** Запиши промежуток «все числа от -3 (включительно) до 7 (не включая)».

Решение: левая граница -3 включительно → [-3. Правая граница 7 не включена → 7). Получаем [-3; 7).

**Ответ: [-3; 7).**

### Реши сам

> Подсказка 1 (направление): 5 не включена (строгое неравенство).

<details>
<summary>Разбор</summary>

</details>

> Подсказка 1 (направление): -1 включено, 4 не включено.

## Блок 3. Линейное неравенство с одной переменной

### Зачем тебе это знать

Это базовый инструмент. Каждое неравенство в задачах (от простых уравнений до сложных систем) в конечном счёте сводится к линейному неравенству ax > b или подобному.

### Что это такое

**Определение.** Неравенства вида ax > b, ax < b, ax ≤ b, ax ≥ b, где a и b — числа, x — переменная, называются линейными неравенствами с одной переменной.

**Определение.** Решением неравенства называется число, подстановка которого обращает неравенство в верное числовое неравенство.

**Определение.** Решить неравенство — значит найти все его решения или доказать, что решений нет.

### Как решать

Тот же алгоритм, что и для уравнений:
1) Раскрыть скобки.
2) Привести подобные.
3) Перенести слагаемые с переменной в одну сторону, числа — в другую.
4) Разделить обе части на коэффициент при x (с переменой знака, если он отрицательный).
6) Записать ответ в виде промежутка.

### Откуда алгоритм

Из тех самых 5 свойств числовых неравенств. Каждый шаг — равносильное преобразование.

### Где применить

В задачах на оптимизацию: «найди минимальное x, при котором выполняется условие».
В задачах с границами: «при каких x функция положительна».

### Где ошибиться

**Ловушка «при делении на отрицательное число знак сохраняется».** Нет, меняется. -3x > 6 → делим на -3 → x < -2.

**Ловушка «0x > 5 имеет решения».** Нет, 0 > 5 — неверно ни при каком x.

**Ловушка «0x < 5 не имеет решений».** Имеет: 0 < 5 — верно при любом x.

### Задача с разбором

**Задача.** Реши 5x < -30.

Решение: 5x < -30 → делим обе части на 5 (положительное, знак сохраняется) → x < -6.

**Ответ: x < -6, то есть (-∞; -6).**

## Блок 4. Равносильные неравенства

### Зачем тебе это знать

Когда ты решаешь неравенство, ты заменяешь его более простым. Если новое имеет то же множество решений — оно равносильно. Если нет — ты ошибся.

### Что это такое

**Определение.** Неравенства, имеющие одно и то же множество решений, называются равносильными.

### Правила равносильных преобразований

1) Прибавление к обеим частям одного и того же числа (перенос слагаемого с переменой знака).
2) Умножение или деление обеих частей на одно и то же положительное число.
3) Умножение или деление обеих частей на одно и то же отрицательное число с переменой знака.
4) Тождественные преобразования в любой части.

### Откуда правила

Из тех же 5 свойств числовых неравенств, что и в Блоке 1.

### Где ошибиться

**Ловушка «можно умножать на любое число».** Нельзя умножать на ноль (получается 0 = 0 — неравенство теряет смысл).

**Ловушка «при делении на отрицательное число можно забыть про знак».** Нельзя. Это самое частое место ошибок.

**Ловушка «равносильные неравенства имеют одинаковый вид».** Не обязательно. x > 5 и 2x > 10 — равносильны, но записаны по-разному.

### Задача с разбором

**Задача.** Равносильны ли x + 3 > 5 и x > 2?

Решение:
- x + 3 > 5 → x > 2.
- x > 2.

Множества решений совпадают: (2; +∞). Значит, равносильны.

**Ответ: да, равносильны.**

> Подсказка 1 (направление): реши первое.

<summary>Подсказка 2 (конкретный шаг)</summary>

-3x > 9 → делим на -3, знак меняется → x < -3.
</details>

<details>
<summary>Разбор</summary>

Множества совпадают: (-∞; -3). **Ответ: да, равносильны.**
</details>

**Задача 2.** Какое преобразование переводит 2x - 4 > 0 в x > 2?

> Подсказка 1 (направление): как избавиться от -4 и от 2?

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

Прибавь 4 к обеим частям, потом раздели на 2.
</details>

</details>

## Блок 5. Системы линейных неравенств

### Зачем тебе это знать

В задачах часто бывает несколько условий одновременно: «x > 5 и x < 10» — это система из двух неравенств. Без навыка решать системы ты не справишься с условиями из текстовых задач.

### Что это такое

**Определение.** Решением системы неравенств называется значение переменной, удовлетворяющее каждому неравенству системы.

**Определение.** Решить систему — значит найти множество всех её решений.

### Как решать

1) Привести каждое неравенство к виду x > a, x < a, x ≤ a или x ≥ a.
2) На координатной прямой штриховкой отметить решения каждого неравенства.
3) Найти пересечение числовых промежутков.
4) Записать ответ.

### Откуда это

Из понятия пересечения множеств. Решение системы — это значения, которые одновременно принадлежат во все множества-решения каждого неравенства. Значит, это их пересечение.

### Где применить

В задачах: «найди все x, для которых одновременно x > 5 и x < 10» — ответ (5; 10).
В задачах на возраст: «не меньше 18, но не больше 65» — [18; 65].

### Где ошибиться

**Ловушка «систему нужно решать как одно неравенство».** Нет, нужно решать каждое отдельно, потом найти пересечение.

**Ловушка «если множества не пересекаются, у системы нет решений».** Верно. Если множества пусты — система не имеет решений.

**Ловушка «пересечение — это сложение».** Нет, пересечение (∩) — это общая часть, объединение (∪) — это всё вместе.

### Задача с разбором

**Задача.** Реши систему {x ≥ 3, x + 3 < 4}.

Решение:
- x ≥ 3 → x ∈ [3; +∞).
- x + 3 < 4 → x < 1 → x ∈ (-∞; 1).

Пересечение: [3; +∞) ∩ (-∞; 1) = ∅ (пустое множество).

**Ответ: решений нет.**

<details>

(2; +∞) ∩ (-∞; 7) = (2; 7).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (2; 7).**
</details>

## Блок 6. Совокупности неравенств

### Зачем тебе это знать

В задачах бывает условие «x > 5 или x < -3» — это совокупность. Если перепутать совокупность с системой, ответ будет противоположным.

### Что это такое

**Определение.** Если нужно найти множество значений, каждое из которых является решением хотя бы одного из данных неравенств, говорят: нужно решить совокупность неравенств.

**Определение.** Решением совокупности называется значение переменной, удовлетворяющее хотя бы одному из неравенств.

### Как решать

1) Привести каждое неравенство к виду x > a, x < a, x ≤ a или x ≥ a.
2) На координатной прямой штриховкой отметить решения каждого.
3) Найти объединение числовых промежутков.
4) Записать ответ.

### Откуда это

Из понятия объединения множеств. Решение совокупности — это значения, которые принадлежат хотя бы одному из множеств. Значит, это их объединение.

### Где применить

В задачах: «x либо больше 5, либо меньше -3» — это совокупность.
В задачах с условиями типа «или-или».

### Где ошибиться

**Ловушка «совокупность и система решаются одинаково».** Нет. Система — пересечение, совокупность — объединение. Это разные операции.

**Ловушка «пустое объединение невозможно».** Возможно: совокупность 0x = 5 и 0x = -5 не имеет решений.

**Ловушка «объединение всегда связное».** Нет, может быть два куска: x < 1 или x > 3 → (-∞; 1) ∪ (3; +∞).

### Задача с разбором

**Задача.** Реши совокупность {x < 2, x > 5}.

Решение:
- x < 2 → (-∞; 2).
- x > 5 → (5; +∞).
- Объединение: (-∞; 2) ∪ (5; +∞).

**Ответ: (-∞; 2) ∪ (5; +∞).**

### Реши сам

**Задача 1.** Реши совокупность {x ≤ 1, x ≥ 4}.

> Подсказка 1 (направление): найди объединение (-∞; 1] и [4; +∞).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(-∞; 1] ∪ [4; +∞).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (-∞; 1] ∪ [4; +∞).**
</details>

**Задача 2.** Реши совокупность {x < 3, x < 7}.

> Подсказка 1 (направление): одно из неравенств «слабее» другого.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

x < 7 — слабее (покрывает x < 3). Объединение = (-∞; 7).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (-∞; 7).**
</details>

## Блок 7. Двойные неравенства

### Зачем тебе это знать

Двойное неравенство a < x < b — это удобная запись для «x между a и b». Это часто встречается в задачах на промежутки, границы, нормальные диапазоны.

### Что это такое

**Двойное неравенство** m < a < n (или с другими знаками) — это неравенство, в котором переменная «зажата» между двумя числами.

Двойное неравенство можно рассматривать как систему из двух неравенств: a > m и a < n.

### Как решать

Перевести в систему, решить каждое неравенство, найти пересечение.

### Откуда это

Из удобства записи: вместо «x > -3 и x < 5» проще написать -3 < x < 5.

### Где применить

В задачах: «найди целые решения -3 < x < 5» — это x ∈ {-2, -1, 0, 1, 2, 3, 4}.
В задачах на границы: «x ∈ [-20,8; 2,4)» — это двойное неравенство.

### Где ошибиться

**Ловушка «при делении всех частей на отрицательное число оба знака меняются».** Меняются оба. -3 < x < 5 → делим на -2 → получаем 1,5 > x/(-2) > -2,5 → переписываем -2,5 < x/(-2) < 1,5 — то есть меняется направление.

**Ловушка «границы можно прибавлять к любой части».** К любой, но ко всем трём (или к обеим крайним).

### Задача с разбором

**Задача.** Реши -143,9 < 1,7 + 7x < 18,5.

Решение:
Шаг 1: Вычтем 1,7 из всех частей: -145,6 < 7x < 16,8.
Шаг 2: Разделим все части на 7 (положительное, знаки сохраняются): -20,8 < x < 2,4.

**Ответ: x ∈ (-20,8; 2,4).**

### Реши сам

**Задача 1.** Реши -2 < 3x + 1 < 7.

> Подсказка 1 (направление): вычти 1 из всех частей, потом раздели на 3.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

-3 < 3x < 6 → -1 < x < 2.
</details>

<details>
<summary>Разбор</summary>

**Ответ: x ∈ (-1; 2).**
</details>

**Задача 2.** Реши -4 ≤ -2x ≤ 6.

> Подсказка 1 (направление): делим все части на -2 — оба знака меняются.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

-4 / -2 ≥ x ≥ 6 / -2 → 2 ≥ x ≥ -3. Перепишем: -3 ≤ x ≤ 2.

## Босс-файт: задачи на линейные неравенства и системы

Четыре задачи — на совокупности, двойные неравенства, системы, графическое решение.

### Задача 1. Какая система равносильна {x ≥ 3, x < 7}?

**Условие.** Среди предложенных систем найди ту, которая равносильна {x ≥ 3, x < 7}.

Решение: проверяем каждую:
1) {x ≥ 3, -x < 7} → x ≥ 3 и x > -7. Это [3; +∞) ∩ (-7; +∞) = [3; +∞) — НЕ подходит.
2) {x + 1 ≥ 2, x < 7} → x ≥ 1 и x < 7. Это [1; 7) — НЕ подходит.
3) {x ≥ 3, x + 3 < 4} → x ≥ 3 и x < 1. Это пустое множество — НЕ подходит.
4) {x + 4 ≥ 7, x - 1 < 6} → x ≥ 3 и x < 7. Это [3; 7) — ПОДХОДИТ.
5) {2x ≥ 3, x < 7} → x ≥ 1,5 и x < 7. Это [1,5; 7) — НЕ подходит.

**Ответ: 4.**

### Задача 2. Изобрази решение системы {x ≤ 1,5; 1 - 5x < 16}

**Условие.** Изобрази на координатной прямой и запиши в виде промежутка.

Решение:
- x ≤ 1,5 → (-∞; 1,5].
- 1 - 5x < 16 → -5x < 15 → x > -3.

Пересечение: (-3; 1,5].

На координатной прямой: пустая точка в -3, закрашенная точка в 1,5, штриховка между ними.

**Ответ: (-3; 1,5].**

### Задача 3. Найди сумму наибольшего и наименьшего целых решений двойного неравенства

**Условие.** -143,9 < 1,7 + 7x < 18,5. Найди сумму наибольшего и наименьшего целых решений.

Решение:
- Вычтем 1,7: -145,6 < 7x < 16,8.
- Разделим на 7: -20,8 < x < 2,4.

Целые решения: -20, -19, ..., 1, 2. Наименьшее: -20, наибольшее: 2. Сумма: -20 + 2 = -18.

**Ответ: -18.**

### Задача 4. Найди все целые решения системы {2x - 1 > 0, x + 4 < 12}

**Условие.** Найди сумму целых решений.

Решение:
- 2x - 1 > 0 → 2x > 1 → x > 0,5.
- x + 4 < 12 → x < 8.

Пересечение: (0,5; 8).

Целые решения: 1, 2, 3, 4, 5, 6, 7. Сумма: 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28.

**Ответ: 28.**

## Сборник формул

### Свойства неравенств

1) a > b ⇔ b < a.
2) a < b и b < c → a < c.
3) a < b → a + c < b + c.
4) a < b и c > 0 → ac < bc.
5) a < b и c < 0 → ac > bc.

### Числовые промежутки

- (-∞; +∞) — все числа.
- [a; +∞), (-∞; a] — лучи с включённой границей.
- (a; +∞), (-∞; a) — открытые лучи.
- [a; b], (a; b), [a; b), (a; b] — отрезок, интервал, полуинтервалы.

### Решение систем

Пересечение множеств (∩) для системы, объединение (∪) для совокупности.

### Двойное неравенство

m < x < n ⇔ {x > m, x < n}.
