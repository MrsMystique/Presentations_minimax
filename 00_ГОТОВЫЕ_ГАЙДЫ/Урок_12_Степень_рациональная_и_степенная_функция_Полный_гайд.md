## Блок 1. Степень с рациональным показателем и её свойства

### Зачем тебе это знать

Степень с рациональным показателем — это запись корня и умножения одновременно. С ней работают те же правила, что и с целой степенью: a^(m/n) · a^(p/q) = a^(m/n + p/q). Это значит, что любые задачи на степени можно унифицировать и решать по одним формулам.

### Что это такое

Степень с рациональным показателем a^(m/n) — это запись для корня n-й степени из a в степени m:

a^(m/n) = ⁿ√(a^m) = (ⁿ√a)^m.

Например: 8^(2/3) = ∛(8²) = ∛64 = 4. Или: 8^(2/3) = (∛8)² = 2² = 4.

### Свойства — те же, что у целых степеней

- a^(m/n) · a^(p/q) = a^(m/n + p/q) — при умножении показатели складываются.
- a^(m/n) / a^(p/q) = a^(m/n − p/q) — при делении показатели вычитаются.
- (a^(m/n))^q = a^m — при возведении в степень показатели перемножаются.
- a^(-m/n) = 1 / a^(m/n) — отрицательный показатель переворачивает дробь.

Эти правила работают при условии a > 0 (для дробных показателей).

### Откуда

Свойства степени обобщаются с целых показателей на рациональные через общий знаменатель. Если a^(m/n) · a^(p/q) = ⁿ√(a^m) · ᵠ√(a^p), то нужно привести корни к общему знаменателю: ⁿᵠ√(a^(m·q)) · ⁿᵠ√(a^(p·n)) = ⁿᵠ√(a^(m·q + p·n)) = a^((mq + pn)/(nq)) = a^(m/n + p/q).

### Как пользоваться

Работай с дробными показателями так же, как с целыми — по тем же правилам. Главное помнить про ОДЗ: a > 0 для дробных показателей.

Пример: упростить a^(2/3) · a^(1/6):
1. Показатели складываются: 2/3 + 1/6 = 4/6 + 1/6 = 5/6.
2. Ответ: a^(5/6).

### Где применить

В упрощении выражений: x^(1/2) · x^(1/3) = x^(5/6).
В сравнении: 2^(3/5) и 2^(4/7) — больше то, у которого показатель больше.
В вычислениях: 8^(2/3) = 4 (через корни).

### Где ошибиться

**Ловушка «дроби в показателе можно складывать как обычные дроби без общего знаменателя».** Нельзя! 1/2 + 1/3 = 5/6, не 2/5. Нужен общий знаменатель.

**Ловушка «(a · b)^(m/n) = a^(m/n) · b^(m/n) работает всегда».** Работает только при a ≥ 0, b ≥ 0.

**Ловушка «a^(m/n) = (a^m)^(1/n) = (a^(1/n))^m — все три равны».** Это верно для a > 0. Для a < 0 — не всегда (см. знаменитый парадокс: (-1)^(1/2) = i, но (-1)^(2/4) = 1).

### Задача с разбором

**Задача.** Упрости a^(2/3) · a^(1/6).

**Разбор:**
1. a^(2/3) · a^(1/6) = a^(2/3 + 1/6).
2. 2/3 + 1/6 = 4/6 + 1/6 = 5/6.
3. Ответ: a^(5/6).

**Ответ: a^(5/6).**

## Блок 2. Степень с действительным показателем

### Зачем тебе это знать

Потому что не все показатели — рациональные. Есть иррациональные: √2, π, e. С ними работают так же, как с рациональными, но для конкретных вычислений нужен калькулятор.

### Что это такое

Степень с действительным показателем a^α — это предел последовательности a^(α_n), где α_n — рациональные числа, приближающие α.

Для a > 0 значение a^α определено для любого α ∈ R.

### Свойства — те же

Для a > 0:
- a^α · a^β = a^(α+β).
- a^α / a^β = a^(α−β).
- (a^α)^β = a^(α·β).
- a^(−α) = 1 / a^α.

### Как пользоваться

Работаешь так же, как с рациональными. Для конкретного значения используешь калькулятор.

Примеры:
- 2^π ≈ 8,54.
- 2^√2 ≈ 2,665.
- 10^(-√2) ≈ 0,025.

### Где применить

В физике: экспоненциальный рост N(t) = N₀ · e^(kt) — здесь e ≈ 2,71828.
В финансах: сложный процент P(t) = P₀ · (1 + r)^t, где t может быть нецелым.

### Где ошибиться

**Ловушка «a^α определено для всех a».** Только для a > 0. Для a = 0 — только при α > 0. Для a < 0 — только при целых α.

### Задача с разбором

**Задача.** Что больше: 2^√3 или 2^π?

**Разбор:**
1. Основание 2 > 1 — функция 2^x возрастает.
2. π ≈ 3,14159, √3 ≈ 1,73205.
3. π > √3.
5. Значит 2^π > 2^√3.

**Ответ: 2^π > 2^√3.**

## Блок 3. Сравнение степеней

### Зачем тебе это знать

Потому что в задачах ЦТ часто спрашивают: «Какое из чисел больше?» И нужно уметь сравнивать 3^π и π^3, или 2^√5 и 5^√2, или a^x и a^y при разных условиях.

### Главное правило

Если основания одинаковые и больше 1, то больше та степень, у которой показатель больше.

Если основания одинаковые и между 0 и 1, то наоборот — больше та, у которой показатель меньше.

Если основания разные — нужно приводить к одному основанию, или оценивать через калькулятор.

### Как сравнивать

**Случай 1.** Одинаковое основание: a^x vs a^y при a > 1.
- Если x > y, то a^x > a^y.
- Если x < y, то a^x < a^y.

**Случай 2.** Разные основания: a^x vs b^y.
- Привести к одному основанию через свойства степени.
- Или использовать численную оценку.

### Где применить

В задачах на сравнение (типичная задача ЦТ).
В доказательстве неравенств.

### Где ошибиться

**Ловушка «чем больше основание, тем больше степень».** Неверно при разных показателях. 2^10 = 1024, но 10^2 = 100. 2^10 > 10^2, хотя основание 2 меньше 10. Здесь показатель 10 > 2 важнее.

### Задача с разбором

**Задача.** Сравни 3^π и π^3.

**Разбор:**
1. Численная оценка: π ≈ 3,14159, 3^π ≈ 3^3,14 ≈ 31,5.
2. π^3 ≈ 3,14³ ≈ 31,0.
3. 3^π > π^3, но очень незначительно.

(Точнее: 3^π ≈ 31,544, π^3 ≈ 31,006, разница около 1,7%.)

**Ответ: 3^π > π^3, но незначительно.**

## Блок 4. Степенная функция

### Зачем тебе это знать

Степенная функция y = x^α — это фундаментальная модель в физике, экономике, биологии. Без неё ты не прочитаешь половину задач ЦТ.

### Что это такое

Степенная функция — это функция вида y = x^α, где α — фиксированное действительное число.

### Свойства — таблица по α

- α > 0: возрастает на (0, +∞), проходит через (0, 0) и (1, 1).
- α < 0: убывает на (0, +∞), при x → 0⁺ уходит в +∞, при x → +∞ стремится к 0.
- α = 0: постоянная y = 1.
- α = 1: y = x (биссектриса).

### Область определения

- Если α целое ≥ 0: D(f) = R.
- Если α целое < 0: D(f) = R без 0.
- Если α дробный с чётным знаменателем: D(f) = [0, +∞).
- Если α дробный с нечётным знаменателем: D(f) = R.
- Если α иррациональный: D(f) = (0, +∞).

### Где применить

В физике: y = x² (равноускоренное движение), y = x^(1/2) (свободное падение).
В экономике: y = x^(−1) (закон обратной пропорциональности).
В биологии: аллометрическое масштабирование b = k · m^(3/4).

### Где ошибиться

**Ловушка «D(f) = R всегда».** Нет! Только для целых неотрицательных α. Для α = 1/2 D(f) = [0, +∞).

### Задача с разбором

**Задача.** Найди D(f) для y = x^(1/2).

**Разбор:**
1. α = 1/2 — дробный с чётным знаменателем.
2. По таблице: D(f) = [0, +∞).

**Ответ: D(f) = [0, +∞).**

## Сборник формул

### Определение

a^α, при a > 0 для любого α, при a ≤ 0 только для целых α ≥ 0.

### Свойства (при a > 0)

- a^α · a^β = a^(α+β).
- a^α / a^β = a^(α−β).
- (a^α)^β = a^(α·β).
- a^(−α) = 1 / a^α.

### Связь с корнями

a^(m/n) = ⁿ√(a^m).

### Условия применимости

- a > 0 — для дробных и иррациональных показателей.
- a ≥ 0 — для целых показателей ≥ 0.
- a < 0 — нельзя возводить в дробную степень (получим комплексные).
