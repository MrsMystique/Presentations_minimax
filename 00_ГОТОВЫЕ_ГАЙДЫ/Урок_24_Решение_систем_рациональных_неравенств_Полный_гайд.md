## Блок 1. Алгоритм решения системы

### Зачем тебе это знать

Системы неравенств — это способ описать «x удовлетворяет сразу нескольким условиям». Это часто встречается в задачах.

### Алгоритм

1) Реши каждое неравенство системы отдельно.
2) Изобрази решения каждого неравенства на одной числовой прямой.
3) Найди пересечение всех множеств решений (общую часть).
4) Запиши ответ.

### Откуда алгоритм

Из того, что решение системы — это значения, которые удовлетворяют всем неравенствам одновременно. Это и есть пересечение.

### Где применить

В задачах: «найди x, для которого одновременно f(x) > 0 и g(x) < 0».

### Где ошибиться

**Ловушка «система — это объединение».** Нет, это пересечение.

**Ловушка «пустое пересечение означает, что нет решений».** Верно. Если у системы нет общей части, у неё нет решений.

### Задача с разбором

**Задача.** Реши {(x - 2)(x + 3) > 0, x > 0}.

Решение:
1) Первое: (-∞; -3) ∪ (2; +∞).
2) Второе: (0; +∞).
3) Пересечение: (2; +∞).

**Ответ: (2; +∞).**

### Реши сам

**Задача 1.** Реши {(x - 1)(x + 4) < 0, x > -2}.

> Подсказка 1 (направление): первое — (-4; 1).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(-4; 1) ∩ (-2; +∞) = (-2; 1).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (-2; 1).**
</details>

**Задача 2.** Реши {x² - 4 < 0, x² - 9 < 0}.

> Подсказка 1 (направление): первое — (-2; 2), второе — (-3; 3).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(-2; 2) ∩ (-3; 3) = (-2; 2).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (-2; 2).**
</details>

**Задача 3.** Реши {(x - 2)/(x + 1) > 0, x > 0}.

> Подсказка 1 (направление): первое — (-∞; -1) ∪ (2; +∞).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

((-∞; -1) ∪ (2; +∞)) ∩ (0; +∞) = (2; +∞).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (2; +∞).**
</details>

## Блок 2. Сложные системы с дробями

### Зачем тебе это знать

В задачах часто встречаются системы, где каждое неравенство — дробно-рациональное. Это требует навыка из Урока 23.

### Пример

{(x - 1)/(x + 2) > 0, (x + 1)/(x - 3) < 0}.

Решение:
1) Первое: x ∈ (-∞; -2) ∪ (1; +∞).
2) Второе: x ∈ (-1; 3).
3) Пересечение: (1; 3).

### Где ошибиться

**Ловушка «каждое неравенство решается само по себе».** Да, но ответ — это пересечение.

### Задача с разбором

**Задача.** Реши {(x² - 9)/(x - 1) > 0, x² < 4}.

Решение:
1) Первое: (x - 3)(x + 3)/(x - 1) > 0. Нули: -3, 1 (выколотое), 3.
Знаки: самый правый «+», чередуем: (-3; 1) «-», (-∞; -3) «+», (1; 3) «+».
Решение: (-∞; -3) ∪ (1; 3).
2) Второе: (-2; 2).
3) Пересечение: (-2; -3) ∪ (1; 2).

Но (-2; -3) — пустое (т.к. -3 < -2). Значит, ответ: (1; 2).

**Ответ: (1; 2).**

### Реши сам

**Задача 1.** Реши {(x² - 1)/(x + 3) ≥ 0, x ≥ 0}.

> Подсказка 1 (направление): первое — (-∞; -3) ∪ [-1; 1] ∪ ... попробуй сам.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

(x - 1)(x + 1)/(x + 3) ≥ 0. Нули: -3 (выколотое), -1, 1.
Знаки справа «+»: (1; +∞) «+»; (-1; 1) «-»; (-3; -1) «+»; (-∞; -3) «-».
≥ 0: (-∞; -3) ∪ [-1; 1].
Пересечение с x ≥ 0: [0; 1].
</details>

<details>
<summary>Разбор</summary>

**Ответ: [0; 1].**
</details>

## Босс-файт

### Задача 1. Реши {(x - 4)(x + 5) ≤ 0, x > -3}

**Решение:** первое — [-5; 4]. Пересечение с (-3; +∞): (-3; 4].

**Ответ: (-3; 4].**

### Задача 2. Реши {(x² - 4)/(x + 1) > 0, x < 3}

**Решение:** (x - 2)(x + 2)/(x + 1) > 0. Нули: -2, -1 (выколотое), 2.
Знаки: (-∞; -2) «+»; (-2; -1) «-»; (-1; 2) «+»; (2; +∞) «-».
Решение: (-∞; -2) ∪ (-1; 2).
Пересечение с x < 3: (-∞; -2) ∪ (-1; 2).

**Ответ: (-∞; -2) ∪ (-1; 2).**

### Задача 3. Реши {(x + 3)/(x - 5) > 0, (x - 1)/(x + 2) < 0}

**Решение:** первое — (-∞; -3) ∪ (5; +∞). Второе — (-2; 1).
Пересечение: пустое (нет общей части).

**Ответ: нет решений.**

### Задача 4. Реши {(x - 2)(x + 1) ≥ 0, (x + 4)/(x - 3) ≤ 0}

**Решение:** первое — (-∞; -1] ∪ [2; +∞). Второе — [-4; 3).
Пересечение: [-4; -1] ∪ [2; 3).

**Ответ: [-4; -1] ∪ [2; 3).**
