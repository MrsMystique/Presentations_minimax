## Блок 1. Простейшие тригонометрические уравнения

### Уравнение sin x = a

- **|a| > 1:** решений нет.
- **|a| ≤ 1:** x = (-1)^n · arcsin(a) + πn, n ∈ Z.

Частные случаи: sin x = 0 → x = πn; sin x = 1 → x = π/2 + 2πn; sin x = -1 → x = -π/2 + 2πn.

### Уравнение cos x = a

- **|a| > 1:** решений нет.
- **|a| ≤ 1:** x = ±arccos(a) + 2πn, n ∈ Z.

Частные случаи: cos x = 0 → x = π/2 + πn; cos x = 1 → x = 2πn; cos x = -1 → x = π + 2πn.

### Уравнение tan x = a

x = arctan(a) + πn, n ∈ Z.

### Уравнение cot x = a

x = arcctg(a) + πn, n ∈ Z.

## Блок 2. Методы решения

### 1. Разложение на множители

sin 2x - sin x = 0 → 2 sin x cos x - sin x = sin x(2 cos x - 1) = 0.

### 2. Замена переменной

2 sin²x + sin x - 1 = 0. Замена y = sin x. y² + y - 1 = 0... нет, лучше 2y² + y - 1 = 0.

### 3. Однородные уравнения

sin x - cos x = 0. Поделим на cos x: tan x - 1 = 0 → tan x = 1.

### 4. Универсальная подстановка

t = tan(x/2). sin x = 2t/(1+t²), cos x = (1-t²)/(1+t²).

## Блок 4. Отбор корней

### С помощью тригонометрической окружности

Нарисуй окружность, отметь решения, выбери те, что в нужном диапазоне.

### Задача с разбором

**Задача.** Найди корни sin x = 1/2 на [-π; 4π/3].

Решение: общие корни x = π/6 + 2πn или x = 5π/6 + 2πn.
- n = 0: π/6 ≈ 0,52 (в [-π; 4π/3 ≈ 4,19]). Подходит. 5π/6 ≈ 2,62. Подходит.
- n = 1: π/6 + 2π ≈ 6,81. Не подходит. 5π/6 + 2π ≈ 8,94. Не подходит.
- n = -1: π/6 - 2π ≈ -5,76. Не подходит. 5π/6 - 2π ≈ -3,67. Не подходит.

**Ответ: π/6, 5π/6.**

## Босс-файт

### Задача 1. Реши 2 cos²x + cos x - 1 = 0.

**Решение:** y = cos x. 2y² + y - 1 = 0. D = 1 + 8 = 9. y = (-1 ± 3)/4. y = 1/2 или y = -1.
cos x = 1/2 → x = ±π/3 + 2πn.
cos x = -1 → x = π + 2πn.

### Задача 2. Реши sin x + √3 cos x = 1.

**Решение:** это уравнение вида a sin x + b cos x = c. Делим на √(1+3) = 2: (1/2) sin x + (√3/2) cos x = 1/2 → sin(x + π/3) = 1/2 → x + π/3 = (-1)^n · π/6 + πn → x = (-1)^n · π/6 - π/3 + πn.

### Задача 3. Реши sin 2x = cos x.

**Решение:** 2 sin x cos x = cos x → cos x(2 sin x - 1) = 0 → cos x = 0 или sin x = 1/2.
x = π/2 + πn или x = (-1)^n · π/6 + πn.

### Задача 4. Реши sin x = x/2.

**Решение:** оценочный метод. |sin x| ≤ 1, |x/2| ≤ 1 → |x| ≤ 2. Перебор: x = 0 — корень. Другие? sin x = x/2 — графики пересекаются в одной точке (x = 0). Единственный корень.
