# Урок 55. Логарифмические уравнения и неравенства

## Перед тем как начать

Привет. Этот урок — про логарифмические уравнения и неравенства. Логарифм — это «обратная операция» к степени: log_a(b) — это показатель степени, в которую нужно возвести a, чтобы получить b.

---

## Блок 1. Определение логарифма

### Что это такое

**Определение.** log_a(b) = c ⇔ a^c = b, где a > 0, a ≠ 1, b > 0.

### Задача с разбором

**Задача.** Вычисли log_2(16).

Решение: 2^? = 16 = 2^4 → log_2(16) = 4.

**Ответ: 4.**

## Блок 2. Свойства логарифмов

### Семь свойств

1) **log_a(1) = 0.**
2) **log_a(a) = 1.**
3) **log_a(bc) = log_a(b) + log_a(c).**
4) **log_a(b/c) = log_a(b) - log_a(c).**
5) **log_a(b^c) = c · log_a(b).**
6) **log_a(b) = 1 / log_b(a).**
7) **log_(a^k)(b) = log_a(b) / k.**

## Блок 3. Логарифмические уравнения

### Простейшее

log_a(x) = b → x = a^b.

### Задача с разбором

**Задача.** Реши log_2(x) = 3.

Решение: x = 2^3 = 8.

**Ответ: 8.**

### Метод подстановки

Если log_a²(x) - 3 · log_a(x) + 2 = 0, замени y = log_a(x).

### Задача с разбором

**Задача.** Реши log²x - 3 log x + 2 = 0.

Решение: y = log x. y² - 3y + 2 = 0. y = 1 или y = 2. log x = 1 → x = 10. log x = 2 → x = 100.

**Ответ: 10; 100.**

### Реши сам

## Блок 4. Логарифмические неравенства

### Правило

**Если a > 1:** log_a(f(x)) > log_a(g(x)) ⇔ f(x) > g(x) > 0.
**Если 0 < a < 1:** log_a(f(x)) > log_a(g(x)) ⇔ 0 < f(x) < g(x).

### Задача с разбором

**Задача.** Реши log_2(x - 3) > 2.

Решение: x - 3 > 4 → x > 7.

**Ответ: x > 7.**

### Реши сам

**Задача 1.** Реши log_3(x) > 1.
<details>
<summary>Ответ</summary>

x > 3.
</details>

**Задача 2.** Реши log_(1/2)(x) > 2.
<details>
<summary>Ответ</summary>

(1/2)^x > 2... а, нет. log_(1/2)(x) > 2 → 1/2 > 1, значит функция убывает → x < 1/4. И x > 0. → 0 < x < 1/4.
</details>

## Босс-файт

### Задача 1. Реши log_2(x + 1) + log_2(x - 1) = 3.

**Решение:** log_2((x+1)(x-1)) = 3 → (x+1)(x-1) = 8 → x² - 1 = 8 → x² = 9 → x = ±3. ОДЗ: x > 1 → x = 3.

### Задача 2. Реши log²(x) - log(x) - 2 = 0.

**Решение:** y = log x. y² - y - 2 = 0. y = 2 или y = -1. x = 100 или x = 0,1.

### Задача 3. Реши 2^x = 256.

**Решение:** 2^x = 2^8 → x = 8.

### Задача 4. Реши log_3(x - 2) > 0.

**Решение:** log_3 > 0 → x - 2 > 1 → x > 3.
