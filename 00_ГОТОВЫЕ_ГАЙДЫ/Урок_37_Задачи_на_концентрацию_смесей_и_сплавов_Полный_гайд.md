# Урок 37. Задачи на концентрацию смесей и сплавов

## Перед тем как начать

Привет. Этот урок — про задачи на концентрацию. Это задачи, где смешиваются растворы или сплавы с разной концентрацией вещества.

---

## Блок 1. Основные понятия

### Что это такое

**Концентрация** c = m / M, где m — масса вещества, M — масса раствора/сплава.

**Процентная концентрация** p = c · 100% = (m / M) · 100%.

---

## Блок 2. Два типа задач

### Тип 1: смешивание двух растворов

Смешиваем m₁ раствора с концентрацией c₁ и m₂ с концентрацией c₂. Концентрация нового раствора:

c = (m₁c₁ + m₂c₂) / (m₁ + m₂).

### Тип 2: добавление воды (или чистого вещества)

К раствору массы m с концентрацией c добавили Δm воды. Новая концентрация:

c' = mc / (m + Δm).

### Задача с разбором

**Задача.** Смешали 3 кг 5%-го и 7 кг 15%-го раствора щёлочи. Найди концентрацию нового раствора.

Решение:
- m₁ = 3, c₁ = 0,05. m₂ = 7, c₂ = 0,15.
- mобщ = 10.
- Щёлочи: 3 · 0,05 + 7 · 0,15 = 0,15 + 1,05 = 1,2.
- Концентрация: 1,2 / 10 = 0,12 = 12%.

**Ответ: 12%.**

### Реши сам

**Задача 1.** Смешали 4 кг 10% и 6 кг 20% раствора. Найди концентрацию.
<details>
<summary>Ответ</summary>

m = 4 + 6 = 10. Вещества: 4 · 0,1 + 6 · 0,2 = 0,4 + 1,2 = 1,6. c = 1,6/10 = 0,16 = 16%.
</details>

**Задача 2.** К 5 кг 20% раствора добавили 3 кг воды. Найди концентрацию.
<details>
<summary>Ответ</summary>

m = 5 + 3 = 8. Вещества: 5 · 0,2 = 1. c = 1/8 = 0,125 = 12,5%.
</details>

**Задача 3.** Смешали 2 кг 30% и 3 кг 40% раствора. Найди концентрацию.
<details>
<summary>Ответ</summary>

m = 5. Вещества: 0,6 + 1,2 = 1,8. c = 1,8/5 = 0,36 = 36%.
</details>

## Мини-тест

**Задача 1.** Имеется 500 г 10% раствора. Сколько соли в нём?
<details>
<summary>Ответ</summary>

500 · 0,1 = 50 г.
</details>

**Задача 2.** Сколько воды нужно добавить к 200 г 30% раствора, чтобы получить 15%?
<details>
<summary>Ответ</summary>

Соли: 200 · 0,3 = 60 г. Нужно 60/0,15 = 400 г раствора. Добавить 200 г.
</details>

## Босс-файт

### Задача 1. В 5% раствор массой 3,8 кг добавили 1,2 кг воды. Концентрация?

**Решение:** вещества: 3,8 · 0,05 = 0,19 кг. Новая масса: 5. c = 0,19/5 = 0,038 = 3,8%.

### Задача 2. Смешали два раствора соли: 1 кг 10% и 4 кг 25%. Концентрация?

**Решение:** m = 5. Вещества: 0,1 + 1 = 1,1. c = 1,1/5 = 0,22 = 22%.

### Задача 3. К 2 кг 40% раствора добавили 1 кг 20%. Концентрация?

**Решение:** m = 3. Вещества: 0,8 + 0,2 = 1. c = 1/3 ≈ 33,3%.

### Задача 4. Сколько 5% раствора нужно добавить к 10 кг 30%, чтобы получить 15%?

**Решение:** пусть x — масса 5% раствора. Вещества: 0,05x + 3 = 0,15(x + 10) → 0,05x + 3 = 0,15x + 1,5 → 1,5 = 0,1x → x = 15.
