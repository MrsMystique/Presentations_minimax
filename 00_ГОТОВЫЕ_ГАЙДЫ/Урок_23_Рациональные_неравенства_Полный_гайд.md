## Блок 1. Рациональное неравенство и метод интервалов

### Зачем тебе это знать

Метод интервалов — это универсальный способ решения неравенств. Он работает для дробно-рациональных, для произведений множителей, для сложных выражений. Один раз научившись, ты решаешь почти всё.

### Что это такое

**Определение.** Рациональное неравенство — это неравенство, в левой и правой частях которого стоят рациональные выражения.

**Метод интервалов** — это метод решения неравенств, основанный на разбиении числовой прямой на интервалы точками, в которых выражение обращается в ноль или не определено.

### Как применять — алгоритм из 5 шагов

1) Привести неравенство к виду f(x) > 0 (или < 0, ≥ 0, ≤ 0).
2) Найти нули функции f(x) (то есть решить f(x) = 0).
3) Найти точки, где f(x) не определена.
4) Отметить все эти точки на числовой прямой.
5) Определить знак f(x) на каждом интервале и выбрать нужные промежутки.

### Как определить знак

На самом правом интервале знак определяется подстановкой старшего x. На каждом следующем интервале знак меняется (если корень нечётной кратности) или сохраняется (если чётной кратности).

### Откуда метод

Из того, что дробно-рациональная функция может менять знак только в точках, где она = 0 или не определена. Между этими точками знак не меняется.

### Где применить

В задачах: «при каких x дробь положительна?»
В задачах: «на каких промежутках произведение двух скобок отрицательно?»

### Где ошибиться

**Ловушка «метод интервалов работает всегда».** Работает для рациональных выражений. Для иррациональных (с корнями) — сложнее.

**Ловушка «знаки чередуются автоматически».** Только если все корни — простые (кратности 1). Если корень чётной кратности (касание), знак не меняется.

**Ловушка «точки, где f не определена, не учитываются».** Учитываются, но не входят в ответ (в ответе пишем «выколотая точка»).

### Задача с разбором

**Задача.** Реши (x - 2)(x + 3) > 0.

Решение:
1) Нули: x = 2, x = -3.
2) Отметим на прямой: -3 и 2 — простые корни.
3) Самый правый интервал: x = 3 → (3 - 2)(3 + 3) = 1 · 6 = 6 > 0 → знак «+».
4) Чередуем: на (-3; 2) знак «-», на (-∞; -3) знак «+».
5) Неравенство > 0: x ∈ (-∞; -3) ∪ (2; +∞).

**Ответ: (-∞; -3) ∪ (2; +∞).**

## Блок 2. Метод интервалов для дробно-рациональных неравенств

### Зачем тебе это знать

Дробно-рациональные неравенства — частые гости в задачах. Без метода интервалов ты их не решишь.

### Алгоритм

1) Перенеси всё в одну часть, чтобы получилось f(x) > 0 (или < 0).
2) Приведи к общему знаменателю (если нужно).
4) Разложи числитель и знаменатель на множители.
4) Найди нули числителя и нули знаменателя.
5) Нанеси на числовую прямую (нули знаменателя — выколотые точки, нули числителя — закрашенные или выколотые в зависимости от знака).
6) Определи знаки и выбери интервалы.

### Где применить

В задачах: «при каких x дробь (x + 1)/(x - 2) > 0?»

### Где ошибиться

**Ловушка «нули знаменателя — это корни уравнения».** Нет, это точки, где дробь не определена. Они выколотые.

**Ловушка «можно сократить дробь на (x - 2)».** Можно, но не забудь про ОДЗ (иначе потеряешь точку x = 2).

### Задача с разбором

**Задача.** Реши (x + 1)/(x - 2) > 0.

Решение:
1) Нули числителя: x = -1. Нуль знаменателя: x = 2 (выколотая).
2) Метод интервалов: -1 (закрашенная), 2 (выколотая).
3) Самый правый интервал: x = 3 → (3+1)/(3-2) = 4/1 > 0 → «+».
4) Чередуем: на (-1; 2) знак «-», на (-∞; -1) знак «+».
5) > 0: (-∞; -1) ∪ (2; +∞).

**Ответ: (-∞; -1) ∪ (2; +∞).**

## Блок 3. Сложные случаи метода интервалов

### Зачем тебе это знать

В задачах неравенства часто выглядят как «(x - 1)²(x + 3)/(x - 4) > 0» — несколько множителей, разные кратности. Без навыка ты запутаешься.

### Случаи кратных корней

Если множитель входит в чётной степени (x - a)², (x - a)⁴ и т.д., то при переходе через a знак НЕ меняется. Если в нечётной (x - a)¹, (x - a)³ — меняется.

### Где применить

В задачах с кратными множителями.
В задачах: «при каких x произведение (x - 1)² · (x - 2) > 0?»

### Где ошибиться

**Ловушка «всегда чередуем знаки».** Нет. При чётной кратности знак сохраняется.

**Ловушка «квадрат — это всегда ≥ 0».** Сам по себе — да. Но в контексте метода интервалов это значит, что знак через квадрат не переносится.

### Задача с разбором

**Задача.** Реши (x - 1)²(x - 3) ≥ 0.

Решение:
- x = 1 (двойной корень), x = 3 (простой).
- x = 1: чётная кратность → знак не меняется.
- x = 3: нечётная → меняется.
- Самый правый: x = 4 → (4-1)²(4-3) > 0 → «+».
- На (1; 3): «+» (не меняется при x = 1).
- На (-∞; 1): «+» (не меняется при x = 3).
- ≥ 0: вся прямая, потому что знак «+» везде.

Но! x = 1 — двойной корень, (x - 1)² = 0, поэтому вся прямая. Однако нужно проверить: при x = 1 (x - 1)² = 0, (x - 3) = -2, произведение = 0 ≥ 0 ✓.

**Ответ: x ∈ R, -∞.**

### Реши сам

**Задача 1.** Реши (x + 1)²(x - 2) > 0.

> Подсказка 1 (направление): x = -1 (двойной), x = 2 (простой).

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

Знаки: «+» справа, при x = 2 меняется на «-», при x = -1 не меняется (остаётся «-»), при x = -1 — выколотая точка (т.к. > 0, не ≥).
(2; +∞) — знак «+», (-1; 2) — знак «-», (-∞; -1) — знак «-».
> 0: (2; +∞).
</details>

<details>
<summary>Разбор</summary>

**Ответ: (2; +∞).**
</details>

> Подсказка 1 (направление): x = -2 тройной, x = 1 двойной.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

Знаки справа: «+». x = -2 нечётный → меняется на «-». x = 1 чётный → не меняется (остаётся «-»).

## Босс-файт: задачи на рациональные неравенства

### Задача 1. Реши (x - 2)/(x + 1) > 0

**Решение:** нули: x = 2 (закрашенная), x = -1 (выколотая). Метод интервалов.
Самый правый «+», чередуем. (-∞; -1) ∪ (2; +∞).

**Ответ: (-∞; -1) ∪ (2; +∞).**

### Задача 2. Реши (x² - 4)(x - 1) ≤ 0

**Решение:** (x - 2)(x + 2)(x - 1) ≤ 0. Нули: -2, 1, 2.
Самый правый «+», чередуем: (-2; 1) «-», (-∞; -2) «+».
≤ 0: [-2; 1] ∪ [2; ... нет, попробуем ещё раз.

Корни по порядку: -2, 1, 2. Самый правый: x = 3 → (9 - 4)(2) = 5·2 = 10 > 0 → «+».
Знаки: (2; +∞) «+»; (1; 2) «-»; (-2; 1) «+»; (-∞; -2) «-».
≤ 0: (-∞; -2] ∪ [1; 2].

**Ответ: (-∞; -2] ∪ [1; 2].**

### Задача 3. Реши (x + 1)/(x - 3)² ≥ 0

**Решение:** знаменатель (x - 3)² всегда ≥ 0, = 0 при x = 3 (выколотая точка).
Неравенство: числитель ≥ 0 или знаменатель → ∞ (но это при x = 3, выколотая).
Значит, нужно числитель ≥ 0: x + 1 ≥ 0 → x ≥ -1. И x ≠ 3.
Решение: [-1; 3) ∪ (3; +∞).

**Ответ: [-1; 3) ∪ (3; +∞).**

### Задача 4. Реши (x² - 3x + 2)/(x² + 1) > 0

**Решение:** знаменатель x² + 1 > 0 всегда. Значит, знак дроби = знаку числителя.
x² - 3x + 2 > 0 → (x - 1)(x - 2) > 0 → x < 1 или x > 2.

**Ответ: (-∞; 1) ∪ (2; +∞).**

## Сборник формул

### Метод интервалов

1) Привести к виду f(x) > 0.
2) Найти нули f.
3) Нанести на прямую.
4) Определить знаки.
5) Выбрать нужные интервалы.

### Правило кратности

- Нечётная кратность → знак чередуется.
- Чётная кратность → знак не меняется.
