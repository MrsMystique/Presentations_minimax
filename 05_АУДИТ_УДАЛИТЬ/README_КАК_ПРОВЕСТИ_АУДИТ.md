Проверено хешами SHA-256: совпадение хеша = побайтово один и тот же файл.

## КАК ПРОВЕСТИ АУДИТ

1. Открой папку.
2. Для сомнительного — сравни с каноном (пути ниже).
3. Если канона нет и файл не нужен — удаляй. Если сомневаешься — не удаляй, это дешевле.

**Проверка «а это точно дубль?»** в любой папке:
```
Get-FileHash "путь\к\файлу" -Algorithm SHA256
```
Сравни с хешем файла-канона. Совпало — дубль.
