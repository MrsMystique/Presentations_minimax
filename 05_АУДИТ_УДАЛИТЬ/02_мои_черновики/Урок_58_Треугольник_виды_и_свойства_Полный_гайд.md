# Урок 58. Треугольник. Виды треугольников. Теоремы синусов и косинусов

## Перед тем как начать

Привет. Этот урок — про треугольники: виды, элементы, теоремы синусов и косинусов.

---

## Блок 1. Виды треугольников

### По сторонам

- **Разносторонний** — все стороны разные.
- **Равнобедренный** — две стороны равны.
- **Равносторонний** — все стороны равны.

### По углам

- **Остроугольный** — все углы < 90°.
- **Прямоугольный** — один угол = 90°.
- **Тупоугольный** — один угол > 90°.

---

## Блок 2. Неравенство треугольника

### Теорема

**Каждая сторона треугольника меньше суммы двух других.**

a < b + c, b < a + c, c < a + b.

### Следствие

Если это неравенство нарушается, то треугольника с такими сторонами не существует.

---

## Блок 3. Элементы треугольника

### Высота

**Высота** — перпендикуляр из вершины к противоположной стороне.

### Медиана

**Медиана** — отрезок из вершины к середине противоположной стороны.

### Биссектриса

**Биссектриса** — отрезок из вершины, делящий угол пополам.

### Средняя линия

**Средняя линия** — отрезок, соединяющий середины двух сторон. Параллельна третьей стороне и равна её половине.

---

## Блок 4. Теорема синусов

### Формулировка

**a / sin A = b / sin B = c / sin C = 2R**, где R — радиус описанной окружности.

### Что это значит

Стороны пропорциональны синусам противоположных углов.

---

## Блок 5. Теорема косинусов

### Формулировка

**c² = a² + b² - 2ab · cos C.**

### Что это значит

Это «обобщённая теорема Пифагора». Если C = 90°, то cos C = 0 и c² = a² + b².

## Блок 6. Задачи

### Задача с разбором

**Задача.** Стороны треугольника 5 и 8, угол между ними 60°. Найди третью сторону.

Решение: c² = 25 + 64 - 2 · 5 · 8 · cos 60° = 89 - 80 · 0,5 = 89 - 40 = 49 → c = 7.

**Ответ: 7.**

### Задача с разбором

**Задача.** Угол треугольника 30°, противолежащая сторона 5. Найди радиус описанной окружности.

Решение: a / sin A = 2R → R = a / (2 sin A) = 5 / (2 · 0,5) = 5.

**Ответ: 5.**

### Реши сам

**Задача 1.** Стороны 7 и 9, угол между ними 90°. Третья сторона?
<details>
<summary>Ответ</summary>

c² = 49 + 81 = 130 → c = √130.
</details>

**Задача 2.** Угол 45°, противолежащая сторона 6√2. Радиус описанной окружности?
<details>
<summary>Ответ</summary>

R = 6√2 / (2 · √2/2) = 6√2 / √2 = 6.
</details>

**Задача 3.** Может ли быть треугольник со сторонами 1, 2, 5?
<details>
<summary>Ответ</summary>

Нет: 1 + 2 = 3 < 5.
</details>

**Задача 4.** Угол 60°, противолежащая сторона 8. Другая сторона 5. Найди угол напротив.
<details>
<summary>Ответ</summary>

a/sin A = b/sin B → 8/sin 60° = 5/sin B → sin B = 5 · √3/2 / 8 = 5√3/16.
</details>

## Босс-файт

### Задача 1. Стороны 6, 7, 8. Найди наибольший угол.

**Решение:** наибольший угол напротив наибольшей стороны (8). cos C = (36 + 49 - 64) / (2 · 6 · 7) = 21/84 = 1/4. C = arccos(1/4).

### Задача 2. Угол 30°, противолежащая сторона 4. Радиус описанной окружности?

**Решение:** R = 4 / (2 · sin 30°) = 4 / 1 = 4.

### Задача 3. В треугольнике a = 3, b = 5, угол C = 120°. Найди c.

**Решение:** c² = 9 + 25 - 2 · 3 · 5 · cos 120° = 34 - 30 · (-1/2) = 34 + 15 = 49 → c = 7.

### Задача 4. Доказать, что в равностороннем треугольнике все углы 60°.

**Решение:** сумма углов 180°, все углы равны (симметрия) → каждый 60°.
