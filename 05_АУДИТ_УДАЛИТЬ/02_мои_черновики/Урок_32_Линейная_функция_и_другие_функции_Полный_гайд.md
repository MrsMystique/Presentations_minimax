## Блок 1. Линейная функция y = kx + b

### Что это такое

**Определение.** Линейной функцией называется функция вида y = kx + b, где k и b — числа, x — независимая переменная.

### Свойства

- **D(y) = R** (все x).
- **E(y):** если k ≠ 0, то все y; если k = 0, то y = b (одно значение).
- **График:** прямая.
- **k** — угловой коэффициент (наклон).
- **b** — точка пересечения с осью Oy.

### Возрастание/убывание

- **k > 0:** возрастает.
- **k < 0:** убывает.
- **k = 0:** постоянна (y = b).

### Где применить

В задачах на движение с постоянной скоростью.
В экономике: линейная зависимость спроса от цены.

### Задача с разбором

**Задача.** Построй график y = 2x - 3.

Решение: при x = 0, y = -3. При y = 0, x = 1,5. Проведи прямую через точки (0; -3) и (1,5; 0).

## Блок 2. Обратная пропорциональность y = k/x

### Что это такое

**Определение.** y = k/x, где k ≠ 0.

### Свойства

- **D(y) = (-∞; 0) ∪ (0; +∞)** (x ≠ 0).
- **E(y) = (-∞; 0) ∪ (0; +∞)** (y ≠ 0).
- **График:** гипербола (две ветви).
- **k > 0:** ветви в I и III четвертях.
- **k < 0:** ветви во II и IV четвертях.

### Задача с разбором

**Задача.** Построй график y = 4/x.

Решение: точки (1; 4), (2; 2), (4; 1), (-1; -4), (-2; -2), (-4; -1). Гипербола в I и III четвертях.

## Блок 3. Функция y = x³

### Свойства

- **D(y) = R.**
- **E(y) = R.**
- **График:** кубическая парабола.
- Нечётная функция.
- Возрастает на всей области определения.

---

## Блок 4. Функция y = √x

### Свойства

- **D(y) = [0; +∞).**
- **E(y) = [0; +∞).**
- **График:** ветвь параболы.
- Возрастает.

---

## Блок 5. Функция y = |x|

### Свойства

- **D(y) = R.**
- **E(y) = [0; +∞).**
- **График:** V-образная фигура с вершиной в (0; 0).
- Чётная функция.

### Задача с разбором

**Задача.** Построй график y = |x - 2|.

Решение: y = |x - 2| — это V с вершиной в (2; 0). Для x ≥ 2: y = x - 2. Для x < 2: y = -(x - 2) = 2 - x.

## Босс-файт

### Задача 1. Найди точку пересечения y = 2x + 1 и y = -x + 4

**Решение:** 2x + 1 = -x + 4 → 3x = 3 → x = 1. y = 3. Точка (1; 3).

### Задача 2. Построй график y = -3/x

**Решение:** точки (1; -3), (3; -1), (-1; 3), (-3; 1). Гипербола во II и IV четвертях.

### Задача 3. При каких x y = √(x - 1) определена?

**Решение:** x - 1 ≥ 0 → x ≥ 1. [1; +∞).

### Задача 4. Найди E(y) для y = -2|x| + 3

**Решение:** -2|x| + 3 ≤ 3. E(y) = (-∞; 3].
