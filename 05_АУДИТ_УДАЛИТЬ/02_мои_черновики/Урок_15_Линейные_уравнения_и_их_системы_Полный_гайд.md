## Блок 1. Уравнение. Корень уравнения

### Зачем тебе это знать

Каждый раз, когда ты решаешь задачу с буквой «x», ты работаешь с уравнением. Без понимания того, что такое «корень уравнения» и «решить уравнение», ты не сможешь двигаться дальше — ни к квадратным уравнениям, ни к дробям, ни к текстовым задачам.

### Что это такое

**Определение.** Равенство с переменной называется уравнением.

**Определение.** Корнем уравнения называется значение переменной, которое обращает это уравнение в верное числовое равенство.

**Определение.** Решить уравнение — значит найти все его корни или доказать, что их нет.

Пример: в уравнении 2x = 8 корнем является x = 4 (потому что 2·4 = 8 — верное числовое равенство). Других корней нет.

### Откуда взялись эти определения

Из практики. Если у тебя есть две чашки, и в каждой по 4 яблока, а всего у тебя 8 яблок, то сколько чашек? 8 / 4 = 2. Это и есть решение уравнения 4x = 8 → x = 2.

В древности задачи формулировали словами: «купил 5 аршин ткани, заплатил 40 монет, сколько стоит один аршин?». И только потом поняли, что удобнее записать 5x = 40 и найти x.

### Как найти корень уравнения на практике

В общем случае — никак, потому что уравнения бывают сложные. Но для линейных уравнений (вид ax = b) алгоритм простой: разделить обе части на a.

Примеры:
- 3x = 9 → x = 3.
- -2x = 10 → x = -5.
- 0·x = 5 → решений нет (никакое число не даёт 0 = 5).
- 0·x = 0 → x — любое число (любое значение удовлетворяет).

### Где применить

В задачах на движение: v·t = S (путь = скорость × время).
В задачах на стоимость: цена × количество = стоимость.
В уравнениях с двумя переменными: ax + by = c.

### Где ошибиться

**Ловушка «корни уравнения всегда есть».** Не всегда. Уравнение 0·x = 5 не имеет корней. Уравнение 5x + 5 = 5x тоже не имеет корней (получается 0 = 5 после переноса).

**Ловушка «если переменных две — корни всегда два».** Нет, корней может быть бесконечно много (например, x + y = 5 — подходят любые пары, сумма которых 5).

**Ловушка «корень — это только одно число».** Корень — это каждое отдельное значение, удовлетворяющее уравнению. В уравнении x² = 4 два корня: 2 и -2.

### Задача с разбором

**Задача.** Реши уравнение 3(x - 2) = 2x + 1.

Решение:
1) Раскроем скобки: 3x - 6 = 2x + 1.
2) Перенесём 2x влево, а -6 вправо (с противоположными знаками): 3x - 2x = 1 + 6.
3) Приведём подобные: x = 7.

Проверка: 3(7 - 2) = 3·5 = 15. 2·7 + 1 = 14 + 1 = 15. ✓

**Ответ: x = 7.**

## Блок 2. Линейное уравнение с одной переменной

### Зачем тебе это знать

Линейные уравнения — это самый частый «кирпичик» в задачах. Если ты умеешь решать их за 30 секунд, у тебя останется время на сложные преобразования в других блоках.

### Что это такое

**Определение.** Уравнение вида ax = b, где a и b — числа, а x — переменная, называется линейным уравнением с одной переменной.

**Примеры:** 3x = 9, 0,5x = 2, -7x = 14.

### Откуда это название

«Линейное» — потому что график уравнения ax = b (если переписать как y = ax - b) — это прямая линия. А само уравнение ax = b — это «отпечаток» пересечения этой прямой с осью x.

### Как решать на практике

Если a ≠ 0: x = b / a.
Если a = 0 и b = 0: x — любое число (бесконечно много решений).
Если a = 0 и b ≠ 0: решений нет.

Пример: 4x = 12 → x = 3. -2x = 8 → x = -4. 0x = 0 → x — любое.

### Где применить

В задачах с процентами: 0,2x = 100 → x = 500.
В задачах на движение: x/3 = 60 → x = 180 (за 3 часа проехал 60 км/ч).

### Где ошибиться

**Ловушка «линейное — это только ax = b».** Нет. Линейное — это любое уравнение, которое сводится к ax = b. Например, 2(x + 3) = 10 тоже линейное, потому что сводится к 2x = 4.

**Ловушка «при делении на отрицательное число результат не меняется».** Меняется знак: -2x = 8 → x = -4 (не 4).

**Ловушка «линейное уравнение всегда имеет один корень».** Нет, у 0x = 0 бесконечно много корней, у 0x = 5 — ни одного.

### Задача с разбором

**Задача.** Укажи номер уравнения, которое имеет более одного корня:

1) 5x + 3 = 3
2) 2(9 - 2x) = -4x
3) (2x + 7) / 5 = x
4) (5x + 2) / 3 = (15x + 6) / 9

Решение:
1) 5x = 0 → x = 0. Один корень.
2) 18 - 4x = -4x → 18 = 0. Нет решений.
3) 2x + 7 = 5x → 7 = 3x → x = 7/3. Один корень.
4) 9(5x + 2) = 3(15x + 6) → 45x + 18 = 45x + 18 → 0x = 0. Любое x. Бесконечно много корней.

**Ответ: 5) — уравнение 4 имеет более одного корня (бесконечно много).**

## Блок 3. Равносильные уравнения

### Зачем тебе это знать

Когда ты решаешь уравнение, ты заменяешь его другим, более простым. Если новое уравнение имеет те же корни — оно равносильно. Если нет — ты получил посторонние корни или потерял настоящие.

### Что это такое

**Определение.** Уравнения, имеющие одно и то же множество корней, называются равносильными.

**Важная деталь.** Уравнения, которые не имеют корней, тоже считаются равносильными. Например, 0x = 5 и 0x = 7 — оба не имеют корней, значит, равносильны.

### Откуда взялись правила преобразований

Из свойств числовых равенств: если к обеим частям прибавить одно и то же число, равенство сохраняется. Если обе части умножить на одно и то же ненулевое число — тоже. Для уравнений работает то же самое, но с оговорками.

### Как сохранить равносильность

1) Перенос слагаемого из одной части в другую с переменой знака.
2) Умножение или деление обеих частей на одно и то же число (любое, включая 0).
3) Тождественные преобразования выражений в любой части (раскрытие скобок, приведение подобных).

**Опасный случай:** умножение обеих частей на выражение с переменной. Например, 0,5x = 3 можно умножить на 2 и получить x = 6 — равносильно. Но x/3 = 5 нельзя «домножить на x» — это может добавить посторонний корень x = 0.

### Где применить

В задачах с дробями: (x + 1)/3 = 5 → x + 1 = 15 → x = 14. Это умножение на 3 — безопасно.
В задачах с модулем: |x| = 5 → x = 5 или x = -5. Здесь равносильность сохраняется.

### Где ошибиться

**Ловушка «любое умножение обеих частей безопасно».** Не любое. Если умножаешь на выражение с переменной, нужно проверять, не обращается ли оно в ноль.

**Ловушка «равносильные уравнения — это всегда разные записи».** Не обязательно. Уравнение 2x = 6 и 2x = 6 — равносильны (тождественно).

**Ловушка «если перемножить обе части на -1, знаки поменяются».** Да, это допустимое преобразование, оно сохраняет равносильность.

### Задача с разбором

**Задача.** Установи, равносильны ли уравнения 2x - 6 = 0 и 3x = 9.

Решение:
- 2x - 6 = 0 → x = 3.
- 3x = 9 → x = 3.

Множества корней совпадают: {3}. Значит, уравнения равносильны.

**Ответ: да, равносильны.**

## Блок 4. Решение уравнений, сводящихся к линейным

### Зачем тебе это знать

На практике почти все линейные уравнения приходят к тебе «замаскированными»: со скобками, дробями, иррациональными знаменателями. Если ты знаешь алгоритм, ты раскрутишь любую такую задачу.

### Что это такое

Это уравнения, которые после преобразований принимают вид ax = b. Например, (x - 3)/√2 + x/(√3 + √2) = 3 - 2x + 4 - 4√2 — звучит страшно, но после избавления от иррациональности в знаменателе становится обычным линейным.

### Как решать — алгоритм из 5 шагов

1) Раскрыть скобки.
2) Привести подобные слагаемые.
3) Перенести слагаемые с переменной в одну часть, числа — в другую.
4) Привести подобные.
5) Решить полученное линейное уравнение.

### Откуда взялся этот алгоритм

Из практики: нужно превратить сложное выражение в простую форму ax = b. Каждый шаг — это равносильное (или почти равносильное) преобразование, которое упрощает структуру, не меняя корней.

### Где применить

В задачах с дробями: (2x + 1)/3 = 5 → умножаем на 3 → 2x + 1 = 15 → решаем.
В задачах со скобками: 2(x - 3) + 4(x + 1) = 10.
В задачах с иррациональностью: (x - 3)/(√2 + 1) + x/(√3 + √2) = ... — избавляемся от иррациональности в знаменателе.

### Где ошибиться

**Ловушка «-x в скобке это то же, что +x».** Нет, -(x - 3) = -x + 3, знак меняется у обоих слагаемых.

**Ловушка «при переносе через знак = знак сохраняется».** Нет, меняется на противоположный: x - 5 = 3 → x = 3 + 5 = 8 (а не x = 3 - 5).

**Ловушка «много скобок — значит много корней».** Нет, после раскрытия скобок и приведения подобных остаётся одно линейное уравнение.

### Задача с разбором

**Задача.** Реши (x - 3)/(√2 + 1) + x/(√3 + √2) = 3 - 2x + 4 - 4√2.

Решение:
Шаг 1: Избавимся от иррациональности в знаменателе.
(x - 3)/(√2 + 1) · (√2 - 1)/(√2 - 1) = (x - 3)(√2 - 1)/((√2)² - 1²) = (x - 3)(√2 - 1)/(2 - 1) = (x - 3)(√2 - 1).
x/(√3 + √2) · (√3 - √2)/(√3 - √2) = x(√3 - √2)/((√3)² - (√2)²) = x(√3 - √2)/(3 - 2) = x(√3 - √2).

Шаг 2: Подставим:
(x - 3)(√2 - 1) + x(√3 - √2) = 3 - 2x + 4 - 4√2.

Шаг 3: Раскроем скобки:
x√2 - x - 3√2 + 3 + x√3 - x√2 = 7 - 2x - 4√2.

Шаг 4: Приведём подобные (сократим x√2):
-x - 3√2 + 3 + x√3 = 7 - 2x - 4√2.

Шаг 5: Перенесём всё с x влево, числа — вправо:
-x + 2x + x√3 = 7 - 3 - 3√2 + 4√2 → x + x√3 = 4 + √2 → x(1 + √3) = 4 + √2.

Шаг 6: Найдём x:
x = (4 + √2)/(1 + √3).

Если избавиться от иррациональности в знаменателе: умножить на (1 - √3)/(1 - √3) — это уже сложно. Для проверки подставим в исходное уравнение и получим подтверждение.

**Ответ: x = (4 + √2)/(1 + √3).** (Приблизительно ≈ -0,4 — окончательно можно не упрощать, в школьных задачах часто оставляют в таком виде.)

### Реши сам

**Задача 1.** Реши 3(x - 2) + 2(x + 1) = 18.

> Подсказка 1 (направление): раскрой скобки, потом приведи подобные.

## Блок 5. Линейное уравнение с двумя переменными

### Зачем тебе это знать

Система двух линейных уравнений с двумя переменными — это фундамент для задач с двумя неизвестными (например, «у Васи x яблок, у Пети y яблок, всего 30, а разница 4»). Без этого навыка ты не решишь ни одной такой задачи.

### Что это такое

**Определение.** Уравнение вида ax + by = c, где x и y — переменные, a, b, c — числа, называется линейным уравнением с двумя переменными.

**Определение.** Упорядоченная пара чисел (x₀; y₀) называется решением уравнения ax + by = c, если при подстановке получается верное числовое равенство.

Пример: для уравнения 2x + 3y = 12 пара (3; 2) — решение, потому что 2·3 + 3·2 = 12.

### Откуда название

«Линейное с двумя переменными» — потому что график ax + by = c — это прямая на координатной плоскости. Решения уравнения — это точки на этой прямой.

### Как найти решения

Любое линейное уравнение с двумя переменными имеет бесконечно много решений (если только это не вырожденный случай 0x + 0y = 0).

Алгоритм: вырази одну переменную через другую и подставляй любые значения.

Пример: 2x + 3y = 12 → y = (12 - 2x)/3. Подставляй x = 0 → y = 4. Пара (0; 4). x = 3 → y = 2. Пара (3; 2). И так далее.

### Где применить

В задачах на движение: x — скорость автобуса, y — скорость автомобиля.
В задачах с двумя условиями: x + y = 10 и x - y = 4.
В геометрии: точки на прямой y = 2x + 1.

### Где ошибиться

**Ловушка «решение одно».** Нет, у линейного уравнения с двумя переменными бесконечно много решений (если только не 0x + 0y = c с c ≠ 0, тогда нет решений).

**Ловушка «пара (x; y) — это то же, что (y; x)».** Нет, пары упорядочены. (3; 2) ≠ (2; 3).

**Ловушка «если a = 0, то уравнение не работает».** Работает, просто вырождается в by = c. Если b ≠ 0, то y = c/b, и решений бесконечно (любой x подходит).

### Задача с разбором

**Задача.** Является ли пара (-1; 5) решением уравнения 3x + 2y = 7?

Решение: подставим. 3·(-1) + 2·5 = -3 + 10 = 7. ✓

**Ответ: да, является.**

> Подсказка 1 (направление): подставляй разные x и вычисляй y.

x = 0 → y = 10. x = 5 → y = 5. x = -4 → y = 14.
</details>

</details>

> Подсказка 1 (направление): подставь пару и найди a.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

<summary>Разбор</summary>

</details>

## Блок 6. Система двух линейных уравнений с двумя переменными

### Зачем тебе это знать

Это центральный навык урока. Системы — основа задач с двумя условиями: ты не решишь текстовую задачу «у Маши 5 конфет больше, чем у Пети, а всего 17» без системы.

### Что это такое

**Определение.** Система двух линейных уравнений с двумя переменными:

{a₁x + b₁y = c₁
{a₂x + b₂y = c₂

где a₁, b₁, c₁, a₂, b₂, c₂ — числа, а x и y — переменные.

**Определение.** Решением системы называется пара (x₀; y₀), являющаяся решением и первого, и второго уравнения одновременно.

### Как решать — два основных метода

**Метод подстановки:**
1) Из одного уравнения вырази одну переменную через другую.
2) Подставь это выражение во второе уравнение.
3) Реши полученное линейное уравнение, найди значение одной переменной.
4) Подставь найденное значение в выражение из п.1.
5) Запиши ответ — упорядоченную пару.

**Метод сложения:**
1) Одно уравнение оставь без изменения, второе замени суммой (или разностью) уравнений системы.
2) Из полученного уравнения найди одну переменную.
3) Подставь найденное значение в оставленное уравнение.
4) Найди вторую переменную.
5) Запиши ответ.

### Откуда эти методы

Оба сводят систему двух уравнений с двумя переменными к одному уравнению с одной переменной. Метод подстановки — это «подставь и решай», метод сложения — «вычти и сократи».

### Где применить

В текстовых задачах с двумя условиями (всего 30, разница 4).
В задачах на движение по реке (по течению / против течения).
В задачах с параметром: найти a, при котором система имеет единственное решение.

### Где ошибиться

**Ловушка «в методе подстановки можно подставить куда угодно».** Подставляй выражение в то уравнение, из которого НЕ выражал переменную. Иначе получишь тождество и не найдёшь x.

**Ловушка «в методе сложения можно складывать всегда».** Складывать можно всегда, но чтобы сократить одну переменную, нужно подобрать множители (домножить уравнения на числа, прежде чем складывать).

**Ловушка «в ответе пиши x и y в любом порядке».** Ответ — упорядоченная пара (x; y), где x — значение первой переменной, y — второй. (3; 5) ≠ (5; 3).

### Задача с разбором

**Задача.** Реши систему:

{x + 3y = 2
{x + 4y = -2

Решение методом сложения:
Вычтем из второго уравнения первое: (x + 4y) - (x + 3y) = -2 - 2 → y = -4.
Подставим в первое: x + 3·(-4) = 2 → x - 12 = 2 → x = 14.

**Ответ: (14; -4).**

## Блок 7. Метод решения: число решений системы

### Зачем тебе это знать

Иногда в задачах не нужно решать систему, а нужно сказать, сколько у неё решений. Это проверка навыка «работа с коэффициентами» — очень полезно для задач с параметром.

### Что это такое

Число решений системы определяется по коэффициентам:

**Случай 1: a₁/a₂ ≠ b₁/b₂** — единственное решение (прямые пересекаются в одной точке).

**Случай 2: a₁/a₂ = b₁/b₂ ≠ c₁/c₂** — нет решений (прямые параллельны и не совпадают).

**Случай 3: a₁/a₂ = b₁/b₂ = c₁/c₂** — бесконечно много решений (прямые совпадают).

### Откуда это

Из геометрии: на координатной плоскости уравнение ax + by = c задаёт прямую. Две прямые либо пересекаются (1 точка), либо параллельны (0 точек), либо совпадают (∞ точек).

### Как определять на практике

Смотри на пропорции коэффициентов:
- Если a₁/a₂ ≠ b₁/b₂ — прямые пересекаются.
- Если a₁/a₂ = b₁/b₂, но это ≠ c₁/c₂ — параллельны.
- Если a₁/a₂ = b₁/b₂ = c₁/c₂ — совпадают.

Пример:

{2x + 3y = 5
{4x + 6y = 10

a₁/a₂ = 2/4 = 1/2. b₁/b₂ = 3/6 = 1/2. c₁/c₂ = 5/10 = 1/2. Все три равны → бесконечно много решений.

### Где применить

В задачах с параметром: найти a, при котором система имеет единственное решение.
В задачах «не решая, определи число решений».

### Где ошибиться

**Ловушка «если a₁/a₂ = b₁/b₂, то всегда нет решений».** Нет, может быть бесконечно много решений (если c₁/c₂ тоже такое же).

**Ловушка «если a₁ = 0, формула не работает».** Работает, просто 0/что-то = 0. Например, a₁ = 0, a₂ = 2 → a₁/a₂ = 0.

**Ловушка «смотрю только на a и b, забываю про c».** Все три пропорции важны.

### Задача с разбором

**Задача.** Определи число решений системы:

{3x + 2y = 7
{6x + 4y = 10

Решение:
a₁/a₂ = 3/6 = 1/2. b₁/b₂ = 2/4 = 1/2. c₁/c₂ = 7/10. Пропорции a и b равны (1/2), а пропорция c другая (1/2 ≠ 7/10).

Значит, система не имеет решений.

**Ответ: 0 решений.**

{x + 2y = 5
{2x + 4y = 10

> Подсказка 1 (направление): проверь пропорции коэффициентов.

## Босс-файт: задачи на линейные уравнения и системы

Четыре задачи — на равносильность, системы, метод подстановки и метод сложения. Каждая с пошаговым разбором.

### Задача 1. Реши {x + 3y = 2, x + 4y = -2}

**Условие.** Найди x - y.

**Шаг 1.** Вычтем из второго уравнения первое: (x + 4y) - (x + 3y) = -2 - 2 → y = -4.

**Шаг 2.** Подставим в первое: x + 3·(-4) = 2 → x - 12 = 2 → x = 14.

**Шаг 3.** x - y = 14 - (-4) = 14 + 4 = 18.

**Ответ: 18.**

### Задача 2. Реши {x - 2y = 4, xy = 30}

**Условие.** Пусть (x₁; y₁), (x₂; y₂) — решения системы. Найди x₁y₂ + x₂y₁.

**Шаг 1.** Выразим y из первого: y = (x - 4)/2. Подставим во второе: x·(x - 4)/2 = 30 → x(x - 4) = 60 → x² - 4x - 60 = 0.

**Шаг 2.** Решим квадратное уравнение: D = 16 + 240 = 256 = 16². x₁ = (4 + 16)/2 = 10. x₂ = (4 - 16)/2 = -6.

**Шаг 3.** y₁ = (10 - 4)/2 = 3. y₂ = (-6 - 4)/2 = -5.

**Шаг 4.** x₁y₂ + x₂y₁ = 10·(-5) + (-6)·3 = -50 - 18 = -68.

**Ответ: -68.**

### Задача 3. Найди сумму целых корней 2x - 1 = 2x - 0,5 на промежутке [-4; -2]

**Условие.** Найди сумму всех целых решений уравнения 2x - 1 = 2x - 0,5 на [-4; -2].

**Шаг 1.** Упростим: 2x - 1 = 2x - 0,5 → -1 = -0,5. Это неверно, но в тождестве 2x - 1 ≡ 2x - 0,5 обе части тождественно равны, значит, любое x — решение.

**Шаг 2.** Целые числа из [-4; -2]: -4, -3, -2. Сумма: -4 + (-3) + (-2) = -9.

**Ответ: -9.**

### Задача 4. При каком a система {2x + ay = 5, x + y = 1} не имеет решений?

**Условие.** Найди a, при котором система не имеет решений.

**Шаг 1.** Система не имеет решений, если a₁/a₂ = b₁/b₂ ≠ c₁/c₂.

**Шаг 2.** a₁/a₂ = 2/1 = 2. b₁/b₂ = a/1 = a. Чтобы пропорции были равны: a = 2. Тогда c₁/c₂ = 5/1 = 5 ≠ 2.

**Шаг 3.** Значит, при a = 2 система не имеет решений.

**Ответ: a = 2.**

## Сборник формул

### Виды уравнений

- ax = b (линейное, если a ≠ 0 — один корень, иначе особый случай).
- ax² + bx + c = 0 (квадратное — будет в Уроке 18).
- ax + by = c (линейное с двумя переменными — прямая).

### Особые случаи

- 0·x = 0 → x — любое.
- 0·x = c, c ≠ 0 → решений нет.
- 0x + 0y = 0 → бесконечно много пар (x; y).
- 0x + 0y = c, c ≠ 0 → нет пар.

### Число решений системы

- a₁/a₂ ≠ b₁/b₂ → 1 решение.
- a₁/a₂ = b₁/b₂ ≠ c₁/c₂ → 0 решений.
- a₁/a₂ = b₁/b₂ = c₁/c₂ → ∞ решений.

### Методы решения систем

- Подстановка: выразить одну переменную и подставить в другую.
- Сложение: сложить/вычесть уравнения, чтобы сократить переменную.
