## Блок 2. Задачи о числах

### Позиционная запись числа

Двузначное число 10a + b (a — десятки, b — единицы).
Трёхзначное число 100a + 10b + c.

### Делимость

Если N делится на p и в остатке r, то N = kp + r, где 0 ≤ r < p.

### Задача с разбором

**Задача.** Если двузначное число разделить на сумму его цифр, получится 8. Разность квадратов цифр на 27 меньше числа. Найди число.

Решение: пусть число 10a + b.
- (10a + b)/(a + b) = 8 → 10a + b = 8(a + b) = 8a + 8b → 2a = 7b → a = 7b/2.
- b чётное, b ∈ {2, 4, 6, 8}. a = b/2 · 7 → при b = 2: a = 7 → 72. При b = 4: a = 14 — нет (a ≤ 9).
- Число 72.
- Проверка: a² - b² = 49 - 4 = 45. Число - 45 = 27. ✓

**Ответ: 72.**

### Реши сам

**Задача 1.** Трёхзначное число оканчивается на 3. Если 3 перенести в начало, новое число на 9 больше удвоенного исходного. Найди число.

<details>
<summary>Подсказка</summary>

Пусть число 100a + 10b + 3. Новое число 300 + 10a + b = 2(100a + 10b + 3) + 9. 300 + 10a + b = 200a + 20b + 15. 110a + 19b = 285. Перебор: a = 1 → 19b = 175 → нет. a = 2 → 19b = 65 → нет. a = 3 → 19b = -45 → нет. Hmm, попробуй по-другому.

На самом деле: число 100a + 10b + 3 = 100N + 3, где N = 10a + b. Новое число: 300 + N = 2(100N + 3) + 9 = 200N + 15. 300 + N = 200N + 15. 199N = 285. N ≈ 1,43. Не целое. Задача некорректна — попробуй другие варианты.

Если число 100a + 10b + 3 и новое 3·100 + a·10 + b = 300 + 10a + b. Уравнение: 300 + 10a + b - 2(100a + 10b + 3) = 9. 300 + 10a + b - 200a - 20b - 6 = 9. -190a - 19b = -285. 190a + 19b = 285. 19(10a + b) = 285. 10a + b = 15. Но тогда число 153.
</details>

<details>
<summary>Ответ</summary>

153.
</details>

## Блок 3. Задачи на совместную работу

### Что это такое

Производительность = работа/время. Общая работа = сумма работ каждого.

### Формула

A = p · t, где A — работа, p — производительность, t — время.

### Задача с разбором

**Задача.** Одна труба наполняет бассейн за 6 часов, другая — за 4. За сколько часов наполнят вместе?

Решение:
- 1-я труба: p₁ = 1/6 бассейна/час.
- 2-я: p₂ = 1/4.
- Вместе: p = 1/6 + 1/4 = 2/12 + 3/12 = 5/12.
- Время: t = 1/(5/12) = 12/5 = 2,4 часа.

**Ответ: 2,4 часа.**

### Реши сам

**Задача 1.** Один рабочий выполняет заказ за 8 дней, другой — за 12. За сколько дней вместе?

<details>
<summary>Ответ</summary>

p₁ = 1/8, p₂ = 1/12. p = 1/8 + 1/12 = 3/24 + 2/24 = 5/24. t = 24/5 = 4,8 дня.
</details>

**Задача 2.** Бассейн наполняется первой трубой за 3 часа, второй — за 6 часов. Обе открыли на 1 час, потом закрыли вторую. За сколько времени наполнится остаток?

<details>
<summary>Ответ</summary>

За 1 час вместе: 1/3 + 1/6 = 2/6 + 1/6 = 3/6 = 1/2 бассейна. Осталось 1/2. Первая труба: t = 1/2 / (1/3) = 3/2 = 1,5 часа. Всего: 1 + 1,5 = 2,5 часа.
</details>

## Мини-тест

**Задача 1.** Сумма цифр двузначного числа 12. Если цифры поменять местами, получится число на 36 больше. Найди исходное.
<details>
<summary>Ответ</summary>

10a + b, a + b = 12, 10b + a = 10a + b + 36. 9b - 9a = 36 → b - a = 4. a + b = 12. → a = 4, b = 8. Число 48.
</details>

**Задача 2.** Три насоса наполняют бассейн за 6 часов. Один первый — за 12 часов, один второй — за 18. За сколько третий?
<details>
<summary>Ответ</summary>

1/12 + 1/18 + 1/x = 1/6. 1/x = 1/6 - 1/12 - 1/18 = 6/36 - 3/36 - 2/36 = 1/36. x = 36.
</details>

## Босс-файт

### Задача 1. Двузначное число: сумма цифр 11, разность 5. Найди.

**Решение:** a + b = 11, a - b = 5 → a = 8, b = 3. Число 83.

### Задача 2. Трёхзначное число 17a + a², если цифры 1, 7, a.

**Решение:** 100 + 70 + a = 17a + a². 170 + a = 17a + a². a² + 16a - 170 = 0. D = 256 + 680 = 936. a = (-16 ± √936)/2 ≈ ... не целое. Попробуй пересмотреть.

### Задача 3. Два трактора вспахали поле. Первый — 4 часа, второй — 3 часа. Производительности 1 га/ч и 1,2 га/ч. Найди площадь.

**Решение:** 4 · 1 + 3 · 1,2 = 4 + 3,6 = 7,6 га.

### Задача 4. Мастер и ученик делают деталь. Мастер — за 6 часов, ученик — за 10. Мастер работал 2 часа, потом ученик закончил. Сколько всего времени?

**Решение:** 2/6 = 1/3 сделал мастер. Осталось 2/3. Ученику: t = (2/3)/(1/10) = 20/3 ≈ 6,67 часа. Всего: 2 + 6,67 = 8,67 часа.
