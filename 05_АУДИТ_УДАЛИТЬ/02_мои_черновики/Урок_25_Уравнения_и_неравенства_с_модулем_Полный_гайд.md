## Блок 1. Определение модуля и его свойства

### Зачем тебе это знать

Модуль — это базовый инструмент для уравнений с «расстоянием» или «разностью без знака». Без него ты не решишь ни одной задачи на ЦТ с модулем.

### Что это такое

**Определение.** |x| = x, если x ≥ 0. |x| = -x, если x < 0.

### Свойства

- |x| ≥ 0 всегда.
- |x| = 0 только при x = 0.
- |x| = |-x| (модуль чётный).
- |xy| = |x|·|y|.
- |x/y| = |x|/|y|.
- |x + y| ≤ |x| + |y| (неравенство треугольника).

### Как решать уравнения с модулем

**Метод 1: определение по случаям.**
|x| = a → x = a или x = -a (если a ≥ 0).
|x| = -a → нет решений (если a > 0).

**Метод 2: метод интервалов.**
Разбить числовую прямую на участки по точкам, где выражения под модулем = 0. На каждом участке раскрыть модуль (заменить на ±) и решить обычное уравнение/неравенство.

### Где применить

В задачах с расстоянием: «на каком расстоянии от точки A находится точка B?»
В задачах: «при каких x значение выражения равно 5?»

### Где ошибиться

**Ловушка «|x| = -5 имеет решения».** Нет, модуль неотрицателен.

**Ловушка «|x| = 5 означает x = 5».** Нет, x = ±5.

### Задача с разбором

**Задача.** Реши |x - 3| = 5.

Решение: |x - 3| = 5 → x - 3 = 5 или x - 3 = -5 → x = 8 или x = -2.

**Ответ: -2; 8.**

### Реши сам

**Задача 1.** Реши |2x - 1| = 7.

> Подсказка 1 (направление): два случая.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

2x - 1 = 7 → x = 4. 2x - 1 = -7 → x = -3.
</details>

<details>
<summary>Разбор</summary>

**Ответ: -3; 4.**
</details>

**Задача 2.** Реши |x + 4| + |x - 1| = 7.

> Подсказка 1 (направление): метод интервалов с точками -4 и 1.

<details>
<summary>Подсказка 2 (конкретный шаг)</summary>

x < -4: -(x + 4) - (x - 1) = 7 → -2x - 3 = 7 → -2x = 10 → x = -5. Подходит.
-4 ≤ x < 1: (x + 4) - (x - 1) = 7 → 5 = 7. Нет решений.
x ≥ 1: (x + 4) + (x - 1) = 7 → 2x + 3 = 7 → x = 2. Подходит.
</details>

<details>
<summary>Разбор</summary>

**Ответ: -5; 2.**
</details>

**Задача 3.** Реши |3 - x| = 0.

<details>
<summary>Ответ</summary>

3 - x = 0 → x = 3.
</details>

## Блок 2. Неравенства с модулем

### Зачем тебе это знать

Неравенства с модулем встречаются в задачах не реже уравнений. Базовые правила — точка опоры.

### Базовые правила

- |x| < a (при a > 0) ⇔ -a < x < a. (a = 0 → x = 0. a < 0 → нет решений.)
- |x| > a (при a ≥ 0) ⇔ x < -a или x > a.
- |x| ≤ a ⇔ -a ≤ x ≤ a.
- |x| ≥ a ⇔ x ≤ -a или x ≥ a.

### Как решать

**Метод 1: основные правила** (для одиночного модуля).
**Метод 2: метод интервалов** (для выражений с модулем).

### Где применить

В задачах: «при каких x |x - 3| < 5?»

### Где ошибиться

**Ловушка «|x| < -5 имеет решения».** Нет, не имеет.

**Ловушка «|x| > -5 — все x».** Да, верно. Потому что -5 < 0, а модуль всегда ≥ 0.

### Задача с разбором

**Задача.** Реши |2x - 3| < 5.

Решение: -5 < 2x - 3 < 5 → -2 < 2x < 8 → -1 < x < 4.

**Ответ: (-1; 4).**

### Реши сам

**Задача 1.** Реши |x + 1| ≥ 3.

<details>
<summary>Ответ</summary>

x ≤ -4 или x ≥ 2. (-∞; -4] ∪ [2; +∞).
</details>

**Задача 2.** Реши |3x - 6| ≤ 9.

<details>
<summary>Ответ</summary>

-9 ≤ 3x - 6 ≤ 9 → -3 ≤ 3x ≤ 15 → -1 ≤ x ≤ 5. [-1; 5].
</details>

**Задача 3.** Реши |x² - 4| < 5.

> Подскака: -5 < x² - 4 < 5 → -1 < x² < 9. Левая часть: -1 < x² — это всегда верно. Правая: x² < 9 → |x| < 3.

<details>
<summary>Ответ</summary>

(-3; 3).
</details>

## Блок 3. Модуль в модуле и более сложные случаи

### Зачем тебе это знать

В задачах часто встречается вложенный модуль или модуль с дробями. Без навыка ты застрянешь.

### Как решать

**Метод интервалов:** разбить прямую на участки по всем критическим точкам (где подмодульное выражение = 0). На каждом участке раскрыть модули.

### Где применить

В задачах: «при каких x ||x - 1| - 2| < 1?»

### Где ошибиться

**Ловушка «модуль раскрывается одинаково везде».** Нет, зависит от знака подмодульного выражения.

### Задача с разбором

**Задача.** Реши ||x| - 2| < 1.

Решение:
Пусть t = |x|. |-2 + t| < 1 → -1 < t - 2 < 1 → 1 < t < 3.
Но t = |x| ≥ 0, поэтому: 1 < |x| < 3 → x ∈ (-3; -1) ∪ (1; 3).

**Ответ: (-3; -1) ∪ (1; 3).**

### Реши сам

**Задача 1.** Реши ||x + 1| - 3| < 2.

<details>
<summary>Ответ</summary>

|x + 1| - 3 ∈ (-2; 2) → |x + 1| ∈ (1; 5) → x + 1 ∈ (-5; -1) ∪ (1; 5) → x ∈ (-6; -2) ∪ (0; 4).
</details>

**Задача 2.** Реши |1/|x - 1|| = 2.

<details>
<summary>Ответ</summary>

1/|x - 1| = 2 → |x - 1| = 1/2 → x - 1 = ±1/2 → x = 3/2 или 1/2.
</details>

## Босс-файт

### Задача 1. Реши |x² - 4x + 3| = 0

**Решение:** x² - 4x + 3 = 0 → x = 1 или x = 3.

**Ответ: 1; 3.**

### Задача 2. Реши |x - 2| + |x + 1| = 6

**Решение:** метод интервалов с точками -1 и 2.
x < -1: -(x-2) - (x+1) = 6 → -2x + 1 = 6 → x = -5/2. Подходит (x = -2.5 < -1).
-1 ≤ x < 2: (x-2) - (x+1) = 6 → -3 = 6. Нет.
x ≥ 2: (x-2) + (x+1) = 6 → 2x - 1 = 6 → x = 7/2 = 3.5. Подходит.

**Ответ: -2.5; 3.5.**

### Задача 3. Реши |2x - 5| ≤ 3

**Решение:** -3 ≤ 2x - 5 ≤ 3 → 2 ≤ 2x ≤ 8 → 1 ≤ x ≤ 4.

**Ответ: [1; 4].**

### Задача 4. Реши ||x| - 1| + ||x| - 2| = 2

**Решение:** пусть t = |x|, t ≥ 0.
|t - 1| + |t - 2| = 2.
t < 1: (1-t) + (2-t) = 2 → 3 - 2t = 2 → t = 1/2. Подходит (0 ≤ 1/2 < 1).
1 ≤ t < 2: (t-1) + (2-t) = 2 → 1 = 2. Нет.
t ≥ 2: (t-1) + (t-2) = 2 → 2t - 3 = 2 → t = 5/2. Подходит (2.5 ≥ 2).
Значит, t = 1/2 или t = 5/2. То есть |x| = 1/2 или |x| = 5/2.
x = ±1/2 или x = ±5/2.

**Ответ: -5/2; -1/2; 1/2; 5/2.**

## Сборник формул

### Определение

|x| = x, если x ≥ 0; |x| = -x, если x < 0.

### Уравнения

|x| = a → x = ±a (при a ≥ 0).
|x| = -a (a > 0) → нет решений.

### Неравенства

|x| < a (a > 0) → -a < x < a.
|x| ≤ a → -a ≤ x ≤ a.
|x| > a → x < -a или x > a.
|x| ≥ a → x ≤ -a или x ≥ a.
