Функцией называется зависимость 
переменной у от переменной х, при которой 
значению х соответствует единственное 
значение у. Функция обозначается буквой f или 
f(x), или равенством y= f(x), где х - независимая 
переменная (аргумент), у- зависимая
переменная (значение функции).

Областью определения функции
называется множество допустимых 
значений аргумента. Обозначается 
область определения D(у) или D(f).

Областью значений функции 
называется множество тех значений,
которые может принимать зависимая 
переменная при всех значениях аргумента 
из области определения. Обозначается 
область значений E(у) или E(f).

Графиком функции y=f(x) называется 
фигура, состоящая из всех точек 
координатной плоскости, абсциссы 
которых равны значению аргумента, а 
ординаты - соответствующим 
значением функции.

Нулями функции 
называются значения 
аргумента, при 
которых значения 
функции равны нулю.
Чтобы найти нули 
функции y=f(x), нужно 
решить уравнение
f(x)=0.

Промежутки знакопостоянства -это 
промежутки из области определения 
функции, на которых данная функция 
принимает положительные или 
отрицательные значения. Чтобы найти 
промежутки, на которых функция у=f(x)
принимает положительные значения, 
нужно решить неравенство f(x)> 0, 
отрицательные - f(x)<0.

Функция y=f(x) называется чётной, если её область 
определения симметрична относительно нуля и для 
каждого х из области определения f(-x) = f(x).
График чётной функции симметричен относительно 
оси Оу.

Функция у= f(x) называется нечётной, если ее область 
определения симметрична относительно нуля и для каждого 
х из области определения f(-x) = -f(x). График нечётной функции 
симметричен относительно начала координат.

1. Аналитический способ: функция задаётся с 

помощью математической формулы.

2. Табличный способ: функция задаётся с 

помощью таблицы.

3. Описательный способ: функция задаётся 
словесным описанием.

4. Графический способ: функция задаётся с 
помощью графика.
