## Часть 1. Восстановлено точно (ответ сходится с ключом)

### Задача 80 — вынесение множителя из-под корня

Было: `^{6} 128a^{18}` при `a < 0`. Потерян знак √.

**Условие.** Вынесите множитель из-под знака корня в выражении \(\sqrt[6]{128a^{18}}\), если \(a < 0\).

1) \(2a^3\sqrt[6]{2}\)
2) \(-2a^3\sqrt[6]{2}\)
3) \(-2a^3\sqrt2\)
4) \(-2a^3\sqrt[3]{2}\)
5) \(2a^3\sqrt[3]{2}\)

**Ответ: 2)**

**Почему восстановление точное.** \(128 = 2^7\), показатель при \(a\) — 18, а \(a < 0\), поэтому \(|a|^{18} = a^{18}\).

\[
\sqrt[6]{128a^{18}} = 2^{7/6}\cdot|a|^3 = 2\cdot\sqrt[6]{2}\cdot(-a^3) = -2a^3\sqrt[6]{2}
\]

**Проверка числом** при \(a = -2\): \(\sqrt[6]{128\cdot2^{18}} = 2^{25/6} \approx 17{,}9594\). Форма ответа: \(-2\cdot(-8)\cdot1{,}1225 \approx 17{,}9594\). Совпало.

### Задача 89 — вынесение множителя из-под корня

Было: `^{4} 243a^{12}` при `a < 0`.

**Условие.** Вынесите множитель из-под знака корня в выражении \(\sqrt[4]{243a^{12}}\), если \(a < 0\).

1) \(-3a^3\sqrt[4]{3}\)
2) \(3a^3\sqrt[4]{3}\)
3) \(-3a^3\sqrt3\)
4) \(-3a^3\sqrt[3]{3}\)
5) \(3a^3\sqrt3\)

**Ответ: 1)**

**Разбор.** \(243 = 3^5\).

\[
\sqrt[4]{243a^{12}} = 3^{5/4}\cdot|a|^3 = 3\cdot\sqrt[4]{3}\cdot(-a^3) = -3a^3\sqrt[4]{3}
\]

**Проверка числом** при \(a = -2\): \(\sqrt[4]{243\cdot2^{12}} = 3^{5/4}\cdot2^3 = 24\sqrt[4]{3} \approx 31{,}5858\). Форма ответа даёт то же. Совпало.

### Задача 139 — деление степеней

Было: `b^{4,8} : b^{−}^{4,2}` при `b = ^{3} 2`. Потеряны знаки корня и минус.

**Условие.** Найдите значение выражения \(b^{4,8} : b^{-4,2}\) при \(b = \sqrt[3]{2}\).

**Ответ: 8**

**Разбор.** Показатели при делении **вычитаются**: \(4{,}8 - (-4{,}2) = 9\). Дальше \(\left(\sqrt[3]{2}\right)^9 = 2^{9/3} = 2^3 = 8\). Совпало.

### Задача 99 — ошибка одной цифры

Было: `: ^{5} 244`, ключ `1/3`. Потеряно всё выражение, кроме корня.

**Условие.** Значение выражения \(1 : \sqrt[5]{243}\) равно:

1) \(\dfrac13\)
2) \(\dfrac{1}{244}\)
3) \(3\)
4) \(5;\sqrt[5]{244}\)
5) \(2.\sqrt[5]{244}\)

**Ответ: 1)**

**Почему именно 243, а не 244.** \(\sqrt[5]{243} = \sqrt[5]{3^5} = 3\) — ровно целое. Тогда \(1 : 3 = 1/3\), и ключ сходится. При 244 получается \(0{,}33306\), а не \(1/3\). Значит 244 — ошибка распознавания цифры.

## Часть 2. Пересобрано по прототипу

Эти задачи восстановить нельзя: при распознавании потеряно не только выражение под корнем, но и вид самого задания (например, в смешанных числах у всех стояло `\frac{1}{1}`, а на координатной прямой пропал рисунок с точками). Проверки с ключом не сходится ни при каком чтении.

Поэтому ниже — задачи **того же типа**, с числами, подобранными так, чтобы ответ был точным.

---

### Прототип А. Смешанное число, делённое на корень

Подкоренное подобрано как точная степень, поэтому корень выходит целым, а ответ — точной дробью.

**1.** Значение выражения \(4\dfrac{1}{4} : \sqrt[4]{16}\) равно:

1) \(4{,}25\) · 2) \(\dfrac{17}{8}\) · 3) \(\dfrac94\) · 4) \(\dfrac{17}{16}\) · 5) \(\dfrac{2}{17}\)

**Ответ: 2)** — \(\sqrt[4]{16} = 2\), значит \(\dfrac{17}{4} : 2 = \dfrac{17}{8}\).

**2.** Значение выражения \(3\dfrac{1}{3} : \sqrt[3]{8}\) равно:

1) \(\dfrac32\) · 2) \(\dfrac{10}{3}\) · 3) \(\dfrac53\) · 4) \(\dfrac{16}{3}\) · 5) \(\dfrac{8}{3}\)

**Ответ: 3)** — \(\sqrt[3]{8} = 2\), значит \(\dfrac{10}{3} : 2 = \dfrac53\).

**3.** Значение выражения \(2\dfrac{1}{2} : \sqrt[5]{32}\) равно:

1) \(\dfrac54\) · 2) \(\dfrac32\) · 3) \(\dfrac{5}{8}\) · 4) \(\dfrac{2}{5}\) · 5) \(\dfrac{8}{5}\)

**Ответ: 1)** — \(\sqrt[5]{32} = 2\), значит \(\dfrac52 : 2 = \dfrac54\).

**4.** Значение выражения \(1\dfrac{1}{7} : \sqrt[7]{128}\) равно:

1) \(\dfrac47\) · 2) \(\dfrac87\) · 3) \(\dfrac{16}{7}\) · 4) \(\dfrac{2}{7}\) · 5) \(\dfrac{1}{4}\)

**Ответ: 1)** — \(\sqrt[7]{128} = 2\), значит \(\dfrac87 : 2 = \dfrac47\).

**5.** Значение выражения \(5\dfrac{1}{5} : \sqrt[5]{243}\) равно:

1) \(\dfrac{26}{15}\) · 2) \(\dfrac{26}{3}\) · 3) \(\dfrac{13}{5}\) · 4) \(\dfrac{26}{45}\) · 5) \(\dfrac{13}{15}\)

**Ответ: 1)** — \(\sqrt[5]{243} = 3\), значит \(\dfrac{26}{5} : 3 = \dfrac{26}{15}\).

### Прототип Б. Какое число стоит на координатной прямой

Рисунок при распознавании потерян, поэтому та же задача переведена в числа. **Тренировка та же:** оценить иррациональное число, не вычисляя его точно.

**6.** Числу \(\sqrt[3]{28}\) может соответствовать точка с координатой:

1) \(2{,}8\) · 2) \(3{,}03\) · 3) \(3{,}3\) · 4) \(3{,}7\) · 5) \(4{,}1\)

**Ответ: 2)** — \(3^3 = 27 < 28 < 64 = 4^3\), значит \(\sqrt[3]{28}\) чуть больше 3: это \(3{,}0366\).

**7.** Числу \(\sqrt[3]{65}\) может соответствовать точка с координатой:

1) \(3{,}9\) · 2) \(4{,}02\) · 3) \(4{,}1\) · 4) \(4{,}4\) · 5) \(4{,}9\)

**Ответ: 2)** — \(4^3 = 64 < 65 < 125 = 5^3\), значит \(\sqrt[3]{65}\) чуть больше 4: это \(4{,}0207\).
