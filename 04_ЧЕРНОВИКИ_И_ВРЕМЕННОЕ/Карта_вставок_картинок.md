>
> Каждая запись содержит:
> - **Где**: номер строки в гайде.
> - **Что заменить**: ASCII-схема, которую заменяем.
> - **Какая картинка**: ID фигуры из `Фигуры_Тригонометрия_промпты.md` + путь к промпту.
> - **Подпись**: что написать под картинкой в готовом макете.

## ИНСТРУКЦИЯ ДЛЯ ВЁРСТКИ

1. Открыть `Тригонометрия_Полный_гайд.md`.
2. Найти строку из колонки «Где».
3. Выделить блок кода (между ``` ```) или ASCII-схему.
4. Заменить на блок: `![подпись](путь/к/картинке.png)`.
5. Использовать ID из колонки «Какая картинка» для поиска готового промпта в `Фигуры_Тригонометрия_промпты.md`.
