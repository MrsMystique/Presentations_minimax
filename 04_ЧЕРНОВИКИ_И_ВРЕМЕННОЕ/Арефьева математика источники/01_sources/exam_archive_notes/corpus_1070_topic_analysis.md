## 2. Topic Taxonomy (developed from corpus)

### 2.1 ЧИСЛА И ВЫЧИСЛЕНИЯ (Numbers and Calculations) — f0b22c2b
- **Дроби (Fractions)** — equivalent fractions, comparison, simplification, mixed/sum/product.
- **Степени и стандартный вид (Powers / scientific notation)** — `a·10^n` recognition, conversion.
- **Действия с десятичными дробями (Decimal arithmetic)** — `(a^2 - b^2 + c·d) / e`-style
  compound expressions.
- **Пропорции / прямая и обратная пропорциональность (Proportionality)**.
- **Делимость и остатки (Divisibility & modular arithmetic)** — "при делении на … даёт остаток …".
- **НОД / НОК (GCD / LCM)** — explicit GCD/LCM problems.
- **Единицы измерения (Unit conversion)** — km/h ↔ m/s, ц ↔ кг, ч ↔ мин, etc.
- **Проценты (Percentages)** — "X % от Y", "увеличить/уменьшить на p%".
- **Округление (Rounding)** — "округление числа … с точностью до …".
- **Чётность / знаки (Parity / signs)** — "какое из чисел чётное", "цифра 5 в разряде …".
- **Расположение чисел на числовой оси (Number-line ordering)**.
- **Сравнение иррациональных чисел (Irrational comparison)** — `√n` vs `m`, ordering.
- **Координатная прямая / точки с целыми координатами (Integer lattice on a line)**.
- **Тригонометрические значения (Trig values)** — discrete questions on `sin 75° cos 75°` etc.
- **Обратные/противоположные/взаимно-обратные числа (Reciprocals, opposites)**.
- **Арифметика корней и дробных степеней (Roots / fractional exponents)**.
- **Логарифмы (Logarithms)** — simple numerical `log_a √b`-type problems.
- **Время возврата автобусов (Bus-period LCM application)**.
- **Метод промежутков / обратные тригонометрические неравенства (Inverse-trig inequalities)**.

### 2.2 ВЫРАЖЕНИЯ И ИХ ПРЕОБРАЗОВАНИЯ (Expressions and Transformations) — 8fd0d79b
- **Разложение на множители (Factoring polynomials)** — `x(ka-b)+b-ka = (ka-b)(x+1)` style.
- **Сокращение дробей (Reducing rational expressions)** — `P(x)/Q(x)` simplification.
- **Тождественные преобразования (Identities)** — `cos(α-2π) - sin(π/2 - α)`.
- **Формулы сокращённого умножения (FOIL / difference of squares)** — `196-(3-a)^2`.
- **Дроби, действия с дробями (Fraction arithmetic, mixed numbers)**.
- **Многочлены (Polynomials)** — degree, single term, monomial-vs-binomial identification.
- **Степени с рациональным/дробным показателем (Rational exponents)**.
- **Свойства степеней (Power rules)** — `a^m : a^n`, `a^m·a^n`, `(a^n)^m`.
- **Корни и их свойства (Roots)** — extracting a factor from `√(a^n)`.
- **Арифметика с процентами / процентные выражения (Percent in expressions)**.
- **Линейные/пропорциональные/обратные формулы (Linear / proportional / inverse formulas)**
  — `m = ρV → ρ = m/V`, boat-vs-current problems.
- **Задачи с физическим/экономическим содержанием (Word problem → expression)** —
  альбомы + краски, плот vs катер, ёлочные шары, плотник, etc.
- **Область определения (Domain of expression)** — `√(x+5)/(x-7)`-style.
- **Степенно-показательные выражения (Exponential/power-form simplifications)**.
- **Логарифмические и тригонометрические значения (Logs / trig values, numeric)**.
- **Преобразования с параметром a, b, c (Algebraic manipulation with parameters)**.

### 2.3 УРАВНЕНИЯ И НЕРАВЕНСТВА (Equations and Inequalities) — 9ccd94b1, ccba6d80
- **Линейные уравнения (Linear equations)** — equivalent transformations.
- **Квадратные уравнения (Quadratic equations)** — sum of roots, Vieta's theorem.
- **Дробно-рациональные уравнения (Rational equations)** — with `√(x+a)` terms.
- **Иррациональные уравнения (Irrational equations)** — with `√(ax+b)`.
- **Показательные уравнения (Exponential equations)** — `a·b^x + c = d`, `3^(x+1)·5^(-x+1) > 1.08`.
- **Логарифмические уравнения и неравенства (Log equations/inequalities)** — `log_0.3(x+54) ≤ 2 log_0.3(x-2)`.
- **Тригонометрические уравнения (Trig equations)** — `sin 2x = √3 cos x`, `2+2 sin 5x = 1`.
- **Тригонометрические неравенства и количество корней (Trig, root counting)** —
  `sin x = -x/(16π)`.
- **Системы уравнений с двумя переменными (Systems of two equations)** — linear & mixed.
- **Системы неравенств (Systems of inequalities)** — `(2x+8 ≥ x²) ∧ ((x-1)² > 0)`.
- **Рациональные неравенства (Rational inequalities)** — `((x²+7x+10)(x-4)²)/(4-x²) ≥ 0`.
- **Уравнения с модулем (Absolute-value equations)** — `|2x²-x-7| = |5x+1|`.
- **Уравнения высших степеней (Higher-degree / biquadratic)** — `x⁴-8x-40 = √x - 2`.
- **Системы с параметром (Parametric / families of systems)**.
- **Текстовые задачи → уравнения / системы (Word problems → equations)**:
  - Проценты / скидки (Discounts)
  - Работа и производительность (Work rate — three workers)
  - Смеси и сплавы (Mixtures — salt, candies)
  - Движение (Motion — boats, cyclists, motorcycles)
  - Покупка / экономия (Purchase / savings)
  - Альбомы / марки / конфеты (Albums / stamps / candy counts)
  - НОК / НОД (GCD/LCM word problems)
  - Деление с остатком (Remainder word problems)
- **Графики уравнений (Graphs of equations)** — `xy=12`, `x²+(y-4)²=16`, parabola/hyperbola/circle.

### 2.4 КООРДИНАТЫ И ФУНКЦИИ (Coordinates and Functions) — b1009848, 97d54067
- **Линейная функция (Linear function)** — `y=kx+b`, symmetry about Oy, passage through point.
- **Квадратичная функция / парабола (Quadratic / parabola)** — vertex, axis of symmetry,
  min/max value, direction of branches.
- **Парабола: сдвиги и преобразования (Parabola shifts)** — shifts along Ox and Oy.
- **Кусочно-заданная функция по графику (Piecewise / graphical function)** — min/max, sign,
  intervals of increase/decrease, range, zero.
- **Свойства функций (Function properties)** — чётность / нечётность, возрастание / убывание.
- **Область определения и область значений (Domain / range)** — `log`-style or piecewise.
- **Прогрессии (Progressions)**:
  - **Арифметическая прогрессия (AP)** — `a_n = a + (n-1)d`, sum `S_n`, find d, n, a_n.
  - **Геометрическая прогрессия (GP)** — `b_n = b₁·q^(n-1)`, sum `S_n`, mixed AP↔GP problems.
- **Числовые последовательности (Number sequences)** — `a_n = 243n-4n²`, find max term.
- **Графики движения (Motion graphs)** — `S(t)=v·t` identification, fastest pedestrian.
- **Диаграммы (Diagrams / bar charts)** — percent within day, "на X % меньше".
- **Свойства чётной/нечётной функции (Even/odd function on graph)**.
- **Периодическая функция (Periodic function)** — using graph to read off values.
- **Точки на координатной плоскости, длины отрезков, симметрия (Lattice geometry on plane)**:
  - Длина диагонали параллелограмма по узлам сетки (Diagonal of a grid parallelogram).
  - Периметр треугольника по узлам сетки (Triangle perimeter on grid).
  - Точка M на оси ординат, равноудалённая от A и B (Equidistant point on Oy).
  - Симметрия относительно начала координат (Symmetry about origin).
- **Кусочные и ступенчатые графики (Step-like / piecewise)**.
- **Логарифмическая функция (Logarithmic function)** — zeros, points on graph.
- **Свойства графиков элементарных функций (Elementary function graphs)** — identification.

### 2.5 ГЕОМЕТРИЧЕСКИЕ ФИГУРЫ И ИХ СВОЙСТВА (Geometry) — 07a74478, 29e8b5bf
- **Плоские фигуры / взаимное расположение (Planar figures)**:
  - Симметрия относительно точки / прямой (Point & line symmetry).
  - Многогранники: что ими является (Polyhedron identification).
  - Сечение вращением (Cross-section by rotation — "получен вращением …").
- **Углы, прямые (Angles & lines)**:
  - Вертикальные/смежные углы (Vertical/adjacent angles).
  - Сумма углов вокруг точки (Sum of angles around intersection).
  - Развёрнутый угол и лучи на нём (Straight angle with rays).
  - Параллельные прямые и секущая (Parallel lines + transversal).
  - Соответственные/накрест лежащие углы (Corresponding / alternate angles).
  - Внешний угол треугольника (Exterior angle of triangle).
  - Центральный и вписанный углы (Central & inscribed angles on arc).
  - Прямой двугранный угол (Right dihedral angle).
- **Треугольники (Triangles)**:
  - Произвольный / остроугольный / равнобедренный (Acute, isosceles).
  - Прямоугольный: высота, медиана к гипотенузе, периметр, tg, cos, sin, sin².
  - Тупоугольный на координатной сетке: cos угла (Obtuse triangle on grid — cos).
  - Целочисленные стороны, max perimeter (Integer sides, max perimeter).
  - Вписанный в окружность: высота к третьей стороне (Inscribed in circle).
  - Высоты остроугольного равнобедренного, пересечение в O (Heights meet at O).
  - Равнобедренный + параллельная прямая (Isosceles + parallel line).
  - Хорды, пересекающиеся в точке, угол между хордами (Chords intersection angle).
- **Четырёхугольники (Quadrilaterals)**:
  - Трапеция (Trapezoid): вписанная / описанная, средняя линия, радиус.
  - Параллелограмм / ромб: диагонали, высота, биссектриса.
  - Прямоугольник: вписан ромб (Rectangle with inscribed rhombus).
  - Выпуклый четырёхугольник: касательная/описанная окружность.
- **Окружность и круг (Circle & disk)**:
  - Касательные и секущие, длина отрезка AK (Tangents & secant length).
  - Хорды, пересекающиеся в точке (Intersecting chords).
  - Дуги, разбивающие окружность (Arcs dividing circle).
  - Угол AMB по хордам (Inscribed angle from chord endpoints).
  - Две окружности с общей точкой C (Two circles sharing point C).
- **Стереометрия (Solid geometry)**:
  - **Сфера и шар (Sphere)**: сечение плоскостью, расстояние до плоскости, объём.
  - **Цилиндр (Cylinder)**: развёртка, диагональ осевого сечения, объём.
  - **Конус (Cone)**: объём, площадь основания, сечение, угол при вершине.
  - **Пирамида (Pyramid)**: правильная треугольная / четырёхугольная, боковое ребро,
    плоский угол при вершине, объём.
  - **Призма (Prism)**: правильная треугольная, отсечение плоскостью, диагональное сечение.
  - **Куб (Cube)**: сечение плоскостью через 3 точки, длина ломаной, расстояние от
    вершины до плоскости.
  - **Параллелепипед (Parallelepiped)**: диагональное сечение, развёртка, углы.
  - **Правильный многоугольник (Regular n-gon)**: радиус описанной окружности,
    внутренний угол, периметр, медиана.
  - **Сечения и ломаные (Sections and space polygonal chains)**.
- **Координатная геометрия в задачах (Coordinate-geometry sub-tasks)** — grid-based
  triangles, parallelogram diagonals (also cross-listed under КООРДИНАТЫ И ФУНКЦИИ).

## 6. Patterns and Observations

1. **Massive problem templating**: The Belarusian CT/CE bank uses a small number of
   *problem templates* (probably <100) and instantiates each one 5–20 times with new numerical
   data. The "Часть B" files (ccba6d80, 29e8b5bf, 97d54067) are the densest in templating
   — most problems are recognizably the same archetype as a prior problem.

2. **Variant parallelism**: The two complete ЦЭ 2025 variants (2e81aaeb and b3c487f1) are
   perfectly parallel — problem #1 in both asks "how many integers lie on this interval",
   problem #2 in both is a sphere-section diameter problem, problem #3 in both is "which pair
   is identically equal", etc. This is intentional exam design to ensure identical coverage
   with different numbers. The pair of variants is essentially one problem set × 2 with
   re-randomized numbers.

3. **Approximate exam blueprint (ЦЭ 2025, 30 problems)**:
   - ~5 pure ЧИСЛА (including 1 in problems 1–10, 2 in 11–20, 1–2 in 21–30);
   - ~4–5 ВЫРАЖЕНИЯ (тождества, одночлены, числовые выражения);
   - ~7 УРАВНЕНИЯ И НЕРАВЕНСТВА (mixed: квадратные, иррациональные, тригонометрические, логарифмические, модуль, неравенства);
   - ~5 КООРДИНАТЫ И ФУНКЦИИ (график функции, AP/GP, мин/макс, нечётная функция, корень);
   - ~10 ГЕОМЕТРИЯ (планиметрия 3–4, стереометрия 4–5, координатная геометрия 1–2).

4. **Heat-map of Часть A files**:
   - **07a74478 (geometry A)**: dominated by 7 "evergreen" sub-templates:
     пересекающиеся прямые (22), касательные+секущая (18), конус (15), перпендикуляр (10),
     симметрия (13), треугольник на сетке с cos (10), дуги ABC (10).
   - **b1009848 (coordinates A)**: dominated by AP (13), диагональ параллелограмма на сетке (10),
     квадратичная мин/макс (12), линейная чётная (10), диаграммы (8), эскизы парабол (6).
   - **9ccd94b1 (equations A)**: dominated by 6 repeating templates cycled in groups of 6:
     катеты-корни, поставщики, иррациональное, система неравенств, равносильные, текстовое
     условие.
   - **8fd0d79b (expressions A)**: dominated by 5 templates: разложение `(ka-b)(x+1)`,
     пропорция, dried-fruits, дробь, плот-катер. ~10 each.
   - **f0b22c2b (numbers A)**: dominated by 5 templates: equivalent fractions, decimal-arithmetic
     compound, standard form, ordering, place-value.

5. **"Экзотические" sub-topics** (only in one or two places):
   - Диаграммы / bar-charts: only in b1009848.
   - Автобусные периоды / matchbox: only in f0b22c2b (problem 128).
   - Задача "5π/6 + смежный угол": only in f0b22c2b.
   - Задача "Витя и тетради": only in ccba6d80.
   - "Сосуды с солью": only in ccba6d80 (80, 160).
   - Спичечный коробок: only in ccba6d80.
   - "Коробки 6n" (boxes 6×): only in f0b22c2b (problem 112).
   - "Строительная бригада / поставщики" — appears in 9ccd94b1 and ccba6d80 (variant form).

6. **Striking absent categories** (in this corpus):
   - Производные / интегралы (no calculus) — not in the ЦТ/ЦЭ syllabus at this level.
   - Векторы (vectors) — not as a primary topic.
   - Теория вероятностей / статистика (no combinatorics/probability) — also not at this level.
   - Комплексные числа (complex numbers) — not present.
   - Тригонометрические уравнения с выбором ответа: lots in 9ccd94b1 part A and ccba6d80 part B.

7. **Encoding artefacts** observed in the extracted text:
   - "Най ди те" (should be "Найдите");
   - "плос ко стью" (should be "плоскостью");
   - "ок руж ность" (should be "окружность");
   - All formulas are written with non-breaking spaces; e.g. `6 х ² – 9 х + 12 = 0`.
   - The artifact is consistent across files and does not affect problem classification.

8. **Apparent grade-level assumption**: The corpus is aimed at a strong high-school exit
   exam (Беларусь 11-й класс / Россия ЕГЭ equivalent). The mix of items matches the
   well-known 5-domain ЦТ/ЦЭ partition: ЧИСЛА / ВЫРАЖЕНИЯ / УРАВНЕНИЯ / КООРДИНАТЫ / ГЕОМЕТРИЯ.

9. **Variant-set recommendation**: For a minimal training/eval set covering the full syllabus,
   the most economical selection would be: a single 30-problem ЦЭ variant (2e81aaeb or
   b3c487f1) + Часть A 9ccd94b1 (100) + Часть B 29e8b5bf (100) + Часть A b1009848 (110) +
   Часть A f0b22c2b (140) — total ~510 problems that already cover every archetype
   enumerated above. The Часть A/B 07a74478/97d54067/ccba6d80/8fd0d79b files provide
   additional practice volume on the same templates.
