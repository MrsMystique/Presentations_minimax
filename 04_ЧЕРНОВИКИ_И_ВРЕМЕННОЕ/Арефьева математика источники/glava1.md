При изучении физики, математики, химии вы встречались с формулами, которые содержат степени некоторых величин. Например,

\[
E_{\text{к}}=\frac{mv^2}{2},
\]

где \(E_{\text{к}}\) — кинетическая энергия, \(m\) — масса тела, \(v\) — его скорость.

Количество нераспавшихся атомов радиоактивного вещества \(N(t)\) к моменту времени \(t\) можно подсчитать по формуле

\[
N(t)=N_0\,2^{-\frac{t}{T}},
\]

где \(N_0\) — первоначальное количество радиоактивных ядер, \(T\) — период полураспада вещества. Очевидно, что при некоторых значениях \(T\) и \(t\) показатель степени \(-\dfrac tT\) может оказаться дробным.

В 7-м классе вы изучили понятие степени числа с целым показателем. При расширении числового множества, на котором рассматривается степень, определение степени дается таким образом, чтобы свойства, рассмотренные ранее, сохранялись. Дадим определение степени числа с дробным показателем.

Рассмотрим степень положительного числа \(a\) с показателем \(\dfrac1n\), где \(n\) — натуральное число, большее 1, т. е. \(a^{1/n}\). Для степени с этим показателем справедливо свойство возведения степени в степень:

\[
\left(a^{1/n}\right)^n=a^{(1/n)\cdot n}=a.
\]

С другой стороны, неотрицательное число, \(n\)-я степень которого равна \(a\), называется **арифметическим корнем \(n\)-й степени** из числа \(a\), т. е.

\[
\left(\sqrt[n]{a}\right)^n=a.
\]

Таким образом,

\[
a^{1/n}=\sqrt[n]{a}.
\]

Рассмотрим степень положительного числа \(a\) с показателем \(\dfrac mn\), где \(m\) — целое число, а \(n\) — натуральное, большее 1, т. е. \(a^{m/n}\). Представим \(a^{m/n}\) в следующем виде:

\[
a^{m/n}=\left(a^{1/n}\right)^m=\left(\sqrt[n]{a}\right)^m=\sqrt[n]{a^m}.
\]

Таким образом, получили, что \(a^{m/n}=\sqrt[n]{a^m}\).

> **Определение.** Степенью числа \(a>0\) с рациональным показателем \(\dfrac mn\), где \(m\) — целое число, а \(n\) — натуральное (\(n>1\)), называется число \(\sqrt[n]{a^m}\), т. е. корень \(n\)-й степени из \(a\) в степени \(m\):
>
> \[
> a^{m/n}=\sqrt[n]{a^m}.
> \]

Например,

\[
3^{1/5}=\sqrt[5]{3};\qquad
2^{3/4}=\sqrt[4]{2^3}=\sqrt[4]{8};\qquad
7^{1/2}=\sqrt7;
\]

\[
0{,}2^{-2/7}=\sqrt[7]{0{,}2^{-2}}=\sqrt[7]{25};\qquad
a^{2/3}=\sqrt[3]{a^2}.
\]

**Решение.** Воспользуемся определением степени с рациональным показателем:

в)

\[

\]

### Свойства степени с рациональным показателем

Для степени с рациональным показателем справедливы все свойства степени с целым показателем.

Докажем одно из свойств степени с рациональным показателем. Пусть \(a>0\). Покажем, что

\[
a^{m/n}\cdot a^{p/q}=a^{m/n+p/q},
\]

где \(m,p\) — целые числа, \(n,q\) — натуральные, большие 1.

По определению степени с рациональным показателем:

\[
a^{m/n}=\sqrt[n]{a^m},\qquad a^{p/q}=\sqrt[q]{a^p}.
\]

По свойству корня:

\[
\sqrt[n]{a^m}=\sqrt[nq]{a^{mq}},\qquad
\sqrt[q]{a^p}=\sqrt[nq]{a^{np}}.
\]

По свойству корней:

\[
\sqrt[nq]{a^{mq}}\cdot\sqrt[nq]{a^{np}}
=\sqrt[nq]{a^{mq}\cdot a^{np}}
=\sqrt[nq]{a^{mq+np}}.
\]

По определению степени с рациональным показателем:

\[
\sqrt[nq]{a^{mq+np}}
=a^{\frac{mq+np}{nq}}
=a^{m/n+p/q}.
\]

Таким образом,

\[
a^{m/n}\cdot a^{p/q}=a^{m/n+p/q}.
\]

Для \(a>0\) и рациональных \(m,n\):

\[
a^m\cdot a^n=a^{m+n};\qquad
a^m:a^n=a^{m-n};\qquad
(a^m)^n=a^{mn}.
\]

Для \(a>0\), \(b>0\) и рационального \(n\):

\[
(ab)^n=a^n b^n;\qquad
(a:b)^n=a^n:b^n.
\]

### Степень с иррациональным показателем

Степень с иррациональным показателем определяется через десятичные приближения показателя степени.

Например, для вычисления значения степени \(2^{\sqrt3}\) рассмотрим неравенства:

\[
2<2^{\sqrt3}<2^2,\quad\text{так как }1<\sqrt3<2;
\]

\[
2^{1{,}7}<2^{\sqrt3}<2^{1{,}8},\quad\text{так как }1{,}7<\sqrt3<1{,}8;
\]

\[
2^{1{,}73}<2^{\sqrt3}<2^{1{,}74},\quad\text{так как }1{,}73<\sqrt3<1{,}74;
\]

\[
2^{1{,}732}<2^{\sqrt3}<2^{1{,}733},\quad\text{так как }1{,}732<\sqrt3<1{,}733,\text{ и т. д.}
\]

С помощью калькулятора можно приближенно вычислить значения степеней с рациональным показателем:

\[
2^{1{,}732}\approx3{,}3218801,\qquad
2^{1{,}733}\approx3{,}3241834.
\]

Получаем приближенное значение степени: \(2^{\sqrt3}\approx3{,}32\). Более точное значение степени с иррациональным показателем можно получить, продолжив процесс оценки через десятичные приближения, увеличивая точность приближения показателя.

Для любого действительного \(a>0\) и любого действительного числа \(\alpha\) определено понятие степени \(a^\alpha\). Для степени с действительным показателем справедливы все свойства степени с рациональным показателем.

Для \(a=0\) определена степень с положительным рациональным показателем:

\[
0^{m/n}=\sqrt[n]{0^m}=0,
\]

где \(m\) и \(n\) — натуральные числа, \(n>1\). Например,

\[
0^{2/3}=\sqrt[3]{0^2}=0.
\]

### Пример 2. Упростите выражение

\[
\text{а) }(a^{\sqrt5})^{\sqrt5};\qquad
\text{б) }a^{\sqrt7}\cdot a^{3-\sqrt7};\qquad
\text{в) }a^{\sqrt3-1}:a^{\sqrt3}.
\]

**Решение.** Воспользуемся свойствами степени:

а) \((a^{\sqrt5})^{\sqrt5}=a^{\sqrt5\cdot\sqrt5}=a^5\);

б) \(a^{\sqrt7}\cdot a^{3-\sqrt7}=a^{\sqrt7+3-\sqrt7}=a^3\);

в) \(a^{\sqrt3-1}:a^{\sqrt3}=a^{\sqrt3-1-\sqrt3}=a^{-1}=\dfrac1a\).

## Примеры основных заданий и их решения

### 1. Представьте в виде корня степень с рациональным показателем

\[
3^{1/6};\quad 2^{3/4};\quad 5^{1/2};\quad 10^{7/2};\quad
2^{-3/5};\quad 4^{-0{,}3};\quad a^{2/5};\quad (x-y)^{3/7}.
\]

**Решение:**

\[
3^{1/6}=\sqrt[6]{3};\qquad
2^{3/4}=\sqrt[4]{2^3}=\sqrt[4]{8};\qquad
5^{1/2}=\sqrt5;
\]

\[
10^{7/2}=\sqrt{10^7}=\sqrt{10\,000\,000};\qquad
2^{-3/5}=\sqrt[5]{2^{-3}}=\sqrt[5]{\frac18};
\]

\[
4^{-0{,}3}=4^{-3/10}=\sqrt[10]{4^{-3}}=\sqrt[10]{\frac1{64}};
\qquad a^{2/5}=\sqrt[5]{a^2};\qquad
(x-y)^{3/7}=\sqrt[7]{(x-y)^3}.
\]

### 2. Представьте корень в виде степени с рациональным показателем

\[
\sqrt[4]7;\quad \sqrt[7]{2^3};\quad \sqrt{11};\quad \sqrt{5^3};\quad
\sqrt{3^{-3}};\quad \sqrt[5]{a^4};\quad \sqrt[3]{m+n}.

**Решение:**

\[
\sqrt[4]7=7^{1/4};\quad
\sqrt[7]{2^3}=2^{3/7};\quad
\sqrt{11}=11^{1/2};\quad
\sqrt{5^3}=5^{3/2};
\]

\[
\sqrt{3^{-3}}=3^{-3/2};\quad
\sqrt[5]{a^4}=a^{4/5};\quad
\sqrt[3]{m+n}=(m+n)^{1/3}.
\]

\[

\[

### 12. Упростите выражение

а) \(\dfrac{a^2-a^{3/2}}{a-a^{1/2}}-\dfrac{a^{0{,}25}}{a^{-0{,}75}}\);

б) \(\left(\dfrac{x^2+y^2}{xy^{1/2}+x^{3/2}}-\dfrac{x+y}{y^{1/2}+x^{1/2}}\right)xy^{-1}\).

**Решение:**

а)

\[
\frac{a^2-a^{3/2}}{a-a^{1/2}}-\frac{a^{0{,}25}}{a^{-0{,}75}}
=\frac{a^{3/2}(a^{1/2}-1)}{a^{1/2}(a^{1/2}-1)}-a^{0{,}25-(-0{,}75)}
=a-a=0;
\]

б)

\[
\begin{aligned}
\left(\frac{x^2+y^2}{xy^{1/2}+x^{3/2}}-\frac{x+y}{y^{1/2}+x^{1/2}}\right)xy^{-1}
&=\left(\frac{x^2+y^2}{x(y^{1/2}+x^{1/2})}-\frac{x+y}{y^{1/2}+x^{1/2}}\right)xy^{-1}\\
&=\frac{x^2+y^2-x(x+y)}{x(y^{1/2}+x^{1/2})}\cdot\frac{x}{y}\\
&=\frac{y(y-x)}{x(y^{1/2}+x^{1/2})}\cdot\frac{x}{y}\\
&=\frac{y-x}{y^{1/2}+x^{1/2}}=y^{1/2}-x^{1/2}.
\end{aligned}
\]

### 13. Найдите значение выражения

г)* \(\dfrac{(\sqrt{343})^{\sqrt{20}}}{7^{\sqrt{45}-2}}=\dfrac{(7^{3/2})^{2\sqrt5}}{7^{3\sqrt5-2}}=7^{3\sqrt5-(3\sqrt5-2)}=7^2=49\).

### 15. Сократите дробь

\[

\[
