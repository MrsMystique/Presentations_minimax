# 📋 СПРАВОЧНИК ФОРМУЛ — Геометрия 1–11 класс

**Назначение.** Компактный список всех формул, встречающихся в гайде. Используй как шпаргалку при решении задач. Подробный вывод каждой формулы — в основном файле `Геометрия_11_Полный_гайд.md` в Секции 1.7 «Конструкторский принцип формул».

**Структура.** Формулы сгруппированы по **типу фигуры** (не по номерам). В каждой строке указано имя типа, формула, когда применять и мини-пример.

## ПЛОСКАЯ ГЕОМЕТРИЯ (5–9 класс)

### Треугольники

| Тип треугольника | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Любой треугольник** (через сторону и высоту) | \(S = \frac{1}{2} a h\) | Дан треугольник, дано основание и высота к нему | \(a = 6, h = 4 \Rightarrow S = 12\) |
| **Любой треугольник** (через две стороны и угол между ними) | \(S = \frac{1}{2} a b \sin C\) | Даны две стороны и угол между ними | \(a = 5, b = 8, \angle C = 30° \Rightarrow S = 10\) |
| **Любой треугольник** (через три стороны) | \(S = \sqrt{p(p-a)(p-b)(p-c)}\) | Даны три стороны (углы не даны) | \(a = 3, b = 4, c = 5 \Rightarrow S = 6\) |
| **Прямоугольный треугольник** | \(S = \frac{1}{2} a b\) | Есть угол 90° (катеты \(a, b\)) | \(a = 3, b = 4 \Rightarrow S = 6\) |
| **Равносторонний треугольник** | \(S = \frac{a^2 \sqrt{3}}{4}\) | Все стороны равны, все углы 60° | \(a = 6 \Rightarrow S = 9\sqrt{3}\) |
| **Равнобедренный прямоугольный треугольник** | \(S = \frac{c^2}{4}\) | Угол 90° между катетами, катеты равны, гипотенуза \(c\) | \(c = 4 \Rightarrow S = 4\) |
| **Сумма углов треугольника** | \(\angle A + \angle B + \angle C = 180°\) | Любой треугольник | \(50° + 60° + \angle C = 180° \Rightarrow \angle C = 70°\) |
| **Теорема синусов** (любой треугольник) | \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R\) | Сторона через угол и описанную окружность | \(a = 6, \angle A = 30° \Rightarrow R = 6\) |
| **Теорема косинусов** (любой треугольник) | \(c^2 = a^2 + b^2 - 2ab\cos C\) | Сторона через две другие и угол между ними | \(a = 3, b = 4, \angle C = 60° \Rightarrow c^2 = 13\) |
| **Теорема Пифагора** (прямоугольный треугольник) | \(c = \sqrt{a^2 + b^2}\) | Только для прямоугольного (угол 90°) | \(a = 3, b = 4 \Rightarrow c = 5\) |
| **Тригонометрия в прямоугольном треугольнике** | \(\sin A = \frac{a}{c}, \cos A = \frac{b}{c}\) | Определение \(\sin\), \(\cos\) через стороны | \(\sin 30° = \frac{1}{2}, \cos 30° = \frac{\sqrt{3}}{2}\) |

### Четырёхугольники

| Тип четырёхугольника | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Квадрат** | \(S = a^2\) | Все стороны равны, все углы 90° | \(a = 5 \Rightarrow S = 25\) |
| **Прямоугольник** | \(S = ab\) | Все углы 90°, смежные стороны \(a, b\) | \(a = 3, b = 4 \Rightarrow S = 12\) |
| **Параллелограмм** (через сторону и высоту) | \(S = ah\) | Дано сторона \(a\) и высота \(h\) к ней | \(a = 5, h = 3 \Rightarrow S = 15\) |
| **Параллелограмм** (через две стороны и угол) | \(S = ab\sin\alpha\) | Даны две смежные стороны и угол между ними | \(a = 5, b = 8, \alpha = 30° \Rightarrow S = 20\) |
| **Ромб** (через сторону и высоту) | \(S = a h\) | Все стороны равны, но это **не** квадрат | \(a = 5, h = 4 \Rightarrow S = 20\) |
| **Ромб** (через диагонали) | \(S = \frac{1}{2} d_1 d_2\) | Даны две диагонали | \(d_1 = 6, d_2 = 8 \Rightarrow S = 24\) |
| **Трапеция** | \(S = \frac{a+b}{2} h\) | Два основания \(a, b\) параллельны, высота \(h\) | \(a = 4, b = 10, h = 5 \Rightarrow S = 35\) |
| **Произвольный четырёхугольник** | \(S = \frac{1}{2} d_1 d_2 \sin\alpha\) | Любой четырёхугольник (через диагонали и угол между ними) | — |

### Окружность и круг

| Что считаем | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Длина окружности** | \(C = 2\pi r\) | Периметр круга | \(r = 5 \Rightarrow C = 10\pi\) |
| **Площадь круга** | \(S = \pi r^2\) | Площадь круга | \(r = 5 \Rightarrow S = 25\pi\) |
| **Длина дуги** | \(\ell = \dfrac{\alpha}{180°} \pi r\) | Угол \(\alpha\) в градусах | \(\alpha = 90°, r = 10 \Rightarrow \ell = 5\pi\) |
| **Площадь сектора** | \(S_{\text{сект}} = \dfrac{\alpha}{360°} \pi r^2\) | Угол \(\alpha\) в градусах | \(\alpha = 90°, r = 10 \Rightarrow S = 25\pi/4\) |
| **Степень точки** (секущие из внешней точки) | \(PA \cdot PB = PC \cdot PD\) | Секущие к окружности из точки \(P\) | — |

### Векторы на плоскости

| Операция | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Координаты вектора** | \(\vec{a} = (a_1, a_2)\) | Запись вектора через координаты | \(\vec{a} = (3, 4)\) |
| **Модуль вектора** | \(|\vec{a}| = \sqrt{a_1^2 + a_2^2}\) | Длина вектора через координаты | \(\vec{a} = (3, 4) \Rightarrow |\vec{a}| = 5\) |
| **Скалярное произведение** (через координаты) | \(\vec{a} \cdot \vec{b} = a_1 b_1 + a_2 b_2\) | Умножение векторов через координаты | \(\vec{a} = (1,2), \vec{b} = (3,-1) \Rightarrow \vec{a} \cdot \vec{b} = 1\) |
| **Скалярное произведение** (через угол) | \(\vec{a} \cdot \vec{b} = |\vec{a}| \cdot |\vec{b}| \cdot \cos\alpha\) | Умножение через длины и угол | — |
| **Условие перпендикулярности** | \(\vec{a} \perp \vec{b} \Leftrightarrow \vec{a} \cdot \vec{b} = 0\) | Проверка, что векторы перпендикулярны | — |

## СТЕРЕОМЕТРИЯ (10–11 класс)

### Многогранники (объёмы)

| Тип тела | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Прямоугольный параллелепипед** | \(V = abc\) | Все грани — прямоугольники, рёбра \(a, b, c\) | \(a=2, b=3, c=4 \Rightarrow V = 24\) |
| **Призма** (прямая и наклонная) | \(V = S_{\text{осн}} \cdot h\) | Любая призма через площадь основания и высоту | \(S = 12, h = 5 \Rightarrow V = 60\) |
| **Наклонная призма** (через перпендикулярное сечение) | \(V = S_{\perp} \cdot l\) | Когда проще найти перпендикулярное сечение | — |
| **Пирамида** | \(V = \frac{1}{3} S_{\text{осн}} \cdot h\) | Любая пирамида | \(S = 12, h = 6 \Rightarrow V = 24\) |
| **Усечённая пирамида** | \(V = \frac{h}{3}(S_1 + \sqrt{S_1 S_2} + S_2)\) | Два основания \(S_1, S_2\), высота \(h\) | — |
| **Диагональ прямоугольного параллелепипеда** | \(d^2 = a^2 + b^2 + c^2\) | Длина пространственной диагонали | \(a = 3, b = 4, c = 12 \Rightarrow d = 13\) |

### Тела вращения

| Тип тела | Формула | Когда применять | Мини-пример |
|---|---|---|---|
| **Цилиндр** | \(V = \pi r^2 h\) | Прямой круговой цилиндр | \(r = 3, h = 5 \Rightarrow V = 45\pi\) |
| **Конус** | \(V = \frac{1}{3} \pi r^2 h\) | Прямой круговой конус | \(r = 3, h = 5 \Rightarrow V = 15\pi\) |
| **Усечённый конус** | \(V = \frac{\pi h}{3}(R^2 + Rr + r^2)\) | Два основания радиусов \(R, r\), высота \(h\) | — |
| **Шар** | \(V = \frac{4}{3} \pi R^3\) | Объём шара радиуса \(R\) | \(R = 3 \Rightarrow V = 36\pi\) |
| **Шаровой сегмент** | \(V = \frac{\pi h^2}{3}(3R - h)\) | Сегмент высоты $h$ в шаре радиуса $R$ | — |

### Площади поверхностей

| Тип тела | Формула | Когда применять |
|---|---|---|
| **Прямая призма** | \(S_{\text{бок}} = P \cdot h\) | Периметр основания × высота |
| **Наклонная призма** (через перпендикулярное сечение) | \(S_{\text{бок}} = P_{\perp} \cdot l\) | Периметр перпендикулярного сечения × боковое ребро |
| **Правильная пирамида** | \(S_{\text{бок}} = \frac{1}{2} P_{\text{осн}} \cdot l\) | Периметр основания × апофема / 2 |
| **Цилиндр** | \(S_{\text{бок}} = 2\pi r h\) | Окружность основания × высота |
| **Конус** | \(S_{\text{бок}} = \pi r l\) | Окружность основания × образующая |
| **Сфера** | \(S = 4\pi R^2\) | Площадь поверхности шара |

## ГЛОССАРИЙ ПЕРЕМЕННЫХ (используется во всех формулах)

| Переменная | Значение |
|---|---|
| \(a, b, c\) | Стороны (треугольника, четырёхугольника, параллелепипеда) |
| \(h\) | Высота — перпендикуляр к основанию |
| \(d_1, d_2\) | Диагонали (ромба, четырёхугольника) |
| \(d\) | Диагональ (параллелепипеда, квадрата) |
| \(r\) | Радиус (вписанной окружности или меньшего основания конуса) |
| \(R\) | Радиус описанной окружности (или большего основания конуса) |
| \(p\) | Полупериметр (\(p = \frac{a+b+c}{2}\)) |
| \(l\) | Длина бокового ребра (призмы) или образующая (конуса) |
| \(S\) | Площадь |
| \(V\) | Объём |
| \(P\) | Периметр |
| \(m\) | Средняя линия трапеции |
| \(\alpha, \beta, \gamma\) | Углы (общего положения, при вершине, центральный) |
| \(\angle A, \angle B, \angle C\) | Углы при вершинах \(A, B, C\) |
