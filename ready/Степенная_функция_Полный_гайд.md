## Привычка, которая пригодится на весь параграф

Прежде чем решать любую задачу дальше — не только здесь, а вообще в этом

1. **Что я вижу?** (степень, корень, дробь, знак минус — что вообще есть)
2. **Что здесь знакомое?** (я это уже где-то делал, просто в другой записи)
3. **Что я применю?** (какое правило, какой приём)
4. **Что от меня хотят?** (найти область определения, построить график, доказать чётность)

Не отвечай на них развёрнуто — это не сочинение, это секундная проверка

## Проверь себя за 2 минуты

**1. Степень с целым показателем.** Сможешь с ходу сказать, чему равно
2^3, 2^-2, (-3)^2? Если рука тянется написать
2^-2 = -4 — держи в голове фильтр: минус в показателе НИКОГДА не
делает число отрицательным, он только переворачивает дробь.

> Если засомневался: a^n * a^m = a^n+m, a^n : a^m = a^n-m,
> (a^n)^m = a^nm, a^-n = 1/a^n. Это база, на которой
> держится весь параграф.

**2. Арифметический корень.** корень(16) — это сколько? А
корень_3(-27)? А корень_4(16)? В этом параграфе такие корни
буквально на каждом шагу — это и есть способ задать функцию через
дробный показатель.

**3. Чётные и нечётные числа.** Умеешь с ходу отличить чётный
знаменатель от нечётного? В показателе степени это критично: от
чётности знаменателя зависит, на каких x функция существует.

**4. Десятичная дробь и обыкновенная.** 0,75 — это сколько в виде дроби?
0,4 = 2/5. В показателе степени удобнее работать именно в
обыкновенной дроби.

**5. График простейших функций.** Как выглядит y = x, y = x^2,
y = 1/x? Без этого умельного образа в голове графики новых функций
не получится «увидеть» — только заучить.

**6. Область определения и область значений.** D(f) — это какие
x можно подставить; E(f) — какие y получатся. Эти две вещи
часто путают, а в степенной функции разница между ними максимально
резкая.

# §2. Степенная функция

## Блок 1. Что такое степенная функция и где её можно рисовать

### Зачем

Без этого блока всё дальнейшее — это догадки. Здесь ты увидишь одну и ту
же идею в разных записях: натуральный показатель, целый, дробный,
иррациональный. И поймёшь, что это не разные функции, а одна и та же —
просто с разной «инструкцией» в показателе.

**Где встречается в жизни:**

- **Физика.** y = x^2 — это зависимость пройденного пути от времени при равноускоренном движении без начальной скорости. y = x^3 встречается в физике твёрдого тела (зависимость энергии от деформации в нелинейном режиме). y = x^1/2 — связь между длиной стороны квадрата и его площадью.
- **Архитектура.** Арка — это перевёрнутая парабола (y = x^2). Купол — поверхность вращения, в основе которой лежит x^n. Кубическая парабола y = x^3 — характерная форма провисающего троса.
- **Финансы.** Сложный процент — это экспонента, но сама экспонента «прячется» за пределом степенной функции при показателе, стремящемся к бесконечности. Зависимость «многократное удвоение» — это именно степенной рост.
- **Олимпиады.** Графики степенных функций — постоянный гость. Узнать ветвь гиперболы, параболу и кубическую параболу с одного взгляда — базовый навык, без которого на контрольной будет трудно.

### Что

Степенная функция — это функция вида y = x^α, где α — любое действительное число (α ∈ R).

Здесь x — независимая переменная (аргумент), α —
фиксированное действительное число (показатель степени). Показатель
α НЕ зависит от x — это константа, выбранная один раз,
когда функция задана.

**Связь с §1.** В §1 мы научились работать со степенями с рациональным и иррациональным показателем как с числами: упрощать выражения, применять свойства, проверять ОДЗ. В §2 вся та же арифметика применяется к функциям: показатель α — это константа, а x меняется. Поэтому все ловушки про ОДЗ, степени в степени и распределение работают и здесь — мы просто «запускаем двигатель» из §1 в новых условиях.

Когда α — целое неотрицательное (α = 0, 1, 2, 3, …),
с этой записью никаких сюрпризов: x^0 = 1 (кроме x = 0),
x^1 = x, x^2 — обычная парабола. Когда α — целое
отрицательное — получаем 1/x, 1/x^2, и так далее. Когда
α — дробное — появляется корень. Когда α — иррациональное
— это уже предел, но запись y = x^α остаётся той же самой.

> **Запомнить (метод «Переводчик» для степенной функции):**
> одна и та же функция может быть записана через показатель x^α
> или через корень \sqrt[n]{x^m}. Перевод между этими записями —
> ключ к задачам с дробными α.

### Откуда

Степенная функция появилась как естественное расширение: сначала
натуральный (x^1, x^2, x^3, …), потом целый (включая
отрицательные), потом рациональный (включая дробные), и наконец —
действительный. Каждое расширение делалось так, чтобы старые правила
(произведение степеней, степень в степени) продолжали работать.

Для нас важно не отслеживать всю эту цепочку расширений, а понимать
следствие: **область определения D(f) зависит от того, какой именно
показатель α стоит в задаче**. Целый α можно подставить
в любое число (ну, почти — кроме x = 0 для отрицательных). Дробный
α — только в положительные числа, иногда ещё и с ограничением.

### Как — таблица D(f) для разных α

| Тип α                  | Пример      | D(f)               |
|---------------------------------|-------------|------------------------|
| Целый α > 0            | α = 2, 3, 4, 5 | R                   |
| Целый α = 0            | α = 0 | x ≠ 0 (y = 1) |
| Целый α < 0            | α = -1, -2, -5 | R без 0 |
| Дробный α = m/n, n чётное | α = 1/2, 3/2 | x ≥ 0 |
| Дробный α = m/n, n нечётное | α = 1/3, 1/5 | x ≥ 0 (но корень n-й степени берётся из любых x) |
| Иррациональный α | α = корень(2), π | x > 0 |

Это та таблица, которую нужно держать в голове, как таблицу умножения.
Если α не попадает ни в одну строку уверенно — стоит открыть
задачу и перечитать, что именно за показатель.

> **Запомнить (метод «Предохранитель ОДЗ»):**
> прежде чем писать «D(f) = R», посмотри на показатель.
> Если α — дробный, ты работаешь с корнем, а у корня чётной
> степени нет отрицательных подкоренных значений. Если α —
> отрицательный целый, у тебя в знаменателе стоит x^k, и x = 0
> нельзя.

### Где применить

В каждой задаче §2 — найти область определения, найти нули, построить
график. Каждое из этих действий стартует с одного и того же вопроса:
«а какой у меня α?». Если ответ есть — таблица выше даёт
область определения бесплатно.

### Где ошибиться

**Ловушка «D(f) = R по умолчанию».** Когда видишь y = x^α,
первая реакция — написать R. Это верно ТОЛЬКО для целого
положительного α. Для отрицательного целого — уже R
без нуля. Для дробного — только x ≥ 0. Для иррационального —
только x > 0.

**Ловушка «корень из отрицательного бывает».** корень(-2) —
не существует в общем случае. Корень нечётной степени (корень_3(-8) = -2)
существует, но запись через дробный показатель x^1/3 при
x < 0 требует x > 0. Это та же поломка, что обсуждали
в §1. В задачах §2 мы держим общую формулу x ≥ 0 для дробных
α.

**Ловушка «квадрат уничтожает корень в показателе».** Когда видишь (a^корень(2))^2, рука тянется написать a^2 — ведь «корень из 2 умножить на 2 даёт 2». Это ошибка. Показатели перемножаются: корень(2) * 2 = 2 * корень(2), а не 2. Правильно: (a^корень(2))^2 = a^(2 * корень(2)). Корни НЕ уничтожаются от умножения на число — только от умножения на такой же корень: (a^корень(2))^корень(2) = a^2. Здесь та же ловушка, что обсуждали в §1, но теперь она приходит из конкретного α в степенной функции.

**Ловушка «возвести ноль в отрицательную степень».** 0^-1 —
не определено. Если α < 0, то x = 0 не входит в D(f).
Точка x = 0 всегда выколотая для функций y = 1/x, y = 1/x^2,
и так далее.

### Задача с разбором: область определения для набора α

Найди D(f) для функций:

1. y = x^5
2. y = x^-3
3. y = x^1/2
4. y = x^-1/2
5. y = x^1/3
6. y = x^корень(3)

**Шаг 1.** На каждый α смотрим в таблицу выше.

1. α = 5 — целый положительный → D(f) = R.
2. α = -3 — целый отрицательный → D(f) = R без 0.
3. α = 1/2 — дробный, знаменатель чётный → D(f) = [0, +∞).
4. α = -1/2 — отрицательный дробный → D(f) = (0, +∞). (И корень, и деление на x^1/2 — оба требуют x > 0.)
5. α = 1/3 — дробный, знаменатель нечётный → D(f) = [0, +∞) в общей формуле, хотя корень кубический из отрицательного числа существует.
6. α = корень(3) — иррациональный → D(f) = (0, +∞).

**Шаг 2.** Проверка логики: отрицательная дробь α = -1/2 — это
1/корень(x), и здесь два ограничения сразу: и под корнем x > 0,
и в знаменателе (что совпадает с ограничением корня).

## Блок 2. Множество значений E(f) и нули функции

### Зачем

Если D(f) отвечает на вопрос «какие x можно подставить», то
E(f) отвечает на «какие y можно получить». Без E(f) ты не
сможешь решить, может ли функция принять значение 5 или −3. А нули —
это точки пересечения с осью x, главный инструмент для графика.

### Что

E(f) — множество всех значений, которые принимает y = x^α
на своей области определения.

| Тип α | D(f) | E(f) |
|---|---|---|
| Целый α > 0, чётный | R | [0, +∞) |
| Целый α > 0, нечётный | R | R |
| Целый α = 0 | x ≠ 0 | {1} |
| Целый α < 0, чётный | R без 0 | (0, +∞) |
| Целый α < 0, нечётный | R без 0 | R без 0 |
| Дробный α = m/n, чётное n | [0, +∞) | [0, +∞) |
| Дробный α = m/n, нечётное n | [0, +∞) (общая формула) | [0, +∞) (общая формула) |
| Иррациональный α | (0, +∞) | (0, +∞) |

Главный узор: E(f) — это «луч» вверх или вниз, реже вся
R. Полностью обе оси — только для нечётных целых
α в R.

**Нуль функции** — это значение x, при котором f(x) = 0.
Для степенной функции y = x^α единственный нуль — это x = 0
(и то только тогда, когда 0 входит в D(f)). Это верно для
любого α: 0^α = 0 (при α > 0), для
α < 0 точка x = 0 выколотая и нуля нет вообще.

> **Запомнить:**
> единственный нуль степенной функции — x = 0. Никаких других
> пересечений с осью x нет. Это свойство резко упрощает жизнь:
> построить график — значит отметить точку (0, 0) и провести кривую.

### Откуда

Почему E(f) устроено именно так? Посмотрим на график y = x^2:
это парабола, она «лежит» только в верхней полуплоскости (y ≥ 0).
Никаким x нельзя получить y = -1. Значит, E(y = x^2) = [0, +∞).

Для y = x^3 — кубическая кривая, она проходит через все значения
от -∞ до +∞. Значит, E(y = x^3) = R.

Для y = x^-2 = 1/x^2 — график «лежит» над осью x, никогда
y не бывает отрицательным. E(y) = (0, +∞) (ноль
исключён, потому что 1/x^2 никогда не равен нулю).

### Как

Чтобы найти E(f) для конкретной y = x^α, держи в голове три
ориентира:

1. **Знак результата.** x^α при x > 0 всегда положительно (если α — обычный действительный, не специальный).
2. **Достижимость нуля.** y = 0 достижимо только при x = 0 (если 0 ∈ D(f)).
3. **Поведение на бесконечности.** При x → +∞ значение y либо уходит в +∞, либо падает к нулю — зависит от знака α.

### Где применить

В задачах вида «принадлежит ли точка (a, b) графику функции» —
b должно лежать в E(f), иначе точка не на графике. В задачах
на уравнение x^α = c — должно быть c ∈ E(f).

### Где ошибиться

**Ловушка «E(f) = R по умолчанию для любого α».**
Нет. Для чётного целого α (например x^2, x^4)
E(f) = [0, +∞), не R.

**Ловушка «нулей много».** У y = x^α всегда ноль один — это
x = 0 (если 0 ∈ D(f)). У y = (x-2)^2 нуль уже x = 2,
но это другая функция, не степенная в чистом виде — там есть сдвиг.

**Ловушка «нуль всегда есть».** Если α < 0, то x = 0 не в
D(f), значит нульности у y = x^α нет вообще. Например,
y = 1/x не имеет нулей.

### Задача с разбором: упражнение 2.1 из задачника

**Условие:** найди нули функции f(x) = x^-0,75 среди
A(0,8;  1/8), B(0,3;  1/27), C(1/81;  -27),
D(32;  1/4).

**Шаг 1.** Нуль функции — это x, при котором f(x) = 0. Для
степенной функции единственный кандидат — x = 0. Но α = -0,75 < 0,
значит 0 ∉ D(f) (делить на ноль нельзя).

**Шаг 2.** Вывод: у f(x) = x^-0,75 нулей нет. Среди точек A, B, C, D ни одна не является нулём.

**Шаг 3.** Что на самом деле проверяют в этой задаче? Умеешь ли ты
отличить «нуль функции» от «точка лежит на графике». Точка лежит на
графике, если её y-координата равна f(x-координата).
Проверим для надёжности:

- A: f(0,8) = 0,8^-0,75 = 1/0,8^0,75. Это положительное число, не 1/8 — точка A не на графике.
- B: f(0,3) = 0,3^-0,75 = 1/0,3^0,75. Это не 1/27 — точка B не на графике.
- C: f(1/81) = 81^0,75. Положительное число, не -27 — точка C не на графике (и ещё y = -27 вообще не может быть значением f при x > 0).

**3.** y = (x^3 - 2x^2 + x)^-0,8. Основание g(x) = x^3 - 2x^2 + x = x(x-1)^2. При x = 0 и x = 1 основание = 0, и y не определена (α < 0, деление на ноль). На остальных x основание либо положительное, либо отрицательное. Но α = -0,8 — дробный, и для x^0,8 нужно x > 0. Значит, и для g(x)^0,8 нужно g(x) > 0. Определяем знак g(x) = x(x-1)^2:
- при x < 0: x < 0, (x-1)^2 > 0, значит g(x) < 0 — не подходит.
- при 0 < x < 1: x > 0, (x-1)^2 > 0, значит g(x) > 0 — подходит.
- при x > 1: x > 0, (x-1)^2 > 0, значит g(x) > 0 — подходит.
- при x = 0 или x = 1: g(x) = 0 — выколотая точка.
Значит, g(x) > 0 при x ∈ (0, 1) ∪ (1, +∞). На этих участках |g(x)| меняется от 0 до ∞, поэтому y = 1/|g(x)|^0,8 меняется от 0 до +∞. **E(f) = (0, +∞).**

**5.** y = (x + 4x^3)^-2 = 1/(x + 4x^3)^2. Знаменатель (x + 4x^3)^2 ≥ 0, и обращается в ноль при x = 0 (это единственный корень уравнения x(1 + 4x^2) = 0 в R). Значит, y > 0 для всех x ≠ 0, и y → 0 при |x| → ∞. **E(f) = (0, +∞).**

**6.** y = корень_4((9x^4 - 8x^2 + 1)/(4x^2 + 1)). Подкоренное выражение g(x) = (9x^4 - 8x^2 + 1)/(4x^2 + 1). Замена t = x^2: g_в_терминах_t = (9t^2 - 8t + 1)/(4t + 1). Значит, g_в_терминах_t < 0 при t ∈ ((4 - √7)/9, (4 + √7)/9), то есть для x ∈ (-√0,738; -√0,150) ∪ (√0,150; √0,738). На этих x подкоренное выражение отрицательно, и y не определена — D(f) ≠ R. На остальных x g(x) ≥ 0, и y ≥ 0. Минимум g(x) на D(f) равен 0 (на границе D(f)), значит y_мин = 0. При |x| → ∞, g ≈ (9/4)x^2 → ∞, значит y → ∞. **E(f) = [0, +∞), но D(f) ≠ R.**

## Блок 3. Монотонность — возрастание и убывание

### Зачем

Если ты знаешь, что функция возрастает, ты знаешь: больше x —
больше y. Это превращает задачу «сравни f(a) и f(b)» в
задачу «сравни a и b», что тривиально. Без монотонности ты
считаешь f(a) и f(b) каждый раз отдельно — лишняя работа.

### Что

Главное правило степенной функции:

- Если α > 0 — функция y = x^α **возрастает** на всей области определения.
- Если α < 0 — функция y = x^α **убывает** на всей области определения.
- Если α = 0 — функция постоянна: y = 1 при x ≠ 0.

При этом «область определения» в каждом случае своя — для целого
α это R (или R без 0), для
дробного — x ≥ 0 или x > 0. Но **на своей области
определения** поведение монотонности одно и то же.

> **Запомнить (метод «Рентген знаков» для монотонности):**
> знак α — это «инструкция» о направлении: плюс = вверх (возрастание),
> минус = вниз (убывание). Если α записан через дробь, проверь
> только знак числителя. Например, α = -5/3 < 0 — убывает;
> α = 7/4 > 0 — возрастает. Знаменатель на знак не влияет,
> только на D(f).

### Откуда

Для y = x^2 возрастание видно: x = 1 даёт y = 1, x = 2
даёт y = 4, x = 3 даёт y = 9 — функция идёт вверх. Для
y = x^-1 = 1/x убывание видно: x = 1 даёт y = 1, x = 2
даёт y = 0,5, x = 3 даёт y = 1/3 — функция идёт вниз.

Это общее правило: при положительном α функция x^α идёт вверх (большему x — большее y), при отрицательном α — вниз (большему x — меньшее y). Это работает на всей области определения, где функция существует. На графиках это видно сразу — параболы и кубические параболы идут вверх, гиперболы идут вниз.

Правило: знак α определяет направление «движения» функции — плюс тянет вверх, минус тянет вниз. Это и есть ключ к монотонности в задачах §2, без всяких производных.

### Как — алгоритм

1. Посмотри на знак α.
2. α > 0: функция возрастает на D(f).
3. α < 0: функция убывает на D(f).
4. Если перед x^α стоит коэффициент или сложная конструкция ((x+1)^α) — действуй осторожно (см. ловушки).

### Где применить

В задачах на сравнение значений (f(a) vs f(b)), в задачах на
max/min, в задачах на построение графика — везде, где речь идёт о большем
и меньшем.

### Где ошибиться

**Ловушка «убывает, потому что в знаменателе».** Возьмём
y = 1/(x^2 + 1). В знаменателе сумма, которая всегда ≥ 1 —
это не степенная функция. Знак α здесь ни при чём. **Монотонность
определяется типом функции, а не положением x в числителе или
знаменателе.**

**Ловушка «возрастает, потому что α > 0, игнорируя D(f)».**
Для α = 1/2 функция y = корень(x) возрастает на [0, +∞).
Но если в задаче написано y = корень(x - 5) — это уже другая
функция (со сдвигом), она возрастает на [5, +∞), не на всей
R.

**Ловушка «(x+1)^α ведёт себя так же, как x^α».**
Функция y = (x+1)^1/2 возрастает (так как α > 0), но
начинает расти только с x = -1. До этого она не определена.

### Задача с разбором: упражнение 2.4 из задачника

**Условие:** определи монотонность функций:

2. y = 1 - x^-0,4
3. y = (x + 1)^-0,4
4. y = x^-0,4
5. y = x^-3 * 0,4

Если g(x) монотонна по x, и f(t) монотонна по t, то
f(g(x)) монотонна по x:

- возрастающая ° возрастающую = возрастающая
- убывающая ° убывающую = возрастающая
- возрастающая ° убывающую = убывающая
- убывающая ° возрастающую = убывающая

### Задача с разбором: упражнение 2.9 из задачника

**Условие:** дана функция f(x) = x^-π. Условие сравнения: f(a) ≤ n
(или какое-то другое условие сравнения). Сравни f(a) и f(b),
если известно, что... (две подзадачи).

**Шаг 2.** Убывающая функция: большему x соответствует меньшее

- **a)** Если f(a) ≤ n и a > b (или другое условие на a и b) — сравниваем f(a) и f(b).

В обеих подзадачах ключевой ход — один и тот же: знак монотонности
определяет, в какую сторону «переворачивается» неравенство при сравнении
аргументов.

### Задача с разбором: упражнение 2.10 из задачника

**Условие:** найди наибольшее и наименьшее значение f(x) = x^-π и
g(x) = x^-π/x на множестве натуральных чисел N.

**Шаг 1.** f(x) = x^-π. α = -π < 0 → функция убывает на
(0, +∞). На натуральных числах 1, 2, 3, 4, … функция
убывает (так как каждое следующее натуральное число больше
предыдущего). Наибольшее значение — при наименьшем x = 1:
f(1) = 1^-π = 1. Наименьшего нет (при x → ∞, f → 0,
но 0 не достигается).

**Шаг 2.** g(x) = x^-π/x — это уже не чистая степенная функция.
Показатель -π/x сам зависит от x. Здесь нужен другой ход.

Считаем значения напрямую — калькулятор нам в помощь, нам важен не логарифм, а конкретное число:
- g(1) = 1^(-π/1) = 1.
- g(2) = 2^(-π/2) ≈ 0,337.
- g(3) = 3^(-π/3) ≈ 0,317.
- g(4) = 4^(-π/4) ≈ 0,337.
- g(5) = 5^(-π/5) ≈ 0,364.
- g(6) = 6^(-π/6) ≈ 0,394.

Смотрим на строку значений: 1 → 0,337 → 0,317 → 0,337 → 0,364 → 0,394.

Минимум при x = 3 (≈ 0,317), максимум при x = 1 (равен 1). ## Блок 4. Чётность и нечётность степенной функции

### Зачем

Если функция чётная, её график симметричен относительно оси y —
достаточно построить правую половину и отразить. Это экономит работу.
Аналогично для нечётной: график симметричен относительно начала координат.

В задачах §2 (пробот) №4 — последнем упражнении — проверяется именно это
свойство для двух функций: y = x^1/3 и y = x^-7/2.

### Что

Степенная функция y = x^α чётная или нечётная в зависимости от α:

| α | Чётность | Почему |
|---|---|---|
| Целый чётный α > 0 (α = 2, 4, 6, …) | Чётная | (-x)^α = x^α при чётном α |
| Целый нечётный α (α = 1, 3, -1, -3, …) | Нечётная | (-x)^α = -x^α при нечётном α |
| Дробный α = m/n, нечётное n | Нечётная | (-x)^m/n = -(x^m/n) |
| Дробный α = m/n, чётное n | Ни чётная, ни нечётная | D(f) = [0, +∞) — несимметричная область определения |
| Иррациональный α | Ни чётная, ни нечётная | D(f) = (0, +∞) — несимметричная область определения |
| α = 0 | Чётная | y = 1 симметрична |

Главное наблюдение: чётность/нечётность — это **симметрия области
определения относительно нуля**. Если D(f) симметрична
(x ∈ D(f) ↔ -x ∈ D(f)) и f(-x) = ± f(x) —
функция чётная или нечётная.

Для дробного α с чётным знаменателем D(f) = [0, +∞).
Точка -1 ∈ D(f)? Нет. Значит, симметрии нет — функция не может
быть чётной или нечётной.

> **Запомнить (метод «Капкан с перевёрнутыми скобками» для чётности):**
> y = (-x)^α vs y = x^α — это РАЗНЫЕ функции при
> дробном α. При целом α (чётном или нечётном) минус
> «съедается» или «переворачивает» знак. При дробном α — минус
> в основании часто не имеет смысла.

### Откуда

Возьмём y = x^3. (-x)^3 = -x^3. То есть f(-x) = -f(x) —
нечётная.

Возьмём y = x^2. (-x)^2 = x^2. То есть f(-x) = f(x) — чётная.

Возьмём y = x^1/3. (-x)^1/3 — это корень_3(-x).
Корень нечётной степени из отрицательного числа существует:
корень_3(-8) = -2. То есть f(-x) = корень_3(-x) = -корень_3(x) = -f(x).
Нечётная.

Возьмём y = x^1/2. (-x)^1/2 = корень(-x) — не существует при x > 0.
D(f) = [0, +∞) — не симметрично. Не чётная и не нечётная.

### Где применить

В задачах 2.11 из задачника — определение чётности/нечётности. И
везде, где построение графика можно упростить через симметрию.

### Где ошибиться

**Ловушка «x^1/3 чётная, потому что кубический корень».**
Наоборот — x^1/3 нечётная: корень_3(-x) = -корень_3(x).

**Ловушка «x^1/2 нечётная, потому что...».**
x^1/2 = корень(x) не определена при x < 0, поэтому не может
быть ни чётной, ни нечётной — нет симметрии.

**Ловушка «x^α нечётная при любом дробном α».**
Только при нечётном знаменателе.

## Блок 5. Графики y = x^α — каталог форм

### Зачем

График — это «карта» функции. Если ты умеешь представить форму графика
y = x^α для любого α, ты можешь:
- построить график без таблицы значений,
- сравнить значения f(a) и f(b) визуально,
- найти max/min геометрически.

Задача 2.6 из задачника — это и есть построение двух графиков:
y = x^1/7 и y = x^-1,2.

### Что — каталог из семи форм

**Случай 1. α > 0, целый чётный (α = 2, 4, 6, …):**

График — **парабола**. Проходит через (0, 0), симметрична
относительно оси y, ветви вверх. Чем больше α, тем «у́же»
парабола в окрестности нуля и тем быстрее она уходит вверх на бесконечности.

y = x^2: классическая парабола.
y = x^4: более «прижатая» к оси y около начала, быстрее уходит вверх на бесконечности.

**Случай 2. α > 0, целый нечётный (α = 1, 3, 5, …):**

График — **кубическая парабола**. Проходит через (0, 0), симметрична
относительно начала координат. На (-∞, 0] — убывает, на
[0, +∞) — возрастает.

y = x^3: классическая кубическая кривая.
y = x^5: ещё более «резкая» около нуля, ещё быстрее на бесконечности.

**Случай 3. 0 < α < 1 (дробный или иррациональный):**

График — **ветвь гиперболы (форма «ветви с наклоном»)**. Проходит через
(0, 0) и (1, 1). На [0, 1] растёт быстро (круто), на
[1, +∞) — медленно (выпуклая вниз).

y = x^1/2 = корень(x): верхняя полупарабола (медленно растёт).
y = x^1/3: круче, чем корень(x).
y = x^1/7: почти вертикально около нуля, почти горизонтально на бесконечности.

**Случай 4. α > 1 (целый или нецелый):**

График — «крутая» парабола. Похож на случай 1, но по сути
несимметричен (если α — не целый чётный, нет симметрии
относительно оси y).

y = x^2,5: нечто среднее между x^2 и x^3.

**Случай 5. α < 0, целый чётный (α = -2, -4, …):**

График — **ветвь гиперболы (форма «двух рогов вверх»)**. Определён на
R без 0. На (-∞, 0) и (0, +∞)
отдельно — обе ветви идут вверх. Точка x = 0 — выколотая, график
«улетает» в +∞ при x → 0.

y = 1/x^2: классический пример — две симметричные ветви вверх.

**Случай 6. α < 0, целый нечётный (α = -1, -3, …):**

График — **гипербола**. Определён на R без 0.
На (-∞, 0) — ниже оси x (отрицательные значения),
на (0, +∞) — выше оси x (положительные значения).
Симметричен относительно начала координат.

y = 1/x: классическая гипербола.
y = 1/x^3: ещё «круче» около нуля и на бесконечности.

**Случай 7. α = 0:**

График — горизонтальная прямая y = 1 с выколотой точкой (0, *).

**Случай 8 (бонус). α = 1:**

График — биссектриса y = x (прямая через начало координат под углом 45°).

### Откуда

Эти формы выводятся из двух фактов:

1. Знак α определяет монотонность (блок 3).
2. Чётность/нечётность α определяет симметрию графика (блок 4).

Всё остальное — конкретная «крутизна» — определяется значением α
и конкретной точкой на графике.

### Где применить

В задачах 2.6 (построение графика), 2.9 (сравнение значений), 2.10
(max/min), 2.11 (чётность/нечётность) — везде, где нужно представить
график.

### Где ошибиться

**Ловушка «y = (-x)^α — это зеркальная функция от y = x^α».**
Для целого α это верно ((-x)^2 = x^2, (-x)^3 = -x^3).
Для дробного α — это либо та же функция (если α = m/n с
нечётным n и f(-x) = -f(x)), либо вообще не функция (если α с чётным n).

> **Запомнить (метод «Капкан с перевёрнутыми скобками» для графиков):**
> при построении y = (-x)^α vs y = x^α проверь две
> вещи: (1) α — целый? (2) α — чётный или нечётный?
> Только после этого рисуй «зеркало». При дробном α зеркала
> может не быть — функция просто не определена на отрицательных x.

**Ловушка «парабола при любом α > 0».**
y = x^3 — кубическая парабола, не обычная. y = x^1/2 —
полупарабола, не парабола. Термин «парабола» применим строго к α = 2.

**Ловушка «гипербола при любом α < 0».**
y = 1/x^2 — это НЕ гипербола, это «две ветви вверх» (случай 5).
Термин «гипербола» применим строго к α = -1.

## Boss Fight — задача на 12 шагов, где нужно использовать несколько инструментов сразу

> **Эта задача использует:** Блок 1 (D(f)), Блок 2 (E(f), нули), Блок 3 (монотонность), Блок 5 (графики), все пять авторских методов.

**Условие:** дана функция f(x) = (x^2 - 4)^-1/3.

Требуется:
1. Найти D(f).
2. Определить монотонность на каждом участке D(f).
3. Найти нули функции.
4. Найти E(f).
5. Определить чётность/нечётность.
6. Построить эскиз графика.
7. Сравнить f(-3) и f(3).
8. Найти наибольшее и наименьшее значение на [2, 5].

**Шаг 1. Применяю четыре вопроса.** Что вижу: дробный показатель
-1/3, основание — биквадратная функция x^2 - 4. Что применю:
предохранитель ОДЗ (дробный α с нечётным знаменателем +
отрицательное α — есть особенности). Что от меня хотят: полный
анализ функции.

**Шаг 2. Нахожу D(f).** f(x) = 1/(x^2 - 4)^1/3. Здесь
α = -1/3 (отрицательный дробный с нечётным знаменателем).
Показатель 1/3 — это кубический корень: (x^2 - 4)^1/3 = корень_3(x^2 - 4).
Кубический корень определён для любого подкоренного выражения. Но
делитель не может быть нулём: x^2 - 4 ≠ 0, то есть x ≠ ± 2.

D(f) = (-∞, -2) ∪ (-2, 2) ∪ (2, +∞).

**Шаг 3. Монотонность на каждом участке.** Функция
g(x) = x^2 - 4 — парабола с вершиной в (0, -4), ветви вверх.
Поведение по участкам:
- На (-∞, -2): g(x) убывает (от +∞ до 0).
- На (-2, 2): g(x) убывает (от 0 до -4) и затем возрастает (от -4 до 0). Здесь не чистая монотонность.

На участке (-2, 2) функция g(x) сначала убывает (от 0 при
x → -2 до -4 при x = 0), затем возрастает (от -4 до
0 при x → 2). Значит, |g(x)| тоже немонотонна на (-2, 2).

Применим метод «Рентген знаков»: α = -1/3 < 0 → f убывает по g.
Но g сама немонотонна на (-2, 2) — значит, f тоже не чисто
монотонна на этом участке.

Точный анализ:
- На (-∞, -2): g убывает от +∞ до 0. По g f убывает (α < 0). Композиция убывающей по g и убывающей по x — возрастает. f возрастает на (-∞, -2).
- На (-2, 0): g убывает от 0 до -4. По g f убывает. Композиция возрастает. f возрастает на (-2, 0).
- На (0, 2): g возрастает от -4 до 0. По g f убывает. Композиция убывает. f убывает на (0, 2).
- На (2, +∞): g возрастает от 0 до +∞. По g f убывает. Композиция убывает. f убывает на (2, +∞).

**Шаг 4. Нули функции.** f(x) = 0 тогда и только тогда, когда
1/(x^2 - 4)^1/3 = 0. Это невозможно — дробь с ненулевым числителем
никогда не равна нулю. **Нулей нет.**

**Шаг 5. Нахожу E(f).** Подкоренное выражение x^2 - 4 принимает
значения в [-4, +∞) (так как x^2 ≥ 0). Исключая x^2 = 4
(где функция не определена), значения x^2 - 4 в D(f): на
(-∞, -2) — от 0 до +∞ (но не 0); на (-2, 2) — от
-4 до 0 (не считая 0); на (2, +∞) — от 0 до +∞ (не считая 0).

Итого, x^2 - 4 принимает значения в D(f): [-4, 0) ∪ (0, +∞).
Исключая 0, получаем то же.

Тогда (x^2 - 4)^1/3 принимает значения: [-корень_3(4), 0) ∪ (0, +∞).

И наконец, f(x) = 1/(x^2 - 4)^1/3 принимает значения: на (-∞, -корень_3(4)] функция отрицательна (от -∞ до -1/корень_3(4)); на (0, +∞) функция положительна (от +∞ до 0).

E(f) = (-∞, -1/корень_3(4)] ∪ (0, +∞).

Это два луча: вниз от -1/корень_3(4) и вверх от 0.

**Шаг 6. Чётность/нечётность.** D(f) симметрична относительно нуля
(если x ∈ D(f), то -x ∈ D(f)). f(-x) = ((-x)^2 - 4)^-1/3 = (x^2 - 4)^-1/3 = f(x). **Чётная.**

**Шаг 7. Эскиз графика.** Используя результаты шагов 2-6:
- График симметричен относительно оси y.
- На (-∞, -2) — возрастает от 0 (выколотая точка слева) до +∞. Нет, стоп: при x → -∞, g → +∞, f = 1/g^1/3 → 0^+. При x → -2^-, g → 0^+, f → +∞. Значит, f на (-∞, -2) возрастает от 0 до +∞.

Стоп, проверим знак: g(x) = x^2 - 4 > 0 при x < -2 и при x > 2. Значит, на этих участках f > 0. На (-2, 2) g < 0, и f < 0.

Уточнённый эскиз:
- На (-∞, -2): f > 0, возрастает от 0 до +∞.
- На (-2, 2): f < 0, сначала возрастает от -∞ до -1/корень_3(4) (при x = 0), затем убывает от -1/корень_3(4) до -∞.
- На (2, +∞): f > 0, убывает от +∞ до 0.

График похож на «две гиперболы вверх» (при x > 2 и при x < -2) и
«две гиперболы вниз» (при -2 < x < 2, с «горбом» при x = 0).

**Шаг 8. Сравниваю f(-3) и f(3).** По чётности f(-3) = f(3).
**Равны.**

**Шаг 9. Max/min на [2, 5].** На этом участке f убывает от
+∞ до f(5) = (25 - 4)^-1/3 = 21^-1/3 ≈ 0,362.
На [2, 5] функция убывает, но в точке x = 2 выколотая. Значит,
f на [2, 5] принимает значения в (21^-1/3, +∞) — точная
граница не достигается в точке x = 2, но максимум не достигается — функция стремится к +∞
(функция стремится к +∞ при x → 2^+).

На замкнутом множестве максимума нет (из-за выколотой точки). На
практике наибольшее значение f на [2, 5] не существует (стремится к +∞ при x → 2+), наименьшее значение f на [2, 5] равно f(5) = 21^-1/3.

**Шаг 10. Проверка ОДЗ.** На каждом этапе проверял, что x в нужном
интервале. Ок.

**Шаг 11. Проверка размерности.** α = -1/3 безразмерный. x
безразмерный. f(x) безразмерный. Ок.

**Шаг 12. Проверка обратным вычислением.** Возьмём x = 3. g(3) = 9 - 4 = 5. f(3) = 5^-1/3 = 1/корень_3(5) ≈ 0,584. По графику из шага 7 на участке (2, +∞) f убывает, и при x = 3 значение где-то между f(2^+) (большое) и f(5) (маленькое). 0,584 — попадает в этот диапазон. Ок.

**Ответ:** D(f) = (-∞, -2) ∪ (-2, 2) ∪ (2, +∞), нулей
нет, чётная, эскиз — две ветви вверх и «горб» вниз. f(-3) = f(3).
Наименьшее значение f на [2, 5] равно 21^-1/3.

# Ловушки — список имён

Эти пять сбоев мышления повторяются из блока в блок. Если ты узнал
себя хотя бы в одном — это нормально, у каждого сбоя есть имя и причина.

**«D(f) = R по умолчанию».** Смотри на α, прежде
чем писать область определения. Целый α ≠ дробный α ≠
иррациональный α.

**«E(f) = R по умолчанию».** Для чётного целого α
E(f) = [0, +∞), не R.

**«Ноль функции есть, если f существует».** Если α < 0, то
x = 0 ∉ D(f), и нулей нет вообще.

**«Убывает, потому что в знаменателе».** Монотонность определяется
знаком α (при целом α — точно, при дробном — на своей
области определения). Положение x в числителе или знаменателе
само по себе ничего не решает.

**«Чётная, потому что x в чётной степени».** Это верно для целого
чётного α. Для дробного α с чётным знаменателем
функция вообще не определена на отрицательных x и не может быть
чётной/нечётной.

# Сборник формул — всё в одном месте

## Определение

y = x^α, α ∈ R, x ∈ D(f).

## Область определения D(f)

| α | D(f) |
|---|---|
| Целый α > 0 | R |
| Целый α = 0 | R без 0 (y = 1) |
| Целый α < 0 | R без 0 |
| Дробный α = m/n, n чётное | [0, +∞) |
| Дробный α = m/n, n нечётное | [0, +∞) (общая формула) |
| Иррациональный α | (0, +∞) |

## Множество значений E(f)

| α | E(f) |
|---|---|
| Целый α > 0, чётный | [0, +∞) |
| Целый α > 0, нечётный | R |
| Целый α = 0 | {1} |
| Целый α < 0, чётный | (0, +∞) |
| Целый α < 0, нечётный | R без 0 |
| Дробный / иррациональный α | [0, +∞) или (0, +∞) |

## Монотонность

- α > 0 → y = x^α возрастает на D(f).
- α < 0 → y = x^α убывает на D(f).
- α = 0 → постоянная y = 1 (убывания и возрастания нет).

## Чётность/нечётность

- Целый чётный α → чётная.
- Целый нечётный α → нечётная.
- Дробный α = m/n, m чётное + n нечётное → чётная (например, x^(2/3), x^(4/5)).
- Дробный α = m/n, m нечётное + n нечётное → нечётная (например, x^(1/3), x^(3/5)).
- Дробный α = m/n, n чётное → ни чётная, ни нечётная (например, x^(1/2), x^(3/2)).
- Иррациональный α → ни чётная, ни нечётная.

Ключ: при чётном m (числитель) и нечётном n (знаменатель) функция чётная, потому что (-x)^(m/n) = ((-x)^m)^(1/n) = (x^m)^(1/n) = x^(m/n). Знак «минус» глотается чётным m, а нечётный корень его не возвращает.

## Графики — формы

| Случай | α | Форма |
|---|---|---|
| 1 | Целый чётный α > 0 | Парабола |
| 2 | Целый нечётный α | Кубическая парабола |
| 3 | 0 < α < 1 | Ветвь с наклоном (полупарабола) |
| 4 | α > 1, нецелый | Крутая парабола |
| 5 | Целый чётный α < 0 | Две ветви вверх |
| 6 | Целый нечётный α < 0 | Гипербола |
| 7 | α = 0 | Горизонталь y = 1 |
| 8 | α = 1 | Биссектриса y = x |

## Пять ключевых методов

| Метод | Где работает |
|---|---|
| **Переводчик** | y = x^α ↔ корень / дробная степень. Любая запись показателя |
| **Рентген знаков** | Знак α определяет монотонность (плюс — вверх, минус — вниз) |
| **Страж основания** | x > 0 для дробных α; x ≠ 0 для отрицательных целых α |
| **Предохранитель ОДЗ** | Сверяй α с таблицей D(f), прежде чем писать |
| **Капкан с перевёрнутыми скобками** | (-x)^α vs x^α при дробном α — разные функции |
