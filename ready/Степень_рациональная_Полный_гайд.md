§ 1. СТЕПЕНЬ С РАЦИОНАЛЬНЫМ И ДЕЙСТВИТЕЛЬНЫМ ПОКАЗАТЕЛЕМ: ПОЛНЫЙ ГАЙД

ПЕРЕД ТЕМ КАК НАЧАТЬ

Это не тест на оценку — это фильтр, который показывает, что у тебя уже есть в руках, а где придётся на секунду притормозить.

Дальше по тексту будут попадаться ловушки — места, где решение обычно идёт не туда. У каждой ловушки будет имя. Если попал — это значит, что ты наткнулся на конкретный сбой мышления, у которого есть название и причина.

Привычка, которая пригодится на весь параграф

Прежде чем решать любую задачу дальше, задай себе четыре вопроса:
1. Что я вижу? (степень, корень, дробь, знак минус — что вообще есть)
2. Что здесь знакомое? (я это уже где-то делал, просто в другой записи)
3. Что я применю? (какое правило, какой приём)
4. Что от меня хотят? (вычислить число, упростить выражение)

Проверь себя за 2 минуты

Степень с целым показателем. Чему равно 2^(-3)? А (0,2^(-1))^3?
Фильтр: минус в показателе НИКОГДА не делает число отрицательным, он только переворачивает дробь! a^(-n) = 1 / a^n.

Арифметический корень. корень_3(27) — это сколько? А корень_4(16)? (Ответы: 3 и 2).

Разложение на простые множители. Запомни: 8 = 2^3, 16 = 2^4, 27 = 3^3, 32 = 2^5, 64 = 2^6, 81 = 3^4. Это главные герои задач.

Формулы сокращённого умножения. (a - b) * (a + b) = a^2 - b^2. Она вернётся в новой одежде совсем скоро.

БЛОК 1. ЧТО ВООБЩЕ ЗНАЧИТ a^(1/n) — СМОТРИМ НА ЧИСЛАХ

Зачем

Здесь ты увидишь одну и ту же идею в двух записях: степень и корень. И поймёшь, почему они — одна и та же идея.
В жизни: Один полутон на фортепиано — это частота, умноженная на 2^(1/12). Каждая следующая нота — это прошлая, умноженная на дробную степень двойки. Период полураспада в физике: N(t) = N0 * 2^(-t/T).

Что

Запись 2^3 — это ответ на вопрос: «что получится, если 2 умножить само на себя 3 раза?» (2 * 2 * 2 = 8).
Запись 8^(1/3) — это обратный вопрос: «какое неотрицательное число состоит из 3 одинаковых множителей, произведение которых равно 8?» Ответ: 2, так как 2 * 2 * 2 = 8.

Метод «Переводчик»:
a^(1/n) = корень_n(a) — знаменатель дроби показывает степень корня.

Как переходить к сложной дроби a^(m/n)

a^(m/n) = корень_n(a^m) = (корень_n(a))^m
Числитель m — в какую степень возвести.
Знаменатель n — корень какой степени извлечь.
Главное условие: Основание должно быть строго положительным (a > 0).

Задача с разбором: Вычислить 8^(2/3)

Есть два пути решения.
Путь 1 (в лоб): 8^(2/3) = корень_3(8^2) = корень_3(64) = 4.
Путь 2 (умный): 8^(2/3) = (корень_3(8))^2 = 2^2 = 4.
Вывод: Если основание — хорошая степень, выгоднее сначала извлечь корень, чтобы не работать с большими числами.

Реши сам

Задача 1: Вычисли 27^(1/3).
Разбор: Какое число в кубе даёт 27? Ответ: 3.

Задача 2: Вычисли 27^(2/3).
Разбор: Сначала корень: корень_3(27) = 3. Потом в квадрат: 3^2 = 9. Ответ: 9.

Задача 3: Вычисли 16^(-1/2).
Разбор: Минус переворачивает дробь: 1 / 16^(1/2) = 1 / корень(16) = 1/4. Ответ: 1/4.

БЛОК 2. ОДЗ-ЛОВУШКА: ПОЧЕМУ a > 0 — НЕ ПРИХОТЬ

Что

Для степени с дробным показателем m/n основание обязано быть положительным: a > 0.

Почему? (Откуда взялось правило)

Возьмём число -8 и показатель 1/3.
Если считать через корни: корень_3(-8) = -2 — всё работает.
Но дробь 1/3 равна дроби 2/6. Попробуем посчитать через неё: (-8)^(2/6) = корень_6((-8)^2) = корень_6(64) = +2.
Получился бред: один и тот же пример из-за разной записи дроби дал два разных ответа (-2 и +2). Чтобы математика не ломалась, ввели жесткое ОДЗ: для дробных степеней основание может быть только больше нуля!

Метод «Предохранитель ОДЗ»:
Видишь букву с дробным показателем — по условию она обязана быть > 0.
Особый случай с нулем: 0^(2/3) = 0 (в положительную дробную степень возводить можно). Но 0^(-1/2) — это 1 / корень(0) = 1/0 (на ноль делить нельзя, выражение не имеет смысла).

Реши сам

Задача 1: Имеет ли смысл выражение (-4)^(2/3)?
Ответ: Нет, для дробной степени основание не может быть отрицательным.

Задача 2: Имеет ли смысл 0^(-1/2)?
Ответ: Нет, это скрытое деление на ноль.

БЛОК 3. СВОЙСТВА СТЕПЕНИ — СТАРЫЕ ПРАВИЛА НА НОВОМ МАТЕРИАЛЕ

Для a > 0, b > 0 и дробных показателей работают все старые правила:
a^m * a^n = a^(m + n) (при умножении показатели складываются).
a^m : a^n = a^(m - n) (при делении показатели вычитаются).
(a^m)^n = a^(m * n) (при возведении степени в степень они перемножаются).

Покажем, почему правило работает

Мы хотим доказать, что a^(m/n) * a^(p/q) = a^(m/n + p/q).
1. Переводим в корни: корень_n(a^m) * корень_q(a^p).
2. Приводим корни к общему показателю n*q (как обычные дроби приводим к общему знаменателю): корень_nq(a^(m*q)) * корень_nq(a^(p*n)).
3. Заносим под одну крышу корня: корень_nq(a^(m*q + p*n)).
4. Переводим обратно в степень: a^((m*q + p*n) / (n*q)).
5. Разделяем дробь в показателе на две: a^(m/n + p/q). Готово — правило работает.

Главные ловушки блока

Ловушка «Сложить дроби в лоб»: При умножении a^(2/3) * a^(4/5) показатели складываются через общий знаменатель! 2/3 + 4/5 = 10/15 + 12/15 = 22/15. Результат: a^(22/15).

Ловушка «Сложил основания, а возводил в степень»: Эти два действия внешне похожи (везде дробный показатель, везде двойка где-то), но результат разный — складываются показатели или перемножаются. Глаз цепляется за «1/3 и 1/2», и рука тянется сложить их в обоих примерах. Не складывай.
a^(1/3) * a^(1/2) = a^(1/3 + 1/2) = a^(5/6).
(a^(1/3))^(1/2) = a^(1/3 * 1/2) = a^(1/6).

Задача с разбором: Вычислить 5 * 125^(-1/3)

Метод «Страж основания»: Приведи все числа к одному простому основанию.
Число 125 = 5^3 — это и есть работа Стража: основание 5 уже «сидит» внутри 125, надо его увидеть и вытащить.
Переписываем пример: 5^1 * (5^3)^(-1/3).
Перемножаем степени (правило «степень в степени»): 3 * (-1/3) = -1. Получаем 5^1 * 5^(-1).
Складываем показатели (правило «умножение оснований»): 5^(1 + (-1)) = 5^(1 - 1) = 5^0 = 1.
Ответ: 1.

Реши сам

Задача 1: Упрости a^(2/3) * a^(1/6).
- Подсказка 1 (направление): умножение оснований — показатели складываются. Какие дроби складываются?
- Подсказка 2 (почти ответ): 2/3 + 1/6 = 4/6 + 1/6 = 5/6.
- Разбор: показатели складываются по правилу умножения. Ответ: a^(5/6).

Задача 2: Упрости (a^(1/2))^2.
- Подсказка 1 (направление): это степень в степени — показатели перемножаются.
- Подсказка 2 (почти ответ): 1/2 * 2 = 1.
- Разбор: перемножаем показатели по правилу степени в степени. Ответ: a^1 = a.

Задача 3: Упрости a^(3/4) : a^(1/2).
- Подсказка 1 (направление): деление оснований — показатели вычитаются.
- Подсказка 2 (почти ответ): 3/4 - 1/2 = 3/4 - 2/4 = 1/4.
- Разбор: показатели вычитаются. Ответ: a^(1/4).

БЛОК 4. СТЕПЕНЬ ПРОИЗВЕДЕНИЯ И СТЕПЕНЬ ДРОБИ

Если степень стоит за скобками, она распределяется на каждый множитель внутри:
(a * b)^n = a^n * b^n
(a / b)^n = a^n / b^n

Ловушка «Степень и сумма»: Запомни намертво: (a + b)^(1/2) НЕ РАВНО a^(1/2) + b^(1/2). Раскрывать степень можно только для умножения и деления!

Задача с разбором: Упростить (16x)^(3/4) * (1/8 * x^(3/8))^(-1/3)

1. Раскрываем первую скобку: 16^(3/4) * x^(3/4).
2. Считаем число: 16^(3/4) = (корень_4(16))^3 = 2^3 = 8. Получили 8 * x^(3/4).
3. Раскрываем вторую скобку. Минус в показателе -1/3 — это два действия одновременно: и знак меняется (становится +1/3), и основание переворачивается (8 и x^(3/8) меняются местами). Получаем: (8 / x^(3/8))^(1/3) = 8^(1/3) / x^(1/8) = 2 * x^(-1/8).
4. Перемножаем результаты: (8 * 2) * x^(3/4 - 1/8) = 16 * x^(6/8 - 1/8) = 16 * x^(5/8).
Ответ: 16 * x^(5/8).

Реши сам

Задача 1: Упрости (27 * y)^(2/3).
- Подсказка 1 (направление): степень распределяется на каждый множитель — раскрой скобку.
- Подсказка 2 (почти ответ): 27^(2/3) = (корень_3(27))^2 = 3^2 = 9. Останется 9 * y^(2/3).
- Разбор: (27*y)^(2/3) = 27^(2/3) * y^(2/3) = 9 * y^(2/3). Ответ: 9 * y^(2/3).

Задача 2: Упрости (a / b)^(3/5).
- Подсказка 1 (направление): степень дроби — возводи и числитель, и знаменатель.
- Подсказка 2 (почти ответ): a^(3/5) / b^(3/5).
- Разбор: (a/b)^(3/5) = a^(3/5) / b^(3/5). Ответ: a^(3/5) / b^(3/5).

БЛОК 5. СТЕПЕНЬ С ИРРАЦИОНАЛЬНЫМ ПОКАЗАТЕЛЕМ

Что это такое

В показателе степени может стоять не только целое или дробное число, но и иррациональное (то есть бесконечная непериодическая десятичная дробь). Например, 2^корень(3) — это 2 в степени, равной корню из 3. Само число 2^корень(3) — вполне конкретное действительное число, его можно посчитать через приближения: корень(3) ≈ 1,732, значит, 2^1,732 ≈ 3,32. Калькулятор так и считает. Но для нас, как для математиков, важнее другое: как с этим выражением обращаться, не зная его точного значения.

Как работать без приближений

Нам не нужно ничего приближать! Мы работаем с иррациональным показателем просто как с переменной-буквой. Все свойства степеней остаются прежними — это и есть сила алгебры: можно сократить корень с корнем, не зная их точного значения.

Пример 1: (a^корень(5))^корень(5) = a^(корень(5) * корень(5)) = a^5.
Пример 2: a^корень(7) * a^(3 - корень(7)) = a^(корень(7) + 3 - корень(7)) = a^3.

Ловушка «Корни сами не складываются»: Помни, что корень(2) * корень(2) = 2 (показатели сложились и дали 1, корень уничтожился). Но корень(2) + корень(2) — это 2 * корень(2), а НЕ корень(4) = 2. Складывать корни с одинаковым подкоренным выражением можно только через вынесение общего множителя, а не через сложение под корнем.

Ловушка «Квадрат сверху ≠ квадрат корня»: (a^корень(2))^2 = a^(2 * корень(2)). Квадрат сверху не уничтожает корень в показателе, потому что показатели перемножаются, а сам корень остаётся в показателе. Корень уничтожился бы, только если бы мы возводили в степень, равную самому корню: (a^корень(2))^корень(2) = a^2.

Задача с разбором: Вычислить 8^корень(2) : 2^(1 + 3 * корень(2))

Включаем «Страж основания»: 8 = 2^3.
Переписываем числитель: (2^3)^корень(2) = 2^(3 * корень(2)).
Выполняем деление (вычитаем показатели): 2^(3 * корень(2) - (1 + 3 * корень(2))) = 2^(3 * корень(2) - 1 - 3 * корень(2)) = 2^(-1) = 1/2.
Ответ: 1/2.

Реши сам

Задача 1: Упрости a^корень(5) * a^(2 - корень(5)).
- Подсказка 1 (направление): умножение оснований — показатели складываются.
- Подсказка 2 (почти ответ): корень(5) + (2 - корень(5)) = 2.
- Разбор: показатели складываются, иррациональная часть сокращается. Ответ: a^2.

Задача 2: Упрости (a^корень(3))^корень(3).
- Подсказка 1 (направление): степень в степени — показатели перемножаются.
- Подсказка 2 (почти ответ): корень(3) * корень(3) = 3.
- Разбор: перемножаем показатели, корень уничтожает сам себя. Ответ: a^3.

(Переход к Блоку 6: степень с иррациональным показателем мы освоили — все свойства работают. Теперь посмотрим, как степени в дробной одежде помогают раскладывать старые знакомые выражения на множители через формулы сокращённого умножения.)

БЛОК 6. РАЗЛОЖЕНИЕ НА МНОЖИТЕЛИ И ФОРМУЛЫ (ФСУ)

Здесь старые формулы сокращенного умножения переодеваются в дробную одежду. Твоя задача — научиться их узнавать.

Приём 1. Вынесение общего множителя

Когда основание a положительно (a ≥ 0), его можно представить как a^(1/2) * a^(1/2). Это и есть ключ к вынесению: всё, что стоит в виде a^k, можно записать как произведение a при меньшем показателе.
Пример: a + a^(1/2) = a^(1/2) * a^(1/2) + a^(1/2) = a^(1/2) * (a^(1/2) + 1).
Правило «Капкан со скобками»: Всегда выноси за скобки букву с НАИМЕНЬШИМ показателем.

Приём 2. Разность квадратов

Любое выражение a - b при a, b > 0 можно разложить как разность квадратов:
a - b = (a^(1/2))^2 - (b^(1/2))^2 = (a^(1/2) - b^(1/2)) * (a^(1/2) + b^(1/2)).
Пример: a^(2/3) - b^(1/2) = (a^(1/3))^2 - (b^(1/4))^2 = (a^(1/3) - b^(1/4)) * (a^(1/3) + b^(1/4)).

Приём 3. Сокращение дробей

Задача: Сократить дробь (a - 36) / (a^(1/2) + 6).
Решение: Раскладываем числитель как разность квадратов: (a^(1/2) - 6) * (a^(1/2) + 6) / (a^(1/2) + 6). Скобки с плюсом сокращаются.
Ответ: a^(1/2) - 6.

Ловушка «Сокращение слагаемых»: В дроби (a + a^(1/2)) / a^(1/2) НЕЛЬЗЯ просто зачеркнуть a^(1/2). Сначала вынеси общий множитель в числителе: a^(1/2) * (a^(1/2) + 1) / a^(1/2) = a^(1/2) + 1.

Реши сам

Задача 1: Вынеси общий множитель в выражении a^(3/2) - a^(1/2).
- Подсказка 1 (направление): используй Правило «Капкан со скобками» — выноси букву с наименьшим показателем.
- Подсказка 2 (почти ответ): a^(1/2) * (a - 1).
- Разбор: a^(1/2) * a + a^(1/2) * (-1) = a^(1/2) * (a - 1). Ответ: a^(1/2) * (a - 1).

Задача 2: Разложи как разность квадратов: x - 4.
- Подсказка 1 (направление): представь x как (x^(1/2))^2, а 4 как (4^(1/2))^2 = 2^2.
- Подсказка 2 (почти ответ): (x^(1/2) - 2) * (x^(1/2) + 2).
- Разбор: x - 4 = (x^(1/2))^2 - 2^2 = (x^(1/2) - 2) * (x^(1/2) + 2). Ответ: (x^(1/2) - 2) * (x^(1/2) + 2).

БЛОК 7. ДЕСЯТИЧНЫЕ ДРОБИ КАК СКРЫТЫЕ СТЕПЕНИ

Частый приём — подсунуть десятичную дробь в основание, которая на самом деле является степенью чистого числа. Это любимая задача составителей, потому что легко промахнуться, не увидев степени. Запомни табличку:
0,36 = 0,6^2
0,25 = 0,5^2
0,008 = 0,2^3
0,125 = 0,5^3

Задача с разбором: Найти значение (0,36 * a^(2/3))^(1/2) * (1/125 * a)^(-1/3)

1. Разбираем первую скобку: (0,6^2 * a^(2/3))^(1/2) = 0,6 * a^(1/3).
2. Разбираем вторую скобку. Минус переворачивает 1/125 в 125: (125 * a^(-1))^(1/3) = (5^3 * a^(-1))^(1/3) = 5 * a^(-1/3).
3. Перемножаем результаты: (0,6 * 5) * a^(1/3 - 1/3) = 3 * a^0 = 3 * 1 = 3.
Ответ: 3.

Реши сам

Задача 1: Вычисли 0,25^(1/2).
- Подсказка 1 (направление): посмотри в табличку — что стоит в основании 0,25?
- Подсказка 2 (почти ответ): 0,25 = 0,5^2, поэтому 0,25^(1/2) = 0,5.
- Разбор: 0,25^(1/2) — это квадратный корень из 0,25, и он равен 0,5. Ответ: 0,5.

Задача 2: Вычисли 0,008^(2/3).
- Подсказка 1 (направление): сначала извлеки кубический корень, потом возведи в квадрат.
- Подсказка 2 (почти ответ): корень_3(0,008) = 0,2, потом 0,2^2 = 0,04.
- Разбор: 0,008^(2/3) = (корень_3(0,008))^2 = 0,2^2 = 0,04. Ответ: 0,04.

BOSS FIGHT — ГЛАВНАЯ СЛОЖНАЯ ЗАДАЧА ПАРАГРАФА

Условие: Упростить выражение: [ (27^(2/3) * 9^(-1/2)) / (корень_3(3))^2 ] * [ ((a^(1/3) / a^(1/9))^(-9))^(1/4) ]

Решаем строго по шагам, разделив пример на два независимых куска: числовой (левый) и буквенный (правый).

Шаг 1. Считаем левый (числовой) кусок:
Приводим всё к основанию 3: 27 = 3^3, 9 = 3^2, корень_3(3) = 3^(1/3).
Числитель: (3^3)^(2/3) * (3^2)^(-1/2) = 3^2 * 3^(-1) = 3^(2 - 1) = 3^1.
Знаменатель: (3^(1/3))^2 = 3^(2/3).
Делим числитель на знаменатель: 3^1 / 3^(2/3) = 3^(1 - 2/3) = 3^(1/3).
Итог шага: левый кусок = 3^(1/3) = корень_3(3). Запомни это число, оно вернётся в шаге 3.

Шаг 2. Считаем правый (буквенный) кусок:
Дробь внутри скобок: a^(1/3) / a^(1/9) = a^(3/9 - 1/9) = a^(2/9).
Возводим в степень -9: (a^(2/9))^(-9) = a^(2/9 * (-9)) = a^(-2).
Возводим во внешнюю степень 1/4: (a^(-2))^(1/4) = a^(-2 * 1/4) = a^(-1/2) = 1 / a^(1/2).
Итог шага: правый кусок = 1 / a^(1/2) = 1 / корень(a). Запомни это, оно тоже вернётся в шаге 3.

Шаг 3. Перемножаем куски:
3^(1/3) * (1 / a^(1/2)) = корень_3(3) / корень(a).
Ответ: корень_3(3) / корень(a).

КРАТКИЙ СБОРНИК ФОРМУЛ ДЛЯ ПАРАГРАФА

Условие применения всех формул ниже: a > 0 (или a ≥ 0 для чётного показателя корня).

Определение: a^(m/n) = корень_n(a^m).
Условие: a > 0. Пример: 8^(2/3) = (корень_3(8))^2 = 4.

Умножение оснований: a^m * a^n = a^(m + n).
Условие: a > 0. Основания одинаковые. Пример: 2^3 * 2^4 = 2^7.

Деление оснований: a^m : a^n = a^(m - n).
Условие: a > 0. Основания одинаковые. Пример: 2^5 : 2^2 = 2^3.

Степень в степени: (a^m)^n = a^(m * n).
Условие: a > 0. Пример: (2^3)^2 = 2^6.

Распределение степени: (a * b)^n = a^n * b^n и (a / b)^n = a^n / b^n.
Условие: a > 0, b > 0. НЕ работает на (a + b)^n — это вычисление через бином Ньютона.
Пример: (2 * 3)^2 = 4 * 9 = 36.

Разность квадратов: a - b = (a^(1/2) - b^(1/2)) * (a^(1/2) + b^(1/2)).
Условие: a > 0, b > 0. Пример: x - 4 = (корень(x) - 2) * (корень(x) + 2).

Связанные ловушки: «Степень и сумма» (распределение не работает на +), «Сокращение слагаемых» (вынесение общего множителя обязательно перед сокращением дроби).

Микро-проверка перед сборником: если видишь дробный или иррациональный показатель — проверь a > 0. Если видишь действие с двумя основаниями — приведи к одному через Стража. Если видишь скобку со сложением — НЕ раскрывай степень, ищи другой ход.
